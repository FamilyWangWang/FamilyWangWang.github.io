GEO-08 全等三角形与中位线

Concept ID: GEO-08

八年级： 核心

中文 Companion · 知识树 · GEO-08 真题索引 · Deutsche Hauptfassung

怎样证明两条线段一样长​

画一个正方形 ABCDABCDABCD，在对角线 ACACAC 上随便取一点 PPP，再量一量 PBPBPB 和 PDPDPD。不管 PPP 取在哪里，两段总是一样长。量出来的结果让你相信了，但这还不是证明：尺子只能量个大概，而且只量了你眼前这一张图。

证明要讲清楚：为什么对角线上的每一个点都满足 PB=PDPB = PDPB=PD。几何里有一个用得比什么都多的工具：找两个分别含有这两条线段的三角形，证明这两个三角形能完全重合。三角形重合了，里面对应的线段自然一样长。

在这个例子里，要找的是三角形 ABPABPABP 和 ADPADPADP。它们共用边 APAPAP；AB=ADAB = ADAB=AD，因为都是正方形的边；∠BAP\angle BAP∠BAP 和 ∠DAP\angle DAP∠DAP 都是 45∘45^\circ45∘，因为对角线把直角平分了。为什么有这三条就够了，这一章会讲。之后我们还要用同一个工具证明平行四边形的性质和中位线定理。

“全等”到底是什么意思​

如果把一个三角形平移、旋转，必要时翻个面，能和另一个三角形完全重合，我们就说这两个三角形全等。全等时，三条边和三个角都一一对上。

写法是：

△ABC≅△DEF.\triangle ABC \cong \triangle DEF.△ABC≅△DEF.

国内课本常把全等号写成 ≌，和这里的 ≅\cong≅ 是同一个意思。

字母的顺序很重要，它说明了谁和谁重合：AAA 对 DDD，BBB 对 EEE，CCC 对 FFF。照着顺序就能读出哪些量相等：

AB=DE,BC=EF,CA=FD,∠A=∠D,∠B=∠E,∠C=∠F.AB = DE,\quad BC = EF,\quad CA = FD,\quad \angle A = \angle D,\quad \angle B = \angle E,\quad \angle C = \angle F.AB=DE,BC=EF,CA=FD,∠A=∠D,∠B=∠E,∠C=∠F.

全等好用就好用在这里：只要证出一次全等，任何一对对应的边或角相等都可以直接拿来用。

四个全等判定，以及它们为什么成立​

证明全等，不需要把六个量都比一遍。选对三个量就够了。四个全等判定告诉我们，哪三个量够用。

从图里可以一眼看出：每个判定需要哪几条边、哪几个角，以及角要在什么位置。

每个判定背后的道理都一样：用给定的这几个量，只能画出一种三角形。两个三角形如果这几个量都相同，就等于是用同一种画法画出来的，当然能重合。

  • 边边边（SSS，德语也是 SSS）。 先画边 ABABAB。点 CCC 到 AAA 的距离是 bbb，到 BBB 的距离是 aaa，所以 CCC 在两个圆上。两个圆最多交于两点，而且这两点关于 ABABAB 对称。两个可能的三角形互为镜像，所以是全等的。
  • 边角边（SAS，德语 SWS）。 先画出 AAA 处的角，在两条边上分别量出 ABABAB 和 ACACAC。BBB 和 CCC 的位置就定了，第三条边也就定了。注意：这个角必须是两条已知边的夹角。
  • 角边角和角角边（ASA / AAS，德语 WSW / SWW）。 角边角是已知一条边和它两端的角：画出 ABABAB，在 AAA、BBB 两端分别画出已知角，两条射线只交于一点 CCC。角角边是已知两个角和其中一个角的对边：用内角和 180∘180^\circ180∘ 算出第三个角，已知边两端的角就都知道了，回到角边角。
  • 大边对角（德语 SsW）。 已知两条边，以及其中较长的那条边所对的角。德语缩写 SsW 里，大写的 S 指较长的边，小写的 s 指较短的边，W 是角。别把它和“大边对大角”（三角形里较长的边对着较大的角）弄混。这一条要多讲几句，因为去掉“较长边”这个条件，它就不成立了。

开头的问题现在也有答案了：三角形 ABPABPABP 和 ADPADPADP 中，AB=ADAB = ADAB=AD，APAPAP 是公共边，夹角都是 45∘45^\circ45∘。按边角边，两个三角形全等，所以 PB=PDPB = PDPB=PD。

为什么“两边和随便一个角”不够​

取 AB=6AB = 6AB=6，BC=4BC = 4BC=4，AAA 处的角是 30∘30^\circ30∘。这个角不是两条边的夹角，而是 BCBCBC 所对的角，而 BCBCBC 恰好是两条边里较短的一条。

画出 AAA 处的角，在一条边上量出 AB=6AB = 6AB=6。点 CCC 要在另一条边上，而且到 BBB 的距离是 444，所以 CCC 在以 BBB 为圆心、半径为 444 的圆上。

这张图让你看到：圆和那条射线交了两次，于是得到两个不同的三角形 ABC1ABC_1ABC1​ 和 ABC2ABC_2ABC2​，而它们的三个已知量完全一样。

C1C_1C1​ 和 C2C_2C2​ 是同一条射线上的两个不同点，所以第三条边不一样长：图里 AC1≈2.6AC_1 \approx 2.6AC1​≈2.6，AC2≈7.8AC_2 \approx 7.8AC2​≈7.8。蓝色三角形 ABC1ABC_1ABC1​ 整个落在橙色三角形 ABC2ABC_2ABC2​ 里面，两者不可能重合。所以一般的“边边角”不能用来判定全等。

那为什么加上“角对着较长边”就行了？假设 BC>ABBC > ABBC>AB。BBB 到 AAA 的距离比半径 BCBCBC 小，所以 AAA 在圆的里面。过圆内一点的直线和圆正好交两次，而且两个交点分别在这一点的两侧。从 AAA 出发的射线上就只剩一个交点，CCC 只有一种可能，三角形也就定下来了。（如果 BC=ABBC = ABBC=AB，AAA 本身就在圆上，只有另一个交点可能是 CCC，所以三角形如果存在，也是唯一的。）

有一个常用的特殊情况：直角三角形里，直角对着斜边，而斜边是最长的边。所以两个直角三角形如果斜边相等、再有一条直角边相等，按大边对角就全等。这就是课本上常说的“斜边直角边”（HL）。

第一个收获：中垂线上的点​

用边角边和边边边，可以证明一个你以前可能只是在用的结论。设 MMM 是 ABABAB 的中点，ggg 是过 MMM 垂直于 ABABAB 的直线，也就是 ABABAB 的中垂线。

ggg 上的每一点 PPP 到 AAA、BBB 的距离相等。 三角形 AMPAMPAMP 和 BMPBMPBMP 共用边 MPMPMP，AM=BMAM = BMAM=BM，MMM 处的两个角都是 90∘90^\circ90∘。按边角边，△AMP≅△BMP\triangle AMP \cong \triangle BMP△AMP≅△BMP，所以 PA=PBPA = PBPA=PB。

反过来，只要 PA=PBPA = PBPA=PB，PPP 就在 ggg 上。 这时三角形 AMPAMPAMP 和 BMPBMPBMP 三条边对应相等，按边边边全等。于是 ∠AMP=∠BMP\angle AMP = \angle BMP∠AMP=∠BMP。这两个角加起来是 180∘180^\circ180∘，所以各是 90∘90^\circ90∘。

这就是全等题的典型套路：全等先给你一条边或一个角，剩下的只是一小步计算。

怎样在图里找到合适的一对三角形​

竞赛题里的三角形不会帮你涂好颜色，得自己去找。按下面的顺序问自己几个问题，会顺手很多。

  1. 要证哪两条线段（或哪两个角）相等？ 先用颜色把它们标出来。
  2. 它们分别在哪些三角形里？ 每条线段都是好几个三角形的边。给第一条找一个三角形，给第二条也找一个，两个三角形看起来大小、形状差不多就对了。
  3. 已经知道哪些相等关系？ 常见的来源有：
    • 两个三角形的公共边，
    • 两条直线相交时的对顶角，
    • 有平行线时的内错角和同位角，
    • 正方形、正三角形、菱形或中点带来的相等线段，
    • 由同一个角加上相同的一块拼成的角，比如两边都是 γ+60∘\gamma + 60^\circγ+60∘。
  4. 用哪个判定？ 仔细看角的位置。角夹在两边中间，用边角边；角在对面，就要求它对着较长的边（大边对角）。

如果怎么也凑不出一对，多半是缺一条辅助线。好的辅助线会造出一个三角形，正好和图里已有的某个三角形对应。

在边上向外作正三角形或正方形​

竞赛里有一种图特别常见：在三角形的两条边上向外作正三角形（或正方形）。

设 ABCABCABC 是三角形，在 ABABAB 上向外作正三角形 ABDABDABD，在 ACACAC 上向外作正三角形 ACEACEACE。要证明 DC=BEDC = BEDC=BE。

DCDCDC 和 BEBEBE 分别在三角形 ADCADCADC 和 ABEABEABE 里，两个三角形都有一个顶点在 AAA。来比一比：

  • AD=ABAD = ABAD=AB，都是正三角形 ABDABDABD 的边。
  • AC=AEAC = AEAC=AE，都是正三角形 ACEACEACE 的边。
  • ∠DAC\angle DAC∠DAC 由 ∠DAB=60∘\angle DAB = 60^\circ∠DAB=60∘ 和 ∠BAC\angle BAC∠BAC 拼成；∠BAE\angle BAE∠BAE 由 ∠BAC\angle BAC∠BAC 和 ∠CAE=60∘\angle CAE = 60^\circ∠CAE=60∘ 拼成。两个角都等于 ∠BAC+60∘\angle BAC + 60^\circ∠BAC+60∘。（这要求 ∠BAC<120∘\angle BAC < 120^\circ∠BAC<120∘；否则两个角都从另一侧量，仍然相等。）

按边角边，△ADC≅△ABE\triangle ADC \cong \triangle ABE△ADC≅△ABE，所以 DC=BEDC = BEDC=BE。

从图里能看出：蓝色三角形绕 AAA 转一下，正好落在橙色三角形上。

这次旋转才是全等的真正原因。绕 AAA 旋转 60∘60^\circ60∘，DDD 转到 BBB（到 AAA 的距离不变，转过 60∘60^\circ60∘），CCC 转到 EEE（同样的道理），所以整条线段 DCDCDC 转到了 BEBEBE。一旦看出了旋转，配对就不用猜了：一个三角形的每个顶点转到哪里，另一个三角形的对应顶点就在哪里。

旋转还告诉我们更多：DCDCDC 绕 AAA 转 60∘60^\circ60∘ 后落在 BEBEBE 上，所以直线 DCDCDC 和 BEBEBE 的夹角是 60∘60^\circ60∘。不用旋转的话，就要靠角来证明：找两个在交点处有一对对顶角的三角形，再用全等得到它们还有一对角相等。由内角和，第三个角也就相等了。

如果边上作的是正方形，一切照旧，只是把 60∘60^\circ60∘ 换成 90∘90^\circ90∘。另外还有一个好用的事实：ABABAB 上所作正方形的中心 OOO 和 AAA、BBB 组成等腰直角三角形，因为 OA=OBOA = OBOA=OB，∠AOB=90∘\angle AOB = 90^\circ∠AOB=90∘，所以两个底角 ∠OAB\angle OAB∠OAB、∠OBA\angle OBA∠OBA 都是 45∘45^\circ45∘。所以正方形的中心之间，也常常可以用旋转 90∘90^\circ90∘ 来联系。

全等告诉我们平行四边形的哪些性质​

平行四边形 ABCDABCDABCD 的定义只有一句：AB∥CDAB \parallel CDAB∥CD 且 BC∥ADBC \parallel ADBC∥AD。其他性质都要证明，而证明靠的就是全等。

对角线 ACACAC 把平行四边形分成三角形 ABCABCABC 和 CDACDACDA。因为 AB∥CDAB \parallel CDAB∥CD，∠BAC\angle BAC∠BAC 和 ∠DCA\angle DCA∠DCA 是内错角，相等；因为 BC∥ADBC \parallel ADBC∥AD，∠BCA\angle BCA∠BCA 和 ∠DAC\angle DAC∠DAC 也相等；ACACAC 是公共边。按角边角，△ABC≅△CDA\triangle ABC \cong \triangle CDA△ABC≅△CDA。由此得到：

  • 对边相等： AB=CDAB = CDAB=CD，BC=DABC = DABC=DA。
  • 对角相等： ∠B=∠D\angle B = \angle D∠B=∠D；换另一条对角线，同样得到 ∠A=∠C\angle A = \angle C∠A=∠C。
  • 对角线互相平分。 设两条对角线交于 ZZZ。三角形 ABZABZABZ 和 CDZCDZCDZ 中，AB=CDAB = CDAB=CD，两端都是内错角，按角边角全等。所以 AZ=CZAZ = CZAZ=CZ，BZ=DZBZ = DZBZ=DZ。

做证明时，更常用的是反过来：怎样判断一个四边形是平行四边形？特别好用的一条是：一组对边平行且相等的四边形是平行四边形。 证明：设 AB∥CDAB \parallel CDAB∥CD，AB=CDAB = CDAB=CD。三角形 ABCABCABC 和 CDACDACDA 共用 ACACAC，AB=CDAB = CDAB=CD，∠BAC=∠DCA\angle BAC = \angle DCA∠BAC=∠DCA 是内错角。按边角边全等，所以 ∠BCA=∠DAC\angle BCA = \angle DAC∠BCA=∠DAC。这是直线 BCBCBC 和 ADADAD 被 ACACAC 所截的内错角，所以 BC∥ADBC \parallel ADBC∥AD。

用边角边加对顶角，同样可以证明：对角线互相平分的四边形是平行四边形。

三角形的中位线​

在三角形 ABCABCABC 中，MMM 是 ACACAC 的中点，NNN 是 BCBCBC 的中点。线段 MNMNMN 叫做中位线。中位线定理说：

MN∥AB并且MN=12 AB.MN \parallel AB \quad\text{并且}\quad MN = \tfrac{1}{2}\,AB.MN∥AB并且MN=21​AB.

证明从哪里想起？“等于一半”不好直接证，“一样长”就好证多了。所以我们把 MNMNMN 加倍：延长 MNMNMN 到点 PPP，使 NP=MNNP = MNNP=MN。这样 NNN 既是 MPMPMP 的中点，又是 BCBCBC 的中点。两条互相平分的线段，总会带来一对有对顶角的全等三角形。

左图是把 MNMNMN 加倍到 PPP，右图是梯形里对应的做法；两幅图里，全等的那对三角形都涂成了蓝色和橙色。

证明分三步：

  1. 看三角形 MNCMNCMNC 和 PNBPNBPNB：NC=NBNC = NBNC=NB，NM=NPNM = NPNM=NP，∠MNC=∠PNB\angle MNC = \angle PNB∠MNC=∠PNB 是对顶角。按边角边，△MNC≅△PNB\triangle MNC \cong \triangle PNB△MNC≅△PNB（MMM 对 PPP，CCC 对 BBB）。
  2. 于是 PB=MC=MAPB = MC = MAPB=MC=MA，而且 ∠MCN=∠PBN\angle MCN = \angle PBN∠MCN=∠PBN。这两个角是直线 CACACA 和 BPBPBP 被 BCBCBC 所截的内错角，所以 BP∥AMBP \parallel AMBP∥AM。
  3. 四边形 ABPMABPMABPM 中，AMAMAM 和 BPBPBP 平行且相等，所以 ABPMABPMABPM 是平行四边形。于是 MP∥ABMP \parallel ABMP∥AB，MP=ABMP = ABMP=AB。NNN 是 MPMPMP 的中点，所以 MN=12ABMN = \tfrac12 ABMN=21​AB，并且 MN∥ABMN \parallel ABMN∥AB。

这个定理还有一种常用的说法：过 ACACAC 的中点 MMM 作 ABABAB 的平行线，它一定经过 BCBCBC 的中点。 理由很短：过 MMM 只能作一条 ABABAB 的平行线，而中位线 MNMNMN 就是一条这样的平行线。所以这条平行线就是 MNMNMN，它和 BCBCBC 交在 NNN。

梯形的中位线​

梯形 ABCDABCDABCD 中 AB∥CDAB \parallel CDAB∥CD，记 a=ABa = ABa=AB，c=CDc = CDc=CD。MMM 是腰 ADADAD 的中点，NNN 是腰 BCBCBC 的中点。线段 MNMNMN 叫做梯形的中位线，它满足：

MN∥AB并且MN=a+c2.MN \parallel AB \quad\text{并且}\quad MN = \frac{a+c}{2}.MN∥AB并且MN=2a+c​.

思路是：三角形的中位线我们已经会了，那就把梯形变成三角形。连接 DNDNDN 并延长，交直线 ABABAB 于 EEE。上面那张图的右半边，把三角形 NCDNCDNCD 和 NBENBENBE 涂成了蓝色和橙色。只要证出这两个三角形全等，就同时得到两件事：NNN 是 DEDEDE 的中点，BE=cBE = cBE=c。这样 MNMNMN 就成了三角形 AEDAEDAED 的中位线，剩下的交给三角形中位线定理。这两个三角形有哪些相等的边和角，用前面“怎样在图里找到合适的一对三角形”里的几个问题去找。

这里也有同样的另一种说法：过一条腰的中点作底边的平行线，一定经过另一条腰的中点，因为过 MMM 只有一条 ABABAB 的平行线。

怎样把全等证明写清楚​

全等证明如果每次都按同一个格式写，别人读起来就很轻松。拿前面正三角形的例子来写：

要证： DC=BEDC = BEDC=BE。

考虑三角形 ADCADCADC 和 ABEABEABE。

(1) AD=ABAD = ABAD=AB，因为 ABDABDABD 是正三角形。 (2) AC=AEAC = AEAC=AE，因为 ACEACEACE 是正三角形。 (3) ∠DAC=60∘+∠BAC=∠BAE\angle DAC = 60^\circ + \angle BAC = \angle BAE∠DAC=60∘+∠BAC=∠BAE。

由 (1)(2)(3)，按边角边，△ADC≅△ABE\triangle ADC \cong \triangle ABE△ADC≅△ABE。

所以对应边 DCDCDC 和 BEBEBE 相等。

写的时候注意四件事。第一，明确说出是哪两个三角形。第二，每个等式都写理由，不能只说“看得出来”。第三，顶点按对应顺序写，让人看得出 AAA 对 AAA、DDD 对 BBB、CCC 对 EEE。第四，写出用的是哪个判定，并检查角是不是真的夹在两边中间。

现在你试试​

现在你试试（1）： ABCDABCDABCD 是正方形，PPP 在 ABABAB 上，QQQ 在 BCBCBC 上，并且 AP=BQAP = BQAP=BQ。证明 DP=AQDP = AQDP=AQ。附加：证明 DP⊥AQDP \perp AQDP⊥AQ。

查看答案

看三角形 DAPDAPDAP 和 ABQABQABQ：DA=ABDA = ABDA=AB（正方形的边），AP=BQAP = BQAP=BQ（已知），∠DAP=∠ABQ=90∘\angle DAP = \angle ABQ = 90^\circ∠DAP=∠ABQ=90∘。按边角边，△DAP≅△ABQ\triangle DAP \cong \triangle ABQ△DAP≅△ABQ，其中 DDD 对 AAA，AAA 对 BBB，PPP 对 QQQ。所以 DP=AQDP = AQDP=AQ。

附加：由全等得 ∠ADP=∠BAQ\angle ADP = \angle BAQ∠ADP=∠BAQ。设 DPDPDP 和 AQAQAQ 交于 SSS。在三角形 ASDASDASD 中，∠SAD=90∘−∠BAQ=90∘−∠ADP\angle SAD = 90^\circ - \angle BAQ = 90^\circ - \angle ADP∠SAD=90∘−∠BAQ=90∘−∠ADP，所以 ∠ASD=180∘−∠ADP−(90∘−∠ADP)=90∘\angle ASD = 180^\circ - \angle ADP - (90^\circ - \angle ADP) = 90^\circ∠ASD=180∘−∠ADP−(90∘−∠ADP)=90∘。背后其实是绕正方形中心旋转 90∘90^\circ90∘。

现在你试试（2）： 三角形 ABCABCABC 中，DDD、EEE、FFF 分别是 ABABAB、ACACAC、BCBCBC 的中点。证明四个小三角形 ADEADEADE、DBFDBFDBF、EFCEFCEFC、FEDFEDFED 全等。

查看答案

由中位线定理，DE=12BCDE = \tfrac12 BCDE=21​BC，EF=12ABEF = \tfrac12 ABEF=21​AB，DF=12ACDF = \tfrac12 ACDF=21​AC。又因为是中点，AD=DB=12ABAD = DB = \tfrac12 ABAD=DB=21​AB，AE=EC=12ACAE = EC = \tfrac12 ACAE=EC=21​AC，BF=FC=12BCBF = FC = \tfrac12 BCBF=FC=21​BC。四个三角形的三条边都是 12AB\tfrac12 AB21​AB、12AC\tfrac12 AC21​AC、12BC\tfrac12 BC21​BC，按边边边全部全等。

现在你试试（3）： 两个三角形都满足 AB=7AB = 7AB=7，AC=5AC = 5AC=5。再加上 (a) ∠B=40∘\angle B = 40^\circ∠B=40∘，或者 (b) ∠C=40∘\angle C = 40^\circ∠C=40∘，能不能保证全等？

查看答案

(a) BBB 处的角对着 AC=5AC = 5AC=5，是较短的边，大边对角用不上，可能像反例那样画出两个不同的三角形。(b) CCC 处的角对着 AB=7AB = 7AB=7，是较长的边，按大边对角，两个三角形全等。

做竞赛题时怎样用​

题目里出现下面这些信号时，可以想想全等或中位线：

题目里的信号可以试试
要证两条线段或两个角相等找一对分别含有它们的三角形
边上向外作正三角形或正方形边角边，夹角是“公共角 +60∘+ 60^\circ+60∘”或“+90∘+ 90^\circ+90∘”；想想旋转，配对就出来了
图里有平行四边形对边相等、内错角、对角线互相平分
三角形两边的中点中位线：平行且等于一半
四边形四条边的中点连一条对角线，让每两个中点落在同一个三角形里
中点加平行线过中点把线段加倍或延长，用对顶角
点在中垂线上到两端距离相等，再用边边边
要求一个角先证全等，再把对应角放进角度计算

在作图题里，全等判定还有另一个作用：它告诉你给定的几个量能不能唯一确定一个三角形。

最容易出错的地方​

  • 顶点没对上。 写成 △ADC≅△AEB\triangle ADC \cong \triangle AEB△ADC≅△AEB，就等于说 AD=AEAD = AEAD=AE、AC=ABAC = ABAC=AB，一般来说这是错的。读结论之前，先检查顶点顺序。
  • 用了边边角。 两条边加一个不是夹角的角，一般只有在这个角对着两边中较长的那条（或者两边一样长）时才够用。如果它对着较短的边，就可能像反例那样画出两个不同的三角形。
  • 没检查角的位置。 一个角是 ∠BAC+60∘\angle BAC + 60^\circ∠BAC+60∘ 还是 60∘−∠BAC60^\circ - \angle BAC60∘−∠BAC，要看图形怎么摆。对着图检查一遍；如果题目给了“某角小于 60∘60^\circ60∘”之类的条件，想一想它是用来保证什么的。
  • 把要证的结论当成了条件。 证明“过 MMM 的平行线经过中点”时，不能一开始就假设交点是中点。先证明，再使用。
  • 相信了眼睛。 图上看起来一样长，不算理由。列出来的每一个等式都要有根据。

这个想法以后还会出现在哪里​

  • GEO-02：等腰三角形“等边对等角”及其逆命题都可以用全等来证明；反过来，等腰三角形也经常给你全等需要的相等边。
  • GEO-04：正方形、长方形和正三角形提供了大量相等的边和固定的角，正好是全等判定需要的材料。
  • GEO-05：同一个圆的半径都相等，于是会出现等腰三角形和全等三角形，比如证明泰勒斯定理（直径所对的圆周角是直角）的时候。
  • GEO-03：全等三角形面积相等，可以不计算就比较面积。
  • GEO-09（尺规作图与轨迹）：那里要写作图步骤并证明作图正确。全等判定决定给定的量能不能唯一确定三角形，而中垂线是第一条重要的轨迹。
  • GEO-07：中位线定理对任何三角形都成立，立体图形的一个面也不例外。把四面体同一个面上两条棱的中点连起来，这条线段就平行于这个面的第三条棱，并且等于它的一半。

回头看这一章​

全等把“这两条线段一样长吗”变成了“这两个三角形能重合吗”。四个判定边边边、边角边、角边角/角角边和大边对角，说明了哪三个量就够用；它们成立，是因为这三个量只能画出一种三角形。边边角不够，是因为一个圆可能和一条直线交两次。用全等可以证明平行四边形的性质，再由此得到三角形和梯形的中位线定理。
