COM-06 递推计数

Concept ID: COM-06

主索引 · 知识树 · COM-06 真题索引 · Deutsche Hauptfassung

一个大的计数问题，可以由小问题组成​

有些题不适合从头到尾直接列举。如果你一开始就想写出所有可能，情况会很快分叉。

递推计数会先问另一个问题：

大目标的数量，怎样由更小目标的数量决定？\text{大目标的数量，怎样由更小目标的数量决定？}大目标的数量，怎样由更小目标的数量决定？

你不是逐个数每一种可能，而是描述一种可能最后怎样结束，或者怎样从更小的可能生成。

COM-06 训练的就是这个视角：

不要先数完整故事，先数最后一步。\text{不要先数完整故事，先数最后一步。}不要先数完整故事，先数最后一步。

这刚开始会有点不习惯，因为你像是从结尾开始想。但最后一步常常是最干净的切口：每一种完整走法都有且只有一个最后一步。只要按最后一步分类，就不容易重复计数。

最后一步能把情况分干净​

想象一个孩子上楼梯，每一步可以跨 111、222 或 333 级。到第 nnn 级有多少种走法？

到第 nnn 级的最后一步只有三种：

  • 从第 n−1n-1n−1 级跨 111 级；
  • 从第 n−2n-2n−2 级跨 222 级；
  • 从第 n−3n-3n−3 级跨 333 级。

这三类互不重叠。所以：

wn=wn−1+wn−2+wn−3.w_n=w_{n-1}+w_{n-2}+w_{n-3}.wn​=wn−1​+wn−2​+wn−3​.

这就是递推的核心。wnw_nwn​ 由前面的几个数量表示。

关键是这三类真的互不重叠。最后一步是跨 111 级的走法，不可能同时也是跨 222 级的走法。正因为这样，三个数量才可以直接相加。

目标最后一步贡献
第 nnn 级来自 n−1n-1n−1wn−1w_{n-1}wn−1​
第 nnn 级来自 n−2n-2n−2wn−2w_{n-2}wn−2​
第 nnn 级来自 n−3n-3n−3wn−3w_{n-3}wn−3​

为了让递推开始，你还需要初始值。小楼梯可以直接数。

初始值不是小事​

没有初始值的递推，就像没有第一阶的梯子。你需要可靠的小情况。

在楼梯题里，可以设：

w0=1.w_0=1.w0​=1.

意思是：已经在目标处时，有一种方式，那就是什么也不做。这个值刚开始看起来有点奇怪，但它能让公式很整齐。

初始值不是技术细节。它说明这个故事在最小规模时怎样开始。如果开头错了，递推会很认真地把错误一路传下去。

然后：

w1=1,w2=2,w3=4.w_1=1,\quad w_2=2,\quad w_3=4.w1​=1,w2​=2,w3​=4.

从这里开始，递推就能往后走了。

有时递推数的是“变化”​

不是所有递推都像楼梯。比如一块巧克力沿折痕掰开时，关键数量可以是“现在有多少块”。

每次掰开一个已有的块，相当于把一个块变成两个块。因此总块数每次正好增加 111。

开始时：

s0=1.s_0=1.s0​=1.

掰一次后：

s1=2.s_1=2.s1​=2.

掰 kkk 次后：

sk=1+k.s_k=1+k.sk​=1+k.

如果巧克力一共有 L⋅BL\cdot BL⋅B 个小格，要全部分开，就需要

L⋅B−1L\cdot B-1L⋅B−1

次掰开。这里最重要的不是巧克力的形状，而是块数的变化。

递推计数不是盲目套公式​

一个好的递推必须回答三个问题：

  1. 我到底在数什么？
  2. 大情况怎样由小情况产生？
  3. 为什么这些分类不重不漏？

第三个问题特别重要。如果两类包含同一种可能，就会重复计数。如果少了一类，就会漏数。

楼梯题里分类干净，是因为最后一步的长度只能是 111、222 或 333。巧克力题里变化干净，是因为每次掰开块数都正好多 111。

现在你试试​

现在你试试： 一个孩子每一步可以跨 111 或 222 级。到第 555 级有多少种走法？

显示解答

设 ana_nan​ 是到第 nnn 级的走法数。 最后一步来自 n−1n-1n−1 或 n−2n-2n−2，所以 an=an−1+an−2.a_n=a_{n-1}+a_{n-2}.an​=an−1​+an−2​. 用 a0=1a_0=1a0​=1、a1=1a_1=1a1​=1，得到 a2=2,a3=3,a4=5,a5=8.a_2=2,\quad a_3=3,\quad a_4=5,\quad a_5=8.a2​=2,a3​=3,a4​=5,a5​=8. 所以一共有 888 种走法。

做真题时可以这样走​

  1. 给要数的数量命名，例如 wnw_nwn​。
  2. 寻找一个唯一的最后一步，或唯一的最后变化。
  3. 按这个最后步骤分类。
  4. 把每一类写成更小的计数问题。
  5. 直接检查初始值。
  6. 说明为什么没有重复计数，也没有漏掉情况。

容易出错的地方​

第一个常见错误，是只写公式，不解释分类为什么成立。奥数题里，真正重要的是递推式背后的理由。

第二个常见错误，是猜初始值。前几个小情况要真的算出来。

第三个常见错误，是混淆递推和找规律。规律可以被观察到；递推要解释为什么后面的值由前面的值产生。

回头看​

递推计数把大的计数问题变小。你要寻找最后一步、最后一次变化，或者一种由小情况构造大情况的唯一方式。

最重要的问题是：

这个大问题由哪些更小的计数问题组成？\text{这个大问题由哪些更小的计数问题组成？}这个大问题由哪些更小的计数问题组成？
