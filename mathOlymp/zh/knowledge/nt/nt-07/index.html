NT-07 奇偶性、模分类与整数约束

Concept ID: NT-07

主索引 · 知识树 · NT-07 真题索引 · Deutsche Hauptfassung

整数总会带着一个余数​

只要题目讨论整数，就不是每一步计算都同样重要。很多时候，可以先问一个粗问题：这个数是奇数还是偶数？除以 333、444、555 分别可能余几？

这些问题看起来很小，却能立刻删掉很多不可能情况。NT-07 的核心就是：把整数按照余数分类，让题目变得可控。

做题时先问：

哪些余数必须保持不变，或者必须互相配合？\text{哪些余数必须保持不变，或者必须互相配合？}哪些余数必须保持不变，或者必须互相配合？

余数的价值在于：它们很粗，但很可靠。你丢掉了数字的许多细节，却保留了整除、奇偶、循环中最重要的信息。正是这种简化，让一些复杂题目先变得可控。

奇偶性是最快的余数筛子​

奇偶性就是把整数分成偶数和奇数。换句话说，你在看模 222 的余数：

偶数≡0(mod2),奇数≡1(mod2).\text{偶数}\equiv 0\pmod 2,\qquad \text{奇数}\equiv 1\pmod 2.偶数≡0(mod2),奇数≡1(mod2).

加法和乘法中，这两个类别经常已经够用了。

表达式奇偶性
偶数 + 偶数偶数
偶数 + 奇数奇数
奇数 + 奇数偶数
奇数 · 奇数奇数

如果一个和是奇数，它就不可能由两个相同整数相加得到。如果一个操作每次翻两张卡片，那么某个数量的奇偶性可能永远不变。

做奇偶性论证时，通常不需要算大数。你把每个数替换成“偶”或“奇”，再检查目标状态是否可能落在同一个类别里。

模分类是更细的抽屉​

有时只看奇偶太粗。那就换一个更大的模数。模 333 有三个抽屉：

0, 1, 2(mod3).0,\ 1,\ 2\pmod 3.0, 1, 2(mod3).

模 444 有四个抽屉：

0, 1, 2, 3(mod4).0,\ 1,\ 2,\ 3\pmod 4.0, 1, 2, 3(mod4).

不用一开始就试所有模数。要选和题目有关的模数。题目出现“能被 333 整除”，就自然看模 333。题目出现奇偶操作，就自然看模 222。平方数题里，模 444 常常有用，因为平方数模 444 只可能余 000 或 111。

所以选模数其实是在读题：条件里出现了哪个数？什么操作会反复发生？最后要求什么整除性？合适的模数通常就藏在这些词里。

操作可能保持余数不变​

很多题会反复改变某个状态：翻卡片、连点、替换数字。这个时候重要的不只是“现在发生了什么”，而是“无论怎么操作，什么不会变”。

每一步合法操作后都保持不变的量，叫不变量。

证明不变量时，不能只看几个例子。你要看任意一次合法操作，并说明操作前后余数或奇偶性保持一致。这样它才真的能限制所有过程。

比如每次翻两张卡片，朝上的红色卡片数会变化 −2-2−2、000 或 +2+2+2。所以红色朝上张数的奇偶性不变。这样，一个看似很长的游戏搜索，就变成了一个奇偶问题。

计数题里也有奇偶结构​

计数题也可能藏着奇偶性。如果对象总是成对出现，总数通常是偶数。如果题目最后要求奇数，就必须有一个无法配对的剩余部分。

直线和交点题中，这种结构很常见。一组平行线内部没有交点，但会和其它组的直线产生交点。因此总交点数常常由若干个组大小的乘积组成。

如果你只需要判断某个数量能不能是奇数，就不一定要画出所有交点。可以直接看每一部分对模 222 的贡献。

现在你试试​

现在你试试： 五张卡片一开始都是蓝面朝上。每次必须翻转两张卡片。最后能不能让每张卡片都红面朝上？

显示解答

开始时红面朝上有 000 张，目标是 555 张。每次翻两张，红面朝上张数只会变化 −2-2−2、000 或 +2+2+2。所以奇偶性保持为偶数。555 是奇数，因此不可能。

做真题时可以这样走​

  1. 先把关键数量写成整数。
  2. 如果题目可能涉及奇偶，先看模 222。
  3. 如果题目出现被 333、444、555 整除，或者类似结构，就选对应的模数。
  4. 对反复操作的题，寻找每一步都不改变的余数。
  5. 先删掉不可能的余数类，再逐个检查剩下的情况。
  6. 最后确认原题的所有条件仍然满足。

容易出错的地方​

第一个常见错误，是把余数当普通数字。由 a≡1(mod3)a\equiv 1\pmod 3a≡1(mod3) 和 b≡2(mod3)b\equiv 2\pmod 3b≡2(mod3)，只能得到 a+b≡0(mod3)a+b\equiv 0\pmod 3a+b≡0(mod3)，不能得到 a+b=3a+b=3a+b=3。

第二个常见错误，是只看游戏或操作的初始状态。操作题中，要检查每一种合法操作都会怎样改变余数。

第三个常见错误，是把余数筛选当成完整解答。余数符合只表示“还可能”，后面仍然要检查其它条件。
