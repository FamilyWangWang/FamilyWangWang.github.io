ALG-03 比例、百分比与单位量

Concept ID: ALG-03

主索引 · 知识树 · ALG-03 真题索引 · Deutsche Hauptfassung

有些数字必须放在比较里才有意义​

一个数字单独看，常常信息不够。252525 名学生参加比赛，如果学校一共只有 300300300 人，那比例很高；如果学校一共 125012501250 人，那比例就低很多。同样是 252525，意义完全不同。

ALG-03 讲的就是这种眼光：把数字看成比例、百分比或单位量。它不是单纯做分数运算，而是不断追问：

这个数是相对于哪个总量来说的？

只要这个问题清楚，很多题就会变得稳定。你能看出某个量是不是翻倍了，一个价格是不是减少了 15\frac1551​，某个比例是不是更大，两个单位是不是可以直接比较。

在比例题里，基准量就像脚下的地面。如果你不知不觉换了地面，同一个数字的意义会变掉。所以写一句“相对于……”通常很值得。

比例是在说明两个量之间的关系​

比例 3:43:43:4 不是孤立的 333 和 444。它的意思是：一种量有 333 份时，另一种量有 444 份。

三个人分面包，三只动物比较体重，一个班级卖奖券，都可能用比例来缩短题目语言。

题目语言数学写法保持不变的东西
A 是 B 的两倍A=2BA = 2BA=2B倍数 222
B 比 A 多三分之一B=A+13A=43AB = A + \frac13A = \frac43AB=A+31​A=34​A以 A 为基准
C 比 B 少四分之一C=B−14B=34BC = B - \frac14B = \frac34BC=B−41​B=43​B以 B 为基准
555 枚硬币按 4:14:14:1 分444 份和 111 份每一份的大小

最重要的是：说“多三分之一”时，这个三分之一是原来那个量的三分之一；说“少四分之一”时，这个四分之一也是从当前被比较的量里取出来的。

这类句子要慢读。“A 比 B 多 13\frac1331​”和“A 比自己原来多 13\frac1331​”不是同一件事。只有先弄清这个分数取自哪个整体，后面的式子才会稳。

百分比一定要问：谁是 100%？​

百分比只是百分之几的写法：

12.5%=12.5100=1812.5\% = \frac{12.5}{100} = \frac1812.5%=10012.5​=81​

但是题目真正难的地方通常不是换算，而是基准。505050 的 20%20\%20% 和 400400400 的 20%20\%20% 完全不是同一个数。

遇到百分比，先问三个问题：

  1. 哪个量是 100%100\%100%？
  2. 题目给了或要求哪个部分？
  3. 这个总量后来有没有发生变化？

价格变化题里，第三个问题特别重要。如果一个价格先降 20%20\%20%，然后再降 20%20\%20%，总降幅不是 40%40\%40%。第一次降价以后，第二次降价的基准已经变小了。

稳妥的写法是用乘法因子：

新价格=原价格⋅(1−15)=原价格⋅45\text{新价格}=\text{原价格}\cdot\left(1-\frac15\right)=\text{原价格}\cdot\frac45新价格=原价格⋅(1−51​)=原价格⋅54​

连续两次各降 15\frac1551​，就是：

最终价格=初始价格⋅45⋅45\text{最终价格}=\text{初始价格}\cdot\frac45\cdot\frac45最终价格=初始价格⋅54​⋅54​

乘法因子通常比直接说“降了多少百分点”更安全。它会自动带着新的基准量往前走。每发生一次变化，你就问：当前这个量被乘上了哪个因子？

单位量能把大题变小​

单位量的意思是：先问“每一个单位对应多少”。

比如 1.51.51.5 只母鸡在 1.51.51.5 天里下 1.51.51.5 个蛋，这句话故意写得有点别扭。但你可以把它整理成几个清楚的问题：

  • 一只母鸡一天能下多少蛋？
  • 母鸡更多时会怎样？
  • 天数更多时会怎样？

蛋的数量和母鸡数量成正比，也和天数成正比。所以可以先降到“一只母鸡一天”，再升到题目要求的情况。

这张图表示单位量题的路径。它看起来慢一点，但能保护你不丢单位。

正比例和反比例要分清​

不是所有比例都往同一个方向变化。

正比例是两个量一起变大或一起变小。母鸡数量翻倍，在同样天数里蛋数也翻倍。学校人数翻倍，在同样比例下参赛人数也翻倍。

反比例里，常常是一个乘积保持不变。完成同一份工作时，人数变成两倍，时间可能变成一半。这时不能把所有数都往同一个方向乘。

情况类型稳定关系
母鸡更多，蛋更多正比例每只母鸡每天的蛋数
学生更多，同一比例下人数更多正比例参加比例
工人更多，同一工程用时更少反比例人数 ⋅\cdot⋅ 时间
价格多次下降每一步基准改变乘法因子

所以你不要只问“哪个数变大了”。你要问：哪个关系保持不变？

百分比、分数和小数是三种语言​

奥数题经常在几种写法之间切换。题目里写 12.5%12.5\%12.5%，列式时用 18\frac1881​ 更方便，算钱时又可能用小数。

这些常用换算要很熟：

百分比分数小数
50%50\%50%12\frac1221​0.50.50.5
25%25\%25%14\frac1441​0.250.250.25
12.5%12.5\%12.5%18\frac1881​0.1250.1250.125
20%20\%20%15\frac1551​0.20.20.2
75%75\%75%34\frac3443​0.750.750.75

心算时，分数常常更好用。算钱时，小数可能更直接。比较比例时，百分比有时最容易读。

按比例分配，通常要按贡献分​

公平分配不一定是平均分。如果两个人共同贡献某种东西，奖励应该按真实贡献来分。

面包问题就是这个思路：先算每个人自己吃了多少，再算每个人实际给了别人多少。真正决定分配比例的，不是开始拥有多少面包，而是贡献出去多少面包。

如果贡献比例是 4:14:14:1，那么总共 555 份里，第一人拿 444 份，第二人拿 111 份。

5 枚硬币⋅45=4 枚硬币5\text{ 枚硬币}\cdot \frac45 = 4\text{ 枚硬币}5 枚硬币⋅54​=4 枚硬币

以及

5 枚硬币⋅15=1 枚硬币5\text{ 枚硬币}\cdot \frac15 = 1\text{ 枚硬币}5 枚硬币⋅51​=1 枚硬币

计算很短。关键想法在计算之前：不要按一开始拥有多少来分，而要按实际贡献来分。

现在你试试：两次降价​

现在你试试： 一件 T 恤连续两次各降价 15\frac1551​，最后价格是 161616 欧元。原价是多少？

显示解答

每次降价后都剩下原来那一步价格的 45\frac4554​。所以

16=x⋅45⋅45=x⋅162516 = x\cdot\frac45\cdot\frac45 = x\cdot\frac{16}{25}16=x⋅54​⋅54​=x⋅2516​

因此 x=25x = 25x=25。原价是 252525 欧元。

关键是：第二次降价是从已经降低后的价格里再降，而不是从最初价格里再降。

做真题时可以这样走​

  1. 标出基准量：哪个量是整体，也就是 100%100\%100%？
  2. 把比例写成方程或份数。
  3. 把百分比换成顺手的分数。
  4. 判断关系是正比例还是反比例。
  5. 多次变化时用乘法因子，不要直接相加百分数。
  6. 答案写上单位，再检查单位是否合理。

如果你要找错误，通常先查基准量。很多错误答案的计算本身很整齐，但从一开始就把“整体”选错了。

容易出错的地方​

第一个常见错误，是把百分比变化直接相加。两次降低 20%20\%20%，不等于一次降低 40%40\%40%。

第二个常见错误，是分数的基准错了。“多三分之一”不是指新数量的三分之一，而是旧数量的三分之一。

第三个常见错误，是混用不同单位。“每件 T 恤多少欧元”“每所学校多少学生”“每只母鸡每天多少蛋”是不同单位。只有单位说清楚以后，数字才能比较。
