ALG-06 分数、平均数与混合问题

Concept ID: ALG-06

主索引 · 知识树 · ALG-06 真题索引 · Deutsche Hauptfassung

有时候，真正要追踪的是藏在整体里的那一部分​

分数、平均数和混合问题看起来像三个主题。一个讲果汁，一个讲成绩，一个讲分式条件。但在奥数题里，它们常常有同一个核心：

你不能只看外面的总量，还要追踪总量里面的某个部分。

混合题里，这个部分可能是杯子里的樱桃汁。平均数题里，这个部分是所有数的总和。分数题里，这个部分是分子相对于分母的关系。只要这个“里面的量”没有丢，题目就不会变成一堆零散技巧。

这些题最常见的错误，是只看外面的容器。杯子可能还是一样满，但樱桃汁比例变了；数的个数可能没变，但总和变了。所以你要一直问：我真正要追踪的内部量是什么？

分数是相对于某个整体的部分​

一个分数 35\frac3553​ 的意思是：整体被分成 555 个相等的部分，我们取其中 333 个。所以必须先知道整体是谁。

如果一个杯子有 34\frac3443​ 满，整体是这个杯子。如果一种混合饮料中 34\frac3443​ 是果汁，整体是整杯混合物。同样的 34\frac3443​，可以表示完全不同的东西。

题目里的说法整体是谁追踪什么
一个杯子的 34\frac3443​一个杯子装了多少
一种混合物的 34\frac3443​整个混合物某种成分
一段路的 34\frac3443​全路程部分路程
一个总和的 34\frac3443​整个总和其中一项

所以第一步不是找公式，而是问：这个分数是哪个整体的部分？

这个问题能避免很多错算。如果整体变了，同一个分数不能自动沿用。旧混合物的一个比例，不一定还是新混合物的同一个比例。

混合题要同时记两本账​

混合题通常有两个量同时存在：

  • 混合物的总量；
  • 某一种成分的量。

只看总量，你不知道浓度。只看某种成分，你不知道它分布在多少混合物里。所以两本账都要写。

比如一杯 200200200 ml 的混合饮料，其中 14\frac1441​ 是樱桃汁。那么樱桃汁有

200⋅14=50 ml200\cdot\frac14=50\text{ ml}200⋅41​=50 ml

如果喝掉 100100100 ml 混合饮料，并不是喝掉 100100100 ml 樱桃汁。因为喝掉的是同样比例的混合物，所以喝掉的樱桃汁是 100100100 ml 的 14\frac1441​，也就是 252525 ml。

这张图表示安全路线：每一次喝掉、加满、混合之后，都重新计算成分量。

所以，混合题里很适合写两列：总量，以及被追踪的成分量。比例是最后用“成分量除以总量”得到的。如果只记录比例，遇到加满或倒出时就很容易乱。

加满以后，比例会改变​

有一类典型题会说：先喝掉一部分混合饮料，再用另一种饮料加满。然后再喝，再加满。

表面上这是杯子里的故事。真正要追踪的是比例变化。

如果每次加满后杯子回到原来的容量，那么总量恢复了。但成分变了：一部分原来的液体已经被喝掉，另一种新液体被加进来。

可以这样列表：

步骤总量被追踪的成分比例
开始GGGKKKKG\frac{K}{G}GK​
喝掉一部分变小同比例减少暂时不变
用另一种成分加满又变成 GGG原成分不增加比例变小

所以，如果饮料已经混匀，喝掉本身不会改变比例；真正改变比例的是用另一种成分加满。

平均数的本质是总和重新平均分​

算术平均数不是一种神秘的新数。它的意思是：如果把所有数的总和平均分给每一个位置，每个位置会是多少。

对于 444 个数：

平均数=4 个数的总和4\text{平均数}=\frac{\text{4 个数的总和}}{4}平均数=44 个数的总和​

如果平均数是 888，那么这 444 个数的总和必须是

4⋅8=324\cdot 8=324⋅8=32

很多平均数题都可以先回到总和。不要急着处理“平均”这个词，先把它翻译成总和。

加权平均里，每个数的分量不一样​

成绩、价格或混合物里，有些值不一定一样重要。一场考试可能算两次，一个小测只算一次。一大杯果汁对口味的影响比一小勺果汁大。

这时用加权平均：

加权平均=w1x1+w2x2+⋯+wnxnw1+w2+⋯+wn\text{加权平均}=\frac{w_1x_1+w_2x_2+\cdots+w_nx_n}{w_1+w_2+\cdots+w_n}加权平均=w1​+w2​+⋯+wn​w1​x1​+w2​x2​+⋯+wn​xn​​

权重 www 表示这个值算几份，或者影响有多大。如果一次考试算两倍，就在总和里以权重 222 出现。

最重要的一句话是：只有权重相同的时候，才能直接把几个数普通平均。

分式条件要看分子、分母和整除​

有些题给出类似

1320+n20\frac{13}{20}+\frac{n}{20}2013​+20n​

的式子。这时通常先合并：

13+n20\frac{13+n}{20}2013+n​

之后条件会清楚很多：

  • 小于 111，就是 13+n<2013+n<2013+n<20；
  • 是整数，就是 202020 整除 13+n13+n13+n；
  • 和 111 相差某个单位分数，就是把 1−13+n201-\frac{13+n}{20}1−2013+n​ 写成题目要求的形式。

这里分数、不等式和整除会一起出现。这很正常：一个好的表达式可以同时打开几种思路。

现在你试试：平均数里少了一个数​

现在你试试： 444、777、151515 和 xxx 的平均数是 888。xxx 是多少？

显示解答

四个数平均数为 888，总和就是 4⋅8=324\cdot 8=324⋅8=32。已知三个数的和是 4+7+15=264+7+15=264+7+15=26，所以 x=32−26=6x=32-26=6x=32−26=6。

关键一步是回到总和。平均数只是总和被平均分后的结果。

做真题时可以这样走​

  1. 说清整体：混合物、总和、杯子、数列还是分母。
  2. 决定要追踪哪一部分：成分、贡献、分子还是缺少的值。
  3. 混合题永远同时写总量和成分量。
  4. 把平均数条件改写成总和条件。
  5. 加权平均里先找权重，不要直接普通平均。
  6. 分式条件从分子、分母和整除关系读起。

如果你发现自己同时移动很多百分比和分数，先停下来画表。表格不是装饰，它是在帮你记住每个量现在是多少。

容易出错的地方​

第一个常见错误，是把几个平均数再直接平均。两个组的平均数只有在组的大小相同的时候，才能直接再平均。

第二个常见错误，是忘记成分量。稀释或加满时，不是浓度保持不变，而是原来那种成分的实际数量被继续带到下一步。

第三个常见错误，是分母不清楚。分母可能是固定数、总量，也可能是变量。分母不清楚时，你比较的比例可能根本不属于同一个整体。
