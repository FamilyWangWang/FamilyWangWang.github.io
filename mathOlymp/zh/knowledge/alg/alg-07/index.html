ALG-07 代数恒等变形、乘法公式与因式分解

Concept ID: ALG-07

八年级： 核心

中文 Companion · 知识树 · ALG-07 真题索引 · Deutsche Hauptfassung

同一个式子，换个写法就能看出更多​

先看一个小问题：求所有满足

xy=x+y+9xy = x + y + 9xy=x+y+9

的正整数对 xxx、yyy。

你可以先试几个数。取 x=2x = 2x=2，得到 2y=y+112y = y + 112y=y+11，所以 y=11y = 11y=11。可是怎么保证没有漏掉别的解呢？候选的数有无穷多个，一个一个试是试不完的。

换一种写法。把所有项移到左边，两边再同时加 111：

xy−x−y+1=10,也就是(x−1)(y−1)=10.xy - x - y + 1 = 10, \qquad \text{也就是} \qquad (x-1)(y-1) = 10.xy−x−y+1=10,也就是(x−1)(y−1)=10.

问题一下子变成有限的了：两个整数的积等于 101010，而 101010 的因数只有几个。由 10=1⋅10=2⋅5=5⋅2=10⋅110 = 1\cdot 10 = 2 \cdot 5 = 5\cdot 2 = 10 \cdot 110=1⋅10=2⋅5=5⋅2=10⋅1，得到四组解 (2,11)(2,11)(2,11)、(3,6)(3,6)(3,6)、(6,3)(6,3)(6,3)、(11,2)(11,2)(11,2)。负因数对在这里用不上，因为 x−1x-1x−1 和 y−1y-1y−1 都不会小于 000。

方程本身一点没变，变的只是它的样子。这一章要练的就是这件事：把式子改写成能看出结构的形式，让乘积、平方或者某个关键的整体露出来。

展开和提公因式，是同一个等式的两个方向​

分配律说的是

a(b+c)=ab+ac.a(b + c) = ab + ac.a(b+c)=ab+ac.

从左往右读，就是展开：把乘积变成和。从右往左读，就是提公因式：把和变成乘积。

两个方向都要会，但用处不一样。展开是为了整理，展开以后才能合并同类项。提公因式是为了看清结构，因为乘积会告诉你因数、正负号和什么时候等于 000。

下面这个例子先展开，再提公因式：

3a(a+2)−a2=3a2+6a−a2=2a2+6a=2a(a+3).3a(a+2) - a^2 = 3a^2 + 6a - a^2 = 2a^2 + 6a = 2a(a+3).3a(a+2)−a2=3a2+6a−a2=2a2+6a=2a(a+3).

中间那一步最整齐，右边那一步最有信息量。看到 2a(a+3)2a(a+3)2a(a+3)，你马上知道：对任何整数 aaa，这个式子都是偶数；它等于 000 只发生在 a=0a = 0a=0 或 a=−3a = -3a=−3 的时候。

提公因式什么时候都可以做，提出的是字母也没关系。比如把 a2+5a=aba^2 + 5a = aba2+5a=ab 的各项移到左边，再提出 aaa，得到 a(a+5−b)=0a(a + 5 - b) = 0a(a+5−b)=0。但如果接下来要两边除以 aaa，就必须先说明 a≠0a \neq 0a=0。提公因式不会丢解，除以字母却可能丢解。

有时整个式子没有公因式，但分成两组以后，每一组各有公因式。这时先在每组里提一次，再整体提一次：

ab+2a+3b+6=a(b+2)+3(b+2)=(a+3)(b+2).ab + 2a + 3b + 6 = a(b+2) + 3(b+2) = (a+3)(b+2).ab+2a+3b+6=a(b+2)+3(b+2)=(a+3)(b+2).

第二步能做，是因为两组里剩下的都是同一个 b+2b+2b+2。后面要讲的配凑，其实就是这种分组分解：只是那个让分组成功的常数一开始不在式子里，要你自己补上去。

三个乘法公式，以及它们为什么对​

对任意的数 aaa、bbb，都有

(a+b)2=a2+2ab+b2,(a+b)^2 = a^2 + 2ab + b^2,(a+b)2=a2+2ab+b2,

(a−b)2=a2−2ab+b2,(a-b)^2 = a^2 - 2ab + b^2,(a−b)2=a2−2ab+b2,

(a+b)(a−b)=a2−b2.(a+b)(a-b) = a^2 - b^2.(a+b)(a−b)=a2−b2.

前两个叫完全平方公式，第三个叫平方差公式。每一个都可以直接展开来验证。完全平方公式里，(a+b)(a+b)=a2+ab+ba+b2(a+b)(a+b) = a^2 + ab + ba + b^2(a+b)(a+b)=a2+ab+ba+b2，中间两项合起来正好是 2ab2ab2ab。平方差公式里，中间两项一正一负，互相抵消：(a+b)(a−b)=a2−ab+ba−b2=a2−b2(a+b)(a-b) = a^2 - ab + ba - b^2 = a^2 - b^2(a+b)(a−b)=a2−ab+ba−b2=a2−b2。

左边的图告诉你“2ab2ab2ab”是从哪里来的：边长为 a+ba+ba+b 的大正方形里，有两块一样的 ababab 长方形，而不是一块。右边的图说明 a2−b2a^2 - b^2a2−b2 为什么是一个乘积：从大正方形里挖掉小正方形，再把绿色那一块转一下，接到右边，就拼成了长 a+ba+ba+b、宽 a−ba-ba−b 的长方形。

第二个公式其实不算新东西。在第一个公式里把 bbb 换成 −b-b−b，它就出来了。

把第一个公式减去第二个，a2a^2a2 和 b2b^2b2 都消掉了，剩下

(a+b)2−(a−b)2=4ab.(a+b)^2 - (a-b)^2 = 4ab.(a+b)2−(a−b)2=4ab.

题目里同时出现两个数的和与积时，这个式子很有用：知道 a+ba + ba+b 和 ababab，马上就能算出 (a−b)2(a-b)^2(a−b)2。

用同样的办法，还可以写出三项和的平方：

(a+b+c)2=a2+b2+c2+2ab+2ac+2bc.(a+b+c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc.(a+b+c)2=a2+b2+c2+2ab+2ac+2bc.

每一项自己乘自己出现一次，任意两项的乘积各出现两次。画成面积图，就是一个被分成 3×33 \times 33×3 块的大正方形。

把数字写成代数式​

乘法公式不只是给字母用的，很多速算技巧背后都是它们：

1032=(100+3)2=10000+600+9=10609,103^2 = (100 + 3)^2 = 10000 + 600 + 9 = 10609,1032=(100+3)2=10000+600+9=10609,

98⋅102=(100−2)(100+2)=10000−4=9996.98 \cdot 102 = (100-2)(100+2) = 10000 - 4 = 9996.98⋅102=(100−2)(100+2)=10000−4=9996.

奥数题常常要你说明某个技巧对所有的数都成立。这时就要用位值把数写成式子。十位是 aaa、个位是 111 的两位数可以写成 10a+110a + 110a+1，于是

(10a+1)2=100a2+20a+1.(10a+1)^2 = 100a^2 + 20a + 1.(10a+1)2=100a2+20a+1.

从这个式子里，你能看出平方是由哪几部分拼起来的。比如 712=4900+140+1=504171^2 = 4900 + 140 + 1 = 5041712=4900+140+1=5041。这里 20a=14020a = 14020a=140 超过了 100100100，会向百位进位，所以要把三部分加起来，不能直接把数字抄下来。所以式子给你的不只是一个答案，而是一个对每个数字 aaa 都成立的理由。

在长长的式子里认出平方​

更难的是反过来：看到一长串和，要认出里面藏着一个平方。可以留意两个信号：

  • 有两项本身就是平方，比如 x2x^2x2 和 9=329 = 3^29=32，或者 4a2=(2a)24a^2 = (2a)^24a2=(2a)2 和 9b2=(3b)29b^2 = (3b)^29b2=(3b)2。
  • 剩下那一项恰好是它们“底数”乘积的两倍：6x=2⋅x⋅36x = 2\cdot x \cdot 36x=2⋅x⋅3，12ab=2⋅2a⋅3b12ab = 2\cdot 2a\cdot 3b12ab=2⋅2a⋅3b。

这时就有 x2+6x+9=(x+3)2x^2 + 6x + 9 = (x+3)^2x2+6x+9=(x+3)2，以及 4a2−12ab+9b2=(2a−3b)24a^2 - 12ab + 9b^2 = (2a - 3b)^24a2−12ab+9b2=(2a−3b)2。

平方经常藏得更深，因为式子还没有展开。比如两个相差 444 的数相乘，再加上 444：

n(n+4)+4=n2+4n+4=(n+2)2.n(n+4) + 4 = n^2 + 4n + 4 = (n+2)^2.n(n+4)+4=n2+4n+4=(n+2)2.

例如 7⋅11+4=81=927 \cdot 11 + 4 = 81 = 9^27⋅11+4=81=92。所以，题目里一出现“乘积加上一个数”，就值得展开再看一眼。

平方差也很好认：两个平方中间是减号。比如 9x2−25=(3x−5)(3x+5)9x^2 - 25 = (3x-5)(3x+5)9x2−25=(3x−5)(3x+5)。

让式子只跟 a−ca - ca−c 有关​

有时题目不告诉你 aaa 和 ccc 各是多少，只告诉你它们的差。这时要问：这个式子是不是只取决于 a−ca - ca−c？

看这个式子：

T=a2−2ac+c2−4a+4c.T = a^2 - 2ac + c^2 - 4a + 4c.T=a2−2ac+c2−4a+4c.

前三项正好是完全平方公式，等于 (a−c)2(a-c)^2(a−c)2。后两项提出 −4-4−4：−4a+4c=−4(a−c)-4a + 4c = -4(a-c)−4a+4c=−4(a−c)。所以

T=(a−c)2−4(a−c).T = (a-c)^2 - 4(a-c).T=(a−c)2−4(a−c).

只要 a−c=5a - c = 5a−c=5，就有 T=25−20=5T = 25 - 20 = 5T=25−20=5，不管 aaa 和 ccc 本身有多大。

如果一眼看不出这样的整理，怎么办？有一个稳妥的检验办法：代换。令 d=a−cd = a - cd=a−c，也就是 a=c+da = c + da=c+d，把它代进 TTT 算一遍。如果算完以后含 ccc 的项全部消掉了，TTT 就真的只跟 ddd 有关。如果还剩下 ccc，说明 TTT 也跟 ccc 有关，只知道差是不够的。

硬凑出一个乘积：整数方程里的配凑​

本章开头，我们给 xy−x−y=9xy - x - y = 9xy−x−y=9 加上一个合适的数，凑出了 (x−1)(y−1)=10(x-1)(y-1) = 10(x−1)(y−1)=10。只要方程长成“xyxyxy 加上 xxx 和 yyy 的倍数等于一个数”的样子，这一招就能用。

要加的那个数是怎么找到的？答案是倒着想。看方程

xy−3x−5y=0.xy - 3x - 5y = 0.xy−3x−5y=0.

我们想要 (x−□)(y−□)(x - \square)(y - \square)(x−□)(y−□) 这样的乘积。展开时，含 xxx 的那一项是 xxx 乘第二个括号里的数得来的，含 yyy 的那一项是 yyy 乘第一个括号里的数得来的。要得到 −3x-3x−3x，第二个括号就得是 y−3y - 3y−3；要得到 −5y-5y−5y，第一个括号就得是 x−5x - 5x−5。展开检验一下：

(x−5)(y−3)=xy−3x−5y+15.(x-5)(y-3) = xy - 3x - 5y + 15.(x−5)(y−3)=xy−3x−5y+15.

这个乘积比方程左边多了一个 +15+15+15。所以两边同时加 151515，就得到

(x−5)(y−3)=15.(x-5)(y-3) = 15.(x−5)(y−3)=15.

一般地，xy+px+qy=(x+q)(y+p)−pqxy + px + qy = (x+q)(y+p) - pqxy+px+qy=(x+q)(y+p)−pq。系数是交叉着跑到另一个括号里的，而需要补上的数就是 pqpqpq。

到这一步，题目就变成了找因数。要求整数解时，151515 的所有因数对都要考虑，负的也不能漏：

(1,15), (3,5), (5,3), (15,1), (−1,−15), (−3,−5), (−5,−3), (−15,−1).(1,15),\ (3,5),\ (5,3),\ (15,1),\ (-1,-15),\ (-3,-5),\ (-5,-3),\ (-15,-1).(1,15), (3,5), (5,3), (15,1), (−1,−15), (−3,−5), (−5,−3), (−15,−1).

如果只要正整数解，就把每一对检查一遍。因为 x≥1x \geq 1x≥1、y≥1y \geq 1y≥1，所以 x−5≥−4x - 5 \geq -4x−5≥−4，y−3≥−2y - 3 \geq -2y−3≥−2。每一个负因数对里都有一个因数太小，所以只剩正的因数对。它们给出 (x,y)=(6,18)(x,y) = (6,18)(x,y)=(6,18)、(8,8)(8,8)(8,8)、(10,6)(10,6)(10,6)、(20,4)(20,4)(20,4)。

如果要的是整数解，负因数对就要算进来。比如 xy+x+y=5xy + x + y = 5xy+x+y=5 变成 (x+1)(y+1)=6(x+1)(y+1) = 6(x+1)(y+1)=6，666 的八个因数对给出八组解，其中就有 (x,y)=(−2,−7)(x,y) = (-2,-7)(x,y)=(−2,−7)，因为 (−1)⋅(−6)=6(-1)\cdot(-6) = 6(−1)⋅(−6)=6。

遇到平方差，还多一道限制。x2−y2=40x^2 - y^2 = 40x2−y2=40 变成 (x−y)(x+y)=40(x-y)(x+y) = 40(x−y)(x+y)=40。两个因数的和是 2x2x2x，是偶数，所以两个因数要么都是偶数，要么都是奇数。对正整数 xxx、yyy，x−yx - yx−y 是较小的因数，x+yx + yx+y 是较大的因数，所以只剩 2⋅202 \cdot 202⋅20 和 4⋅104 \cdot 104⋅10 两种，得到 (x,y)=(11,9)(x,y) = (11,9)(x,y)=(11,9) 和 (7,3)(7,3)(7,3)。先看奇偶，往往能在计算之前就划掉一大半因数对。

分式：先分解，再约分​

分子或分母里含有字母的分式，第一条规矩最容易忘：分母不能等于 000。 动手算之前，先写下哪些值不允许取。

约分只能约掉公共的因式，绝不能约掉单独的某一项。所以要先把分子和分母都分解成乘积：

x2−9x2+3x=(x−3)(x+3)x(x+3)=x−3x(x≠0, x≠−3).\frac{x^2 - 9}{x^2 + 3x} = \frac{(x-3)(x+3)}{x(x+3)} = \frac{x-3}{x} \qquad (x \neq 0,\ x \neq -3).x2+3xx2−9​=x(x+3)(x−3)(x+3)​=xx−3​(x=0, x=−3).

约分以后看不见 x+3x+3x+3 了，但 x=−3x = -3x=−3 照样不能取。约分后的式子只在原来的式子有意义的地方才和它相等。

分式相加减，要先通分。最省事的公分母通常就是两个分母的积：

1x−1−1x+1=(x+1)−(x−1)(x−1)(x+1)=2x2−1(x≠±1).\frac{1}{x-1} - \frac{1}{x+1} = \frac{(x+1) - (x-1)}{(x-1)(x+1)} = \frac{2}{x^2 - 1} \qquad (x \neq \pm 1).x−11​−x+11​=(x−1)(x+1)(x+1)−(x−1)​=x2−12​(x=±1).

整理分母时，平方差公式又派上了用场。

遇到繁分数，就把分子和分母同时乘以那个碍事的小分母：

21+1x=2xx+1(x≠0, x≠−1).\frac{2}{1 + \frac{1}{x}} = \frac{2x}{x + 1} \qquad (x \neq 0,\ x \neq -1).1+x1​2​=x+12x​(x=0, x=−1).

同一个分式反复出现时，可以给它起个名字。在 5x−3=1+3x−3\frac{5}{x-3} = 1 + \frac{3}{x-3}x−35​=1+x−33​ 里令 t=1x−3t = \frac{1}{x-3}t=x−31​，方程就成了 5t=1+3t5t = 1 + 3t5t=1+3t，所以 t=12t = \frac12t=21​，x−3=2x - 3 = 2x−3=2，也就是 x=5x = 5x=5。换元以后，乱糟糟的分式方程变成了一次方程。换完元还要想一想 ttt 能取哪些值：分子是 111 的分数永远不会等于 000。如果解出来要求 t=0t = 0t=0，原方程就没有解。

分式不等式要特别小心：两边乘以分母时，如果分母是负的，不等号要反过来。所以通常要按分母的正负分类讨论。

配方：离完全平方还差多少​

有时离完全平方只差一点点。看 x2+6x+5x^2 + 6x + 5x2+6x+5，先问：哪个平方是以 x2+6xx^2 + 6xx2+6x 开头的？是 (x+3)2=x2+6x+9(x+3)^2 = x^2 + 6x + 9(x+3)2=x2+6x+9。所以

x2+6x+5=(x+3)2−4=(x+3−2)(x+3+2)=(x+1)(x+5).x^2 + 6x + 5 = (x+3)^2 - 4 = (x+3-2)(x+3+2) = (x+1)(x+5).x2+6x+5=(x+3)2−4=(x+3−2)(x+3+2)=(x+1)(x+5).

最后一步又是平方差公式。这样，就算猜不出因式，也能把二次式分解开。如果想直接猜，就找两个数，让它们的积和和都对得上：x2−5x+6x^2 - 5x + 6x2−5x+6 里这两个数是 −2-2−2 和 −3-3−3，所以 x2−5x+6=(x−2)(x−3)x^2 - 5x + 6 = (x-2)(x-3)x2−5x+6=(x−2)(x−3)。

分解以后还能解方程。x2−5x+6=0x^2 - 5x + 6 = 0x2−5x+6=0 可以写成 (x−2)(x−3)=0(x-2)(x-3) = 0(x−2)(x−3)=0。两个数相乘等于 000，其中至少有一个是 000，所以 x=2x = 2x=2 或 x=3x = 3x=3。反过来，配方也能说明一个方程根本没有解：x2+6x+11=(x+3)2+2x^2 + 6x + 11 = (x+3)^2 + 2x2+6x+11=(x+3)2+2，它至少是 222，永远不会等于 000。

配方以后的样子还方便比大小。对正整数 aaa，比 a2a^2a2 小的最大平方数是 (a−1)2=a2−2a+1(a-1)^2 = a^2 - 2a + 1(a−1)2=a2−2a+1。两个相邻的平方数 n2n^2n2 和 (n+1)2(n+1)^2(n+1)2 之间，没有别的平方数。所以，只要你能说明一个式子严格夹在 (a−1)2(a-1)^2(a−1)2 和 a2a^2a2 之间，它就一定不是平方数。

现在你试试​

现在你试试： 把 25−4y225 - 4y^225−4y2 和 x2−14x+49x^2 - 14x + 49x2−14x+49 分解因式。

查看答案

25−4y2=52−(2y)2=(5−2y)(5+2y)25 - 4y^2 = 5^2 - (2y)^2 = (5 - 2y)(5 + 2y)25−4y2=52−(2y)2=(5−2y)(5+2y)。在 x2−14x+49x^2 - 14x + 49x2−14x+49 里，49=7249 = 7^249=72，14x=2⋅x⋅714x = 2 \cdot x \cdot 714x=2⋅x⋅7，所以它等于 (x−7)2(x - 7)^2(x−7)2。

做奥数题时怎样用​

动笔之前，先想清楚你想把式子变成什么样子。下面这张图可以帮你做决定。

这张图说明，每一次变形都有目标：要么让乘积露出来，要么让平方露出来，要么让一个关键的整体露出来。

图里没写的有两件事：题目涉及一个数的各位数字时，先用位值把它写成 10a+b10a + b10a+b 这样的式子；最后要检查所有附加条件，比如是不是正数、数字是不是在 000 到 999 之间、分母是不是不为 000。

最容易想错的地方​

最常见的错误是写成 (a+b)2=a2+b2(a+b)^2 = a^2 + b^2(a+b)2=a2+b2。看看面积图就知道少了什么：那两块 ababab。

第二个错误是约掉单独的项。x+3x\frac{x+3}{x}xx+3​ 里的 xxx 不能约，因为分子里的 xxx 不是因式。

第三个错误是配凑时把数放错了括号。xy−3x−5yxy - 3x - 5yxy−3x−5y 里，555 跟着 xxx，333 跟着 yyy。所以凑完一定要展开验算。

第四个错误出在因数对上。求整数解时漏掉负因数对，就会丢解；求正整数解时不明确排除负因数对，推理就有漏洞。

第五个错误是两边除以一个可能为 000 的字母，或者忘了分式里哪些值不能取。
