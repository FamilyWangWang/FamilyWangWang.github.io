主线二

主线 二代数与结构

代数一开始只是一门手艺：怎么把 x 解出来。可是走着走着，数学家发现真正要紧的不是 x 等于几，而是那些运算规律本身。于是代数从「解方程的技术」变成了「研究结构的学问」——这条主线讲的就是这次身份转变。

转变的关键时刻，发生在一个很具体的问题上：五次方程有没有求根公式？

一次方程移项就解决。二次方程有求根公式，巴比伦人四千年前就会了。三次和四次方程的公式，十六世纪的意大利人吵得头破血流才算出来（顺带逼出了复数，见主线一 1.9）。照这个势头，五次方程的公式应该也只是更长更难看而已。

结果是：它不存在。不是没人聪明到找出来，是有人证明了它不可能存在。

下面九张卡片，前六张是解方程的手艺（他现在和往后几年要天天用的），后三张开始往结构上走。

2.1 　山脚

字母代替数 · 代数的第一步

Variable · Term

用一个字母代表一个数——可能是还不知道的，也可能是会变的。就这一下，数学从「算一道题」变成了「算一类题」。

它为了解决什么才出现

在字母进入数学之前，每一道题都得从头讲一遍。「有一堆苹果，拿走三个还剩五个，原来有几个」——想说清楚一般规律，只能一个例子一个例子地举。

有了字母，(a+b)² = a² + 2ab + b² 这一行字，一口气说完了无穷多个算式。这是数学史上最划算的一笔买卖。

一个几乎没人明说的区分：字母有三种用法

同样是字母，在三种场合里含义完全不同。分不清这三种，做题时会经常觉得「这个 x 好像跟刚才那个 x 不是一回事」——因为它确实不是。

一、未知数　x² = 4 里的 x。它有确定的值，只是我们还不知道，解出来就固定了。它在等着被抓住。

二、变量　f(x) = x² 里的 x。它不等着被抓住，它跑遍所有值，每取一个值就给出一个结果。这是主线四的主角。

三、参数　ax² + bx + c = 0 里的 a、b、c。它们在一道具体的题里是固定的，但写成字母是为了表示「随便哪一组系数都行」。它们代表「任意一个」。

求根公式之所以厉害，正是因为它同时用到了三种：用参数（a,b,c）表达的、关于未知数（x）的、对所有情况都成立的答案。

下游整条主线 · 函数（主线四）· 公式与建模（主线七）· 一切用符号表达一般规律的地方
常见的坑

什么叫「同类项」？3a 和 5a 能合并成 8a，但 3a 和 5a² 不能。理由很朴素：a 和 a² 是两种不同的东西，就像 3 个苹果加 5 个橘子，合不成 8 个什么。

判断标准是：字母部分完全一样（同样的字母、同样的次数），才是同类项。2xy 和 5yx 是同类项（乘法可交换），2xy 和 5x²y 不是。

注意 Term（代数式，如 3x+2）和 Gleichung（方程，如 3x+2=0）的区别：Term 只是一个式子，没有真假；Gleichung 是一个断言，有真假（回到主线零 0.2）。德语课本对这两个词分得很清楚，中文常常都叫「式子」，反而含糊。

2.2 　山脚

式子的变形 · 分配律是唯一的引擎

Termumformung · binomische Formeln

展开、合并、提公因式——代数课上那些手上功夫，翻来覆去只用到一条规律：a(b+c) = ab + ac。

一条规律，两个方向

分配律从左往右读，是展开（ausmultiplizieren）：把括号拆开。从右往左读，是提公因式（ausklammern）：把括号提出来。

这两件事看着相反，其实是同一条规律的两次使用。而整个代数运算的技巧，说到底就是判断此刻该往哪个方向走——要算数值就展开，要解方程就提公因式（见 2.6）。

三条二项公式

下面三条在德国课本里叫 binomische Formeln，编号是 1、2、3，会被反复点名。它们不是新规律，全都是分配律算两遍的结果——但因为用得太频繁，值得直接认脸：

①  (a + b)² = a² + 2ab + b²
②  (a − b)² = a² − 2ab + b²
③  (a + b)(a − b) = a² − b²

第三条尤其好用，因为它把「平方差」变成了乘积——这正是因式分解要的方向。

上游字母代数（2.1）· 分配律（主线一 1.3）· 面积（主线三）
下游因式分解（2.6）· 配方法与求根公式（2.5）· 多项式乘法 · 二项式定理与帕斯卡三角（主线五、主线六）
全世界最普遍的代数错误

(a + b)² ≠ a² + b²

这个错误每年在每个国家的每间教室里都会发生，值得专门点名。同一族的还有：√(a+b) ≠ √a + √b，1/(a+b) ≠ 1/a + 1/b，log(a+b) ≠ log a + log b（主线一 1.8 提过）。

它们的共同点是：把一个「对乘法友好」的运算，硬套在加法上。平方、开方、取倒数、取对数，全都能顺畅地穿过乘法，但穿不过加法。记住这一条，四个坑一起躲开。

2.3 　山脚

方程 · 天平比喻，以及它的极限

Gleichung · Äquivalenzumformung

方程是一句断言：这两个式子相等。解方程，就是在保持这句话真假不变的前提下，一步步把它改写成「x = 某个数」。

天平比喻，以及它管到哪儿为止

老师都会讲天平：两边同时加同样的重量，天平还是平的；两边同时减，还是平的。这个比喻很好，但它只管住了加减。

真正的规则是：只有「可逆」的操作才安全。一步变形如果能原样撤销，它就不会改变解集；如果撤不回来，就可能出事。这正是主线零 0.4 讲的 ⟺ 和 ⟹ 的区别，现在它有了非常实际的后果。

哪些变形安全，哪些不安全
这一步操作箭头会出什么事
两边加或减同一个数⟺完全安全，解集不变
两边乘或除同一个非零数⟺安全。注意「非零」两个字
两边除以一个含 x 的式子⟸ 危险可能丢根——那个式子等于 0 的情况被你偷偷排除了
两边同时平方⟹ 危险可能多出假根——平方把负号吃掉了

丢根的例子：解 x² = 3x。

如果两边除以 x，得 x = 3——但 x = 0 其实也是解！你在除的那一刻，默默假定了 x ≠ 0。

正确做法是移项后提公因式：x² − 3x = 0，即 x(x−3) = 0，两个解都在。

多根的例子：解 √(x+2) = x。两边平方得 x+2 = x²，解出 x = 2 和 x = −1。但 x = −1 代回原式是 √1 = −1，不成立。它是平方这一步凭空造出来的。

所以代回原方程检验（Probe）不是老师要求的仪式，是数学上真的必要的一步——只要你的解法里出现过一次单向箭头。

下游各种方程的解法（2.4–2.8）· 不等式 · 函数的零点（主线四）
常见的坑

检验的时候，一定要代回原方程，不是代回你化简到一半的某一步。因为如果错误出在化简过程里，代回化简后的式子会「验」得非常顺利——它验的是你的错误，不是原题。

2.4 　山脚

一次方程与不等式 · 只有一条新规则

lineare Gleichung · Ungleichung

一次方程是最听话的一类：移项、合并、除掉系数，三步到底。不等式的解法几乎一模一样，只多一条规则——但那一条特别容易忘。

那条新规则

看这个显然成立的式子：2 < 5。

两边同乘 −1：左边变 −2，右边变 −5。可是 −2 > −5——大小关系翻过来了。

乘以（或除以）负数时，不等号必须变向

为什么？因为乘 −1 就是把整根数轴以 0 为中心翻个面。原来在左边的跑到右边去了，「谁更大」当然要跟着换。

这条规则不用死记：只要想一下数轴翻面的画面，就永远不会忘。而它也解释了为什么等式没有这个麻烦——等号两边一样大，翻不翻面都一样大。

解集怎么写

方程的答案通常是几个数，不等式的答案通常是一整段。三种写法都要认得：

不等式写法：　x ≥ 2
集合写法：　　L = { x ∈ ℝ | x ≥ 2 }
区间写法：　　[2, ∞)

方括号表示端点包含在内，圆括号表示不包含。无穷那一头永远用圆括号，因为 ∞ 不是一个数，够不着（回到主线一 1.10）。

下游一次函数与斜率（主线四）· 线性规划（主线七）· 定义域的讨论 · 绝对值不等式
常见的坑

除以一个含字母的系数时，必须分情况讨论——因为你不知道它是正是负，甚至不知道它是不是 0。解 ax > 1 时，a > 0、a < 0、a = 0 三种情况的答案完全不同。这正是工具箱里的招数「分情况讨论」（主线零 0.6）第一次派上实际用场。

2.5 　山腰

二次方程 · 求根公式其实只有一个想法

quadratische Gleichung · quadratische Ergänzung

求根公式不该是背下来的一串字符。它就是「配方法」做一遍的结果——你只要懂了配方法，公式忘了都能当场推出来。

难在哪里

x² = 9 很好解，开方就行。(x+3)² = 9 也很好解，还是开方。

难的是 x² + 6x = 7 ——因为 x 出现了两次，没法一口气开方拿掉。

于是有了那个唯一的想法：能不能把左边凑成一个完整的平方？凑成了，就退化成上面那种好解的情况。这个动作德语叫 quadratische Ergänzung，字面就是「二次的补全」，而中文叫「配方」——两个名字说的是同一件事，而且都很形象，因为它真的是在补一块。

把公式推一遍
从 x² + px + q = 0 推出求根公式

移项：x² + px = −q

两边补上 (p/2)²，让左边凑成完整平方：

x² + px + (p/2)² = (p/2)² − q

左边正是 (x + p/2)²：

(x + p/2)² = (p/2)² − q

现在 x 只出现一次了，可以开方（注意正负两个根）：

x + p/2 = ± √( (p/2)² − q )

x = − p/2 ± √( (p/2)² − q )

这就是求根公式。∎

如果方程写成 ax² + bx + c = 0 的形式，同一套推导会给出另一个常见写法 x = (−b ± √(b²−4ac)) / 2a。两个公式是同一件事——把第二个除以 a 化成首项系数为 1，就回到第一个。课本用哪一种都行，重要的是你知道它们从哪来。

根号里那一块决定一切

公式里根号下面的东西叫判别式（Diskriminante），记作 D。它一个人决定了方程有几个解，而且这件事有非常直观的几何含义——就是抛物线和 x 轴的位置关系：

附赠：系数和根的秘密关系

把两个根加起来、乘起来，会发现它们直接就是系数：

x₁ + x₂ = −p　　　x₁ · x₂ = q

这叫韦达定理。它的实用价值是心算凑根：解 x² − 7x + 12 = 0，只要想「哪两个数加起来是 7、乘起来是 12」——3 和 4，一秒出答案，不用套公式。

它的理论价值更大：它第一次揭示了「方程的系数」和「方程的根」之间有确定的对应关系。顺着这条线索一路追问下去，最后追到的就是伽罗瓦理论——也就是这条主线的山顶。

下游抛物线与顶点式（主线四）· 极值问题（主线四）· 因式分解（2.6）· 复数（主线一 1.9）· 伽罗瓦理论（山顶）
常见的坑

用求根公式前，必须先把方程整理成标准形式（右边等于 0，且按次数排好）。x² + 3x = 10 不能直接读出 q = 10，要先移项成 x² + 3x − 10 = 0，此时 q = −10。这一步漏掉，后面全错。

还有：开方那一步必须带 ±。丢掉负根是二次方程题最高频的失分点。

2.6 　山腰

因式分解 · 把加法变成乘法

Faktorisieren · Nullproduktsatz

因式分解的全部意义，在于一条几乎显然的性质：几个数相乘等于 0，那其中必有一个是 0。这是解高次方程唯一的通用武器。

为什么非要变成乘积

面对 x³ − 6x² + 11x − 6 = 0，一堆加加减减，完全无从下手——因为「几个东西加起来等于 0」什么信息也给不了你，可能性无穷多。

但如果能写成 (x−1)(x−2)(x−3) = 0，答案立刻全出来了：三个因子里必有一个是 0，所以 x = 1, 2, 3。

加法藏信息，乘法露信息。这就是为什么代数里花那么大力气把式子往乘积上凑。

顺便注意：这跟主线一 1.6 的素因数分解是同一个思路换了个舞台——把一个复杂对象拆成不可再拆的零件之积。整数拆成素数，多项式拆成一次因式。两边的定理长得几乎一样。

四种常用手法

一、提公因式　6x² + 9x = 3x(2x + 3)。永远先看这一步。

二、二项公式倒着用　x² − 16 = (x+4)(x−4)，x² + 6x + 9 = (x+3)²。认脸就行（2.2）。

三、凑两个数　把 x² + px + q 拆成 (x+m)(x+n)，需要 m+n = p 且 mn = q——正是韦达定理反过来用。

四、先猜一个根，再做除法　这是对付三次以上方程的办法，见下。

因式定理：找到一个根，就摘下一个因子
因式定理 · Linearfaktor

如果 x = a 是多项式 P(x) 的一个根（也就是 P(a) = 0），那么 (x − a) 一定是 P(x) 的一个因子。

用法：先试出一个根（通常从常数项的因数里猜，比如 ±1、±2、±3），然后用多项式除法把 (x−a) 除掉，次数就降了一级。三次降成二次，二次就有求根公式了。

以 x³ − 6x² + 11x − 6 为例：试 x = 1，得 1 − 6 + 11 − 6 = 0，中了。于是除以 (x−1) 得 x² − 5x + 6，再分解成 (x−2)(x−3)。三个根到手。

这个「猜一个、降一级」的循环，是中学阶段解三次以上方程的标准路数。它也悄悄告诉你一件事：次数每降一级就轻松一大截——而这正是五次方程那堵墙的背景。

常见的坑

零积法则只对 0 成立。(x−1)(x−2) = 0 能推出 x=1 或 x=2；但 (x−1)(x−2) = 6 不能推出 x−1=6 或 x−2=6——因为 6 可以拆成无穷多对数相乘。碰到这种，老老实实展开、移项、化成右边等于 0 再说。

2.7 　山腰

多项式 · 次数决定一切

Polynom · Fundamentalsatz der Algebra

多项式就是「只用加减乘和正整数次幂搭出来的式子」。它的次数——最高那一项的指数——几乎决定了它的一切脾气。

次数说明什么

次数 1：　直线，最多 1 个零点
次数 2：　抛物线，最多 2 个零点
次数 3：　最多 3 个零点，必定至少有 1 个
次数 n：　最多 n 个零点

三次多项式「必定至少有一个实根」这件事有个很朴素的理由：x³ 在 x 很大时是正的很大，x 很小时是负的很小，而它的图像画得出来、连得上——中间必然穿过 0 一次。这个直觉在主线四会变成一条正式的定理（介值定理）。

代数基本定理

把根的范围放宽到复数，「最多 n 个」就升级成了「恰好 n 个」（重根按重数算）。这就是代数基本定理，主线一 1.9 已经从「造数」的角度见过它一次，现在从「解方程」的角度再见一次。

换句话说：只要允许用复数，任何多项式方程都解得出来。这是补洞工程完工的证书。

但要小心一个误会：「解一定存在」和「能用公式写出来」是两回事。代数基本定理保证五次方程有五个复数根；伽罗瓦证明的是你没法用加减乘除和开方把它们写出来。存在，但写不出。这两件事之间的缝隙，就是这条主线山顶的全部风景。

2.8 　山腰

方程组 · 一个未知数不够用的时候

lineares Gleichungssystem

两个未知数，就需要两个方程。而解方程组的一切方法，本质上都在做同一件事：想办法把未知数消掉一个。

三种解法，一个目的

代入法（Einsetzungsverfahren）：从一个方程里把 y 解出来，塞进另一个。适合某个未知数系数是 1 的时候。

加减消元法（Additionsverfahren）：把两个方程相加或相减，让某个未知数正好抵消。适合系数配得整齐的时候。

图解法：画出两条直线，交点就是解。不精确，但它能让你看见解是什么意思。

高斯消元：把手艺变成流程

未知数一多，靠眼力挑「该消哪个」就不现实了。高斯消元法把这件事变成了一套死板的流程：用第一个方程消掉后面所有方程里的第一个未知数，再用第二个方程消掉后面的第二个未知数，一路做成阶梯形，然后从最后一个方程往回代。

这套流程的意义超出了做题：它不需要灵感，纯靠机械步骤，所以可以交给计算机。今天从天气预报到工程仿真，背后跑的都是它的后代。这是代数和主线六「算法」的第一次握手。

常见的坑

加减消元时，两个方程要整条乘，不能只乘其中几项。把 2x + 3y = 7 乘以 3，是 6x + 9y = 21——右边那个 7 也要乘。漏掉右边是这一类题最常见的错。

矩阵 · 把一整个方程组当成一个东西

Matrix

解方程组的时候，未知数的名字其实没用——真正在动的只有那些系数。把系数排成一张表，方程组就浓缩成了一个对象。

从方程组到矩阵

2x + 3y = 7
4x −  y = 1

x 和 y 这两个字母纯属陪跑，换成 u 和 v 结果一模一样。有用的只有：

　┌ 2   3 │ 7 ┐
　└ 4  −1 │ 1 ┘

这张表就是矩阵。高斯消元的每一步（交换两行、某行乘一个数、某行减去另一行的倍数），在矩阵上都是很干净的行操作。

矩阵真正的身份：它是一个「动作」

矩阵最初只是记账用的表格，但很快人们发现它是别的东西：一个矩阵描述的是对空间的一次变换——旋转、拉伸、投影、翻转。而两个矩阵相乘，意思是「先做这个变换，再做那个变换」。

一旦这么看，一件怪事就变得理所当然了：

A · B　通常 ≠　B · A

矩阵乘法不满足交换律。这在只见过数的人看来简直是异端——毕竟 3×5 和 5×3 从来都一样。

但换成「动作」就完全自然了：先向前走一步再右转，和先右转再向前走一步，你会站在完全不同的地方。动作的顺序当然要紧。

这是这条主线上最重要的一次观念转折。在此之前，「乘法」意味着数与数相乘，而且总能交换；在此之后，「乘法」变成了「把两个操作接起来」，交换律只是某些情况下的巧合。代数从此不再是关于数的学问，而是关于运算的学问——这一步迈出去，就到山顶了。

常见的坑

写惯了数的人会习惯性地把 AB 和 BA 当成一回事，或者以为 (A+B)² = A² + 2AB + B²。后者是错的——展开应该是 A² + AB + BA + B²，而 AB 和 BA 合并不了。2.2 那条二项公式，前提是乘法可交换。前提没了，公式就没了。

山顶与远方

这条主线的山顶，是数学史上最动人的一段故事，也是「代数」这个词彻底改变含义的地方。同样不要求懂。

一个二十岁的人和一堵墙

三次、四次方程的公式在十六世纪就有了。之后近三百年，全欧洲最好的头脑都在找五次方程的公式，全部失败。

1824 年，挪威人阿贝尔证明了它不存在。但真正说清楚为什么的是法国人伽罗瓦。他的想法惊人地漂亮：

不要盯着根本身，去看那些根之间的「对称性」。如果把这些根打乱重排，哪些排法会让方程的所有关系保持不变？这些「保持不变的重排」自己构成了一个结构——今天叫群。伽罗瓦证明：方程能不能用公式解出来，完全取决于这个群的结构长什么样。而五次方程的群，结构上就是不行。

伽罗瓦二十岁死于一场决斗。决斗前夜他熬夜整理手稿，在页边反复写着「我没有时间了」。那些潦草的纸页开创了现代代数。

群、环、域：把规律本身抽出来

伽罗瓦之后，数学家意识到：与其研究「数」，不如研究「运算的规律」。把规律抽出来单独命名，就有了这三样东西——他其实早就见过它们，只是没听过名字：

群：一套东西加一种运算，满足结合律、有单位元、每个元素有逆元。整数在加法下是群。魔方的所有转法在「接着转」这个运算下也是群。一切对称都是群。

环：有两种运算（像加和乘）。整数 ℤ 是环，多项式也是环——这就是为什么 2.6 的因式分解和主线一 1.6 的素因数分解长得那么像：它们是同一种结构上的同一个定理。

域：环再加上「除得动」。ℚ、ℝ、ℂ 都是域，ℤ 不是（3 除以 2 跑出整数了）。主线一那五次扩张，用今天的话说就是在一步步造出更好的域。

抽象代数的威力在于：证一次，到处能用。关于群的定理，对整数成立，对魔方成立，对晶体的对称成立，对密码算法也成立——因为它证的是结构，不是具体的东西。

线性代数：矩阵那条线的尽头

2.9 那张系数表，往上走就是线性代数，几乎是全世界理工科第一年的必修课。它研究向量空间和线性映射，而它之所以无处不在，是因为一旦问题被局部化、简化，几乎所有东西都是线性的。

今天你手机里的图像处理、搜索引擎的排序、机器学习的每一次训练，底下跑的都是大规模的矩阵运算。他这一代人天天在用的技术，地基就是这一章。

这条路在大学叫什么

  • Lineare Algebra I / II——2.8 和 2.9 的正式展开，理工科第一年必修
  • Algebra——群、环、域，以及伽罗瓦理论的完整证明
  • Zahlentheorie——和主线一山顶接上，现代版本大量使用代数结构
  • Kryptographie（密码学）——有限域上的代数，撑着今天的整个互联网
