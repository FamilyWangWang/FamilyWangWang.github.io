主线零

主线 零数学的语言与证明

这条主线不回答任何数学问题。它管的是另一件事：什么样的回答才算数。

其余七条主线各自研究一样东西——数、形、变化、随机。这一条不研究任何东西，它研究那七条主线说话的方式。所以它在全景图上不是第八条，而是垫在底下的那一层。

它也是学校最不教的一条。课本会教你解方程，但很少有人告诉你「解出来了」到底是什么意思；会让你证明两个三角形全等，但很少有人讲清楚「证明」这个动作本身遵守什么规则。结果是很多人学了十年数学，却从没意识到自己一直在一套非常严格的语法里说话。

这条主线要做的，就是把那套语法拿到台面上来。它有一个很实在的好处：一旦你看清了这套语法，别的所有主线都会变得容易一些，因为你终于知道自己在读什么了。

0.1 　山脚

集合 · 数学的容器

Menge · set

把一些东西放在一起当成一个整体看，这个整体就叫集合。就这么简单——简单到它可以当整个数学的地基。

它为了解决什么才出现

数学里到处需要说「这一类东西」：所有偶数、所有三角形、所有小于 10 的素数、掷骰子所有可能的结果。集合就是为了给「这一类东西」一个正式的说法。

它看起来平淡，但十九世纪末数学家发现了一件让人吃惊的事：几乎所有数学对象都可以用集合搭出来。数可以用集合定义，函数可以定义成一种特殊的集合，几何图形就是点的集合。集合论因此成了整座数学大厦的地基——虽然大部分人盖楼的时候并不需要往下看那么深。

一个小例子

写法是花括号：A = {2, 3, 5, 7}，读作「A 是由 2、3、5、7 组成的集合」。

3 ∈ A　　（3 属于 A）
4 ∉ A　　（4 不属于 A）
{2, 3} ⊂ A　（{2,3} 是 A 的子集）

两个集合可以做运算，跟数的加减很像：

A ∪ B　并集：A 里的加上 B 里的
A ∩ B　交集：两边都有的
A \ B　差集：A 里有但 B 里没有的

上游没有。这是整本册子里最底下的一块砖。
下游函数的定义域与值域（主线四）· 概率的样本空间（主线五）· 数系 ℕ ℤ ℚ ℝ ℂ 本身就是集合（主线一）· 几何图形作为点集（主线三）
常见的坑

集合里不分顺序，也不数重复。{1, 2, 3}、{3, 2, 1} 和 {1, 2, 2, 3} 是同一个集合。如果顺序重要，那你要的是「数列」或者「元组」，不是集合。这个区别在概率题里会真的坑到人。

还有个容易混的：∈ 是「元素属于集合」，⊂ 是「集合是集合的一部分」。3 ∈ A 对，3 ⊂ A 错；{3} ⊂ A 对，{3} ∈ A 错（除非 A 里真的装着一个集合）。

0.2 　山脚

命题 · 一句话是真是假

Aussage · proposition

能判断真假的陈述句，叫命题。数学书上的每一句正经话都是命题——这是数学和其他所有文体最大的区别。

它为了解决什么才出现

「今天几号？」不是命题，因为问句没有真假。「这道题真难」也不是命题，因为「难」没有客观标准。但「17 是素数」是命题（真的），「所有偶数都能被 4 整除」也是命题（假的）。

为什么要专门强调这件事？因为它规定了数学的游戏规则：在数学里，一句话要么真要么假，没有「差不多」「大概」「某种意义上」。这种苛刻正是数学能层层往上垒的原因——每一块砖都必须是实心的，不然上面的全塌。

一个小例子

判断下面哪些是命题：

「7 + 5 = 12」　　　　　　是，而且真
「7 + 5 = 13」　　　　　　是，但假
「x + 5 = 12」　　　　　　不是——x 没定，真假就没定
「请把方程解出来」　　　　不是，祈使句
「√2 是无理数」　　　　　是，而且真（主线一证过了）

第三个特别值得留意。含未知数的式子本身没有真假，它要等到「对所有 x」或者「存在某个 x」这样的话补上去，才变成命题。这就是下一张卡片的内容。

上游集合（0.1），因为很多命题说的就是集合里的事
下游量词（0.3）· 蕴含（0.4）· 一切定理与证明 · 布尔代数与逻辑电路（主线六）
常见的坑

「这句话是假的」——这句话是真是假？真的话它就是假的，假的话它就是真的。它不是命题，是个悖论。这类自我指涉的句子在两千年里一直是个哲学玩具，直到二十世纪才发现它藏着数学的一个根本限制。那是这条主线山顶上的风景（见 0.9）。

「所有」和「存在」· 数学里最有用的不对称

Allquantor ∀ · Existenzquantor ∃

数学里几乎每个重要的句子，开头都藏着「所有」或者「存在」。而这两个词有一个极其有用的不对称：推翻其中一个，和推翻另一个，代价差了天上地下。

它为了解决什么才出现

「素数是奇数」——这句话什么意思？是说「所有素数都是奇数」（假的，2 就不是），还是「存在奇数的素数」（真的）？日常语言在这里含糊得要命，而数学不能含糊。所以专门造了两个符号：

∀  读作「对所有」　　∃  读作「存在」

写清楚之后，刚才那句话的两种意思就完全分开了，一个假一个真，再也混不了。

那个不对称

下面这张表值得单独记住。它是数学里最省力的杠杆之一，也直接解释了为什么「举反例」是那么强大的一招：

要证明它要推翻它
∀ 所有 x 都满足 P
「所有素数都是奇数」		 贵。必须对每一个 x 都成立，通常得给一个覆盖全部情况的一般性论证 便宜。找到一个反例就够了——比如 2
∃ 存在某个 x 满足 P
「存在偶数的素数」		 便宜。找到一个例子就够了——比如 2 贵。必须证明没有任何一个 x 满足，要扫遍全部

这张表的实用价值是：拿到一个不确定的命题，先花两分钟找反例。因为如果它是错的，反例往往几分钟就能找到；而如果找了半天找不到，你对它为什么成立的理解也会深很多，证明反而更好写了。工具箱里的招数三讲的就是这件事。

一个小例子：否定「所有」

「所有天鹅都是白的」的否定是什么？

不是「所有天鹅都不是白的」。是「存在一只天鹅不是白的」。

¬(∀x : P(x))　⟺　∃x : ¬P(x)
¬(∃x : P(x))　⟺　∀x : ¬P(x)

否定的时候，∀ 和 ∃ 互换，然后否定跑到里面去。这条规则在写反证法的时候天天要用——反证法第一步就是否定结论。

上游命题（0.2）· 集合（0.1）
下游反证法（0.6）· 极限的 ε-δ 定义（大学 Analysis，那里是三四个量词套在一起）· 「至少有一个解」「恰好有一个解」这类说法（主线二）
常见的坑

量词的顺序不能换。「每个人都有一个妈妈」和「有一个人是所有人的妈妈」，符号上只差了 ∀ 和 ∃ 的先后，意思天差地别。

∀ 人 x, ∃ 人 y : y 是 x 的妈妈　　（真）
∃ 人 y, ∀ 人 x : y 是 x 的妈妈　　（假）

这个坑在中学不太致命，但到了大学的极限定义会立刻要命——「连续」和「一致连续」的全部区别就在两个量词的顺序上。现在留个印象就好。

0.4 　山腰

「如果…那么」· 最容易被误解的连接词

Implikation · hinreichend und notwendig

A ⟹ B 的意思是「A 成立的话，B 就一定成立」。它不意味着反过来也对——而几乎所有人在几乎所有场合都会不小心把它反过来用。

它为了解决什么才出现

「下雨则地湿」是真的。「地湿则下雨」呢？不一定——可能是洒水车过去了。这两句话完全不同，但日常说话时人们经常滑来滑去。

数学不允许滑。所以从一个 A ⟹ B 出发，衍生出了三个亲戚，而它们的真假关系恰好构成一个非常漂亮的图案：

充分与必要：两个绕口的词

如果 A ⟹ B，那么：

A 是 B 的充分条件——有 A 就够了，足以保证 B。
B 是 A 的必要条件——想要 A 成立，必须先有 B。

中文这两个词很绕，德语反而直白：hinreichend 就是「够用了」，notwendig 就是「必需的」。用德语的字面意思去想，反而不容易错。

举例：「是正方形」⟹「是长方形」。所以「是正方形」对「是长方形」来说是充分的（是正方形就够了），「是长方形」对「是正方形」来说是必要的（不是长方形就绝不可能是正方形）。

如果两个方向都成立，就写 A ⟺ B，读作「当且仅当」（德语 genau dann, wenn）。这时候 A 和 B 是同一件事的两种说法。数学定义里的「当且仅当」几乎总是这个意思。

上游命题（0.2）· 否定与量词（0.3）
下游反证法（0.6）· 一切几何证明（主线三）· 方程的同解变形（主线二，每一步化简其实都在用 ⟺）· 条件概率（主线五，那里 P(B|A) 和蕴含长得像但完全不同）
常见的坑

解方程时的箭头方向。两边平方是 ⟹ 不是 ⟺——它可能凭空造出根来。所以解完之后必须把根代回原方程检验，那不是老师要求的仪式，是数学上真的必要的一步。反过来，两边同时加一个数是 ⟺，不会丢根也不会多根。

养成习惯：每化简一步，心里问一句「这一步是双向的吗」。

定义、公理、定理 · 各干什么

Definition · Axiom · Satz

数学书上的句子分几种，各有各的身份。搞混它们，读数学就永远隔着一层。

三种身份

定义（Definition）——给一个东西起名字。定义没有对错，只有好用不好用。「我们把只能被 1 和自己整除、且大于 1 的数叫素数」——你不能说这句话是错的，你只能说它有没有用。（而它极其有用，见主线一 1.6。）

公理（Axiom）——不加证明就接受的出发点。公理也不是被发现的真理，是被选出来的起点。你得从某个地方开始，不然就要无限往回追问。

定理（Satz）——从定义和公理出发，一步步推出来的结论。定理必须证明。这是唯一一种需要你付出劳动的句子。

另外还有两个跑龙套的：引理（Lemma）是为了证大定理而先证的小定理，推论（Korollar）是大定理证完之后顺手就掉下来的结果。

一个真实的故事：第五公设

欧几里得列了五条公理。前四条都短小明白（比如「两点之间可以画一条直线」），第五条却又长又拗口，说的大意是「过直线外一点，只能画一条平行线」。

两千年里，无数数学家觉得第五条太复杂，一定能从前四条推出来，于是拼命尝试。全部失败。

到十九世纪，有人换了个思路：如果它推不出来，那我干脆假设它是错的，看看会不会撞出矛盾。结果撞不出矛盾——反而长出了一整套自洽的新几何：球面上，过直线外一点一条平行线也画不出来；双曲面上，能画无穷多条。

这个故事之所以重要，是因为它彻底改变了人们对数学的理解：公理不是从天上抄下来的真理，是我们自己选的规则。选不同的规则，玩不同的游戏，而每个游戏都可能对应现实的某一面。

下游证明的方法（0.6）· 欧氏几何的公理体系（主线三）· 非欧几何（主线三山顶）· 概率的公理化（主线五）· 哥德尔不完备定理（0.9）
常见的坑

读书时把定义当定理来「理解」，是最常见的浪费。看到「定义：……」，不要问「为什么是这样」，要问「这么定义有什么好处」。前一个问题没有答案，后一个问题往往能让你一下看懂整节。

反过来，看到「定理：……」，就必须问「凭什么」——那儿是有证明的，而且证明才是内容本身。

德语原词

德国课本里的证明常常用固定格式开头：Voraussetzung（已知）、Behauptung（求证）、Beweis（证明），最后用 q.e.d. 或 ∎ 收尾。看到这三个词就知道自己读到哪一段了。

证明的五件武器

Beweismethoden

「证明」听起来玄，其实翻来覆去就是五种打法。知道有哪五种，卡住的时候就有地方可挑。

大多数时候的默认选择
一 · 直接证明

从已知出发，一步一步推到结论。每一步都必须有理由——用了哪条定义、哪条定理、哪条运算律。这是最朴素也最常用的一种。

要证「不可能」「唯一」「无穷多」
二 · 反证法

先假设结论错的，然后推出一个明显荒谬的东西，于是那个假设站不住。主线一里用了两次：素数无穷多、√2 不是分数。凡是要证「做不到」，先想它。

要推翻一个说法
三 · 举反例

只要找到一个不成立的例子，整句「所有…」就倒了。这是最便宜的武器（见 0.3 那张表）。拿到不确定的命题，先花两分钟试着推翻它。

情况天然分成几类
四 · 分情况讨论

把所有可能切成互不重叠、又能盖全的几块，一块一块证。关键是「不重不漏」——漏一种情况，整个证明就废了。带绝对值、带正负号的题几乎都要用它。

结论对每个正整数 n 都成立
五 · 数学归纳法

推倒第一块骨牌，再证明「每一块倒了下一块就会倒」。无穷多个命题，两步就全证完了。它太重要，下面单独给一张卡片。

正面难走的时候
加一招 · 走逆否

不证 A ⟹ B，改证 ¬B ⟹ ¬A。两者永远同真假（见 0.4 那张方阵图），而后者常常好走得多。严格说它是反证法的近亲。

常见的坑

「举例子」不是证明。验证了 100 个数都符合，也证明不了「所有数都符合」。例子只能推翻全称命题，不能证明它。这是初学者最常犯、也最要命的一个错。

反过来：证明「存在」的时候，举出一个例子就是完整的证明。两者的区别完全在于那句话开头是 ∀ 还是 ∃。回去看 0.3 那张表。

数学归纳法 · 一排无穷长的多米诺

vollständige Induktion

要证明一件事对每一个正整数都成立，而正整数有无穷多个。归纳法用两步就干完了这件看起来不可能的事。

它为什么管用

想象一排无穷长的多米诺骨牌。你想让它们全倒，需要确认两件事，而且只需要这两件：

第一，第一块确实倒了。（归纳起点，Induktionsanfang）
第二，不管是第几块，只要它倒了，它后面那块就一定会倒。（归纳步骤，Induktionsschritt）

这两条都成立的话，全部无穷多块必然全倒——第一块倒推倒第二块，第二块推倒第三块，一直传下去，没有任何一块能幸免。你没有一块一块去推，但你确实证明了它们都会倒。

一个完整的例子
证明：1 + 2 + 3 + … + n = n(n+1)/2

起点（n = 1）：左边是 1，右边是 1·2/2 = 1。相等，第一块倒了。

步骤：假设对某个 n = k 成立，也就是

1 + 2 + … + k = k(k+1)/2

现在看 n = k+1。左边比刚才多加了一个 k+1：

1 + 2 + … + k + (k+1) = k(k+1)/2 + (k+1)

右边提出公因式 (k+1)：

= (k+1)·(k/2 + 1) = (k+1)(k+2)/2

而这正是把 n = k+1 代进原公式该有的样子。所以第 k 块倒了，第 k+1 块就一定倒。

两步都完成，公式对所有正整数 n 成立。∎

注意这个公式你已经见过两次了：工具箱示范二用它算 n 条直线分平面，主线一 1.3 提到过高斯的故事。现在它终于被真正证明了。前两次都是「看出规律」，这一次是「知道它必然成立」——这就是这条主线存在的意义。

上游量词（0.3）· 蕴含（0.4）· 自然数（主线一 1.1）
下游数列与递推（主线六）· 二项式定理（主线二）· 递归算法的正确性（主线六）· 几乎所有关于「对任意 n」的结论
常见的坑

「这不是循环论证吗？我怎么能假设要证的东西成立？」——这是每个人第一次学归纳法都会有的疑问，而且问得很好。

答案是：你假设的不是「结论对所有 n 成立」，而是「结论对某一个 n 成立」，然后去证明它会传给下一个。你证明的是一条传递规则，不是结论本身。规则加上起点，才推出结论。

另一个坑：起点不能忘。只证了传递规则、没证第一块倒，等于排好了一整排骨牌但没人去推——它们会一直立着。这一步只要一行，但漏了整个证明就无效。

符号是怎么来的 · 一张换气的卡片

mathematische Notation

数学看起来满纸符号，可这些符号绝大多数还不到五百岁。在那之前，数学是用大白话写的。

用文字做数学是什么感觉

十六世纪的一道方程，写出来大概长这样：

「求一数，其立方与其六倍之和，等于二十。」

翻译成现在的写法就是 x³ + 6x = 20。

读一句还行，但整页整页这么写，人是没法在脑子里操作的。符号的发明，本质上是把思考的负担从脑子挪到纸上。这跟工具箱里「招数一：画出来」是同一个道理，只是规模大得多。

几个符号的来历
  • + 和 −：十五世纪德国商人的仓库记号，箱子装多了画一横加一竖，少了画一横。后来被数学书借走。
  • =：1557 年，英国人 Robert Recorde 发明。他的理由很可爱：没有两样东西能比两条平行线更相等。在那之前人们写「aequalis」或者干脆写「等于」。
  • √：可能来自拉丁文 radix（根）的首字母 r 写快了变形而来。上面那条横线是后加的，用来圈住被开方的范围。
  • x 表示未知数：笛卡尔的习惯。他用字母表末尾的 x, y, z 表示未知的，开头的 a, b, c 表示已知的——这个约定我们今天还在用，四百年没变。
  • ∑ 和 ∫：分别是希腊字母 Sigma（Summe 的 S）和拉长的字母 s（summa 的 s）。都是「求和」的意思，一个离散一个连续。
好记号会替你思考

这不是修辞。牛顿和莱布尼茨各自独立发明了微积分，但用了不同的记号：牛顿在字母上点一个点，莱布尼茨写成 dy/dx。

结果是：莱布尼茨的记号长得像一个分数，于是链式法则写出来就像分数约分一样自然。英国数学界出于爱国情绪坚持用牛顿的点，落后了欧洲大陆整整一百年。

选对符号，一半的思考是记号自己完成的。这也是为什么值得花力气把式子写整齐——写得清楚，往往就想得清楚。

山顶与远方

这条主线的山顶特别陡，因为它通向的是数学对自己的反思。下面这几段同样不要求懂，知道有这回事就够了——但它们大概是整本册子里最值得在某个晚上发一会儿呆的部分。

把「推理」本身变成数学对象

如果证明有固定的规则，那规则本身能不能拿来研究？十九世纪末，人们开始把命题写成符号、把推理步骤写成运算，于是「逻辑」从哲学变成了数学的一个分支，叫数理逻辑。

这件事有个意外的副产品：既然推理可以形式化成符号操作，那机器就能做。今天的计算机、编程语言、乃至芯片里的逻辑门，全都是这条路上长出来的。0.2 那张卡片里的「真」和「假」，就是后来的 1 和 0。

集合论差点塌了：罗素悖论

0.1 说集合是数学的地基。1901 年罗素问了一个简单得要命的问题，差点把地基掀了：

「所有不包含自己的集合」组成的集合，包不包含它自己？

包含的话，按定义它就不该包含自己；不包含的话，按定义它就该包含自己。怎么走都是矛盾。通俗版是理发师悖论：村里的理发师给且只给「所有不给自己刮胡子的人」刮胡子，那他给不给自己刮？

这个悖论逼着数学家重建了集合论的地基（现在用的叫 ZFC 公理系统），不再允许「随便什么条件都能凑成一个集合」。地基补好了，但所有人都吓出了一身汗。

哥德尔：有些真话，永远证不出来

罗素之后，希尔伯特提出一个宏伟计划：给全部数学找一套公理，证明它既不会自相矛盾，又能证明出所有真命题。这是数学史上最有野心的工程。

1931 年，二十五岁的哥德尔证明了它不可能。他的不完备定理说：任何一个足够强、且不自相矛盾的公理系统里，一定存在真的、但在这个系统里证不出来的命题。而且系统还没法证明自己不矛盾。

他的办法妙到近乎恶作剧：给每个命题编一个号，然后构造出一句话，翻译过来意思是「这句话在本系统内证不出来」。跟 0.2 那个「这句话是假的」是远房亲戚——只不过哥德尔把它变成了严格的数学。

这不是坏消息，是深刻的消息。它划出了形式推理的边界，而知道边界在哪儿，本身就是巨大的进步。

机器开始参与证明了

1976 年，四色定理（任何地图用四种颜色就能染好，相邻区域不同色）被证明了——但那个证明把问题归结成一千多种情况，靠计算机逐个检查。当时数学界吵翻了：一个人类无法通读的证明，算不算证明？

今天这已经不是问题了。Lean、Coq 这类证明助手可以逐行检查一个证明有没有漏洞，严格程度远超人类审稿人；一些顶尖数学家正在把重要定理一条条形式化进去。AI 也开始参与——不是替人证明，而是帮着搜索可能的路径。

某种意义上，这条主线正在他这一代人手里活起来。

这条路在大学叫什么

  • Logik（逻辑）——把 0.2 到 0.4 严格化，通常是数学系或计算机系一年级
  • Mengenlehre（集合论）——0.1 的正式展开，以及罗素悖论之后的重建
  • Beweistheorie（证明论）——研究证明本身的结构，哥德尔的地盘
  • Berechenbarkeitstheorie（可计算性理论）——「什么问题机器算不出来」，和主线六接上

一道也不用算。答得上来，这一章就真的读完了。

  1. 「定义」和「定理」，哪一个可以问「它是对的吗」？哪一个不能？为什么？
