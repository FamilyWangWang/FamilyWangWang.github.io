工具箱

§ 2工具箱

前面两节是地图，这一节是走路的姿势。地图管你去哪儿，这一节管两件事：路上卡住了怎么办，以及怎么让学过的东西真的留在脑子里。

这一节不分海拔。方法论不看你学到哪儿，从今天一直到大学，用的都是同一套。而且它是整本册子里见效最快的部分——今晚做作业就用得上。

上半 · 解题：卡住的时候怎么办

先说一件最要紧的事：卡住是正常状态，不是出问题的信号。

这句话听起来像安慰，其实是关于数学的一个事实描述。职业数学家解决一个问题，卡住的时间占九成以上，顺畅推进的时间不到一成。区别只在于，他们不把「卡住」当成「我不行」，而当成「现在进入正常工作状态了」。

真正会出问题的，是卡住之后什么都不做——干瞪着题目十分钟，然后放弃或者去抄答案。下面这一整节，讲的就是卡住之后手上该有哪些动作。

四步骨架

这套框架来自数学家波利亚（George Pólya）1945 年的一本小书《怎样解题》。八十年过去了，没人做出过更好的版本。它简单到可以背下来：

九招：每一招都有名字

下面这九招，是第二步「拟定计划」时手上真正能掏的东西。给招数起名字很重要——脑子里有名字的东西才调得出来。卡住的时候，就从头到尾把这九个名字过一遍，看哪个能接上。

题里有关系，脑子转不过来
一 · 画出来

能画就画。数轴、线段图、表格、树形图、方框，都算。眼睛能同时看见五样东西，脑子一次只能拿住两三样。画图不是为了好看，是为了把负担从脑子挪到纸上。

题里有 n，或者数字大得吓人
二 · 先试小数字

问的是 100 个？先做 2 个、3 个、4 个。问的是 n 条直线？先画 1 条、2 条。规律藏在小情况里，大情况只是把它放大。这一招在下面的示范二里唱主角。

不确定结论对不对
三 · 找特例和极端

把某个量推到最大、最小、等于 0、等于 1，看会发生什么。一个反例就能推翻一个猜想，而找反例往往比证明容易得多。先试着推翻它，推不翻再去证。

知道要到哪儿，不知道从哪儿起步
四 · 倒着走

从想要的结论出发，问「什么东西成立的话，它就成立了」，一路往回推到已知条件。几何证明题有一半是这么想出来的，只是写下来的时候又倒回正着写。

完全没有头绪
五 · 先解一个更容易的

把题目改简单：少一个条件、少一个维度、换成整数、换成更小的数。解出那个简单版本之后，往往能看见原题的门在哪儿。就算看不见，你至少动起来了。

题里有个「不知道多少」的量
六 · 给它起个名字

不知道就设成 x。这一步看着平淡，其实是代数最大的发明：你不需要知道它是多少，就能拿它做运算。设完之后，题目里的每句话都翻译成一个含 x 的式子。

要证明某件事「不可能」
七 · 找不变量

找一样东西，不管你怎么操作它都不变。如果起点和终点这样东西不一样，那就永远到不了。这是证明「做不到」最锋利的武器，示范三整个建立在这一招上。

要证两个式子相等
八 · 数两次

同一堆东西，用两种不同的办法去数，两个结果必然相等——于是你白得一个等式。组合数学里一半的漂亮恒等式都是这么来的，而且完全不需要计算。

读完题没有任何感觉
九 · 换句话说

合上书，用自己的话把题目讲一遍，像讲给一个没看过题的人听。讲不出来就说明还没读懂，这时候算什么都是白算。很多题在复述的过程中就自己解开了。

卡住了，按这张图走

这一页大概是整本册子里会被翻得最烂的一页。卡住的那一刻先别慌，从最上面往下走：

算完之后：四把尺子

算出答案不等于做完。下面四件事加起来不超过一分钟，能挡掉绝大多数低级失分：

  • 量级对不对。算出一个人身高 2000 米、一个班有 0.7 个人、概率等于 1.4，就不用往下检查了，一定错了。这一招最快，先用它。
  • 单位对不对。问面积，答案的单位应该是平方；问速度，应该是「长度除以时间」。单位不对，说明中间某一步乘除反了。
  • 代个特例试试。推出一个含 n 的公式，就代 n = 1 或 n = 2 进去，跟手算的结果比一比。公式推错的话，这一步几乎百分百能抓出来。
  • 反着验一遍。解方程解出 x = 3，就把 3 代回原来那个方程——注意是原方程，不是你化简过的那一步，不然错在化简你就查不出来。

三道示范

光看招数清单学不会招数，得看它被用出来。下面三道题一道比一道难，我把每一步的犹豫和试错都写下来，包括走了弯路的部分——因为真实的解题过程本来就长这样，教科书上那种一步到位的写法是整理过的结果，不是思考的过程。

示范一 · 现在就能做

一个 8×8 的棋盘上，一共能数出多少个正方形？

① 理解

先问清楚：题目问的是所有正方形，不只是最小的那些格子。2×2 的算不算？算。整个棋盘本身 8×8 的算不算？也算。

所以答案肯定比 64 大。这一步花了十秒，但如果跳过，后面全白做。

② 计划
招数 二

8×8 直接数会乱。先试小数字：从 1×1 的棋盘开始。

1×1 棋盘：1 个正方形。
2×2 棋盘：4 个小的，加 1 个整体，共 5 个。
3×3 棋盘：9 个小的 + 4 个 2×2 的 + 1 个 3×3 的 = 14 个。

数列是 1, 5, 14。看出来了吗——1，1+4，1+4+9。是平方数在累加。

③ 执行

但光看出规律不够，得知道为什么。在 3×3 棋盘上数 2×2 的正方形：它的左上角能放在哪儿？只能放在左上角那个 2×2 的区域里，所以有 2×2 = 4 个位置。

推广开：在 n×n 棋盘上数 k×k 的正方形，左上角有 (n−k+1) 行、(n−k+1) 列可以放，所以有 (n−k+1)² 个。

于是 8×8 棋盘上：

1×1 的有 8² = 64 个
2×2 的有 7² = 49 个
…… 一路到 ……
8×8 的有 1² = 1 个

总数 = 1² + 2² + … + 8² = 204

④ 回顾

用第三把尺子验一下：把公式用在 n = 2 上，得 1² + 2² = 5，跟前面手数的 5 对上了。放心了。

这道题真正教了什么？不是 204 这个数，是「问左上角能放在哪儿」这个转换——把「数正方形」变成了「数位置」。数东西数不清的时候，换个东西数，这个念头以后会反复用到。

示范二 · 要想一会儿

n 条直线，最多能把平面分成几块？

① 理解
招数 九

「最多」这两个字是关键，说明摆法有讲究。什么摆法块数最多？直觉上：别让两条线平行（平行就少一个交点），也别让三条线交于同一点（那样浪费）。先把这条直觉记下来，等会儿要用。

② 计划
招数 二

先试小数字，而且要动手画。

③ 执行

数列是 1, 2, 4, 7。差是 1, 2, 3。猜测：第 n 条线加上去，会多分出 n 块。

但猜测不等于知道。为什么第 n 条线正好多分出 n 块？这才是这道题的心脏。

画一下就清楚了：新的第 n 条线，跟前面 n−1 条各交一次（这就是刚才那句「别平行、别三线共点」在起作用），所以它身上有 n−1 个交点。n−1 个点把这条直线切成了 n 段。而每一段都从中间劈开了一块旧区域，把它变成两块——所以正好多出 n 块。

块数 = 1 + (1 + 2 + 3 + … + n)

括号里就是 1 到 n 求和，等于 n(n+1)/2。所以：

最多分成   1 + n(n+1)/2   块

④ 回顾

验一下：n = 3 代进去得 1 + 6 = 7，跟画出来的一样。n = 0 得 1，也对。

这道题真正教了什么？三件事。第一，递推——不去正面硬算第 n 步，而是搞清楚「从第 n−1 步到第 n 步多了什么」。第二，看出规律只是一半，说清楚为什么是那个规律才是另一半，而且是更值钱的一半。第三，注意最后那个 n(n+1)/2——它和示范一里的平方和一样，都是数列求和。同一个工具在两道完全不同的题里出现，这就是「体系」两个字的意思。

示范三 · 看着不可能，换个角度就破了

一个 8×8 的棋盘，去掉对角的两个角格，剩下 62 格。能不能用 31 张 1×2 的骨牌把它铺满？（骨牌不能重叠、不能出界，横竖都行。）

① 理解

62 格，31 张骨牌，每张盖 2 格，数量正好对得上。所以「格子数不够」这条路堵死了——如果不行，一定是别的原因。

② 第一次尝试
（走了弯路）

先老老实实试着铺。铺了几分钟，每次都在最后剩下两个不相邻的格子。

试了七八种铺法都失败，于是开始怀疑：会不会根本就不可能？

这个念头的转折很重要。「证明能做到」只要给出一个例子，「证明做不到」得排除所有可能——后者需要完全不同的武器。这时候就该想起招数七。

③ 招数 七
找不变量

要找一样「不管怎么铺都不变」的东西。棋盘天生是黑白相间的，那就利用起来：

关键观察：一张 1×2 的骨牌，不管横放竖放，永远盖住一黑一白。相邻的格子颜色必定不同，这是棋盘的定义决定的，逃不掉。

所以 31 张骨牌一定盖住 31 个黑格和 31 个白格。这就是那个不变量。

④ 收网

对角的两个角格，在棋盘上颜色是相同的（不信可以看看真棋盘的 a1 和 h8）。去掉它们，就等于一口气去掉了两个同色格。

于是剩下的 62 格里，一种颜色 30 个，另一种颜色 32 个。

可是 31 张骨牌必须盖住 31 个 + 31 个。30 ≠ 31。所以不可能。不是我们不够聪明，是它压根不存在。∎

⑤ 回顾

回头看，整道题的全部难度都在想到去染色这一下。染色跟题目字面上一个字都不沾——题目里根本没提颜色。是解题的人自己往图上加了一层信息，而这层信息恰好是不变的。

这道题真正教了什么？三件事。第一，「证明做不到」和「证明做得到」是两种完全不同的活儿，前者几乎总是要找不变量。第二，你可以给题目添加它本来没有的结构——染色、编号、分组、取余数，都是这类动作。第三，也是最重要的一点：试了很多次都失败，本身就是一条重要的信息。它是提醒你换武器的信号，不是你笨的证据。

下半 · 学习：数学是垒起来的

解题讲的是「这一道题怎么办」，这一半讲的是「怎么让学过的东西不跑掉」。两件事都重要，但下面这一半更少有人认真讲。

数学跟历史、生物那类科目有一个结构性的区别：它是垒的，不是摊的。历史课这一章没听懂，下一章照样能听。数学不行——分数没弄明白，斜率就是空的；斜率是空的，导数就没有落脚点。数学欠的债会连本带利。

这个区别决定了下面全部的方法。因为知识是垒起来的，所以「哪里塌了」比「学了多少」重要得多；也因为它是垒起来的，回头补一块地基的收益，往往比往上多垒三层还大。

最省力的一招：合上书

如果这一整节只能记住一句话，记这句：看懂了不等于学会了。

翻着书看例题，每一步都点头，这叫「被动重读」。它给人一种流畅感，让人以为自己会了——但那个流畅感来自书，不是来自你。真正的检验只有一个：合上书，拿张白纸，自己从头做一遍。

这一招在心理学里叫「主动回忆」，几十年的实验反复证明它的效果远超反复看。而且它有个附带好处：你会立刻知道自己卡在哪一步，而不是模模糊糊觉得「大概都会」。

它的唯一缺点是难受。合上书的那一刻会感到明显的吃力，而反复看书很舒服。这个难受本身就是学习正在发生的信号——舒服的那种复习，基本上什么都没发生。

隔几天再来一次

今天学会的东西，如果一直不碰，几天后就开始漏。但如果在快要忘掉的时候再捡一次，它待得住的时间会大幅拉长；再隔更久捡一次，就更长。这叫间隔重复。

具体到做法不用搞复杂：新学的内容，当天、隔两三天、隔一周各花五分钟合上书回忆一遍，比考试前一晚花三小时管用得多。关键是那三次都必须是「合上书回忆」，不是「翻开书再看一遍」。

别把同一类题连着刷

一口气做二十道一模一样类型的题，感觉很好——越做越快，越做越顺。但那个「顺」是假的：第二题开始你就不再判断该用什么方法了，因为你知道跟第一题一样。而考试里最难的一步恰恰是判断该用哪招。

把不同类型的题混着做，会明显更慢、更容易错、感觉更差——然后在考试里表现得明显更好。这个反差在教育研究里出现过很多次，靠谱得让人不太舒服。

实用版本：作业按类型做完之后，隔几天从前面几章随机挑五道混着再做一遍。五道就够。

错题：先分诊，再治

「整理错题本」几乎人人听过，但大多数错题本没用，因为它们把所有错题当成同一种病。做错至少有三种完全不同的原因，治法互不通用。抄一遍正确解法只对其中一种有效。

怎么读一本数学书

数学书不能像小说那样读。一页小说可能三分钟，一页数学书花一小时是正常的，而且不代表你慢。具体做法：

  • 手里必须有笔。不动笔读数学，跟不动嘴读外语差不多，看着在学，其实没有。
  • 看到定理，先合上书自己试着证一下。哪怕只试两分钟、根本证不出来也值——因为你会知道难在哪儿，然后书上的证明就从「一串步骤」变成了「原来这里是这么绕过去的」。
  • 看到例子，把数字改小自己再做一遍。书上用 n = 100，你就用 n = 3 亲手算一遍。
  • 看到「显然」「容易看出」，停下来。这两个词是作者省略了步骤的信号，而省略的地方往往正是关键。补出来，或者标个记号回头问。
  • 每读完一节，合上书说一句「这一节在讲什么」。说不出来就是没读完，倒回去。

什么时候可以看答案

看答案不可耻，早看才可耻。判断标准很简单：你有没有真的卡满，而且把九招都过了一遍。过了这一关，看答案是高效学习；没过就看，是在花时间买一个「我会了」的错觉。

还有一件更要紧的事：看完答案之后必须再做一步，否则前面全白搭。合上答案，隔至少半小时——最好是第二天——从空白纸开始自己重做一遍。

因为「看懂别人的解法」和「自己想得出解法」在大脑里是两件不同的事。只做前者，下次遇到同类题还是不会。这一步不做，看答案就真的等于抄答案。

计算器、CAS 和 AI

这一节在别的书上找不到，因为它太新了。但它可能是这一代人学数学面对的最大变量，所以值得说清楚。

先说底层逻辑。数学能力是在「卡住—挣扎—自己出来」这段过程里长出来的，不是在「看到正确答案」的那一刻长出来的。任何工具，只要它让你跳过挣扎那一段，它就在削弱你；只要它让你挣扎得更有效，它就在帮你。计算器、CAS、AI，全部适用这一条。

这样用，是加速
  • 「我卡在这一步了，别告诉我答案，给我一个提示就好」
  • 「我是这么想的（写出你的思路），这个思路有问题吗？」——让它当审稿人，不当作者
  • 「这个概念当初是为了解决什么才被发明出来的？」——问动机。这恰恰是教科书最缺、AI 最擅长的
  • 「再给我三道同类型但换了花样的题」——当出题机用
  • 「这个我没听懂，换一种完全不同的方式解释一遍」
  • 「我这个证明有没有漏洞？」——让它挑刺
  • 用 CAS 或计算器验算自己手算的结果，或者处理那些又长又没有思维含量的数值计算
这样用，是自毁
  • 题目拍进去，抄答案。这是最直接的一种，也是最没有争议的一种
  • 还没卡满二十分钟就去问
  • 问完之后不合上重做——「看懂了」和「会了」之间隔着一整条河
  • 让它替你做整个作业。作业的目的从来不是交上去那张纸，而是你写它时脑子里发生的事
  • 凡是需要手上功夫的地方全交给 CAS——因数分解、通分、求导这类基本操作，手不熟，后面复杂问题里就腾不出脑子想别的
  • 相信它说的每一步而不自己验一遍
最后这一条要单独强调：AI 会用极其自信的语气说错话，数学上尤其如此。它算错的时候，看起来和算对时一模一样——没有犹豫，没有提示，格式一样漂亮。所以凡是它给出的推理，你都得能自己验一遍。

而这件事反过来其实是好消息：「检查别人的推理有没有漏洞」本身就是一项一流的数学能力，而且过去很难练——你手边哪有那么多带着错误的推理可以查？现在有了。把 AI 当成一个知识极广、偶尔会自信地胡说八道的同学，你的任务是听懂它、并且抓住它的错。这么用，它是你能有的最好的陪练。

一句话版本：让工具帮你想得更远，别让它替你想。
