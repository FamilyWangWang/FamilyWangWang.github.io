附页

可选附页考试视角

这本册子的正文里，一个字都没提过考试。那是故意的——知识体系不该被考纲牵着走，而且考纲每几年就改一次，写进去只会让整本册子过时得更快。

但考试是真实存在的，而且确实有一些跟数学本身无关、纯属应试技术的东西是有用的。这一页把它们单独放在这里：要用就翻，不用就当它不存在。以后要改，也只改这一页。

另外说明一句：下面写的都是各国中学数学考试的普遍规律，不针对任何一个具体的考试制度。具体的题型格式、允许用什么计算器、哪些内容在考纲内——这些必须去查他自己学校当年的官方说明，任何第三方资料都可能过期。

一分量地图 · 力气该往哪儿使

中学后半程的数学，分值分布相当不均。知道哪几块最重，比平均用力有效得多。

一个实用的判断：如果一道大题你「思路全对但答案错了」，问题几乎总在地基层——符号、运算顺序、代数变形、正负号。这类错误不靠复习那一章能修好，得靠 工具箱里的错题分诊。

二丢分处总索引

下面这份清单，是把七条主线里每一张「常见的坑」全部抽出来排在一起的结果。这大概是这一页最有用的部分——考前扫一遍，比重做十道题快得多。每条后面的编号可以跳回原卡片看细节。

主线零 · 语言与证明

  • ∈ 和 ⊂ 别混。3 ∈ A 对，3 ⊂ A 错。0.1
  • 否定「所有」得到的是「存在一个不」，不是「所有都不」。写反证法第一步时最容易栽。0.3
  • 量词顺序不能换。「每人都有妈妈」≠「有个人是所有人的妈妈」。0.3
  • 举例子不是证明。验证一百个数也证不了「所有」；但证「存在」时举一个例子就是完整证明。0.6
  • 归纳法的起点不能省。只证传递规则、忘了第一块，整个证明无效。0.7

主线一 · 数与数系

  • −3² 和 (−3)² 不一样（−9 和 +9）。乘方比取负先算。计算器上按错更常见。1.4
  • 绝对值不是「去掉负号」，是「离 0 多远」。带字母时必须分情况讨论。1.4
  • 分母不能为 0——是没有定义，不是等于无穷。求定义域时别漏。1.5
  • 运算顺序：8 − 3 + 2 = 7，不是 3。同级从左到右。1.3
  • log(a+b) ≠ log a + log b。对数把乘法变加法，不是加法。1.8
  • √9 = 3 是有理数。开方不一定产生无理数。1.7

主线二 · 代数与结构

  • (a+b)² ≠ a² + b²。同族的还有 √(a+b)、1/(a+b)、log(a+b)。这是全世界最高频的代数错误。2.2
  • 两边平方会造出假根，除以含 x 的式子会丢根。所以必须代回原方程检验——不是代回化简后的某一步。2.3
  • 用求根公式前先整理成标准形式。x²+3x=10 里的 q 是 −10 不是 10。2.5
  • 开方那一步必须带 ±。丢负根是二次方程题第一大失分点。2.5
  • 零积法则只对 0 成立。(x−1)(x−2)=6 不能拆。2.6
  • 除以含字母的系数要分情况讨论（正、负、零三种）。2.4
  • 加减消元时整条方程都要乘，右边那个常数最容易漏。2.8

主线三 · 形与空间

  • 同位角、内错角相等的前提是两线平行。图看起来平行不算数，题目得给。3.1
  • 写全等式时顶点顺序要对应。△ABC ≅ △DEF 意味着 A↔D、B↔E、C↔F，写乱后面全错。3.2
  • 放大两倍，面积是四倍、体积是八倍。「面积也放大两倍」是最普遍的几何直觉错误。3.3
  • c 永远是斜边（直角对面那条）。图形转过角度、字母换了名字时最容易套错。3.4
  • 计算器的 DEG / RAD 模式。模式不对答案会离谱，而且它不会报错。三角题动手前先看一眼。3.6
  • 正弦定理求角时可能有两个解（锐角和钝角）。这跟 SsW 的歧义是同一件事。3.6
  • 位置向量和方向向量身份不同。写 x⃗ = p⃗ + t·u⃗ 时别搞混谁是起点谁是方向。3.8

主线四 · 函数与变化

  • 算斜率时 Δy 在上、Δx 在下。用单位检查：路程对时间的斜率单位是米/秒。4.2
  • f(2x) 是横向压缩不是拉伸。想不清就跟着一个具体的点走一遍。4.4
  • f′ = 0 是极值的必要条件，不是充分条件。y = x³ 在 0 处导数为 0 但没有极值。4.7
  • 求区间上的最值别忘了检查两个端点。最大值完全可能在边界上，那里导数不为 0。这是极值题第一大失分点。4.7
  • x 轴下方的面积算负的。求实际面积要先找零点、分段、取绝对值。4.8
  • 求原函数别忘 + C。4.9
  • 应用题算出的答案要检查现实意义。半径为负、需要 −3 个工人，是数学解不是现实解。4.7

主线五 · 概率与统计

  • 「至少有一个」几乎永远该反着算：先求「一个都没有」，再用 1 减。5.2
  • 「独立」和「互斥」不是一回事，而且几乎相反。互斥用加法，独立用乘法。5.4
  • P(A|B) 和 P(B|A) 完全是两回事。这一个坑在这本册子里出现三次，代价一次比一次大。5.4 / 5.5 / 5.9
  • 用二项分布前检查三个前提：只有两种结果、概率不变、各次独立。「不放回」就不独立了。5.7
  • p 值不是「假设为真的概率」。它是「假如零假设为真，出现这么极端数据的概率」。5.9
  • 期望值算出来掷不出来（骰子期望 3.5）。它说的是长期平均。5.6

主线六 · 七 · 应用与计算

  • 看到几项就断定规律，是猜想不是结论。6.1
  • 百分比先问「相对于什么」。涨 50% 再跌 50% 得到 75 不是 100。7.4
  • 百分点 ≠ 百分比。4% 到 6% 是涨了 2 个百分点，也是涨了 50%。7.4
  • 单位不对说明中间某步乘除反了。问面积答案必须是平方。7.2
  • 建模题算完必须翻译回现实并检验。没有单位的数字不是答案。7.1

三考前怎么用这本册子

这本册子不是复习资料，但它有一个复习资料给不了的用处：快速定位哪里塌了。

时间紧的时候的优先顺序：先修地基（那条虚线里的东西），再修分值最重的那一块，最后才是查漏补缺。反过来做，是最常见的低效复习。

四考场上的操作

这一节跟数学没关系，纯粹是技术。但它每次能捡回来的分，往往比多复习一星期还多。

开头五分钟

  • 先把整份卷子翻一遍。知道有几道大题、分值怎么分布、哪道看起来最顺手。这五分钟不是浪费，是给自己一张地图。
  • 从最有把握的题开始，不必按顺序。开头顺了，后面思路会更清楚；开头卡死了，会一路慌到结束。
  • 按分值分配时间。一道 8 分的题花掉三分之一的时间，通常是判断失误——那些分再值钱，也不比另外两道 6 分的加起来多。

做题时

  • 读完题先复述一遍（工具箱招数九）。读错题是三种错误里最容易改掉、也最不该犯的一种。
  • 把已知条件一条条圈出来，尤其是那种藏在句子中间的（「其中 x 为正整数」「假设两条线平行」）。出题人把条件藏起来，就是想看你读不读得出来。
  • 不会做也要把已知和思路写下来。大多数评分标准是分步给分的——写出正确的公式、正确的第一步，通常就有分。空白一定是零分，写错了不一定。
  • 每步单独一行，别在脑子里跳步。跳步省下的三十秒，会在检查时以三分钟的代价还回来。
  • 卡住就先跳过，做个记号。坐在那儿死磕是考场上最贵的行为。（工具箱那张「卡住了怎么办」的决策树，考场版是：过一遍九招，两分钟内没头绪就走。）

交卷前的四把尺子

这是工具箱里那四条，考场版：

  • 量级——人高 2000 米、概率 1.4、班里 0.7 个人，不用往下查了。
  • 单位——面积要平方，速度要「长度÷时间」。
  • 特例——推出含 n 的公式，代 n = 1 或 2 试一下。
  • 回代——解出的根代回原方程。

这四件事加起来不到一分钟，但它们挡掉的是那种「明明会做却拿不到分」的错误——而那类错误在总失分里的占比，通常比「真的不会」还高。

工具的使用纪律

  • 考前确认清楚这次允许用什么（哪种计算器、能不能用公式表、有没有不许用工具的部分）。这个只能查学校当年的官方说明，别问别人。
  • 平时就用考试时那台机器。考场上现学按键位置，是白送的失分。
  • 三角函数先看 DEG / RAD。再说一遍，因为它不报错。
  • 计算器算出来的也要过一遍量级。按错一个键，机器不会替你发现。

五关于刷题和押题

刷题有用，但刷法比刷量重要得多。而押题基本是低效策略，理由下面说。

刷题的正确刷法

  • 别把同一类题连着做二十道。越做越顺，但那个「顺」是假的——从第二题开始你就不再判断该用什么方法了，而考试里最难的一步恰恰是判断用哪招。混着做会更慢、更容易错、感觉更差，然后在考试里表现明显更好。（工具箱：交错练习）
  • 做完对答案之后，必须合上书重做一遍。看懂别人的解法和自己想得出解法，在大脑里是两件事。这一步不做，对答案就等于抄答案。
  • 错题先分诊再治。「不会」「会了算错」「看错题」是三种病，要用三种完全不同的药。笼统地「下次细心点」等于没治。（工具箱：错题分诊）
  • 做过的真题隔两周再做一遍。第一遍测的是会不会，第二遍测的才是记不记得住。

为什么押题不划算

押题的逻辑是「猜中考什么，只准备那部分」。它在两个地方站不住：

  • 命题人也知道大家在押题。越是被广泛押中的题型，越容易被换个包装。而换了包装之后，只背了套路的人就完全接不住。
  • 数学是垒起来的。就算真押中了那一章，底下的地基没修，那一章的题照样做不对——这是这本册子从头到尾在说的那件事。

更划算的做法是反过来：与其猜考什么，不如确保没有塌方的地方。地基齐了，考什么都接得住；地基塌着，押中了也拿不到分。

最后一句，也是这一页唯一一句关于心态的话：考试测的是「那一天的你」，不是「你是谁」。它值得认真对待，但不值得用来定义自己。这本册子里那些让人觉得有意思的东西——补洞造出的复数、伽罗瓦二十岁写下的手稿、9% 而不是 99%、七桥问题里被扔掉的那些细节——一样都不会出现在任何一张卷子上，而它们才是数学真正的样子。
