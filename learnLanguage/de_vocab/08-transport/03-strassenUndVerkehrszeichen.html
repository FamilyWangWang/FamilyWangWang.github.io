08-3 道路与交通标志（Straßen und Verkehrszeichen）

本组第 3 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 3 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

先识别车道、路口和人行设施，再看主标志及附加标牌。读懂结构之后，Vorfahrt与Vorrang的不同范围才容易落到具体情境里。

道路语言分三层：道路结构、标志类型和具体通行规则。Vorfahrt 主要用于交叉口不同道路之间，Vorrang 范围更广；Haltlinie 指示必须停车的位置，而停车义务来自相应灯号、标志或指令。看标志时还要把主标志和 Zusatzzeichen 一起理解。

精讲

  1. Straße / Fahrbahn：整条道路空间 / 车辆行驶的路面部分。

  2. Fahrstreifen / Spur：法规和正式用语的车道 / 日常常用说法。

  3. Seitenstreifen / Gehweg：主车道侧带 / 行人道路部分。

  4. Kreuzung / Einmündung：道路穿过相交 / 一条路接入另一条。

  5. Autobahn / Landstraße：出入口受控高速道路 / 城外普通道路。

  6. Einbahnstraße / Sackgasse：Einbahnstraße限制行驶方向，Sackgasse通常说一般车辆不能贯通；行人或骑车人是否可通过，还要看附加图示和实际通道。

  7. Gefälle / Steigung：向下坡度 / 向上坡度。

  8. Verkehrszeichen / Verkehrsschild：正式法规用语 / 日常宽泛说法。

  9. Gefahrzeichen / Vorschriftzeichen / Richtzeichen：分别突出危险警示、命令禁令与通行指引；Richtzeichen也可带强制规定，不能把名称理解成一律只是建议。

  10. Ampel / Lichtzeichen：整套信号设备 / 当前显示的灯号。

  11. Haltlinie / Wartelinie：必须停车位置的实线 / 让行等待提示虚线。

  12. Zebrastreifen / Fußgängerüberweg：日常俗称 / 正式名称。

  13. Vorfahrt / Vorrang：道路交叉关系 / 更广义的先行关系。

  14. Parkverbot / Halteverbot：禁止停放 / 也禁止自愿短暂停车。

  15. beachten / befolgen：留意并纳入行动 / 明确按指令执行。

易混辨析

  • gesperrt / Einfahrtsverbot：整体或特定对象封闭 / 禁止从当前方向驶入。
  • Stoppschild / Vorfahrt-gewähren-Schild：必须先停 / 视情况让行，不必每次完全停。
  • Vorfahrtstraße / Hauptstraße：由标志赋予先行权 / 日常描述较重要的道路。
  • Haltlinie / Haltestelle：路面停止线 / 公共交通停靠点。

语境回收

Jonas fährt auf einer Nebenstraße zu einer unübersichtlichen Kreuzung. Ein Stoppschild und eine Haltlinie verpflichten ihn anzuhalten. Er lässt den Verkehr auf der Vorfahrtstraße passieren und biegt danach rechts ab. Wegen einer Baustelle ist die Fahrbahn einspurig; Jonas folgt der Umleitung, beachtet das Zusatzzeichen und gewährt an einer Engstelle dem Gegenverkehr Vorrang.

Jonas沿支路驶向一个视野不佳的交叉口。停车让行标志和停止线要求他停车；他让优先道路上的车辆通过后右转。由于施工，路面只剩一条车道，他沿绕行路线行驶，注意附加标牌，并在狭窄处让对向车辆先行。

Jonas在Stoppschild处停车，再让优先道路车辆通过；后面窄处让对向车先行，用的是更广的Vorrang。绕行标志与附加标牌一起说明路线，不能只看道路看起来较宽就推断优先。

把词放回句子

Die Fahrbahn ist der für Fahrzeuge bestimmte Straßenteil.（Fahrbahn是道路中供车辆行驶的部分。）Eine Sackgasse hat keine durchgehende Ausfahrt für den betreffenden Verkehr.（尽头路对相应交通没有贯通出口。）Eine Einmündung verbindet eine Straße mit einer anderen, ohne sie zu durchkreuzen.（丁字接入不像十字交叉那样穿过另一条路。）

Das offizielle Wort für Zebrastreifen ist Fußgängerüberweg.（斑马线正式叫Fußgängerüberweg。）Ein Zusatzzeichen ergänzt das Hauptzeichen.（附加标牌补充主标志。）Das Stoppschild verlangt Halt nach den geltenden Regeln.（停车让行标志要求按规则停车。）Vorfahrt betrifft meist Kreuzungen und Einmündungen.（Vorfahrt主要用于交叉口和道路接入口。）

Bei einer Baustelle folgt man der ausgeschilderten Umleitung.（施工时按标示的绕行路线走。）Eine Straße mit mehreren Fahrstreifen ist mehrspurig.（多车道道路是mehrspurig。）Verkehrszeichen muss man beachten.（需要遵守交通标志。）Haltlinie标出按相应信号或指令停车的位置，不能仅凭一道线推断所有通行要求。
