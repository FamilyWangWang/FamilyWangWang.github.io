08-8 违章与事故（Verstöße und Unfälle）

本组第 8 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 6 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

交通事件先分"违反规则"和"发生事故"。Ordnungswidrigkeit 与 Straftat 的法律后果不同，Fahrverbot 也不等于驾驶许可被撤销。事故发生后，首要语言围绕停车、保护现场、查看后果、帮助伤者和交换必要资料展开；责任认定应留给事实和专业处理。

精讲

  1. Verstoß / Verkehrsverstoß：违反规则总称 / 交通领域违规。
  2. Ordnungswidrigkeit / Straftat：行政违法 / 可受刑罚追究的犯罪。
  3. Bußgeld / Verwarnungsgeld：正式行政罚款 / 较轻违规的警告金额。
  4. Bußgeldbescheid / Punkt：正式罚款文书 / 驾驶评价登记计分。
  5. Fahrverbot / Führerscheinentzug：一段时间禁止驾驶 / 驾驶许可被撤销。
  6. Tempoüberschreitung / Abstandsverstoß：超速 / 跟车距离不足。
  7. Unfall / Verkehrsunfall：事故总称 / 道路交通事故。
  8. Zusammenstoß / Auffahrunfall：一般碰撞 / 后车撞前车。
  9. Unfallstelle / Unfallhergang：事故地点 / 事故过程。
  10. Unfallbeteiligter / Unfallzeuge：可能对事故有贡献的参与者 / 目击者。
  11. Personenschaden / Sachschaden：人员伤害 / 财产损失。
  12. Blechschaden / Totalschaden：较轻车辆财损 / 修复不合理的严重损坏。
  13. Warnweste / Warndreieck：提高人员可见性 / 提前警告来车。
  14. Rettungsdienst / Rettungsgasse：急救服务 / 救援车辆通道。
  15. gefährden / behindern：造成危险 / 妨碍正常行动。

易混辨析

  • Führerschein / Fahrerlaubnis：证明文件 / 法律上的驾驶许可。
  • schuld / beteiligt：负有责任 / 行为可能与事故有关。
  • Notruf / Polizei：紧急调度呼叫 / 现场处理机构之一。
  • Verwarnung / Bußgeldbescheid：较轻违规处理 / 正式行政罚款决定。

语境回收

Auf der Autobahn kommt es zu einem Auffahrunfall. Beide Fahrer halten an, ziehen Warnwesten an und sichern die Unfallstelle mit dem Warndreieck ab. Eine Person ist verletzt, deshalb setzt eine Zeugin den Notruf ab und leistet Erste Hilfe. Die übrigen Fahrzeuge bilden eine Rettungsgasse. Später schildern die Unfallbeteiligten der Polizei den Hergang und tauschen ihre Personalien und Versicherungsdaten aus.

高速公路发生追尾。两名驾驶者停车、穿上反光背心，并用警示三角保护现场。有人受伤，一名目击者拨打紧急电话并实施急救，其他车辆形成救援通道。之后事故参与方向警方陈述经过，并交换身份和保险资料。
