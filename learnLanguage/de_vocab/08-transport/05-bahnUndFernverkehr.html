08-5 铁路与长途交通（Bahn und Fernverkehr）

本组第 5 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

把一次行程分成“坐哪班、在哪上、坐哪里”三个问题。再读延误与车票条件，便能理解为什么改查连接不等于自动获得任何班次的乘车权。

坐火车先分清 Verbindung、具体 Zugnummer、Gleis 和 Wagen。车票与座位预订是两件事，Zugbindung 还会限制可乘的长途班次；延误时应关注预计到达时间、换乘是否仍可实现以及乘客权利信息，而不能只看出发晚了几分钟。

精讲

  1. Bahn / Zug：铁路交通系统 / 具体一列车。

  2. Regionalbahn / Regionalexpress：停站较密 / 区域内较快、停站较少。

  3. Intercity / ICE：普通长途列车类别 / 高速长途列车类别。

  4. Bahnhof / Haltepunkt：日常Bahnhof泛说车站；德国EBO运营定义中，Bahnhof至少有一组道岔并具相应运行功能，Haltepunkt没有道岔。区别不是看大厅大小或服务齐全程度。

  5. Bahnsteig / Gleis：旅客站立区域 / 列车运行轨道及编号。

  6. Zuganzeiger / Abfahrtstafel：某站台下一班 / 多班汇总。

  7. Verbindung / Zugnummer：整套行程方案 / 某一具体列车班次。

  8. Direktverbindung / durchgehend：无需换乘的连接 / 连续运行或直达。

  9. Abfahrt / Ankunft / Zwischenhalt：离站 / 到站 / 中途停站。

  10. Verspätung / Anschlussverlust：晚点 / 因此错过后续连接。

  11. Wagen / Wagenreihung：单节车厢 / 全列车厢排列。

  12. Abteil / Großraumwagen：分隔小包间 / 开放式大车厢。

  13. Fahrkarte / Sitzplatzreservierung：乘车资格 / 特定座位预留。

  14. Zugbindung / Flexpreis：指定列车限制 / 通常无该限制的产品。

  15. Sparpreis / Fahrgastrechte：限制较多的优惠票 / 异常运行时的法定权利。

易混辨析

  • Gleis / Wagen / Platz：站台轨道编号 / 车厢编号 / 座位编号。
  • Direktverbindung / Nonstop：无需换乘 / 中途不停。Der Zug fährt durchgehend, hält aber unterwegs.（列车直通，但中途停站。）这里把比较接成句子。
  • Reservierung / Fahrkarte：Ich habe eine Fahrkarte, aber noch keine Sitzplatzreservierung.（我有车票，却还没有座位预订。）精讲已说明两者用途，这里看乘车资格与指定座位如何分开。
  • Zugausfall / Anschlussverlust：本列取消 / 前车延误导致后车没赶上。

语境回收

Tarek hat einen ICE mit Sitzplatzreservierung gebucht. Am Hauptbahnhof prüft er Gleisabschnitt und Wagenreihung und findet seinen Fensterplatz im Ruhebereich. Unterwegs hat der Zug Verspätung, sodass der Anschluss gefährdet ist. Die Anzeige meldet später, dass die Zugbindung aufgehoben wurde. Tarek sucht eine andere Verbindung und bewahrt seine Fahrkarte für einen möglichen Antrag nach den Fahrgastrechten auf.

Tarek预订了ICE和座位。在中央车站，他核对站台区段和车厢编组，找到安静区的靠窗位。途中列车晚点，换乘可能赶不上；显示屏随后通知指定列车限制已解除。Tarek改查其他连接，并保存车票以便按旅客权利提出申请。

Tarek的Zugbindung由显示信息明确说明已解除，他才查另一连接。Wagenreihung帮助定位车厢，Fahrkarte与Sitzplatzreservierung各有用途；保留票据是为后续核对，并不表示补偿已获批准。

把词放回句子

Der Bereich zum Einsteigen heißt Bahnsteig.（上下车区域叫Bahnsteig。）Am Zuganzeiger steht zum Beispiel Gleis 4.（站台显示可写四号轨道。）Die Reihenfolge der Wagen heißt Wagenreihung.（车厢排列叫Wagenreihung。）Gleis是轨道，旅客在对应Bahnsteig候车，不能只按中文“站台号”把两个部位等同。

Eine Reise ohne Umstieg kann eine Direktverbindung sein.（不换乘的行程可叫直达连接。）Ein kleiner abgeteilter Sitzraum heißt Abteil.（隔开的座席包间叫Abteil。）Ein Fensterplatz liegt am Fenster.（靠窗位在窗旁。）Sitzplatzreservierung预留座位，Fahrkarte则提供相应条件下的乘车资格。

Zugbindung beschränkt die Nutzung auf bestimmte Züge nach den Tarifbedingungen.（指定列车限制按票规限定可乘班次。）Ein Regionalexpress hält oft seltener als eine Regionalbahn.（区域快车常比区域慢车少停站。）Fahrgastrechte umfassen Rechte der Reisenden, etwa bei Verspätungen.（旅客权利包括例如晚点时的权利。）具体限制或解除条件应另核对，不凭票名概括全部规则。
