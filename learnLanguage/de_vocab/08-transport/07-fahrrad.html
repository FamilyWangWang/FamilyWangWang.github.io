08-7 自行车（Fahrrad）

本组第 7 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

自行车词汇既包括机械部件，也包括道路空间和安全装备。维修时要准确区分 Reifen、Schlauch、Felge 和 Speiche；上路前则检查制动、灯光和胎压。Radweg、Radfahrstreifen 与 Fahrradstraße 的法律和道路形式不同，不能只凭路面上有自行车图案判断。

精讲

  1. Fahrrad / Rad：完整正式词 / 日常简称，也可指车轮。
  2. Rahmen / Lenker / Sattel：车架 / 车把 / 座垫。
  3. Pedal / Kurbel / Kette：脚踏 / 曲柄 / 链条。
  4. Kettenblatt / Ritzel：前齿盘 / 后齿轮。
  5. Schaltung / Gang：变速系统 / 具体传动挡位。
  6. Felgenbremse / Scheibenbremse：夹轮辋制动 / 夹制动盘。
  7. Reifen / Schlauch：外胎 / 充气内胎。
  8. Felge / Speiche / Nabe：轮辋 / 辐条 / 轮毂中心。
  9. Gepäckträger / Fahrradkorb：承载架 / 开放篮筐。
  10. Klingel / Fahrradlicht / Reflektor：声音提醒 / 主动照明 / 被动反光。
  11. Dynamo / Akku：骑行发电 / 预先充电储能。
  12. Bügelschloss / Faltschloss：硬U形锁 / 多节折叠锁。
  13. Radweg / Radfahrstreifen：独立或指定道路部分 / 车行道上的实线带。
  14. Fahrradstraße / Radschnellweg：自行车优先道路 / 长距离高连续性路线。
  15. aufpumpen / flicken：充气 / 修补内胎孔洞。

易混辨析

  • abschließen / anschließen：锁上车辆 / 把车辆锁到固定物。
  • platt / abgefahren：轮胎没气 / 胎面磨损严重。
  • Klingel / Hupe：自行车铃 / 机动车喇叭。
  • Panne / Unfall：机械故障停驶 / 发生碰撞或人身事件。

语境回收

Vor dem Pendeln prüft Jule Bremsen, Fahrradlicht und Reifen. Der Hinterreifen ist platt, deshalb pumpt sie ihn auf und entdeckt ein Loch im Schlauch. Mit Flickzeug repariert sie den Schlauch, setzt das Rad wieder ein und kontrolliert die Schaltung. Danach trägt sie den Helm, fährt auf dem Radfahrstreifen und schließt das Fahrrad an einer Abstellanlage mit dem Bügelschloss an.

通勤前Jule检查刹车、车灯和轮胎。后胎瘪了，她打气后发现内胎有孔，便用补胎工具修好、装回车轮并检查变速系统。之后她戴上头盔，沿自行车带骑行，在停车设施处用U形锁把车锁好。

自测
