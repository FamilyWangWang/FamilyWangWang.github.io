08-1 汽车部件（Autoteile）

本组第 1 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 4 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述汽车时，先按外部、驾驶舱和机械部分分区最容易记。日常对话中的 Auto 最自然，登记、保险或维修文本更常用 Pkw 和 Fahrzeug。遇到仪表警示时，不要只说"灯亮了"，应指出具体 Warnleuchte、出现时间以及车辆是否还能正常行驶。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. Auto / Pkw / Fahrzeug：日常汽车 / 正式乘用车 / 各类车辆总称。
  2. Karosserie / Stoßstange：车身结构 / 前后吸收轻碰的外部部件。
  3. Windschutzscheibe / Heckscheibe：前挡风玻璃 / 后窗玻璃。
  4. Außenspiegel / Rückspiegel：车外侧镜 / 车内中央后视镜。
  5. Scheinwerfer / Rückleuchte / Blinker：前照灯 / 后灯组 / 转向灯。
  6. Reifen / Rad / Felge：橡胶轮胎 / 完整车轮 / 金属轮辋。
  7. Tacho / Drehzahlmesser：车速表 / 发动机转速表。
  8. Tankanzeige / Warnleuchte：燃油余量显示 / 故障或状态警示灯。
  9. Sitz / Kopfstütze：坐姿位置 / 保护头颈的支撑部件。
  10. Sicherheitsgurt / Airbag：主动扣好的约束装置 / 碰撞时展开的气囊。
  11. Schalthebel / Gang：选择挡位的操纵件 / 具体挡位。
  12. Kupplung / Bremse / Gaspedal：离合器 / 制动 / 加速踏板。
  13. Handbremse / Bremse：驻车防滚 / 行驶制动总系统。
  14. anschnallen / anlegen：日常"系上" / 较正式的"佩戴安全带"。
  15. automatisch / manuell：自动完成换挡等操作 / 由驾驶员手动完成。

易混辨析

  • Motorhaube / Kofferraumdeckel：发动机舱盖 / 行李厢盖。
  • Kennzeichen / Fahrzeugbrief：车辆外部号码牌 / 车辆登记文件旧称。
  • Batterie / Kraftstofftank：车载低压电源 / 储存燃油的容器。
  • Hupe / Blinker：声音警示 / 视觉方向信号。

语境回收

Vor der Fahrt stellt Ana Sitz, Kopfstütze und Außenspiegel ein und schnallt sich an. Sie startet den Motor, löst die Handbremse und legt den ersten Gang ein. Während der Fahrt blinkt plötzlich eine gelbe Warnleuchte auf. Ana schaut auf Tankanzeige und Tacho, fährt vorsichtig auf einen Parkplatz und liest im Handbuch nach, bevor sie die Motorhaube öffnet.

出发前Ana调好座椅、头枕和外后视镜并系上安全带。她启动发动机、松开手刹并挂一挡。行驶中一盏黄色警示灯突然亮起，她查看油量表和车速表，小心驶入停车处，先查说明书再打开引擎盖。

自测

  1. Die vordere Autoscheibe heißt _______. 2. Der Spiegel im Innenraum ist der _______.
  2. Gummi um das Rad ist der _______. 4. Die Geschwindigkeit zeigt der _______.
  3. Das Pedal zum Langsamerwerden gehört zur _______. 6. Vor der Fahrt muss man sich _______.
  4. Eine Richtung zeigt man mit dem _______. 8. Gepäck kommt in den _______.
  5. Der Hebel für die Gänge ist der _______. 10. Ein Auto, das fahren kann, ist _______.
答案
  1. Windschutzscheibe 2. Rückspiegel 3. Reifen 4. Tacho 5. Bremse
  2. anschnallen 7. Blinker 8. Kofferraum 9. Schalthebel 10. fahrbereit
