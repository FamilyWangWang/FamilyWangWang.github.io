08-9 车辆故障与维护（Pannen und Fahrzeugwartung）

本组第 9 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

车辆问题先区分能否安全继续行驶：只是提示保养、需要尽快检查，还是必须立即停车。向救援或维修店说明时，应给出位置、警示灯颜色、异常声音、是否漏液以及车辆能否启动。Wartung 是预防性保养，Reparatur 是修复已有故障，Inspektion 则是按项目系统检查。

精讲

  1. Panne / Schaden：途中妨碍行驶的故障事件 / 部件本身的损坏。
  2. Reifenschaden / Reifenpanne / Platten：轮胎损伤 / 途中轮胎故障 / 口语"瘪胎"。
  3. Ölverlust / Kühlmittelverlust：机油流失 / 冷却液流失。
  4. Kontrollleuchte / Fehlermeldung：仪表状态灯 / 文字或代码信息。
  5. Pannendienst / Abschleppdienst：现场救援 / 重点负责拖运。
  6. Werkstatt / Autowerkstatt：各类技术工作场所 / 汽车维修店。
  7. Inspektion / Wartung / Reparatur：系统检查 / 预防保养 / 修复故障。
  8. Diagnose / Fehlercode：确定原因的过程 / 系统记录的识别码。
  9. Kostenvoranschlag / Rechnung：事前费用估算 / 事后或应付账单。
  10. Ersatzteil / Originalteil：替换用部件 / 制造商体系部件。
  11. Verschleißteil / Defekt：正常消耗部件 / 非正常功能故障。
  12. Motoröl / Ölstand：润滑液 / 当前液位。
  13. Kühlmittel / Bremsflüssigkeit：发动机冷却工作液 / 液压制动工作液。
  14. Reifendruck / Profiltiefe：胎内压力 / 胎纹剩余深度。
  15. überprüfen / austauschen / nachfüllen：检查 / 整件更换 / 补充不足。

易混辨析

  • aufladen / überbrücken：给电池充电 / 用外部电源临时辅助启动。
  • Ölwechsel / nachfüllen：更换整批机油 / 只补足液位。
  • Sommerreifen / Winterreifen / Ganzjahresreifen：暖季优化 / 冬季条件 / 全年折中。
  • Hauptuntersuchung / Inspektion：法定定期技术检验 / 厂家或维修计划检查。

语境回收

Auf der Landstraße leuchtet bei Paul eine rote Kontrollleuchte auf, und der Motor wird heiß. Er hält sicher an, schaltet die Warnblinkanlage ein und ruft den Pannendienst. Unter dem Auto ist Kühlmittel zu sehen; deshalb fährt Paul nicht weiter. Der Abschleppwagen bringt das Fahrzeug in eine Werkstatt. Dort liest der Mechatroniker den Fehlercode aus, erstellt einen Kostenvoranschlag und tauscht einen undichten Schlauch aus.

Paul在乡间公路上看到红色警示灯亮起，发动机变热。他安全停车、打开危险警示灯并呼叫道路救援。车下可见冷却液，因此他不再继续驾驶。拖车把车送到维修店，机电技师读取故障码、出具费用估算，并更换了漏液软管。

自测

  1. Ein technisches Problem unterwegs ist eine _______. 2. Hilfe vor Ort bietet der _______.
  2. Ein Fahrzeug bringt der _______ zur Werkstatt. 4. Regelmäßige Pflege heißt _______.
  3. Systematische Prüfung heißt _______. 6. Eine Kostenschätzung ist der _______.
  4. Flüssigkeit ergänzen heißt _______. 8. Starthilfe mit zweiter Batterie heißt _______.
  5. Zu wenig Luft erkennt man am _______. 10. Stark abgenutzte Teile sind _______.
答案
  1. Panne 2. Pannendienst 3. Abschleppwagen 4. Wartung 5. Inspektion
  2. Kostenvoranschlag 7. nachfüllen 8. überbrücken 9. Reifendruck 10. verschlissen
