08-4 公共交通（Öffentlicher Nahverkehr）

本组第 4 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

城市公共交通的难点不只是车种，而是线路、方向、票制和换乘。先确认 Linie 与 Fahrtrichtung，再看站台显示的实际出发时间；发生 Ausfall 时要找 Ersatzverkehr。车票是否需要购票前、上车后或在站台 entwerten，必须按当地交通联盟规则判断。

精讲

  1. ÖPNV / Nahverkehr：公共短途客运系统缩写 / 短途交通概念。
  2. Straßenbahn / U-Bahn / S-Bahn：街面有轨电车 / 城市轨道 / 市域铁路。
  3. Haltestelle / Bushaltestelle：各类公交停靠点 / 明确为公交站。
  4. Linie / Liniennetz：一条编号服务 / 全部线路构成的网络。
  5. Fahrplan / Anzeige：计划信息 / 现场动态显示。
  6. Abfahrtszeit / Ankunftszeit：离站时间 / 到站时间。
  7. Takt / Verspätung：班次间隔 / 晚于计划的时间差。
  8. Störung / Ausfall：运行问题 / 整个班次取消。
  9. Ersatzverkehr / Schienenersatzverkehr：替代运输总称 / 轨道交通的替代服务。
  10. Anschluss / Umstieg：可接上的下一班 / 换乘动作或节点。
  11. Fahrtrichtung / Endstation：线路当前方向 / 该方向最后一站。
  12. Ticket / Fahrschein：国际化日常说法 / 较正式德语说法。
  13. Einzelfahrkarte / Zeitkarte：一次行程票 / 一段时期内多次使用的票。
  14. Tarifzone / Kurzstrecke：按区域计价 / 按少量站点计价。
  15. kaufen / entwerten：取得票 / 在需要时使纸票正式生效。

易混辨析

  • verspätet / ausgefallen：晚些运行 / 完全不运行。
  • Einstieg / Umstieg：第一次或一般上车 / 从前一线路换到下一线路。
  • Ticketautomat / Entwerter：购票机器 / 给票打戳的设备。
  • Tageskarte / 24-Stunden-Karte：按日历日 / 从启用时起连续24小时；看当地规则。

语境回收

Leonie fährt mit der S-Bahn zur Arbeit. Auf der Anzeige steht, dass ihre Linie wegen einer Störung ausfällt. Sie nimmt den Schienenersatzverkehr bis zu einem Umsteigepunkt und steigt dort in die Straßenbahn um. Dadurch verpasst sie zwar den geplanten Anschluss, erreicht aber mit einem gültigen Ticket und nur zwanzig Minuten Verspätung ihr Ziel.

Leonie乘市域铁路上班。显示屏说她的线路因故障停运，于是她乘轨道替代公交到换乘点，再换有轨电车。虽然错过原定衔接班次，但她持有效车票，最终只晚二十分钟到达。

自测
