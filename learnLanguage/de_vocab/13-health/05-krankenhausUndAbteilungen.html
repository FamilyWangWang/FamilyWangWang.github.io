13-5 医院与科室（Krankenhaus und Abteilungen）

本组第 5 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 3 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Krankenhaus 强调医院机构，Klinik 既可指整家医院，也可指其中某专科。急诊入口常写 Notaufnahme，部分地区或医院使用 Rettungsstelle；Ambulanz 是无需住院的门诊诊疗单位，不自动等于急诊。住院后患者被安排到 Station，若需要持续强化监护则可能进入 Intensivstation。寻找科室时，症状不明可先问 Patientenaufnahme 或医院总台，不必自行判断专科。

精讲

  1. Krankenhaus / Klinik / Fachklinik：医院机构 / 整家医院或专科 / 专注某领域的医院。
  2. Notaufnahme / Rettungsstelle / Ambulanz：急诊部门 / 部分地区急诊称呼 / 不住院的门诊单位。
  3. Station / Normalstation / Intensivstation：病区总称 / 普通住院 / 强化监护。
  4. Überwachungsstation / Isolierstation / Tagesklinik：加强监测 / 隔离措施 / 白天治疗晚上回家。
  5. Palliativstation / Intensivstation：缓解症状和生活质量 / 危重强化监护，目标不同。
  6. Operationssaal / Aufwachraum：实施手术 / 麻醉后恢复监测。
  7. Patientenaufnahme / Krankenhauspforte：办理患者资料 / 入口方向访问服务。
  8. Radiologie / Zentrallabor：影像检查 / 检验样本分析。
  9. Internistik / Chirurgie / Unfallchirurgie：内科总领域 / 外科 / 创伤外科。
  10. Orthopädie / Kardiologie / Neurologie：运动系统 / 心脏循环 / 神经系统。
  11. Dermatologie / Urologie / Gynäkologie：皮肤 / 泌尿 / 女性生殖系统。
  12. Pädiatrie / Psychiatrie / Onkologie：儿科 / 精神医学 / 肿瘤医学。
  13. Anästhesiologie / Intensivmedizin：麻醉围术期 / 危重患者强化治疗。
  14. Stationsarzt / Oberarzt / Chefarzt：病区日常诊疗 / 较高专科责任 / 科室最高医学管理。
  15. aufnehmen / einweisen / verlegen / entlassen：接收住院 / 安排入院 / 转病区 / 出院。

易混辨析

  • ambulant / stationär：不住院完成诊疗 / 入院并占用病床。
  • Notaufnahme / Bereitschaftsdienst：医院急诊处理急性严重问题 / 常规门诊关闭时处理不能等待的问题。
  • Station / Abteilung：实际住院照护单位 / 更大的专业组织部门。
  • Einweisung / Aufnahme：医生安排住院的文件或动作 / 医院实际接收患者。

语境回收

Nach der Untersuchung in der Notaufnahme wird Herr Li stationär aufgenommen. Zunächst bleibt er auf der Überwachungsstation, später wird er auf die Normalstation der Kardiologie verlegt. Bei der Visite erklären Stationsärztin und Pflegefachkraft den Behandlungsplan. Vor der Entlassung erhält er einen Arztbrief und fragt nach dem Kontrolltermin bei seiner Hausarztpraxis.

Li 先生在急诊检查后被收治住院，先留在监护病区，之后转到心内科普通病区。查房时，病区医生和护理人员解释治疗计划。出院前他拿到医生信，并询问家庭医生复查时间。

自测
