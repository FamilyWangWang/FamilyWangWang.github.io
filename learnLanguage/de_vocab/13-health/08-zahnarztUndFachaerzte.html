13-8 牙医与专科（Zahnarzt und Fachärzte）

本组第 8 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 11 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

牙科预约时可以说明 Kontrolle、Zahnschmerzen，或某颗 Füllung 出了问题。牙医检查牙齿、牙龈和口腔，需要时拍 Röntgenbild，再解释是否要补牙、做 Wurzelbehandlung 或其他处理。其他专科医生名称常由器官或领域构成：Kardiologe 看心血管，Orthopädin 看运动系统，HNO-Arzt 处理耳鼻喉问题。症状不明时可先由家庭医生评估和协调。

精讲

  1. Zahnarzt / Zahnarztpraxis / Zahnklinik：牙医 / 日常门诊 / 多专科复杂治疗机构。
  2. Schneidezahn / Eckzahn / Backenzahn / Weisheitszahn：切牙 / 犬牙 / 后牙 / 第三磨牙。
  3. Zahnfleisch / Zahnschmelz / Zahnwurzel：牙龈 / 牙冠外硬组织 / 牙根。
  4. Zahnbelag / Zahnstein：软性细菌膜 / 矿化硬沉积。
  5. Karies / Zahnfleischentzündung / Parodontitis：龋病 / 牙龈炎 / 牙支持组织炎。
  6. Zahnfüllung / Zahnkrone / Zahnbrücke：填补缺损 / 覆盖一颗牙 / 替代缺牙的固定桥。
  7. Zahnimplantat / Zahnprothese：植入颌骨的支持结构 / 替代多颗牙的修复体。
  8. Wurzelbehandlung / Zahnreinigung：根管治疗 / 专业清洁护理。
  9. Internist / Kardiologe：内科医生 / 心脏循环专科。
  10. Orthopäde / Hautarzt：运动系统 / 皮肤专科。
  11. Augenarzt / HNO-Arzt：眼科 / 耳鼻喉科。
  12. Frauenarzt / Kinderarzt：妇科 / 儿科日常称呼。
  13. bohren / füllen / überkronen：钻磨预备 / 填补 / 加牙冠。

易混辨析

  • Zahnbelag / Zahnstein：可刷除的软性菌斑 / 矿化后需专业去除的硬沉积。
  • Krone / Brücke / Implantat：覆盖一颗牙 / 跨越缺牙区 / 植入颌骨的支持结构。
  • Kieferorthopäde / Orthopäde：牙颌矫正专科 / 肌肉骨骼运动系统专科。
  • Zahnreinigung / Zähneputzen：专业清洁 / 日常刷牙。
