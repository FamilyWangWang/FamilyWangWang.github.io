13-1 常见症状（Häufige Symptome）

本组第 1 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 7 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语就医时先描述可观察的 Symptome：从什么时候开始、持续还是间歇、严重程度如何、是否加重。Beschwerden 是更宽泛的"不适"，不等于已经知道疾病原因。可以说 Ich habe seit gestern Fieber und trockenen Husten，也可以说 Die Beschwerden treten vor allem nachts auf。若出现严重呼吸困难、意识异常或其他危急表现，应立即联系当地急救服务；本篇只帮助表达，不用于自行诊断。

精讲

  1. Symptom / Beschwerde / Unwohlsein：具体表现 / 不适总称 / 难定位的一般不舒服。
  2. Müdigkeit / Erschöpfung / Schwäche：想休息睡眠 / 精力耗尽 / 力量能力下降。
  3. Fieber / Fiebergefühl / Schüttelfrost：确认发热 / 主观发热感 / 强烈寒战。
  4. Husten / Reizhusten / Auswurf：咳嗽总称 / 无痰刺激性咳 / 咳出的分泌物。
  5. Schnupfen / Nasenverstopfung / Nasenlaufen：鼻炎症状总称 / 鼻塞 / 流鼻涕。
  6. Halsschmerzen / Heiserkeit / Schluckbeschwerden：喉痛 / 声音嘶哑 / 吞咽困难。
  7. Atemnot / Kurzatmigkeit / Brustenge：呼吸困难 / 呼吸短促 / 胸部紧缩感。
  8. Herzrasen / Schwindel / Benommenheit：心跳很快 / 眩晕不稳 / 意识昏沉。
  9. Kopfschmerzen / Gliederschmerzen / Muskelschmerzen：头痛 / 四肢酸痛 / 肌肉痛。
  10. Bauchschmerzen / Übelkeit / Erbrechen：腹痛 / 恶心感 / 实际呕吐。
  11. Durchfall / Verstopfung / Blähungen：腹泻 / 便秘 / 胀气。
  12. Hautausschlag / Juckreiz / Rötung：皮疹 / 痒感 / 发红。
  13. Schwellung / Blässe / Gewichtsverlust：肿胀 / 苍白 / 体重下降。
  14. husten / sich übergeben / leiden：咳嗽 / 呕吐 / 受症状困扰。
  15. auftreten / abklingen：症状出现 / 症状逐渐减轻。

易混辨析

  • Krankheit / Symptom：疾病诊断 / 疾病可能表现出的症状。
  • Fieber / erhöhte Temperatur：明确发热 / 体温高于个人正常但是否达到"发烧"需按测量和医学判断。
  • Atemnot / Seitenstechen：呼吸困难 / 运动时侧腹刺痛，严重程度和处理不同。
  • Übelkeit / Erbrechen：想吐的感觉 / 实际吐出胃内容物。

语境回收

Seit gestern fühlt sich Karim müde und fiebrig. In der Nacht kamen Schüttelfrost und trockener Reizhusten hinzu. Heute hat er außerdem Kopfschmerzen und keinen Appetit. Beim Anruf in der Praxis beschreibt er, wann die Beschwerden aufgetreten sind, ob er Atemnot hat und wie hoch die gemessene Temperatur ist. Die Mitarbeiterin erklärt ihm das weitere Vorgehen.

从昨天起 Karim 感到疲倦发热，夜里又出现寒战和干咳。今天他还头痛、没有食欲。给诊所打电话时，他说明症状何时出现、是否呼吸困难，以及实测体温多高；工作人员随后告诉他下一步如何处理。

自测

  1. 一般身体不舒服是 _______。 2. 强烈寒战是 _______。
  2. 无痰刺激性咳嗽是 _______。 4. 鼻腔堵塞是 _______。
  3. 呼吸明显困难是 _______。 6. 头脑昏沉是 _______。
  4. 想吐的感觉是 _______。 8. 皮肤痒感是 _______。
  5. 症状开始出现用动词 _______。 10. 症状逐渐减轻用动词 _______。
答案
  1. Unwohlsein 2. Schüttelfrost 3. Reizhusten 4. Nasenverstopfung
  2. Atemnot 6. Benommenheit 7. Übelkeit 8. Juckreiz
  3. auftreten 10. abklingen
