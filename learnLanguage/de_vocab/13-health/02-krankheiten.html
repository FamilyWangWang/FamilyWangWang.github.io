13-2 疾病名称（Krankheitsbezeichnungen）

本组第 2 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

疾病名称不能只凭症状自己判断。Erkältung 和 Grippe 都可能有呼吸道症状，但并不是同一种病；Allergie、Asthma、感染也可能表现相似。德语日常名称与医学诊断有时不同，例如 Schuppenflechte 的医学名称是 Psoriasis。就医时最好说已有的正式诊断，或只描述症状和持续时间，不要把网上看到的名称当成确定结论。

精讲

  1. Erkältung / Grippe / Coronaerkrankung：普通感冒俗称 / 流感 / 新冠病毒所致疾病。
  2. Bronchitis / Lungenentzündung：支气管炎 / 肺组织炎症。
  3. Mandelentzündung / Nebenhöhlenentzündung / Mittelohrentzündung：扁桃体 / 鼻旁窦 / 中耳炎症。
  4. Magen-Darm-Infekt / Lebensmittelvergiftung：感染性胃肠症状俗称 / 食物污染或毒素引起的疾病。
  5. Harnwegsinfektion / Blasenentzündung：尿路感染总称 / 膀胱炎症。
  6. Gürtelrose / Windpocken：同一病毒再激活 / 首次感染常见疾病。
  7. Allergie / Heuschnupfen / Asthma：过敏反应总称 / 过敏性鼻炎俗称 / 慢性气道疾病。
  8. Neurodermitis / Schuppenflechte：特应性皮炎常用名 / 银屑病日常名。
  9. Herzkrankheit / Herzinsuffizienz / Herzrhythmusstörung：心脏病总称 / 泵血不足 / 节律异常。
  10. Migräne / Schlaganfall / Epilepsie：偏头痛疾病 / 急性脑血流损伤 / 反复癫痫发作疾病。
  11. Depression / Angststörung / Burn-out：精神疾病诊断 / 焦虑恐惧疾病 / 耗竭日常称呼。
  12. Rheuma / Arthritis / Arthrose：风湿病集合称呼 / 关节炎症 / 关节退变。
  13. Gastritis / Refluxkrankheit / Reizdarmsyndrom：胃炎 / 反流病 / 功能性肠道综合征。
  14. Nierenstein / Niereninsuffizienz：结石 / 肾功能不足。
  15. Krebs / Tumor / Autoimmunerkrankung：恶性肿瘤总称 / 良性或恶性组织增生 / 免疫攻击自身组织。

易混辨析

  • Infektion / Entzündung：病原体侵入繁殖 / 组织的炎症反应；感染可引起炎症，但炎症不都由感染造成。
  • Krebs / Tumor：恶性肿瘤疾病 / 组织肿块，可良性也可恶性。
  • Arthritis / Arthrose：关节炎症 / 关节退变相关疾病。
  • chronisch / akut：长期持续或反复 / 突然发生或病程较短，不直接表示严重程度。

语境回收

Im Aufnahmebogen trägt Mei nur Diagnosen ein, die ärztlich festgestellt wurden: Asthma und eine Pollenallergie. Seit zwei Tagen hat sie zusätzlich Fieber, Husten und Gliederschmerzen. Sie sagt nicht selbst, es sei Grippe, sondern beschreibt die Symptome. Die Ärztin untersucht sie, erklärt mögliche Ursachen und entscheidet, welche weitere Abklärung sinnvoll ist.

Mei 在接诊表中只填写医生已确认的诊断：哮喘和花粉过敏。近两天她又出现发烧、咳嗽和四肢酸痛。她没有自行断定是流感，而是描述症状。医生检查后说明可能原因，并决定哪些进一步检查有意义。

自测

  1. 医学上的流感是 _______。 2. 肺组织炎症是 _______。
  2. 中耳炎症是 _______。 4. 水痘病毒再激活引起的是 _______。
  3. 花粉过敏性鼻炎俗称 _______。 6. 心脏泵血能力不足是 _______。
  4. 关节炎症是 _______。 8. 甲状腺激素作用不足是 _______。
  5. 恶性肿瘤疾病总称是 _______。 10. 可良性也可恶性的组织增生是 _______。
答案
  1. Grippe 2. Lungenentzündung 3. Mittelohrentzündung 4. Gürtelrose
  2. Heuschnupfen 6. Herzinsuffizienz 7. Arthritis
  3. Schilddrüsenunterfunktion 9. Krebs 10. Tumor
