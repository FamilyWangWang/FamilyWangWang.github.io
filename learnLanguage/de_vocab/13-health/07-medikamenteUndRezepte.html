13-7 药品与处方（Medikamente und Rezepte）

本组第 7 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Medikament 是日常常用词，Arzneimittel 更正式。药盒上的 Wirkstoff 是发挥主要作用的成分，Handelsname 是销售名称；不同商品可能含同一有效成分。德国法定医保的处方药自 2024 年起通常使用 E-Rezept，可凭电子医保卡、应用程序或纸质代码在药房取药。服药前应核对 Dosierung、Einnahmeabstand、Nebenwirkungen 和 Wechselwirkungen。rezeptfrei 不等于对每个人都无风险；具体剂量、停药、合并用药和孕期使用应向医生或药师确认。

精讲

  1. Medikament / Arzneimittel：日常药品说法 / 正式专业法律称呼。
  2. Wirkstoff / Handelsname：产生主要作用的成分 / 商品销售名称。
  3. Generikum / Originalpräparat：相应仿制药 / 最初开发获批药。
  4. Darreichungsform / Dosierung：药物形式 / 用量频率疗程安排。
  5. Tablette / Filmtablette / Kapsel：普通片剂 / 薄膜包衣片 / 胶囊。
  6. Tropfen / Arzneisaft / Sirup：滴剂 / 药用液体 / 黏稠糖浆制剂。
  7. Arzneipulver / Granulat / Brausetablette：粉末 / 颗粒 / 泡腾片。
  8. Salbe / Creme / Arzneigel：较油脂性 / 水油乳化 / 凝胶状外用剂。
  9. Nasenspray / Inhalator / Wirkstoffpflaster：鼻喷 / 吸入装置 / 经皮持续释放药贴。
  10. Einzeldosis / Tagesdosis / Einnahmeabstand：一次量 / 每日总量 / 两次间隔。
  11. Beipackzettel / Packungsbeilage：日常说明书称呼 / 正式常用称呼。
  12. Nebenwirkung / Wechselwirkung / Gegenanzeige：额外不良作用 / 相互影响 / 不应使用的理由。
  13. Allergie / Unverträglichkeit：免疫性过度反应 / 不耐受，机制不必是过敏。
  14. Rezept / E-Rezept / Kassenrezept / Privatrezept：处方总称 / 电子 / 法定医保日常称呼 / 私人结算处方。
  15. rezeptpflichtig / apothekenpflichtig / rezeptfrei：需处方 / 只能药房供应 / 无需处方。

易混辨析

  • Dosis / Dosierung：某一次或某量 / 包含单次量、频率、疗程的整体安排。
  • Nebenwirkung / Allergie：药物主要作用外的不良反应 / 免疫机制相关反应。
  • rezeptfrei / harmlos：无需处方 / 无害；前者绝不等于后者。
  • haltbar bis / verwendbar nach Anbruch：未开封有效期限 / 开封后可用时长，需分别查看。

语境回收

In der Apotheke löst Ben sein E-Rezept ein. Die Apothekerin nennt Wirkstoff und Handelsname und fragt nach weiteren Medikamenten, um mögliche Wechselwirkungen zu prüfen. Ben zeigt seinen Medikationsplan. Gemeinsam lesen sie Dosierung, Einnahmezeit und Hinweise zur Lagerung. Weil Ben eine bekannte Allergie hat, wird auch diese Information vor der Abgabe kontrolliert.

Ben 在药房使用电子处方。药师说明有效成分和商品名，并询问其他用药以检查相互作用。Ben 出示用药计划；两人共同核对剂量、服药时间和保存提示。由于 Ben 有已知过敏，发药前也会核对这项信息。
