13-9 急救与意外（Erste Hilfe und Unfälle）

本组第 9 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 15 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

急救首先要避免自己进入危险：观察 Gefahrenstelle，在安全条件下拨打 Notruf，清楚说明地点、发生了什么、有多少人受伤，并回答 Leitstelle 的问题。不要因语言不完美而延误求助。接线人员会给出具体指示，应留在线上并照做。在德国，危及生命或严重事故拨打 112；诊所关闭时，不能等到下一次门诊但并不危及生命的问题可联系 Bereitschaftsdienst（116117）。

精讲

  1. Notfall / Unfall / Erstversorgung：需立即措施的情况 / 突发损害事件 / 专业治疗前初步照护。
  2. Notruf / Leitstelle / Rettungsdienst：紧急求助电话 / 接听调度中心 / 院前救治服务。
  3. Rettungswagen / Notarzt：急救运输车辆 / 具备相应资格的院前急救医生。
  4. Ersthelfer / Unfallstelle / Gefahrenstelle：现场帮助者 / 事故位置 / 持续危险区域。
  5. Bewusstsein / Bewusstlosigkeit / ansprechbar：意识状态 / 无正常反应 / 能对呼叫作反应。
  6. Atmung / Atemstillstand / Kreislaufstillstand：呼吸 / 无呼吸 / 无有效循环。
  7. Wiederbelebung / Herzdruckmassage / Beatmung：复苏总称 / 胸外按压 / 辅助通气。
  8. Seitenlage / AED：无意识但正常呼吸时的稳定体位 / 自动体外除颤器。
  9. Wunde / Blutung：组织开放损伤 / 血液流出或进入组织。
  10. Schnittwunde / Platzwunde / Schürfwunde / Stichwunde：切割 / 钝力裂开 / 擦伤 / 刺入伤。
  11. Prellung / Verstauchung / Knochenbruch：软组织挫伤 / 关节韧带伤 / 骨折。
  12. Verbrennung / Verbrühung：广义烧伤 / 热液或蒸汽烫伤。
  13. Vergiftung / Stromunfall：有害物质损伤 / 电流事故。
  14. Schock：急救医学中指循环供血严重不足的危急状态，不等于日常所说的"受到惊吓"。
  15. absichern / alarmieren / prüfen / wiederbeleben：保护现场 / 召集救援 / 检查 / 复苏。

易混辨析

  • Notruf / Bereitschaftsdienst：生命危险或严重事故的紧急求助 / 非生命危险但不能等到常规门诊的问题。
  • bewusstlos / schlafend：无法正常唤醒 / 正常睡眠可被唤醒。
  • stabile Seitenlage / Rückenlage：无意识但正常呼吸者的急救体位 / 仰卧，适用情形不同。
  • Schock / Schreck：循环系统危急状态 / 情绪上的惊吓。

语境回收

Nina sieht einen Fahrradsturz. Sie bleibt außerhalb des Verkehrs, spricht den Verletzten an und bittet eine andere Person, die Unfallstelle abzusichern. Weil der Mann nicht normal reagiert, wählt sie den Notruf und nennt den genauen Ort. Sie beantwortet alle Fragen der Leitstelle, prüft die Atmung nach Anleitung und folgt den weiteren Anweisungen, bis der Rettungsdienst eintrifft.

Nina 看到一起自行车摔倒事故。她留在车流外，呼叫伤者，并请另一人保护事故现场。由于男子反应不正常，她拨打急救电话并说明准确地点，回答调度中心的全部问题，按指导检查呼吸，并持续遵照指令，直到救护人员到达。
