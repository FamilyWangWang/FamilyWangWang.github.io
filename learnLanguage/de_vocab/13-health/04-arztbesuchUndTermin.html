13-4 看医生与预约（Arztbesuch und Termin）

本组第 4 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 12 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

预约时先说明是 akute Beschwerden、常规 Kontrolltermin，还是 Vorsorgetermin。到诊所后通常先在 Praxisanmeldung 报到，并出示 Gesundheitskarte。Überweisung 是医生把患者转到另一位医生或专科继续诊疗的文件；医院住院相关的 Einweisung 不是同一回事。德国诊所关闭时，若问题不能等到下一次门诊但并不危及生命，可联系 ärztlicher Bereitschaftsdienst（116117）；危及生命或可能造成永久伤害时拨打 112。

精讲

  1. Arztpraxis / Hausarztpraxis / Facharztpraxis：医生诊所总称 / 基础医疗 / 专科门诊。
  2. Gemeinschaftspraxis / Praxisgemeinschaft：共同经营接诊 / 只共享场所资源、各自经营。
  3. Sprechstunde / Akutsprechstunde / Terminsprechstunde：门诊时段总称 / 急性问题 / 预约接诊。
  4. Kontrolltermin / Vorsorgetermin / Akuttermin：复查 / 预防早诊 / 急性短期安排。
  5. Terminbestätigung / Terminabsage / Terminverschiebung：确认 / 取消 / 改期。
  6. Praxisanmeldung / Praxisempfang / Wartezimmer：报到前台 / 前台职能 / 候诊空间。
  7. Überweisung / Einweisung：转到另一医生专科 / 建议安排住院。
  8. Krankenakte / Patientenakte：疾病资料档案总称 / 某机构保存的患者诊疗记录。
  9. Anamnesebogen / Aufnahmebogen：病史用药风险 / 首诊或入院一般资料。
  10. Befundbericht / Arztbrief：检查发现报告 / 医生间传递完整诊疗信息。
  11. Hausarzt / Facharzt：基础持续照护 / 完成特定专科培训。
  12. MFA / Praxispersonal：医疗助理缩写 / 诊所全体工作人员。
  13. Vertretungsarzt / Bereitschaftsdienst：替代原医生接诊 / 常规门诊关闭时的值班服务。
  14. Videosprechstunde / Terminservicestelle：视频医疗咨询 / 协助寻找门诊预约的服务。
  15. vereinbaren / absagen / verschieben / bestätigen：预约 / 取消 / 改期 / 确认。

易混辨析

  • Termin / Sprechstunde：一次约定时间 / 医生接诊患者的整个时段。
  • Überweisung / Rezept：转介到医生专科 / 处方药品或治疗用品。
  • Bereitschaftsdienst / Notaufnahme：非生命危险但不能等到常规门诊 / 医院处理急危重症的急诊入口。
  • Anmeldung / Aufnahme：门诊报到 / 更完整的接诊或住院登记。

语境回收

Wegen akuter Beschwerden ruft Sofia ihre Hausarztpraxis an. Die MFA fragt nach Symptomen und Dringlichkeit und gibt ihr einen Akuttermin. In der Praxis meldet Sofia sich an und lässt die Gesundheitskarte einlesen. Im Gespräch schildert sie den Verlauf und zeigt einen früheren Befundbericht. Die Hausärztin untersucht sie und stellt bei Bedarf eine Überweisung zur Facharztpraxis aus.

Sofia 因急性不适给家庭医生诊所打电话。医疗助理询问症状和紧急程度，并安排急诊预约。到诊所后，她在前台报到并读取医保卡。问诊时，她描述病程并出示之前的检查报告；家庭医生检查后，如有需要会开具专科转诊单。
