13-3 疼痛的描述（Schmerzen beschreiben）

本组第 3 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 6 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述疼痛时，Wo? Seit wann? Wie stark? Wie genau? Wodurch besser oder schlimmer? 比只说 Es tut weh 更有帮助。位置可说 punktuell 或 großflächig，性质可说 stechend、dumpf、brennend，过程可说 plötzlich begonnen、dauerhaft 或 anfallsartig。数字 Schmerzskala 是个人当下体验的沟通工具，不用于比较不同人的疼痛，也不能单独判断病因。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

die Schonhaltung -en 为避免疼痛而长期采取、可能限制正常动作的姿势 eine Schonhaltung entwickeln B1
das Schmerzmuster - 疼痛在时间、位置和诱因上的重复规律 ein typisches Schmerzmuster B1
die Schmerzhäufigkeit -en 疼痛在一定期间内出现的次数 die Schmerzhäufigkeit dokumentieren B1

dumpf 可变格 模糊、沉重、不尖锐的痛 ein dumpfer Kopfschmerz A2

plötzlich 不变副词；定语可变格 没有明显渐进过程地突然出现（→ 见 02-5） plötzlich einsetzender Schmerz A1

den Schmerzverlauf dokumentieren + A 记录疼痛变化 写时间、强度和诱因 B1
Schmerzmittel eingenommen haben + A 已服用止痛药 同时说明名称剂量时间 A2

精讲

  1. Schmerzstelle / Schmerzbeginn / Schmerzdauer：哪里痛 / 何时如何开始 / 持续多久。
  2. Schmerzstärke / Schmerzskala：主观疼痛强度 / 帮助表达强度的量表。
  3. Schmerzattacke / Dauerschmerz：一次突然发作 / 持续存在的痛。
  4. Ruheschmerz / Belastungsschmerz / Bewegungsschmerz：休息时 / 负荷时 / 特定动作时疼。
  5. Druckschmerz / Berührungsschmerz：按压触发 / 轻触即疼。
  6. Wundschmerz / Nervenschmerz / Phantomschmerz：伤口区域 / 神经相关 / 缺失部位仍感疼。
  7. Schmerzausstrahlung / Schmerzverlauf：向别处扩展 / 随时间的整体变化。
  8. dumpf / stechend / schneidend：沉钝 / 刺痛 / 刀割锐痛。
  9. brennend / elektrisierend：灼烧样 / 电击样。
  10. ziehend / reißend / bohrend：牵拉 / 撕扯 / 钻入样。
  11. pochend / pulsierend：跳痛 / 随脉搏起伏，意义接近。
  12. krampfartig / kolikartig：痉挛样 / 强烈波浪式绞痛样。
  13. punktuell / großflächig / einseitig / beidseitig：小点 / 大片 / 单侧 / 双侧。
  14. plötzlich / allmählich / dauerhaft / anfallsartig：突然 / 渐进 / 持续 / 阵发。
  15. anhalten / nachlassen / zunehmen / verschlimmern：持续 / 减轻 / 增强 / 整体恶化。

易混辨析

  • Schmerz / Druckgefühl：疼痛 / 压迫感；两者可同时存在，应分别描述。
  • stechend / ziehend：尖锐刺入感 / 拉扯延伸感。
  • dauerhaft / wiederkehrend：一直存在 / 消失后反复出现。
  • ausstrahlen / wandern：从原点扩展到另一处 / 疼痛主要位置随时间移动。

语境回收

Die Ärztin fragt Leo nach dem Schmerzbeginn. Der Schmerz habe gestern plötzlich eingesetzt, sagt er. Er sitzt punktuell im unteren Rücken, ist in Ruhe dumpf und wird bei Bewegung stechend. Manchmal strahlt er in das rechte Bein aus. Auf der Schmerzskala liegt er bei sechs von zehn. Leo erklärt außerdem, was die Schmerzen lindert und welches Schmerzmittel er bereits eingenommen hat.

医生询问 Leo 疼痛何时开始。他说疼痛昨天突然出现，集中在下背部一点；休息时沉钝，活动时变为刺痛，有时向右腿放射。按疼痛量表为 6/10。他还说明什么会减轻疼痛，以及自己已经服过哪种止痛药。

自测

  1. 疼痛持续的时间是 _______。 2. 数字表达疼痛强度的是 _______。
  2. 休息时也痛是 _______。 4. 轻触即痛是 _______。
  3. 疼痛向其他部位扩展是 _______。 6. 像电击的痛是 _______。
  4. 只集中在小点是 _______。 8. 一次次突然发作是 _______。
  5. 疼痛逐渐减轻用动词 _______。 10. 疼痛向手臂放射用动词 _______。
答案
  1. Schmerzdauer 2. Schmerzskala 3. Ruheschmerz 4. Berührungsschmerz
  2. Schmerzausstrahlung 6. elektrisierend 7. punktuell 8. anfallsartig
  3. nachlassen 10. ausstrahlen
