13-6 检查与治疗（Untersuchungen und Behandlungen）

本组第 6 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 8 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

检查名词可以沿“为什么检查—怎样取样—得到什么发现—下一步怎样解释”连起来读。本篇保留各方法的区别，同时说明结果为什么还需要医生解释。

医生先通过 Anamnese 了解症状、既往病史和用药，再根据需要进行 Körperuntersuchung、实验室或影像检查。Befund 是检查发现，Diagnose 是综合信息后形成的疾病判断；Verdachtsdiagnose 仍需进一步确认。治疗可能是 Medikation、Physiotherapie、手术或观察等待。患者有权询问目的、替代方案、风险和后续安排，并在重要操作前获得适当说明。

精讲

  1. Untersuchung / Körperuntersuchung / Anamnese：检查总称 / 直接查体 / 系统询问病史。

  2. Befund / Diagnose / Verdachtsdiagnose：检查发现 / 综合疾病判断 / 尚待确认的怀疑。

  3. Blutdruckmessung / Pulsmessung / Temperaturmessung：血压 / 脉搏 / 体温测量。

  4. Blutentnahme / Blutprobe / Urinprobe / Abstrich：采血过程 / 血样 / 尿样 / 表面拭子样本。

  5. Laboruntersuchung / Blutbild：实验室检查总称 / 血细胞成分检验。

  6. Ultraschall / Röntgenuntersuchung：声波成像 / X 射线成像。

  7. CT / MRT：X 射线断层 / 磁场射频断层。

  8. EKG / EEG：心脏电活动 / 脑电活动。

  9. Endoskopie / Magenspiegelung / Darmspiegelung：内镜总称 / 上消化道内镜 / 大肠内镜。

  10. Biopsie / Gewebeprobe：取组织过程 / 取得的样本。

  11. Vorsorgeuntersuchung / Kontrolluntersuchung：预防早诊 / 病情治疗复查。

  12. Therapie / Behandlung / Medikation：治疗方案方法 / 诊疗过程总称 / 药物整体安排。

  13. Operation / Eingriff / Narkose / Lokalanästhesie：手术 / 操作总称 / 全身麻醉 / 局部麻醉。

  14. Physiotherapie / Ergotherapie / Psychotherapie：运动功能 / 日常活动参与 / 心理方法治疗。

  15. Reha / Rehabilitation / Nachsorge：康复简称 / 恢复参与综合过程 / 治疗后持续照护。

易混辨析

  • Befund / Diagnose：检查得到的发现 / 综合判断出的疾病。
  • CT / MRT：使用 X 射线 / 使用磁场和射频，适用情形由专业人员选择。
  • Narkose / Sedierung：Narkose通常指全身麻醉，Sedierung指镇静，深度可不同；镇静不自动保证充分镇痛，具体操作方案另听专业说明。
  • Vorsorge / Nachsorge：疾病前预防早诊 / 治疗后随访监测。

语境回收

Nach der Anamnese tastet die Ärztin den Bauch ab und misst Blutdruck und Puls. Wegen eines auffälligen Befunds ordnet sie eine Blutentnahme und einen Ultraschall an. Die Laboruntersuchung zeigt keine eindeutige Ursache. Deshalb bleibt es zunächst bei einer Verdachtsdiagnose. Die Ärztin erklärt, welche weitere Untersuchung sinnvoll ist und wann der Kontrolltermin stattfinden soll.

询问病史后，医生触诊腹部并测量血压脉搏。因发现异常，她安排抽血和超声。实验室检查没有显示明确原因，所以目前仍只是疑似诊断。医生解释下一项检查为何有意义，以及何时复查。

医生先询问病史并查体，再因异常发现安排采血和超声。检验没有给出明确原因，Verdachtsdiagnose便仍是疑似；没有明确解释与完全没有问题不能画等号。

把词放回句子

Nach der Anamnese bespricht die Ärztin den Befund.（询问病史后，医生讨论检查发现。）Zunächst bleibt es bei einer Verdachtsdiagnose.（目前仍只是疑似诊断。）Für die Laboruntersuchung wird ein Abstrich genommen.（为检验采集一份拭子样本。）Anamnese是获取背景，Befund是发现，Verdachtsdiagnose说判断仍待确认，Abstrich则是取样材料。

Das MRT erzeugt Bilder mit Magnetfeldern und Radiowellen.（磁共振使用磁场和射频成像。）Ein EKG zeichnet die elektrische Aktivität des Herzens auf.（心电图记录心脏电活动。）Bei einer Biopsie entnimmt man eine Gewebeprobe.（活检时取一份组织样本。）MRT、EKG和Biopsie回答的问题不同，不能仅因都是“检查”就互换。

Vor diesem Eingriff wird eine Lokalanästhesie besprochen.（这次操作前会讨论局部麻醉。）Die Ärztin hört die Lunge ab.（医生用听诊器听肺部。）Später kann sie eine Erkrankung diagnostizieren.（之后她可能诊断某种疾病。）abhören是具体检查动作，diagnostizieren是作诊断；是否需要操作、采用何种麻醉还须结合具体说明。
