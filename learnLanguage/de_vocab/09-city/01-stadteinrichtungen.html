09-1 城市设施（Städtische Einrichtungen）

本组第 1 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 5 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述一座城市时，德语常按功能来区分地点：办事去 Rathaus 或 Bürgeramt，文化活动在 Theater、Museum 或 Konzerthaus，日常服务则由各种 -filiale、-zentrum 和公共设施承担。Innenstadt 指中心城区，Altstadt 强调保留下来的历史城区，两者不一定完全重合。询问具体办事地点时，先说设施名称，再问地址、开放时间或是否需要预约最自然。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. Stadtzentrum / Innenstadt：前者强调城市中心这一功能位置，后者是实际的中心城区。
  2. Altstadt / Innenstadt：历史老城 / 当代中心城区；两者可以重合，也可以分开。
  3. Stadtviertel / Wohnviertel：一般城区片区 / 以住宅为主的片区。
  4. Gewerbegebiet / Industriegebiet：商业和轻工业混合区 / 大型生产企业区。
  5. Rathaus / Bürgeramt：市政府机构与建筑 / 直接办理居民日常事务的窗口机关。
  6. Arbeitsagentur / Jobcenter：联邦就业与失业保险服务 / 特定基本保障与就业支持。
  7. Polizeiwache / Feuerwache / Rettungswache：警察驻点 / 消防驻点 / 救护驻点。
  8. Stadtbibliothek / Volkshochschule：公共借阅学习 / 成人课程教育。
  9. Jugendzentrum / Seniorenzentrum：青少年服务场所 / 老年人服务场所。
  10. Theater / Opernhaus / Konzerthaus：综合舞台表演 / 歌剧 / 现场音乐。
  11. Hallenbad / Freibad：室内全年泳馆 / 露天季节性泳池。
  12. Marktplatz / Markthalle：城市传统中心广场 / 容纳市场摊位的室内建筑。
  13. Recyclinghof / Wertstoffhof：两者日常常近义，具体接收范围由当地运营方规定。
  14. Parkhaus / Tiefgarage：多层或封闭停车楼 / 地下停车库。
  15. Bereitschaftspraxis / Notaufnahme：非危及生命的非门诊时段诊疗 / 医院急重症入口。

易混辨析

  • Marktplatz / Wochenmarkt：前者是地点，后者是按日期举行的市场活动。
  • Kunsthalle / Museum：艺术展览场馆 / 通常拥有、研究并展示馆藏的机构。
  • Postfiliale / Paketshop：综合邮政柜台 / 以收寄包裹为主的合作网点。
  • Notaufnahme / Rettungswache：患者进入医院的急诊部门 / 救护车辆和人员的驻地。

语境回收

Lea wohnt in einem ruhigen Wohnviertel am Rand der Innenstadt. Am Vormittag hat sie einen Termin im Bürgeramt und fährt danach zur Stadtbibliothek. Auf dem Rückweg kauft sie Gemüse auf dem Wochenmarkt und bringt alte Elektrogeräte zum Recyclinghof. Am Abend trifft sie Freunde vor dem Programmkino. Weil das Parkhaus voll ist, kommen zwei Freunde mit der Straßenbahn und steigen am Marktplatz aus.

Lea住在中心城区边缘一个安静的住宅区。上午她去居民事务局办事，之后前往市图书馆。回程时，她在周市买菜，并把旧电器送到回收站。晚上她在艺术电影院门前与朋友见面。因为停车楼已满，两位朋友乘有轨电车前来，在市集广场站下车。

自测

  1. 城市中心商业区通常叫 _______。 2. 历史城区叫 _______。
  2. 办理居民登记常去 _______。 4. 成人课程机构是 _______。
  3. 每周固定举行的市场叫 _______。 6. 室内公共泳馆是 _______。
  4. 交送旧电器可去 _______。 8. 地下停车库是 _______。
  5. 消防驻点叫 _______。 10. 医院急诊部门是 _______。
答案
  1. Innenstadt 2. Altstadt 3. Bürgeramt 4. Volkshochschule 5. Wochenmarkt
  2. Hallenbad 7. Recyclinghof / Wertstoffhof 8. Tiefgarage 9. Feuerwache 10. Notaufnahme
