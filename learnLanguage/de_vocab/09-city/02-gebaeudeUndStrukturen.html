09-2 建筑与结构（Gebäude und bauliche Strukturen）

本组第 2 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 6 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

看房、找入口、描述城市景观或报告建筑问题时，只会说 Gebäude 远远不够。德语会清楚区分建筑整体、承重构件、通行空间和外部附属结构。Stockwerk 是日常说法，Geschoss 更常见于建筑、房产和法规语境；Erdgeschoss 在德国通常是地面层，其上一层才叫 erster Stock。

精讲

  1. Bauwerk / Wolkenkratzer：一切固定人工结构的总称 / 超高层建筑这一特定类型。
  2. Eisenbahnbrücke / Viadukt：承载铁路的桥 / 多跨、较长且由连续支撑构成的桥。
  3. Überführung / Viadukt：一般上跨结构 / 多跨且连续支撑的长桥。
  4. Staudamm / Deich：横截水流蓄水 / 沿水边防洪。
  5. Säule / Pfeiler：常为圆形并兼具装饰 / 粗重、强调承重。
  6. Pfeiler / Träger：竖向支撑 / 横向承重构件。
  7. Fundament / Bodenplatte：把荷载传入地基的整体基础 / 常构成建筑底面的板式基础。
  8. Kellergeschoss / Dachgeschoss：地下或半地下楼层 / 位于屋顶结构内的楼层。
  9. Flachdach / Satteldach：低坡度屋顶 / 两面斜坡相交的屋顶。
  10. Laubengang / Ladenpassage：沿外墙连接住户的开放走廊 / 两侧设店的有顶通道。
  11. Haupteingang / Nebeneingang / Notausgang：主入口 / 次入口 / 紧急出口。
  12. Personenaufzug / Lastenaufzug：载人电梯 / 载货电梯。
  13. Dachterrasse / Loggia：位于屋顶上的开放露台 / 嵌入建筑并通常有顶的阳台式空间。
  14. Tragwand / Zwischenwand：承重墙 / 分隔空间的轻质墙。
  15. Baugerüst / Baustellenzufahrt：外墙施工临时架体 / 工程车辆入口。

易混辨析

  • Fassade / Außenwand：经过设计、可见的建筑立面 / 分隔内外并承担技术功能的墙。
  • Kuppel / Gewölbe：覆盖集中空间的穹顶 / 覆盖长条或其他空间的拱形结构。
  • Passage / Durchgang：常带商业店铺的有顶步行空间 / 单纯穿越建筑的通道。
  • Rampe / Treppe：连续坡面 / 分级台阶；无障碍通行通常依赖前者。

语境回收

Das alte Rathaus ist ein geschütztes Baudenkmal. Seine Fassade wird saniert, deshalb steht vor dem Haupteingang ein Baugerüst. Besucher benutzen vorübergehend den Nebeneingang im Innenhof. Der Personenaufzug ist außer Betrieb, aber eine Zufahrtsrampe ermöglicht einen stufenlosen Zugang zum Erdgeschoss. Der Notausgang und die Baustellenzufahrt müssen jederzeit frei bleiben.

老市政厅是一座受保护建筑。它的立面正在修缮，所以主入口前搭了脚手架。访客暂时使用内院里的侧门。客梯停运，但入口坡道仍可让人无台阶进入地面层。紧急出口和工地车道必须始终保持畅通。

自测

  1. 建筑最下方传递荷载的结构是 _______。 2. 建筑外观立面叫 _______。
  2. 德国的地面层叫 _______。 4. 屋顶内楼层叫 _______。
  3. 紧急出口是 _______。 6. 载货电梯是 _______。
  4. 沿屋檐排雨水的是 _______。 8. 承重墙是 _______。
  5. 施工脚手架是 _______。 10. 城市建筑间尚未建设的空地是 _______。
答案
  1. Fundament 2. Fassade 3. Erdgeschoss 4. Dachgeschoss 5. Notausgang
  2. Lastenaufzug 7. Dachrinne 8. Tragwand 9. Baugerüst 10. Baulücke
