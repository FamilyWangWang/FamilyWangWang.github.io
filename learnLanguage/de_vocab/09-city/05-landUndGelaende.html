09-5 乡村与地形（Land und Gelände）

本组第 5 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 1 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

离开城市后，德语会用很具体的词区分聚落、农业用地和自然地形。Land 既可指"国家"，也可在 auf dem Land 中指乡村；Dorf 是有一定规模和共同生活结构的村庄，Weiler 则更小。描述路线和户外环境时，Hang、Ufer、Küste 等词通常需要一个明确参照：山坡、河岸、海岸并不是可互换的"边"。

精讲

  1. Land / Landschaft：城市以外的乡村 / 可见的整体区域景观。
  2. Gegend / Region：边界模糊的周边地区 / 有共同特点的较大区域。
  3. Dorf / Ortschaft / Weiler：生活意义上的村庄 / 中性行政聚落 / 极小聚落。
  4. Feld / Acker：农业地块总称 / 实际耕作作物的土地。
  5. Wiese / Weide：割草或一般草地 / 供牲畜放牧的草地。
  6. Wald / Forst / Hain：自然与日常森林 / 经营管理角度的林区 / 小树林的诗意说法。
  7. Hügel / Berg / Gebirge：低缓隆起 / 单座明显山体 / 连片山系。
  8. Tal / Schlucht：一般谷地 / 狭窄陡峭的深谷。
  9. Ebene / Hochebene：低起伏平原 / 海拔较高的平坦地形。
  10. Hang / Abhang：山体斜面 / 更强调陡峭向下的坡。
  11. Gipfel / Bergkamm：单个最高点 / 连接高点的山脊。
  12. Bach / Fluss / Strom：溪流 / 河流 / 大型重要河流。
  13. See / Teich / Tümpel：湖泊 / 小型常人工静水体 / 很浅的小水洼。
  14. Ufer / Küste / Strand：内陆水体岸边 / 海陆交界大区域 / 可进入的沙砾岸带。
  15. Moor / Sumpf：能形成泥炭的特殊湿地 / 一般泥泞积水地。

易混辨析

  • der See / die See：湖泊 / 海洋；阴阳性改变词义。
  • Quelle / Bach：水涌出地表的源点 / 已经形成并流动的小水道。
  • Insel / Halbinsel：四面环水 / 仍与大陆相连。
  • Feldweg / Wanderweg：以农业通行为主 / 为徒步规划和标识。

语境回收

Mira lebt in einem kleinen Dorf am Rand eines Gebirges. Hinter dem Bauernhof beginnen Wiesen und Felder; weiter oben liegen Weinberge und Wald. Am Wochenende folgt sie einem markierten Wanderweg durch ein schmales Tal. Der Weg führt an einem Bach entlang, steigt dann einen Hang hinauf und endet an einem Aussichtspunkt. Von dort sieht sie den Fluss, mehrere Dörfer und eine weite Ebene.

Mira住在山脉边缘的一个小村庄。农场后面是草地和田野，更高处有葡萄园和森林。周末她沿着标识清楚的徒步路线穿过一条狭窄山谷。路线沿溪而行，随后爬上山坡，终点是观景点。从那里她能看到河流、几个村庄和广阔平原。
