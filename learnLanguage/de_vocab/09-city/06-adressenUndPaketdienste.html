09-6 门牌地址与快递（Adressen und Paketdienste）

本组第 6 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 12 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德国地址通常按"姓名—街道与门牌号—邮编与城市—国家"书写。Adresse 是日常总称，Anschrift 更常见于表格和正式通信；寄件时还要区分 Lieferadresse 与 Rechnungsadresse。快递状态里的 versandt、in Zustellung、zugestellt 分别表示已交运、正在末端派送和已送达，不能都笼统理解成"发货了"。

精讲

  1. Adresse / Anschrift：日常地址总称 / 表格和正式通信中的地址。
  2. Postanschrift / Hausanschrift：接收邮件的地址 / 实际住宅或建筑地址。
  3. Absender / Empfänger：寄件方 / 收件方。
  4. Postfach / Postfachnummer：租用的邮政信箱 / 识别该信箱的编号。
  5. Hausnummer / Hausnummernzusatz：主编号 / 编号后的字母等补充。
  6. Postleitzahl / Ortsteil / Wohnort：邮编 / 城市内部片区 / 常住市镇。
  7. Briefsendung / Warensendung：按信件流程寄送 / 按特定条件寄送小型商品。
  8. Einschreiben / Nachnahme：带投递凭证的挂号产品 / 交付时代收款项。
  9. Porto / Briefmarke：应付邮资 / 表示邮资支付的邮票。
  10. Zustellung / Auslieferung：单件邮件的末端投递 / 货物向客户交付的配送过程。
  11. Packstation / Paketshop：自动包裹柜系统 / 合作商店内的人工服务点。
  12. Sendungsnummer / Zustellnachweis：寄件识别码 / 交付方式和时间的证明。
  13. Zustellversuch / Abholfrist：一次投递尝试 / 改为寄存后可领取的期限。
  14. Ablageort / Ersatzempfänger：指定放置地点 / 获准代收的人。
  15. Retourenlabel / Versandetikett：用于退货的运输标签 / 一般寄件标签。

易混辨析

  • versandt / in Zustellung / zugestellt：已交给运输网络 / 正在末端派送 / 已完成交付。
  • Briefkasten / Paketfach：住宅收信箱 / 自动柜中存放包裹的格口。
  • Abholstation / Packstation：自动或人工取件点总称 / 特定品牌化自动柜系统。
  • Lieferadresse / Ablageort：完整送达地址 / 地址内获准放置包裹的具体位置。

语境回收

Noah bestellt ein Ersatzteil und wählt seine Packstation als Lieferadresse. Kurz danach erhält er eine Versandbestätigung mit Sendungsnummer. Am nächsten Morgen zeigt die Sendungsverfolgung "in Zustellung". Weil alle Paketfächer belegt sind, bringt der Zusteller die Sendung in einen Paketshop. Noah findet eine Benachrichtigungskarte im Briefkasten und holt das Paket am Abend gegen Vorlage seines Abholscheins ab.

Noah订购了一个备件，并选择自动包裹柜作为收货地址。不久后，他收到带寄件编号的发货确认。第二天早晨，物流查询显示"正在派送"。由于所有柜格已满，投递员把包裹送到一个服务点。Noah在信箱里看到通知卡，当晚出示取件凭证领取了包裹。

自测

  1. 正式表格中的地址常叫 _______。 2. 收货地址是 _______。
  2. 寄件人是 _______，收件人是 _______。 4. 门牌号后的字母是 _______。
  3. 物流唯一编号是 _______。 6. 自动包裹柜系统是 _______。
  4. "正在末端派送"是 in \_\_\_\_\_\_\_。 8. 投递不成功的一次尝试是 _______。
  5. 退货运输标签是 _______。 10. 查询物流进度叫 die Sendung _______。
答案
  1. Anschrift 2. Lieferadresse 3. Absender / Empfänger 4. Hausnummernzusatz
  2. Sendungsnummer 6. Packstation 7. Zustellung 8. Zustellversuch 9. Retourenlabel 10. verfolgen
