06-1 蔬菜（Gemüse）

本组第 1 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

买菜时要会辨认名称，也要注意地区同义词：Karotte 和 Möhre、Lauch 和 Porree 指同一种蔬菜。Paprika 在德语里通常先让人想到甜椒；要表达辣椒，需要更具体地说 Chili 或 Peperoni。

精讲

  1. Gemüse / Gemüsesorte：蔬菜总称 / 一种具体类别。
  2. Karotte / Möhre：都是胡萝卜，使用偏好有地区差异。
  3. Sellerie / Knollensellerie / Staudensellerie：总称 / 食根部 / 食叶柄。
  4. Lauch / Porree：同一种蔬菜的地区同义词。
  5. Kohl / Weißkohl / Rotkohl：甘蓝总称 / 白甘蓝 / 紫甘蓝。
  6. Salat / Kopfsalat：沙拉或叶菜总称 / 结球生菜。
  7. Gurke / Essiggurke：鲜黄瓜 / 醋渍小黄瓜。
  8. Paprika：既可指甜椒，也可指辣椒粉，要看搭配。
  9. Pilz / Champignon：蘑菇和真菌总称 / 常见人工栽培口蘑。
  10. Linse / Kichererbse：扁豆 / 鹰嘴豆，都常作干豆类。
  11. Spargel：集合使用，通常不用复数表示一餐中的多根芦笋。
  12. anbauen / ernten：种植 / 收获。
  13. entkernen：适用于甜椒、南瓜等去籽和籽瓤。
  14. hobeln / schneiden：用刨片器得到均匀薄片 / 用刀切的宽泛说法。
  15. roh / blanchiert / bissfest：生的 / 短时焯水的 / 熟而仍有咬感的。

易混辨析

  • Blumenkohl / Brokkoli：白色紧密花球 / 绿色分枝花球。
  • Rettich / Radieschen：较大的萝卜 / 小而圆的樱桃萝卜。
  • Erbse / Bohne：豌豆 / 豆类宽泛名称。
  • Zucchini / Gurke：通常烹调的南瓜属果菜 / 常生食或腌制的黄瓜。

语境回收

Auf dem Wochenmarkt kauft Leo saisonales Gemüse aus regionalem Anbau: einen Bund Radieschen, eine Stange Lauch, zwei Kohlrabi und frischen Spinat. Zu Hause wäscht er alles gründlich. Den Kohlrabi schält er, die Radieschen hobelt er fein, und den Spinat blanchiert er nur kurz, damit er bissfest bleibt.

Leo在周市购买本地当季蔬菜：一把樱桃萝卜、一根韭葱、两个球茎甘蓝和新鲜菠菜。回家后全部洗净；球茎甘蓝削皮，樱桃萝卜刨薄片，菠菜只短暂焯水以保持口感。

自测

  1. Karotte und _______ sind regionale Synonyme. 2. Eine einzelne Einheit Knoblauch heißt _______.
  2. Porree ist ein anderes Wort für _______. 4. Ein kleiner roter Rettich heißt _______.
  3. Gemüse aus der Umgebung ist _______. 6. Paprika wird vor dem Füllen _______.
  4. Sehr dünne Gurkenscheiben werden _______. 8. Gemüse bleibt beim kurzen Garen _______.
  5. Kichererbsen und Linsen gehören zu den _______. 10. Im Herbst werden Kartoffeln _______.
答案
  1. Möhre 2. Zehe 3. Lauch 4. Radieschen 5. regional
  2. entkernt 7. gehobelt 8. bissfest 9. Hülsenfrüchten 10. geerntet
