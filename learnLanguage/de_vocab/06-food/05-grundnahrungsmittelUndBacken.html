06-5 主食与烘焙（Grundnahrungsmittel und Backen）

本组第 5 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德国超市和面包店里，谷物和面包名称经常直接说明原料：Roggenbrot、Vollkornbrot、Dinkelbrötchen。烘焙时则要分清 Hefeteig、Mürbeteig、Blätterteig 和 Sauerteig，因为它们的膨松原理和处理方式不同。

精讲

  1. Getreide / Mehl：谷物原粮 / 磨成的粉。
  2. Weizen / Roggen / Dinkel：小麦 / 黑麦 / 斯佩尔特小麦。
  3. Reis / Naturreis：大米总称 / 保留麸皮层的糙米。
  4. Nudel / Pasta：单根或面条基本词 / 意大利面食总称。
  5. Brot / Brötchen：面包总称或整只面包 / 单人份小面包。
  6. Vollkornbrot / Mischbrot：使用全谷物成分 / 混合多种谷物粉。
  7. Kuchen / Torte：一般烤制甜点 / 多层并有奶油装饰的精致蛋糕。
  8. Keks / Plätzchen：一般小饼干 / 尤其节日小甜饼。
  9. Kruste / Krume：外层硬壳 / 内部柔软组织。
  10. Hefe / Backpulver / Sauerteig：酵母 / 化学膨松剂 / 微生物发酵面种。
  11. Hefeteig / Mürbeteig / Blätterteig：发酵面团 / 酥松面团 / 多层起酥面团。
  12. kneten / rühren：揉压有筋性面团 / 转动混合面糊。
  13. aufgehen：面团膨胀时完成时用 sein。
  14. ausrollen / ausstechen：擀平 / 用模具切出形状。
  15. knusprig / luftig：外层脆 / 内部多孔轻盈。

易混辨析

  • Mehl / Stärke：谷物粉 / 提取的淀粉。
  • Couscous / Bulgur：粗粒小麦制品 / 预煮后破碎的小麦。
  • Baguette / Brezel：长棍面包 / 扭结形碱水面包。
  • glutenfrei / Vollkorn：是否含麸质 / 是否保留全谷物成分。

语境回收

Für die Brötchen löst Ben Hefe in lauwarmem Wasser auf und gibt das Mehl nach und nach dazu. Er knetet den Hefeteig, bis er glatt ist, und lässt ihn eine Stunde gehen. Danach formt er kleine Brötchen, bestreicht sie mit Wasser und bäckt sie im vorgeheizten Ofen. Außen werden sie knusprig, innen bleibt die Krume luftig.

Ben做小面包时先把酵母溶于温水，逐步加面粉，揉到光滑后发酵一小时。之后整形成小面包，表面刷水，放进预热烤箱。外壳变脆，内部仍松软多孔。
