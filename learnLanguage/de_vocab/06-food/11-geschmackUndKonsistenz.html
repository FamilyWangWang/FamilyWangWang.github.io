06-11 口味与质地（Geschmack und Konsistenz）

本组第 11 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 20 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

评价食物时，可以先闻香气，再描述入口和咀嚼，最后说留下的味道。本篇把“好吃”拆成具体体验，也保留不同人的偏好。

评价食物不能只用 gut。味道可拆成甜、酸、咸、苦、鲜香和辣，质地则可描述 cremig、knackig、faserig、zäh 等。scharf 是辣感，würzig 是香料风味浓，两者并不相等。

精讲

  1. Geschmack / Aroma：综合味觉印象 / 特征香气。

  2. Geschmackssinn / Geruchssinn：味觉能力 / 嗅觉能力，两者共同影响风味。

  3. Süße / Säure / Bitterkeit：甜度 / 酸度 / 苦味程度。

  4. Schärfe / Würze：辣感 / 调料带来的风味浓度。

  5. Konsistenz / Textur / Mundgefühl：整体稀稠软硬 / 微观结构 / 口腔综合触感。

  6. süß / sauer / bitter / salzig：四种基础味道描述。

  7. scharf / würzig / pikant：辣 / 香料味浓 / 刺激性香辣或咸鲜。

  8. fade / geschmacklos：味淡无特色 / 几乎没味，也可指不得体。

  9. cremig / sämig / dickflüssig：奶油般细腻 / 浓稠顺滑 / 黏度高。

  10. knusprig / kross / knackig：前两者都可说烤炸后的脆，knackig常说新鲜爽脆；有交叠，不给kross固定比knusprig更强的等级。

  11. zart / weich / zäh：细嫩 / 软 / 难咬断。

  12. mehlig / körnig / glatt：粉质 / 有颗粒 / 无颗粒顺滑。

  13. saftig / trocken / wässrig：多汁 / 缺水分 / 水多且味淡。

  14. versalzen / überwürzt / verbrannt：过咸 / 调料过多 / 烧焦。

  15. schmecken / riechen / duften：尝起来 / 闻起来 / 散发通常宜人的香气。

易混辨析

  • herzhaft / deftig：咸鲜非甜 / 味重且通常较油足。
  • fettig / ölig：含油脂过多 / 表面或口中有明显油层。
  • krümelig / bröselig：散成细小碎屑 / 散成较干小块。
  • flüssig / sämig / fest：液态 / 浓稠可流动 / 保持形状。

语境回收

Die Suppe duftet aromatisch nach Kräutern und hat eine samtige, sämige Konsistenz. Sie schmeckt mild, aber nicht fade; nur im Nachgeschmack ist eine leichte Bitterkeit zu merken. Das Brot dazu ist außen knusprig und innen luftig. Der Salat bleibt knackig und gibt dem weichen Gericht mehr Biss.

汤散发丰富香草气味，质地丝滑浓稠。味道温和但不寡淡，只在后味中有一点苦。搭配的面包外脆内松，沙拉保持爽脆，为柔软菜品增加咬感。

汤的samtig、sämig描述质地，mild与Bitterkeit描述味道；沙拉的knackig又和软汤形成对照。Nachgeschmack不必难吃，故事中的一点苦才是具体内容。

把词放回句子

Ein Geschmack nach dem Schlucken ist der Nachgeschmack.（吞咽后的味道叫余味。）它可能好也可能不好。Eine dicke, glatte Soße ist sämig.（浓稠顺滑的酱汁是sämig。）Frischer Salat ist oft knackig.（新鲜沙拉常爽脆。）Schwer zu kauendes Fleisch ist zäh.（难嚼的肉是zäh。）

Essen mit zu viel Salz ist versalzen.（盐过量的食物是versalzen。）Eine Suppe ohne genug Geschmack kann fade schmecken.（缺少风味的汤可说fade。）Das Innere eines Kuchens kann luftig sein.（蛋糕内部可轻盈多孔。）“淡”和“轻盈”说的是不同体验，不能放进同一个好坏等级。

Geruch und Geschmack tragen zum Aromaeindruck bei.（气味和味道共同形成风味印象。）Zartbitterschokolade schmeckt häufig bitter.（黑巧克力常带苦味。）Etwas sehr Zartes kann auf der Zunge zergehen.（非常细腻的食物可入口即化。）Aroma在日常可说香气或风味，不把原精讲的简写当成所有语境的唯一义。
