06-2 水果（Obst）

本组第 2 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

德语把水果整体称为不可数的 Obst，具体一种则用可数名称。购买时常要说明成熟度和口感：reif、saftig、süß、säuerlich。还要分清 Kern 和 Stein：苹果有多个小籽，桃和樱桃通常有一个硬核。

精讲

  1. Obst / Frucht：日常食用水果总称 / 植物学或单个果实的宽泛词。
  2. Pflaume / Zwetschge：李子总称 / 椭圆且常易脱核的一类欧洲李。
  3. Kirsche / Sauerkirsche：樱桃总称 / 酸樱桃。
  4. Pfirsich / Nektarine：有绒毛表皮的桃 / 光滑表皮的油桃。
  5. Heidelbeere / Blaubeere：同一种蓝莓的两种常见说法。
  6. Orange / Apfelsine：同一种水果，Apfelsine 带地区色彩。
  7. Mandarine / Clementine：宽泛小柑橘 / 通常甜而少籽的杂交种。
  8. Zitrone / Limette：黄色柠檬 / 通常绿色、香气不同的青柠。
  9. Kern / Stein：苹果等的小籽 / 桃樱桃等的单个硬核。
  10. Schale / Fruchtfleisch：果皮 / 内部可食软组织。
  11. reifen / reif：成熟的过程 / 成熟后的状态。
  12. pflücken / ernten：逐个摘取 / 收获整批作物。
  13. auspressen：Ich presse zwei Orangen für den Saft aus.
  14. süß / säuerlich：明显甜 / 带温和酸味。
  15. nachreifen：采摘后继续成熟，不是所有水果都具备这种能力。

易混辨析

  • Erdbeere / Himbeere / Brombeere：草莓 / 覆盆子 / 黑莓。
  • Wassermelone / Honigmelone：西瓜 / 甜瓜类。
  • Grapefruit / Pomelo：葡萄柚 / 通常更大的柚类水果。
  • reif / weich：成熟度合适 / 触感柔软，两者不必然相同。

语境回收

Für einen Obstsalat nimmt Sara eine reife Mango, zwei säuerliche Äpfel, eine Schale Erdbeeren und kernlose Trauben. Sie schält die Mango, löst den Stein heraus und schneidet das Fruchtfleisch in Würfel. Die Äpfel schneidet sie in Spalten. Zum Schluss presst sie eine Limette aus und gibt den Saft darüber.

Sara做水果沙拉，用一个熟芒果、两个微酸苹果、一盒草莓和无籽葡萄。她给芒果削皮去核，把果肉切丁；苹果切瓣，最后挤一只青柠，把汁淋在上面。

自测

  1. Obst ist meist nicht zählbar; eine einzelne Sorte heißt _______. 2. Heidelbeere und _______ sind Synonyme.
  2. Ein Pfirsich hat keinen Kern, sondern einen _______. 4. Noch nicht reifes Obst ist _______.
  3. Saft gewinnt man, indem man Orangen _______. 6. Eine Melone kann man in zwei Hälften _______.
  4. Das Essbare zwischen Schale und Kern heißt _______. 8. Äpfel werden vom Baum _______.
  5. Manche Birnen können bei Zimmertemperatur _______. 10. Obst mit viel Flüssigkeit ist _______.
答案
  1. Obstsorte 2. Blaubeere 3. Stein 4. unreif 5. auspresst
  2. halbieren 7. Fruchtfleisch 8. gepflückt 9. nachreifen 10. saftig
