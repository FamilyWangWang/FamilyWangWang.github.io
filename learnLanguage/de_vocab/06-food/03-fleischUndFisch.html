06-3 肉类与鱼（Fleisch und Fisch）

本组第 3 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 1 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语肉类复合词通常直接说明动物来源：Rindfleisch、Schweinefleisch、Lammfleisch。购买鱼时则要问是整鱼还是 Fischfilet，是否还有 Gräten。Seelachs 名称里虽有 Lachs，却不是鲑鱼，而是鳕形目鱼类的商品名。

精讲

  1. Fleisch / Fleischsorte：肉类总称 / 按来源区分的一类肉。
  2. Rind / Kalb：成年牛来源 / 小牛来源。
  3. Hähnchen / Huhn：食用嫩鸡或烤鸡 / 鸡这种动物和较宽泛鸡肉称呼。
  4. Geflügel / Wild：家禽肉总称 / 可狩猎野生动物及其肉。
  5. Hackfleisch / Filet：绞碎肉 / 去骨且通常较嫩的整块肉。
  6. Steak / Schnitzel / Kotelett：厚切肉排 / 薄切肉片 / 带肋骨肉排。
  7. Wurst / Bratwurst：香肠总称 / 适合煎烤的一类香肠。
  8. Schinken / Speck：腿部腌熟肉 / 脂肪较多的腌熏肉。
  9. Fisch / Fischfilet：鱼或鱼肉总称 / 去除主要骨刺的鱼片。
  10. Lachs / Seelachs：鲑鱼 / 青鳕类商品名，并非同类。
  11. Garnele / Krabbe：虾 / 蟹；Nordseekrabbe 实际常指小虾。
  12. Gräte / Knochen：鱼刺 / 肉中较大的骨头。
  13. filetieren / ausnehmen：取无骨肉片 / 去除内脏。
  14. mager / durchwachsen：脂肪少 / 瘦肉中夹有脂肪。
  15. geräuchert / mariniert：烟熏处理 / 调味液浸渍。

易混辨析

  • Forelle / Lachs：鳟鱼 / 鲑鱼。
  • Kabeljau / Seelachs：大西洋鳕 / 青鳕类商品名。
  • Muschel / Auster：贝类总称 / 牡蛎。
  • roh / geräuchert / durchgegart：生的 / 烟熏的 / 完全熟透的。

语境回收

An der Fischtheke fragt Mira nach einem fangfrischen Fischfilet ohne Gräten. Sie entscheidet sich für Kabeljau. Für die Gäste kauft sie außerdem mageres Rinderhack und ein kleines Stück durchwachsenen Speck. Zu Hause bewahrt sie alles gut gekühlt auf; den Fisch mariniert sie kurz, das Hackfleisch gart sie vollständig durch.

Mira在鱼柜台询问无刺的鲜鱼片，最后选择鳕鱼。她还为客人购买瘦牛肉馅和一小块肥瘦相间的培根。回家后全部冷藏；鱼短暂腌制，肉馅则彻底加热熟透。

自测

  1. Fleisch vom jungen Rind heißt _______. 2. Zerkleinertes Fleisch ist _______.
  2. Ein dünnes Stück Fleisch heißt oft _______. 4. Fischknochen heißen _______.
  3. Seelachs ist kein _______. 6. Ein Fisch ohne Innereien wurde _______.
  4. Fleisch in einer Würzflüssigkeit wird _______. 8. Fleisch mit wenig Fett ist _______.
  5. Ein einzelnes Stück Wurst ist eine _______. 10. Geflügel sollte vollständig _______ werden.
答案
  1. Kalbfleisch 2. Hackfleisch 3. Schnitzel 4. Gräten 5. Lachs
  2. ausgenommen 7. mariniert 8. mager 9. Scheibe 10. durchgegart
