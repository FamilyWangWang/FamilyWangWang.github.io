06-10 烹饪动词（Kochverben）

本组第 10 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 17 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

读懂食谱的关键不是菜名，而是动作顺序和火候。kochen 可以泛指做饭，也可指沸煮；更具体的 dünsten、schmoren、rösten、frittieren 会直接告诉你介质、温度和时间。可分前缀还标出阶段：anbraten 是先煎上色，aufwärmen 是重新加热。

精讲

  1. zubereiten / garen：完成整道食物的制作 / 用热量使食物达到熟度。
  2. kochen / sieden / köcheln：泛指做饭或沸煮 / 达到沸点 / 轻微沸腾。
  3. dünsten / dämpfen：少量液体加盖 / 主要用蒸汽。
  4. braten / anbraten / durchbraten：煎烤 / 先短煎上色 / 煎至内部全熟。
  5. rösten / anrösten：干热形成香气 / 短暂先烘炒。
  6. schmoren / grillen / frittieren：先煎后少液长炖 / 强辐射热烤 / 浸油炸。
  7. erhitzen / erwärmen / aufwärmen：提高温度 / 加到温暖 / 重新加热熟食。
  8. abkühlen / abschrecken：逐渐冷却 / 用冷水快速停止加热。
  9. auftauen / einfrieren：解冻 / 冷冻保存。
  10. würfeln / raspeln / reiben：切丁 / 粗细孔擦丝 / 摩擦成碎屑。
  11. pürieren / mixen：打成泥 / 用机器混合调制。
  12. vermengen / unterheben：均匀混合 / 轻柔翻入保持空气。
  13. abgießen / abtropfen：倒掉液体 / 让液体自行滴干。
  14. einkochen / reduzieren / andicken：熬煮浓缩或保存 / 煮掉水分 / 加材料增稠。
  15. überbacken / gratinieren：表面加配料烤 / 特别强调形成金黄脆层。

易混辨析

  • hacken / würfeln：切成不规则碎末 / 切成规则方块。
  • rühren / schlagen：转动混合 / 快速搅打并常带入空气。
  • schmelzen / karamellisieren：固体变液体 / 糖发生焦糖化。
  • Garzeit / Garstufe：所需时间 / 最终达到的熟度。

语境回收

Zuerst bereitet Lea alle Zutaten vor: Sie wäscht das Gemüse, würfelt die Zwiebeln und raspelt die Karotten. Die Zwiebeln brät sie kurz an, dann gibt sie das übrige Gemüse dazu und dünstet alles mit geschlossenem Deckel. Zum Schluss püriert sie die Suppe, lässt sie noch fünf Minuten köcheln und schmeckt sie ab.

Lea先备齐食材：洗蔬菜、切洋葱丁、擦胡萝卜丝。洋葱短煎后加入其余蔬菜，加盖焖煮。最后把汤打成泥，再小火煮五分钟并调整味道。
