06-4 乳制品与蛋（Milchprodukte und Eier）

本组第 4 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 1 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

乳制品标签常写处理方式、脂肪含量和保质方式：pasteurisiert、homogenisiert、fettarm、laktosefrei。鸡蛋则要会区分 Eigelb 和 Eiweiß，以及 Rührei、Spiegelei、Frühstücksei 等成菜名称。

精讲

  1. Milch / Milchprodukt：饮用奶或乳汁 / 以乳为原料的食品。
  2. Frischmilch / H-Milch：需冷藏且较短保存 / 未开封可常温久存。
  3. Rohmilch / pasteurisierte Milch：未经巴氏处理 / 已短时加热处理。
  4. Sahne / Schlagsahne：奶油总称 / 适合打发的一类奶油。
  5. Sauerrahm / Schmand：酸奶油 / 德国常见、通常脂肪更高的酸奶油。
  6. Joghurt / Quark：发酵酸奶 / 凝乳鲜奶制品。
  7. Frischkäse / Weichkäse：不长时间熟成 / 熟成但质地柔软。
  8. Hartkäse / Schnittkäse：硬质熟成奶酪 / 适合切片的中等硬度奶酪。
  9. Butter / Margarine：乳脂制品 / 主要由植物油等制成。
  10. Laktose / Milcheiweiß：乳糖 / 乳蛋白；不耐受和过敏不是一回事。
  11. Ei / Eigelb / Eiweiß：完整蛋 / 蛋黄 / 蛋清。
  12. Rührei / Spiegelei / Omelett：炒散蛋 / 煎荷包蛋 / 厚蛋饼。
  13. aufschlagen / verquirlen：磕开或打发 / 把蛋液搅匀。
  14. stocken：蛋液受热从液体变成凝固状态。
  15. laktosefrei / fettarm：乳糖属性 / 脂肪含量属性，彼此独立。

易混辨析

  • Eiweiß / Milcheiweiß：蛋清或蛋白质 / 明确指乳蛋白。
  • Eierkuchen / Pfannkuchen：许多地区都指薄煎饼；Pfannkuchen 在柏林等地另有含义。
  • Vollmilch / fettarme Milch：标准较高脂肪含量 / 降低脂肪含量。
  • Mindesthaltbarkeitsdatum / Verbrauchsdatum：最佳品质期限 / 高风险食品的最后食用日期。

语境回收

Im Kühlregal vergleicht Dana Vollmilch, fettarme Milch und eine laktosefreie Variante. Für das Frühstück nimmt sie Naturjoghurt, jungen Gouda und sechs Eier mit. Zu Hause schlägt sie zwei Eier auf, verquirlt sie mit einem Schuss Milch und lässt die Masse langsam stocken. Dazu gibt es Brot mit Frischkäse.

Dana在冷藏柜比较全脂奶、低脂奶和无乳糖奶。早餐还买了原味酸奶、年轻高达奶酪和六个鸡蛋。回家后磕两个蛋，加少量牛奶搅匀，慢慢加热凝固，再配抹鲜奶酪的面包。
