06-7 饮料（Getränke）

本组第 7 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

一杯饮料可以同时说明含气程度、冲泡方式和糖的添加情况。本篇把这些属性分开，帮助你听懂服务员确认的到底是哪一项。

点水时要明确 still 还是 mit Kohlensäure；在德国，Mineralwasser 是特定来源的瓶装水，不是所有带气水的泛称。Saft、Nektar 和 Fruchtsaftgetränk 的果汁比例不同，购买时应看标签。

精讲

  1. Wasser / Mineralwasser：水的总称 / 特定地下水源的瓶装矿泉水。

  2. Leitungswasser / Tafelwasser：自来水 / 可调制的瓶装饮用水。

  3. still / sprudelnd：无气泡 / 有明显气泡。

  4. Saft / Fruchtsaft：果蔬汁宽泛说法 / 标签上果汁含量100%的类别。

  5. Direktsaft / Nektar：不经浓缩还原的果汁 / 加水且果汁比例较低的果饮。

  6. Saft / Schorle：纯果汁 / 果汁与气泡水混合。

  7. Limonade / Sirup：可直接饮用的甜味清凉饮料 / 需稀释的浓缩液。

  8. Tee / Kräutertee：茶饮总称 / 非茶树草本冲泡饮品。

  9. Schwarztee / Grüntee：完全氧化茶 / 未完全氧化茶。

  10. Filterkaffee / Espresso：滴滤咖啡 / 小份高压萃取咖啡。

  11. Cappuccino / Milchkaffee：浓缩加奶泡 / 咖啡加大量热牛奶。

  12. Tasse / Becher / Glas：Tasse常说有柄热饮杯，Becher常较高、可有柄也可无柄，Glas指玻璃饮用杯；不能只看杯把机械分类。

  13. aufgießen / brühen：用热水冲上 / 以热水萃取制作。

  14. einschenken：人用第三格、饮料用第四格。

  15. zuckerfrei / ohne Zuckerzusatz：前者是按适用标准允许的极低糖含量声称，后者说未额外添加糖；后者仍可能有天然糖，前者也不直接推成测量值绝对零。

易混辨析

  • Flasche / Karaffe：储运饮料的窄口瓶 / 上桌分饮的壶。
  • Kaffeepulver / Kaffeesatz：冲煮前的咖啡粉 / 冲煮后的残渣。
  • Kakao / Trinkschokolade：可可粉或普通可可饮 / 通常更浓的巧克力饮。
  • koffeinfrei / zuckerfrei：Der Kaffee ist entkoffeiniert, aber nicht zuckerfrei.（咖啡脱了咖啡因，却并非无糖。）两项含量彼此独立；咖啡商品上的koffeinfrei不据字面推断绝对零残留。

语境回收

Im Café bestellt Li zuerst eine Karaffe Leitungswasser ohne Kohlensäure. Danach nimmt sie einen Cappuccino, ihr Begleiter einen koffeinfreien Filterkaffee ohne Zucker. Für das Kind bestellen sie eine Apfelschorle. Der Kellner schenkt das Wasser ein und bringt die heißen Getränke in großen Tassen.

Li在咖啡馆先点一壶无气自来水，然后自己喝卡布奇诺，同伴喝不加糖的无咖啡因滴滤咖啡，孩子喝苹果气泡果汁。服务员倒水，并用大杯端来热饮。

Li先点Leitungswasser，再安排三种饮品。einschenken是倒饮料动作，Karaffe是上桌容器；koffeinfrei与ohne Zucker互不推导，不能凭一种处理就断定其他含量。

把词放回句子

Wasser aus dem Hahn heißt Leitungswasser.（龙头水叫Leitungswasser。）Wasser ohne Kohlensäure ist still.（无气泡水叫still。）Saft mit Sprudelwasser ist eine Schorle.（果汁加气泡水叫Schorle。）Konzentrierten Sirup muss man verdünnen.（浓缩糖浆需要稀释。）

Tee wird mit heißem Wasser aufgegossen.（茶用热水冲泡。）Nach dem Brühen bleibt Kaffeesatz übrig.（冲煮后剩咖啡渣。）Eine kleine Trinkmenge ist ein Schluck.（小口饮用量是一口Schluck。）冲煮前的Kaffeepulver与之后的Kaffeesatz因此分开。

Entkoffeinierter Kaffee wird oft koffeinfrei genannt.（脱咖啡因咖啡常标koffeinfrei。）商品语境不据此推断绝对零残留。Ohne Zuckerzusatz bedeutet nicht unbedingt zuckerfrei.（未添加糖不一定无糖。）In einer Karaffe serviert man Wasser am Tisch.（用水壶上桌分饮。）Becher也可以带把，不凭杯把就判定任何容器名称。
