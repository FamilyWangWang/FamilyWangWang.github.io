06-7 饮料（Getränke）

本组第 7 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

点水时要明确 still 还是 mit Kohlensäure；在德国，Mineralwasser 是特定来源的瓶装水，不是所有带气水的泛称。Saft、Nektar 和 Fruchtsaftgetränk 的果汁比例不同，购买时应看标签。

精讲

  1. Wasser / Mineralwasser：水的总称 / 特定地下水源的瓶装矿泉水。
  2. Leitungswasser / Tafelwasser：自来水 / 可调制的瓶装饮用水。
  3. still / sprudelnd：无气泡 / 有明显气泡。
  4. Saft / Fruchtsaft：果蔬汁宽泛说法 / 标签上果汁含量100%的类别。
  5. Direktsaft / Nektar：不经浓缩还原的果汁 / 加水且果汁比例较低的果饮。
  6. Saft / Schorle：纯果汁 / 果汁与气泡水混合。
  7. Limonade / Sirup：可直接饮用的甜味清凉饮料 / 需稀释的浓缩液。
  8. Tee / Kräutertee：茶饮总称 / 非茶树草本冲泡饮品。
  9. Schwarztee / Grüntee：完全氧化茶 / 未完全氧化茶。
  10. Filterkaffee / Espresso：滴滤咖啡 / 小份高压萃取咖啡。
  11. Cappuccino / Milchkaffee：浓缩加奶泡 / 咖啡加大量热牛奶。
  12. Tasse / Becher / Glas：有柄热饮杯 / 无柄杯 / 玻璃饮用杯。
  13. aufgießen / brühen：用热水冲上 / 以热水萃取制作。
  14. einschenken：人用第三格、饮料用第四格。
  15. zuckerfrei / ohne Zuckerzusatz：不含糖 / 没有额外加糖，后者仍可能含天然糖。

易混辨析

  • Flasche / Karaffe：储运饮料的窄口瓶 / 上桌分饮的壶。
  • Kaffeepulver / Kaffeesatz：冲煮前的咖啡粉 / 冲煮后的残渣。
  • Kakao / Trinkschokolade：可可粉或普通可可饮 / 通常更浓的巧克力饮。
  • koffeinfrei / zuckerfrei：不含咖啡因 / 不含糖。

语境回收

Im Café bestellt Li zuerst eine Karaffe Leitungswasser ohne Kohlensäure. Danach nimmt sie einen Cappuccino, ihr Begleiter einen koffeinfreien Filterkaffee ohne Zucker. Für das Kind bestellen sie eine Apfelschorle. Der Kellner schenkt das Wasser ein und bringt die heißen Getränke in großen Tassen.

Li在咖啡馆先点一壶无气自来水，然后自己喝卡布奇诺，同伴喝不加糖的无咖啡因滴滤咖啡，孩子喝苹果气泡果汁。服务员倒水，并用大杯端来热饮。

自测

  1. Wasser aus dem Hahn heißt _______. 2. Wasser ohne Kohlensäure ist _______.
  2. Saft mit Sprudelwasser ist eine _______. 4. Konzentrierten Sirup muss man _______.
  3. Tee wird mit heißem Wasser _______. 6. Nach dem Brühen bleibt _______ übrig.
  4. Eine kleine Trinkmenge ist ein _______. 8. Kaffee ohne Koffein ist _______.
  5. Ohne Zuckerzusatz bedeutet nicht unbedingt _______. 10. In einer _______ serviert man Wasser am Tisch.
答案
  1. Leitungswasser 2. still 3. Schorle 4. verdünnen 5. aufgegossen
  2. Kaffeesatz 7. Schluck 8. koffeinfrei 9. zuckerfrei 10. Karaffe
