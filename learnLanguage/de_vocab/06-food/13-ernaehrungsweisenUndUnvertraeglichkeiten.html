06-13 饮食习惯与忌口（Ernährungsweisen und Unverträglichkeiten）

本组第 13 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 8 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

饮食选择和医学禁忌要分开表达：vegetarisch、vegan 是饮食方式，Lebensmittelallergie、Laktoseintoleranz、Zöliakie 则涉及健康风险。点餐时不要只说"我不吃"，而应清楚说明是个人选择、不能耐受，还是已确诊过敏，并询问配料和可能的交叉接触。

精讲

  1. Ernährung / Ernährungsweise / Essgewohnheit：长期饮食整体 / 可命名模式 / 重复行为习惯。
  2. Mahlzeit / Zwischenmahlzeit / Snack：完整一餐 / 两餐间小餐 / 快速零食。
  3. Hunger / Appetit / Sättigung：身体需要食物 / 想吃某物 / 吃后饱足。
  4. Vegetarismus / Veganismus：通常不食肉鱼 / 避免动物来源食材和产品。
  5. Flexitarismus / Pescetarismus：以植物为主偶尔食肉 / 不食肉但食鱼海鲜。
  6. Allergie / Unverträglichkeit：免疫反应 / 引发不适的宽泛非同义概念。
  7. Laktoseintoleranz / Milcheiweißallergie：乳糖消化问题 / 对乳蛋白的免疫反应。
  8. Zöliakie：由麸质触发的自身免疫性疾病，不是生活方式标签。
  9. Allergen / Zutatenliste：触发过敏的物质 / 实际配料清单。
  10. Zutat / Spur：配方中有意加入 / 生产中可能无意带入。
  11. Kreuzkontamination：过敏原可经手、工具、油和操作面无意转移。
  12. meiden / verzichten：为安全等避开 / 有意识放弃，语气和原因不同。
  13. vertragen / enthalten / auslösen：身体耐受 / 食物含有 / 触发反应。
  14. glutenfrei / laktosefrei：不含麸质 / 不含乳糖，针对不同成分。
  15. ausgewogen / einseitig：来源多样比例合理 / 长期依赖少数类别。

易混辨析

  • vegetarisch / vegan / pflanzlich：素食 / 纯素 / 植物来源的单项属性。
  • Diät / Ernährungsweise：特定目的饮食方案 / 日常长期模式。
  • glutenfrei / getreidefrei：不含麸质 / 不含谷物，范围不同。
  • Allergenkennzeichnung / Spurenhinweis：规定过敏原配料标示 / 对无意带入的自愿预防提示。

语境回收

Bei der Reservierung informiert Mina das Restaurant über ihre diagnostizierte Nussallergie. Vor der Bestellung prüft sie mit der Bedienung die Zutatenliste und fragt nach möglichem Kreuzkontakt in der Küche. Ihr Begleiter isst vegan, hat aber keine Allergie. Deshalb erklären beide ihre Anforderungen getrennt und eindeutig.

预订时Mina告知餐厅自己已确诊坚果过敏。点餐前，她与服务人员核对配料并询问厨房是否可能交叉接触。同伴吃纯素但没有过敏，所以两人分别清楚说明各自要求。
