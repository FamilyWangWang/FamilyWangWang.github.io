06-12 德国菜与餐厅（Deutsche Küche und Restaurant）

本组第 12 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 3 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

"德国菜"并不是一种统一风格：Knödel、Klöße、Spätzle、Maultaschen 等都有明显地区分布。餐厅里先看 Speisekarte，再区分单点和 Menü；结账时要说明一起还是分开，并主动说出希望支付的总额或找零方式。

精讲

  1. Vorspeise / Hauptgericht / Nachspeise：前菜 / 主菜 / 甜点。
  2. Beilage：与主菜搭配的土豆、米饭、蔬菜等，不是额外一道主菜。
  3. Speisekarte / Tageskarte / Menü：常规菜单 / 当日菜单 / 固定组合套餐。
  4. Restaurant / Gasthaus / Imbiss：正餐餐馆 / 传统餐饮旅店 / 快餐小店。
  5. Knödel / Kloß：同类团子配菜的地区说法。
  6. Spätzle / Maultaschen：德国西南小面疙瘩 / 施瓦本有馅面食。
  7. Sauerkraut / Rotkohl：发酵白甘蓝 / 熟制紫甘蓝配菜。
  8. Currywurst / Weißwurst：咖喱香肠小吃 / 巴伐利亚白香肠。
  9. Leberkäse：名称含 Leber 和 Käse，但常见配方通常不含奶酪。
  10. Eintopf / Suppe：多种食材一锅成菜 / 汤的宽泛类别。
  11. reservieren / bestellen：提前留桌 / 到店点菜。
  12. empfehlen：人第三格、推荐物第四格。
  13. reklamieren / stornieren：对已提供内容提出异议 / 取消尚未履行的预订。
  14. zusammen / getrennt zahlen：合并付款 / 各自付款。
  15. Stimmt so.：表示不需要找零，应在明确付款金额后使用。

易混辨析

  • Bedienung / Kellner：服务人员或服务过程 / 男服务员。
  • Bestellung / Rechnung：点下的内容 / 最终应付账单。
  • hausgemacht / regional：店内或家庭制作 / 原料或产品来自附近地区。
  • vegetarisch / vegan / fleischlos：不含肉鱼 / 不含动物来源 / 只明确不含肉。

语境回收

Nora hat im Gasthaus einen Tisch für vier reserviert. Als Vorspeise bestellt die Gruppe eine Suppe, danach Sauerbraten mit Knödeln und Rotkohl; für einen Gast gibt es hausgemachte vegane Maultaschen. Zum Nachtisch teilen sie Apfelstrudel. Am Ende bitten sie um die Rechnung und zahlen getrennt.

Nora在传统餐馆订了四人桌。大家前菜点汤，之后吃酸味炖肉配团子和紫甘蓝；一位客人吃店内自制的纯素馅面食。甜点分食苹果卷，最后要账单并各自付款。

自测

  1. Das Essen vor dem Hauptgericht ist die _______. 2. Kartoffeln neben dem Fleisch sind eine _______.
  2. Eine feste Folge mehrerer Gänge heißt _______. 4. Knödel heißen regional auch _______.
  3. Ein Gericht ohne tierische Zutaten ist _______. 6. Vor dem Besuch kann man einen Tisch _______.
  4. Beim Kellner wird das Essen _______. 8. Eine falsche Speise kann man _______.
  5. Mehrere Personen können getrennt _______. 10. Wer kein Rückgeld möchte, sagt _______.
答案
  1. Vorspeise 2. Beilage 3. Menü 4. Klöße 5. vegan
  2. reservieren 7. bestellt 8. reklamieren 9. zahlen 10. Stimmt so
