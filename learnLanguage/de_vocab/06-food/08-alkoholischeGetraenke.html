06-8 酒（Alkoholische Getränke）

本组第 8 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

酒类名称首先区分发酵饮品和蒸馏酒：啤酒由谷物酿造，葡萄酒由葡萄发酵，Spirituosen 则经过蒸馏。点单时还会遇到 trocken、halbtrocken、lieblich、herb 等风味词。饮酒量和反应因人而异；饮酒后不要驾驶或操作危险设备。

精讲

  1. Bier / Wein / Spirituose：谷物发酵酒 / 葡萄发酵酒 / 蒸馏酒。
  2. Pils / Lagerbier：酒花苦味明显的一类 / 低温储藏熟成的宽泛类别。
  3. Weizenbier / Weißbier：同类小麦啤酒，后者在南德常见。
  4. Altbier / Kölsch：杜塞尔多夫地区风格 / 科隆地区风格。
  5. Bier / Radler：纯啤酒 / 啤酒与汽水混合。
  6. Rotwein / Weißwein / Roséwein：红 / 白 / 桃红葡萄酒。
  7. Schaumwein / Sekt：起泡葡萄酒总称 / 德语区常用的具体名称。
  8. Champagner / Prosecco：受产区和生产规范保护的不同名称。
  9. Cider / Apfelwein：英语国际名称 / 德语苹果酒名称。
  10. Schnaps / Spirituose：日常烈酒泛称 / 正式产品类别。
  11. Cocktail / Longdrink：多成分调制饮品 / 烈酒加大量软饮的长饮。
  12. trocken / lieblich：残糖低 / 明显偏甜。
  13. herb / bitter：干爽收敛或带苦感 / 明确的苦味。
  14. brauen / keltern / destillieren：酿啤酒 / 压榨葡萄 / 蒸馏。
  15. alkoholfrei：应以具体产品标签为准，不要只凭名称推断绝对零酒精。

易混辨析

  • Korn / Whisky：德国谷物烈酒 / 谷物蒸馏并木桶熟成的酒。
  • Weinbrand / Likör：葡萄酒蒸馏熟成 / 加糖调味酒。
  • Bierglas / Weinglas / Sektglas：啤酒杯 / 葡萄酒杯 / 细长起泡酒杯。
  • Alkoholgehalt / Promille：饮品中的比例 / 常用于体内酒精浓度的千分比。

语境回收

Beim Abendessen bestellt Amir ein alkoholfreies Weizenbier, seine Begleiterin einen trockenen Weißwein. Der Kellner schenkt den Wein ein und stellt zusätzlich eine Karaffe Wasser auf den Tisch. Zum Geburtstag stoßen alle mit ihren jeweiligen Getränken an. Wer später fährt, bleibt konsequent bei alkoholfreien Getränken.

晚餐时Amir点无酒精小麦啤酒，同伴点干白葡萄酒。服务员倒酒，并在桌上放一壶水。大家用各自的饮品为生日碰杯；之后开车的人始终只喝无酒精饮品。
