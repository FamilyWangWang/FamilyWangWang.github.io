06-9 餐具与厨具（Geschirr und Küchenutensilien）

本组第 9 篇 · 共 13 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 11 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Geschirr 是盘、碗、杯等餐具的总称，Besteck 是刀叉勺的总称，锅具和操作工具则属于 Küchenutensilien。选择器具时除名称外，还要看是否 ofenfest、是否有涂层，以及刀刃是 scharf 还是 stumpf。

精讲

  1. Geschirr / Besteck：盘碗杯具总称 / 刀叉勺总称。
  2. Teller / Schüssel：平盘或浅盘 / 深容器。
  3. Essteller / Suppenteller / Dessertteller：主餐盘 / 汤盘 / 甜点盘。
  4. Esslöffel / Teelöffel：餐勺及食谱大匙 / 茶匙及食谱小匙。
  5. Topf / Pfanne：高直壁锅 / 低边煎锅。
  6. Bräter / Auflaufform：烤炖大块食物 / 烤焗菜的深皿。
  7. Backblech / Backform：平烤盘 / 限定成品形状的烤模。
  8. Kochlöffel / Schöpfkelle：长柄搅拌勺 / 舀汤大勺。
  9. Pfannenwender / Küchenzange：扁平翻面工具 / 夹取翻动工具。
  10. Schneebesen / Mörser：搅打混匀 / 捣碎香料。
  11. Sparschäler / Gemüsemesser：薄削果皮 / 小刀切削。
  12. Brotmesser / Kochmesser：锯齿长刀 / 多用途宽刃刀。
  13. decken / servieren：摆好餐桌 / 端上食物。
  14. abmessen / schöpfen：量取准确体积 / 从大容器舀出。
  15. scharf / stumpf：锋利 / 钝；刀具安全不仅取决于是否锋利。

易混辨析

  • Tasse / Becher：有柄小杯 / 通常无柄或较高的杯。
  • Schneidebrett / Servierplatte：切配垫板 / 上桌展示食物的大盘。
  • Sieb / Trichter：过滤沥水 / 导入窄口容器。
  • Topflappen / Ofenhandschuh：隔热垫 / 包住手的隔热手套。

语境回收

Vor dem Essen deckt Ana den Tisch: Gabeln links, Messer und Löffel rechts, Gläser oben. In der Küche misst sie Brühe im Messbecher ab und gießt sie in einen großen Kochtopf. Die fertige Suppe schöpft sie mit der Kelle in Suppenteller. Den heißen Topf fasst sie nur mit trockenen Ofenhandschuhen an.

饭前Ana摆桌：叉子在左，刀勺在右，杯子在上方。厨房里她用量杯量汤汁，倒入大锅；汤做好后用汤勺盛进汤盘。热锅只用干燥隔热手套拿。

自测

  1. Messer, Gabel und Löffel sind _______. 2. Suppe kommt in einen _______.
  2. Flüssigkeit misst man im _______. 4. Nudeln lässt man im _______ abtropfen.
  3. Suppe wird mit der _______ ausgeteilt. 6. Brot schneidet man mit dem _______.
  4. Ein Messer ohne gute Schneide ist _______. 8. Vor dem Essen wird der Tisch _______.
  5. Eine Form für den Backofen muss _______ sein. 10. Heiße Bleche nimmt man mit _______ heraus.
答案
  1. Besteck 2. Suppenteller 3. Messbecher 4. Sieb 5. Schöpfkelle
  2. Brotmesser 7. stumpf 8. gedeckt 9. ofenfest 10. Ofenhandschuhen
