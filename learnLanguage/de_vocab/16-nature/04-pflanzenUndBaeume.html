16-4 植物与树木（Pflanzen und Bäume）

本组第 4 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 16 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

根、干、芽、叶先帮助定位；常绿、落叶和用途再补充不同属性。本篇不以一个俗名或图片代替可靠鉴定，也保留植物与真菌的区别。

描述植物时可先区分 Baum、Strauch、Kraut 和 Gras，再说明 Wurzel、Stamm、Blatt、Blüte 等部位。Laubbaum 与 Nadelbaum 是按叶片形态划分的常用类别；immergrün 和 laubabwerfend 则描述植物是否全年保留叶片。野外植物和蘑菇不要仅凭图片判断能否食用。

精讲

  1. Pflanze / Baum / Strauch / Kraut：植物总称、乔木、灌木和非木质草本。

  2. Blume / Gras / Moos / Farn / Pilz：观赏花、禾草、苔藓、蕨类及非植物的真菌。

  3. Wurzel / Stamm / Ast / Zweig：根、主干、粗枝和细枝。

  4. Rinde / Blatt / Nadel：树皮、普通叶片和针状叶。

  5. Blüte / Knospe / Frucht / Samen / Pollen：花、芽、果实、种子和花粉。

  6. Laubbaum / Nadelbaum / Obstbaum：阔叶树、针叶树和果树。

  7. Eiche / Buche / Ahorn：橡树、山毛榉和枫树。

  8. Birke / Linde / Kastanie：桦树、椴树和栗树／七叶树日常称呼。

  9. Fichte / Tanne / Kiefer：云杉、冷杉和松树。

  10. Rose / Tulpe / Sonnenblume：三种常见园艺花卉。

  11. Löwenzahn / Gänseblümchen / Brennnessel：蒲公英、雏菊和荨麻。

  12. Getreide / Weizen / Mais / Raps：Getreide是谷物总称，Weizen与Mais是谷物，Raps是油料作物，不属于禾本科谷物。

  13. Zimmerpflanze / Nutzpflanze / Wildpflanze / Heilpflanze：室内、用途、野生和药用分类。

  14. wachsen / blühen / keimen / verwelken：生长、开花、萌发和枯萎。

  15. immergrün / laubabwerfend / essbar / giftig：常绿、落叶、可食和有毒。

易混辨析

  • Pflanze / Pilz：植物 / 真菌；日常采集常并列谈，但科学分类不同。
  • Baum / Strauch：通常有明显主干 / 从近地面分出多条木质枝干。
  • Ast / Zweig：较粗主枝 / 较细末端枝条。
  • Blume / Blüte：作为整体观赏的花卉植物 / 植物的花器官。
  • Fichte / Tanne：云杉针叶较尖且球果下垂 / 冷杉针叶较扁且球果直立。
  • essbar / ungiftig：可以食用 / 没有已知毒性；无毒不自动等于适合食用。

语境回收

Im Frühling treibt die alte Linde neue Blätter und Knospen aus. Unter dem Baum blühen Gänseblümchen und Löwenzahn. Mira pflanzt neben der Hecke einen Strauch und sät Sonnenblumen aus. Die Zimmerpflanzen gießt sie erst, nachdem sie die Erde geprüft hat. Einen unbekannten Pilz im Garten lässt sie stehen, weil sie nicht sicher bestimmen kann, ob er essbar oder giftig ist.

春天，老椴树长出新叶和新芽。树下雏菊和蒲公英开放。Mira 在树篱旁种下一株灌木并播种向日葵。她先检查土壤再给室内植物浇水。花园里一株陌生蘑菇无法可靠鉴定是否可食或有毒，因此她让它留在原处。

Mira先检查土壤再浇水，并把陌生蘑菇留在原处。故事没有从“长在花园里”推断能吃；种灌木、播向日葵与室内照料也分别使用不同动词。

把词放回句子

Ein Strauch hat meist mehrere verholzte Triebe nahe dem Boden; der Stamm ist die Hauptachse eines Baumes.（灌木近地常有多条木质枝干，树干是树的主要轴。）Eine Knospe enthält noch nicht entfaltete Teile.（芽包含尚未展开的部分。）Laubbaum beschreibt eine Baumgruppe mit meist breiten Blättern.（阔叶树通常有宽叶。）这不保证它一定季节性落叶。

Viele Birken haben helle Rinde; bei Kiefern stehen Nadeln oft in Bündeln.（许多桦树有浅树皮，松树针叶常成束。）Löwenzahn trägt gelbe Blütenstände und später Früchte mit Flughaaren.（蒲公英有黄色花序，之后结带冠毛的果实。）这些是常见特征，要认具体物种仍需多项依据。

Eine Nutzpflanze wird etwa für Nahrung oder Fasern angebaut.（用途植物例如为食物或纤维栽培。）Die Samen keimen; eine immergrüne Pflanze behält ganzjährig funktionsfähige Blätter.（种子萌发，常绿植物全年保留功能性叶片。）常绿也会换叶，keimen说萌发，不能把它直接等同整株终生的wachsen。
