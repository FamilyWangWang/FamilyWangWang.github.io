16-1 天气与气象（Wetter und Meteorologie）

本组第 1 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

日常交流里，Wetter 指某时某地的短期大气状况，预报中则常见 Wetterlage、Luftdruck、Front 和 Niederschlag。温度要说清实际测得的 Lufttemperatur 与受风、湿度等影响的 Gefühlstemperatur。收到 Unwetterwarnung 时，应查看发布地区、有效时段和风险类型，而不是只看一个醒目的天气图标。

精讲

  1. Wetter / Wetterlage：具体短期天气 / 一段时间的区域气象形势。
  2. Wetterbericht / Wettervorhersage：天气播报 / 对未来天气的预测。
  3. Meteorologie / Wetterdienst / Messstation：气象科学 / 气象服务机构 / 观测站。
  4. Temperatur / Höchsttemperatur / Tiefsttemperatur：温度总称 / 最高值 / 最低值。
  5. Lufttemperatur / Gefühlstemperatur：实际测量的空气温度 / 人体感受指标。
  6. Luftdruck / Hochdruckgebiet / Tiefdruckgebiet：气压 / 高压区 / 低压区。
  7. Front / Warmfront / Kaltfront：气团过渡带及暖锋、冷锋。
  8. Luftfeuchtigkeit / Niederschlag：空气水汽程度 / 从云落下的水相物总称。
  9. Regen / Nieselregen / Schauer：普通雨 / 细雨 / 短时阵雨。
  10. Gewitter / Blitz / Donner / Hagel：雷暴过程及闪电、雷声、冰雹。
  11. Schnee / Schneeregen / Glatteis：雪 / 雨夹雪 / 地面光滑结冰。
  12. Nebel / Dunst / Tau / Reif：浓雾 / 轻度霾雾 / 露水 / 霜晶。
  13. Wind / Windrichtung / Windgeschwindigkeit / Böe：风及其方向、速度、短时增强。
  14. Sturm / Orkan：强风暴 / 达最高风力等级的极强风暴。
  15. Wolke / Bewölkung / Sonnenschein / Unwetterwarnung：单朵云 / 云量 / 日照 / 危险天气预警。

易混辨析

  • Wetter / Klima：短期大气状态 / 长期统计特征，Klima 在下一篇展开。
  • Wetterbericht / Wettervorhersage：播报可以包含现况 / 预测专指未来。
  • Nieselregen / Schauer：细小连续 / 突然且短时，阵雨不一定小。
  • Nebel / Dunst：能见度显著降低 / 远景轻度模糊。
  • Sturm / Orkan：强风天气总称 / 有明确高风力等级含义的极端风。
  • Tau / Reif / Glatteis：表面水滴 / 表面冰晶 / 大片光滑危险冰层。

语境回收

Am Morgen meldet der Wetterdienst eine Kaltfront. Die Lufttemperatur liegt bei acht Grad, wegen des starken Winds ist die Gefühlstemperatur aber niedriger. Zunächst ist es bewölkt und es fällt Nieselregen. Am Nachmittag ziehen Schauer und ein Gewitter auf; einzelne Böen können Sturmstärke erreichen. Für den Abend gilt deshalb eine Unwetterwarnung. Lea prüft noch einmal die Wettervorhersage und verschiebt ihre Radtour.

早晨，气象服务机构通报一条冷锋。气温为八度，但因强风，体感温度更低。起初多云并有毛毛雨；下午将出现阵雨和雷暴，个别阵风可能达到风暴级，因此傍晚有恶劣天气预警。Lea 再次查看预报并推迟骑行。

自测

  1. 对未来天气的预测是 _______。 2. 人体受风湿度影响感受到的温度是 _______。
  2. 中心气压较低的区域是 _______。 4. 雨雪冰粒总称是 _______。
  3. 突然开始、时间较短的降水是 _______。 6. 闪电后的声音是 _______。
  4. 近地面水滴显著降低能见度是 _______。 8. 短时突然增强的风是 _______。
  5. 达最高风力等级的风暴是 _______。 10. 危险天气预警是 _______。
答案
  1. Wettervorhersage 2. Gefühlstemperatur 3. Tiefdruckgebiet 4. Niederschlag
  2. Schauer 6. Donner 7. Nebel 8. Böe
  3. Orkan 10. Unwetterwarnung
