16-3 动物（Tiere）

本组第 3 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 8 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述动物时，先用 Säugetier、Vogel、Reptil 等大类，再说明是 Haustier 还是 Wildtier。德语中人"吃"用 essen，动物进食通常用 fressen；动物叫声也有专门动词，如狗 bellen、猫 miauen。遇到野生动物应保持距离，不主动喂食，并遵守保护区提示。

精讲

  1. Tier / Säugetier / Vogel / Fisch：动物总称及三类常见脊椎动物。
  2. Reptil / Amphibie / Insekt / Spinne：爬行动物、两栖动物、昆虫和蛛形动物。
  3. Haustier / Wildtier：家庭长期照料的动物 / 自然环境中的野生动物。
  4. Hund / Katze / Pferd：三种常见伴侣或役用动物。
  5. Kuh / Schwein / Schaf / Ziege：常见畜牧动物。
  6. Huhn / Hahn：家鸡总称或母鸡 / 成年雄鸡。
  7. Fuchs / Hase / Reh / Hirsch：德国野外常见的四类哺乳动物。
  8. Wildschwein / Wolf / Bär：需要保持距离的大中型野生动物。
  9. Eichhörnchen / Igel / Maus / Ratte：小型哺乳动物及两类啮齿动物。
  10. Amsel / Spatz / Taube：城镇花园常见鸟类。
  11. Ente / Gans / Schwan：三类常见水禽。
  12. Biene / Wespe / Fliege / Mücke：常见飞行昆虫及辨义。
  13. Fell / Feder / Pfote / Flügel：毛皮、羽毛、兽足和翅膀。
  14. fressen / jagen / brüten：动物进食、捕猎和孵育繁殖。
  15. wild / zahm / giftig / nachtaktiv / ausgestorben：动物状态与物种描述。

易混辨析

  • Tier / Haustier / Nutztier / Wildtier：动物总称 / 家庭伴侣 / 生产用途 / 野外生活。
  • Hase / Kaninchen：野兔通常腿耳更长且不挖群居洞穴 / 兔子更常家养或穴居；Kaninchen 在其他生活场景补充。
  • Reh / Hirsch：狍 / 鹿类或雄鹿常用称呼，不要把 Reh 当作幼鹿。
  • Biene / Wespe：蜜蜂多采花粉花蜜 / 黄蜂夏季常接近甜食或肉食。
  • essen / fressen：人正常进食 / 动物进食；对人用后者通常不礼貌。
  • giftig / gefährlich：有毒 / 危险；有毒动物未必主动造成风险。

语境回收

Am Waldrand beobachtet Nils mit einem Fernglas Tiere. Eine Amsel singt im Gebüsch, während ein Eichhörnchen über einen Ast läuft. Später sieht er ein Reh und in größerer Entfernung zwei Wildschweine. Er bleibt auf dem Weg, hält Abstand und füttert kein Wildtier. Zu Hause geht er mit dem Hund Gassi und kontrolliert dessen Pfoten auf Zecken.

Nils 在林边用望远镜观察动物。一只乌鸫在灌木中鸣唱，一只松鼠跑过树枝。后来他看到一只狍和远处两头野猪。他留在道路上、保持距离，也不喂野生动物。回家后，他遛狗并检查狗爪是否有蜱虫。

自测

  1. 以乳汁哺育幼崽的一类动物是 _______。 2. 家庭长期照料的动物是 _______。
  2. 德国常见的小型鹿科动物是 _______。 4. 尾巴蓬松、善攀树的是 _______。
  3. 城市常见的鸽形鸟是 _______。 6. 为植物授粉的社会性昆虫是 _______。
  4. 鸟类体表结构是 _______。 8. 狗叫用动词 _______。
  5. 动物进食通常用 _______。 10. 某物种已无存活个体是 _______。
答案
  1. Säugetier 2. Haustier 3. Reh 4. Eichhörnchen
  2. Taube 6. Biene 7. Feder 8. bellen
  3. fressen 10. ausgestorben
