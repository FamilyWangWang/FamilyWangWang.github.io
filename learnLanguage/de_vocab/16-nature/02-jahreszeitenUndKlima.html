16-2 季节与气候（Jahreszeiten und Klima）

本组第 2 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 6 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

某一天很热与长期平均升高是两种信息。本篇先分清尺度，再看洪水、干旱和应对措施，读到目标时记得核对基准与范围。

Jahreszeit 描述一年中的周期，Klima 则是某地区长期天气统计及其变化特征，不等于某一天的 Wetter。讨论 Klimawandel 时，Erderwärmung 主要指全球平均温度上升，变化还包括降水、海平面及多类极端事件的概率和强度变化；不能把所有地区所有极端事件都概括为同向增加。Klimaschutz 重在减少原因，Klimaanpassung 重在应对已经发生或难以避免的影响。

精讲

  1. Jahreszeit / Frühling / Sommer / Herbst / Winter：季节总称及四季。

  2. Übergangszeit：季节交替、天气多变的过渡时期。

  3. Klima / Klimazone / Mikroklima：长期气候特征 / 大尺度气候带 / 小范围局地气候。

  4. Küstenklima / Kontinentalklima：受海洋调节的气候 / 内陆温差较大的气候。

  5. Klimawandel / Erderwärmung：气候系统长期变化 / 全球平均温度上升趋势。

  6. Durchschnittstemperatur / Temperaturanstieg / Temperaturrekord：平均温度、升幅和极值。

  7. Hitzewelle / Kältewelle / Hitzeperiode / Frostperiode：异常冷热及一般冷热持续期。

  8. Dürre / Trockenheit：造成明显影响的长期严重缺水 / 广义干燥状态。

  9. Starkregen / Hochwasser / Überschwemmung：强降雨 / 水位过高 / 水淹陆地。

  10. Treibhausgas / Kohlendioxid / Methan：温室气体总称及两种重要气体。

  11. Treibhauseffekt / Emission：大气保温作用 / 向环境排放的过程或量。

  12. Klimaschutz / Klimaanpassung：减少气候变化原因 / 降低其现实影响。

  13. Klimamodell / Klimaprojektion：计算气候系统的模型 / 基于情景的长期变化结果。

  14. Klimabilanz / Kohlenstofffußabdruck / Klimaneutralität：排放核算、总量指标与净平衡目标。

  15. Regenzeit / Trockenzeit / Monsun：降雨集中季、少雨季和季节性风系。

易混辨析

  • Wetter / Klima：当时当地的大气状态 / 多年统计特征及其变化。
  • Klimawandel / Erderwärmung：气候变化的广义过程 / 其中全球平均温度升高这一核心趋势。
  • Dürre / Trockenheit：严重、持久且有影响的缺水 / 一般干燥。
  • Hochwasser / Überschwemmung：水体水位过高 / 水实际淹没通常干燥的区域。
  • Klimaschutz / Klimaanpassung：减排与增强碳汇 / 防热、排涝等适应措施。
  • klimaneutral / emissionsfrei：净影响达到核算平衡 / 某过程不直接产生特定排放，不能混同。

语境回收

Die Stadt erlebt nach einem trockenen Frühling eine lange Hitzewelle. Die Durchschnittstemperatur liegt deutlich über dem früheren Wert, und auch nachts kühlt es kaum ab. Wegen der Trockenheit pflanzt die Gemeinde mehr schattenspendende Bäume und entsiegelt Flächen, damit Starkregen besser versickern kann. Diese Maßnahmen gehören zur Klimaanpassung. Gleichzeitig sollen weniger Emissionen und erneuerbare Energie dem Klimaschutz dienen.

干燥的春季后，这座城市经历了长时间热浪。平均温度明显高于过去，夜间也几乎不降温。因持续干燥，市政府种植更多遮阴树木并减少硬化地面，让强降雨更容易渗透。这些属于气候适应措施；同时，减少排放和使用可再生能源服务于气候保护。

城市的种树和透水地面同时应对热与降雨，属于Klimaanpassung；减少排放则服务于Klimaschutz。故事中的热浪不是单独证明长期趋势的全部证据，适用树种与场地仍需具体评估。

把词放回句子

Klima beschreibt langfristige Wetterstatistik; Erderwärmung bezeichnet den Anstieg der globalen Durchschnittstemperatur.（气候说长期天气统计，全球变暖说全球平均温度上升。）Eine Hitzewelle ist eine anhaltende Phase ungewöhnlicher Hitze, Dürre ein länger dauernder Wassermangel mit Auswirkungen.（热浪是持续异常高温，干旱是产生影响的持续缺水。）阈值与影响须结合地区判断。

Hochwasser bedeutet einen erhöhten Wasserstand; eine Überschwemmung bedeckt sonst trockenes Land.（高水位说水位升高，洪泛说水淹通常干地。）Methan und Kohlendioxid sind Treibhausgase.（甲烷和二氧化碳是温室气体。）Treibhausgas单数指一类气体，此句列两种时用复数Treibhausgase。

Klimaschutz mindert Ursachen, Klimaanpassung verringert Risiken der Folgen.（气候减缓减少原因，适应降低后果风险。）Wasser verdunstet von der Oberfläche.（水从表面蒸发。）verdunsten不是schmelzen融化，也不必沸腾。净平衡目标需说明核算范围，不能把klimaneutral直接读成所有活动都完全无排放。
