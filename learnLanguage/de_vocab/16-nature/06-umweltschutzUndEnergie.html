16-6 环保与能源（Umweltschutz und Energie）

本组第 6 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 12 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Umweltschutz 关注减少污染和资源消耗，Naturschutz 更集中于物种、栖息地和自然过程。谈能源时要区分提供能量的 Energiequelle、可储运转换的 Energieträger 和最终使用的 Strom、Wärme。垃圾分类规则因地区和具体物品而异；不确定时应查询当地处理机构，而不是仅凭包装材质猜测。

精讲

  1. Umwelt / Umweltschutz / Naturschutz：周围环境 / 减少环境负担 / 保护自然物种栖息地。
  2. Nachhaltigkeit / Ressource / Rohstoff：长期可承受原则、可用来源和生产基础材料。
  3. Energie / Energiequelle / Energieträger：能量、能量来源和可储运转换的载体。
  4. Strom / Wärme / Stromnetz：电、热和电力输配系统。
  5. Energieverbrauch / Stromverbrauch / Energieeffizienz：能耗总量、用电量和投入产出效率。
  6. Windenergie / Solarenergie / Wasserkraft / Bioenergie / Geothermie：五类可再生能源来源。
  7. Windkraftanlage / Solaranlage / Wasserkraftwerk：风力、太阳能和水力设施。
  8. Photovoltaik / Solarzelle / Batteriespeicher：光伏技术、发电元件和储电系统。
  9. Biomasse / Wärmepumpe：生物来源物质 / 提升环境热量温度的设备。
  10. Fossilenergie / Kohle / Erdöl / Erdgas：化石能源及三种主要来源。
  11. Kraftwerk / Atomenergie / Kernkraftwerk / Atommüll：发电设施、核能、核电站和放射性废物日常称呼。
  12. Abfall / Restmüll / Biomüll / Sondermüll：废物总称及三类处理渠道。
  13. Mülltrennung / Recycling / Mehrwegflasche / Pfandflasche：分类、材料回收、重复灌装和押金制度。
  14. Schadstoff / Luftverschmutzung / Wasserverschmutzung：有害物及空气、水体污染。
  15. Artenvielfalt / Ökosystem / Schutzgebiet：生物多样性、生态系统和依法保护区域。

易混辨析

  • Umweltschutz / Naturschutz / Klimaschutz：减少综合环境负担 / 保护物种栖息地 / 限制气候变化。
  • Energiequelle / Energieträger：能量产生或取得来源 / 储存并运送能量的物质介质。
  • Energieverbrauch / Energieeffizienz：使用了多少能量 / 每单位能量实现多少用途。
  • wiederverwenden / recyceln：物品直接再次使用 / 材料经过加工后再利用。
  • Mehrwegflasche / Pfandflasche：可重复灌装 / 带押金；带押金的瓶子不一定都是多次灌装。
  • Atomenergie / Kernenergie：前者日常和政治讨论常见 / 后者技术上更准确。

语境回收

Familie Kaya möchte ihren Energieverbrauch und ihren Abfall verringern. Sie misst zuerst den Stromverbrauch großer Geräte und verbessert dann die Energieeffizienz der Beleuchtung. Auf dem Dach erzeugt eine Solaranlage Strom, ein Batteriespeicher verschiebt einen Teil davon in den Abend. Beim Einkauf bevorzugt die Familie Mehrwegflaschen und vermeidet unnötige Verpackungen. Biomüll, Papier und Restmüll trennt sie nach den Regeln ihrer Gemeinde.

Kaya一家想减少能耗和垃圾。他们先测量大型电器的用电量，再提高照明能效。屋顶太阳能装置发电，电池储能把部分电量移到晚间使用。购物时优先选择可重复灌装瓶并避免不必要包装；厨余、废纸和其他垃圾则按当地规定分类。

自测

  1. 保护物种、栖息地和自然过程是 _______。 2. 可储运转换能量的物质或介质是 _______。
  2. 以较少能量实现同等用途的程度是 _______。 4. 半导体把光直接转为电的技术是 _______。
  3. 利用环境热量供暖的设备是 _______。 6. 煤、石油、天然气属于 _______。
  4. 需要专门收集的危险废物是 _______。 8. 物品直接再次使用用 _______。
  5. 生物群落与环境相互作用的系统是 _______。 10. 购买和归还时涉及押金的瓶子是 _______。
答案
  1. Naturschutz 2. Energieträger 3. Energieeffizienz 4. Photovoltaik
  2. Wärmepumpe 6. Fossilenergie 7. Sondermüll 8. wiederverwenden
  3. Ökosystem 10. Pfandflasche
