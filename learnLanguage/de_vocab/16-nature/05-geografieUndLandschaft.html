16-5 地理与地貌（Geografie und Landschaft）

本组第 5 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

从大洋和大陆进入河流、山地与岩石过程，再把地点词放回一条河的描述。本篇重点是位置与变化关系，地图上的名称并不表示地貌永远不变。

本篇从地球表面的大尺度结构进入河流、海岸、冰川和地质过程。描述河流时，Quelle、Flusslauf、Nebenfluss、Mündung 和 Einzugsgebiet 分别对应起点、流经路径、支流、入水处和汇水区域。地貌并非静止不变：Verwitterung 分解岩石，Erosion 搬走物质，Ablagerung 又在别处沉积这些物质。

精讲

  1. Geografie / Erdoberfläche / Kontinent / Ozean：地理学、地表、大陆和大洋。

  2. Meer / Binnenmeer / Küstenlinie：海、内海和海岸边界线。

  3. Bucht / Meerenge / Delta：海湾、海峡和三角洲。

  4. Mündung / Nebenfluss / Flusslauf：入水处、支流和河流路径。

  5. Einzugsgebiet / Wasserscheide：汇水区 / 分隔汇水区的地形线。

  6. Gletscher / Eisberg / Gletschersee：起源于陆地的流动冰体 / 从陆地冰体断裂的漂浮冰块 / 冰川湖；Eisberg不等于海水冻结的Meereis。

  7. Gebirgskette / Vulkan / Krater / Erdbeben：山链及火山地震地貌。

  8. Erdkruste / Erdplatte / Plattengrenze：地壳、构造板块和板块边界。

  9. Gestein / Mineral：天然岩石集合体 / 有特定结构成分的无机物。

  10. Granit / Kalkstein / Sandstein：花岗岩、石灰岩和砂岩。

  11. Boden / Erdschicht / Sediment：土壤、地下层和沉积颗粒物。

  12. Erosion / Verwitterung / Ablagerung：搬走、原地分解和沉积。

  13. Düne / Fjord / Karst / Karsthöhle：沙丘、峡湾、喀斯特及其洞穴。

  14. Lava / Magma / Lawine / Erdrutsch：地表熔岩、地下岩浆、雪崩和滑坡。

  15. Steilküste / Flachküste / Flussinsel / Archipel：陡岸、平缓海岸、河岛和群岛。

易混辨析

  • Ozean / Meer / Binnenmeer：全球相连的大洋主体 / 较小海域 / 大部被陆地包围的海域。
  • Bucht / Fjord：海岸向内凹入的水域总称 / 冰川谷被海水淹没形成的狭长深湾。
  • Quelle / Mündung：河流起点 / 河流汇入其他水体的位置。
  • Erosion / Verwitterung / Ablagerung：物质被移走 / 岩石原地分解 / 物质沉积。
  • Magma / Lava：地表以下熔融岩石 / 到达地表后的物质。
  • Lawine / Erdrutsch：雪冰或岩屑快速下滑 / 土壤岩体沿坡下移。

语境回收

Der Fluss entspringt in einer gebirgigen Region und fließt zunächst durch ein enges Tal. Mehrere Nebenflüsse vergrößern sein Einzugsgebiet. Im Unterlauf transportiert er feine Sedimente, die sich an der Mündung ablagern und ein Delta bilden. An der nahen Steilküste verwittert der Kalkstein, während die Brandung das Gestein erodiert. Die Landschaft verändert sich dadurch langsam, aber ständig.

这条河发源于山区，最初流经狭窄山谷。多条支流扩大了它的汇水区。下游携带细小沉积物，在河口沉积并形成三角洲。附近陡岸的石灰岩不断风化，海浪同时侵蚀岩石；地貌因此缓慢而持续地变化。

支流汇合说明哪些地区的水共同流向下游，沉积物在河口积聚才形成三角洲。沿岸风化与波浪侵蚀又是不同过程；完整段落保留了这些因果环节。

把词放回句子

Ein Ozean ist ein großer Teil des zusammenhängenden Weltmeers; eine Meerenge verbindet größere Meeresgebiete.（大洋属于相连全球海洋的大区，海峡连接较大海域。）An der Mündung fließt ein Fluss in ein anderes Gewässer.（河在入水处汇入另一水体。）Die Wasserscheide trennt Einzugsgebiete.（分水界分隔汇水区。）不要把界线与整片区域混成同一个词。

Ein Eisberg bricht von Landeis ab; an einer Plattengrenze treffen Erdplatten aufeinander.（冰山从陆地冰体断裂，板块边界是构造板块相接处。）Eisberg不是海水冻结形成的Meereis。Verwitterung zerlegt Gestein am Ort, Ablagerung häuft transportiertes Material an.（风化原地分解岩石，沉积积聚搬运来的物质。）

Magma befindet sich unter der Erdoberfläche; nach dem Austritt heißt es Lava.（岩浆在地表下，喷出后称熔岩。）Der Fluss mündet ins Meer.（河流汇入海洋。）münden接in加第四格；完成句中先找主语和入水位置，不把整条Flusslauf都称作Mündung。
