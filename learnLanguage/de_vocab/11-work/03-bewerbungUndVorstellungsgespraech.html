11-3 求职与面试（Bewerbung und Vorstellungsgespräch）

本组第 3 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 7 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语求职材料通常围绕 Anschreiben、Lebenslauf 和与职位相关的证明文件展开，但公司要求可能不同。好的申请不是把所有经历堆进去，而是把职位要求与自己的经验、能力和动机对应起来。面试中应给出具体例子，不只重复 teamfähig、belastbar 等空泛形容词；涉及薪资、到岗日期和工作条件时，用准确、平静的表达最有效。

精讲

  1. Stellenanzeige / Stellenausschreibung：面向求职者的岗位广告 / 正式公布岗位的文本和过程。
  2. Jobangebot / Stellenanzeige：向具体候选人提出的工作机会 / 面向求职者公开发布的岗位广告。
  3. Bewerbung / Bewerbungsunterlage：整个申请行为 / 其中的一份或全部文件。
  4. Anschreiben / Lebenslauf：说明动机和匹配度 / 结构化列出经历能力。
  5. Arbeitszeugnis / Abschlusszeugnis / Bewerbungszertifikat：雇主工作评价 / 学业完成证明 / 随申请提交的单项能力证书。
  6. Arbeitsprobe / Bewerbungsportfolio：一件实际样稿 / 系统汇集多项成果的作品集。
  7. Berufserfahrung / Qualifikation：实际工作经历 / 教育训练经验形成的任职条件。
  8. Fähigkeit / Kompetenz：完成某类任务的能力 / 综合运用知识技能判断的胜任力。
  9. Erstgespräch / Zweitgespräch：首次全面了解双方匹配度 / 后续深入确认条件与疑问。
  10. Gehaltsvorstellung / Eintrittstermin：期望薪酬 / 可开始工作的日期。
  11. Initiativbewerbung / Onlinebewerbung：没有公开岗位时主动申请 / 通过网页系统提交申请。
  12. Onlinebewerbung / E-Mail-Bewerbung：通过网页系统 / 通过电子邮件提交。
  13. Vorstellungsgespräch / Bewerbungsgespräch：同义，前者更固定常见。
  14. geeignet / qualifiziert：适合这项工作 / 已具备必要专业条件。
  15. teamfähig / belastbar：能有效协作 / 在合理压力下稳定工作，均应举例证明。

易混辨析

  • Bewerbung / Anmeldung：参与职位选拔 / 仅登记参加课程或活动。
  • Lebenslauf / Biografie：求职用结构化简历 / 叙述完整人生经历的传记。
  • Referenz / Arbeitszeugnis：可联系或引用的职业评价 / 前雇主出具的正式工作证明。
  • nachfragen / nachhaken：一般补问 / 因拖延或回答不足而追问，后者语气更强。

语境回收

Tariq findet auf der Karriereseite eine passende Stellenausschreibung. Er passt den Lebenslauf an, formuliert ein kurzes Anschreiben und fügt Arbeitszeugnisse sowie zwei Arbeitsproben bei. Eine Woche nach der Eingangsbestätigung erhält er eine Intervieweinladung. Im Vorstellungsgespräch stellt er sich knapp vor, begründet seine Motivation mit konkreten Projekten und fragt nach dem Verantwortungsbereich der Stelle.

Tariq在公司招聘页找到合适的岗位。他调整简历，撰写简洁的求职信，并附上工作证明和两份样稿。收到申请确认一周后，他得到面试邀请。面试中，他简要自我介绍，用具体项目说明动机，并询问该职位的职责范围。

自测

  1. 正式岗位公告是 _______。 2. 求职信是 _______。

  3. 展示多项成果的作品集是 _______。 6. 没有公开岗位时主动申请是 _______。

  5. 正式提交材料是 Unterlagen _______。 10. 礼貌追问进度是 höflich _______。

  2. Bewerbungsportfolio 6. Initiativbewerbung 7. Vorstellungsgespräch 8. Gehaltsvorstellung
  3. einreichen 10. nachhaken
