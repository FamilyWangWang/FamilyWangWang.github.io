11-5 办公用品（Büromaterialien）

本组第 5 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

从记录、夹放到扫描、归档，物品的功能可以连成一条工作线。订购时还要补设备与型号，避免只说“打印材料”。

办公室里的物品常通过构词法形成清楚的功能词：Briefablage 放信件文件，Aktenvernichter 销毁档案，Textmarker 标出文字。Ordner 在德语办公室里通常指带金属夹具的厚文件夹，不只是电脑中的"文件夹"；数字环境里它也可以指文件目录。借用或订购耗材时，型号和用途往往比笼统说 Material 更重要。

精讲

  1. Schreibtisch / Bürostuhl / Rollcontainer：工作桌 / 可调办公椅 / 桌下带轮小柜。

  2. Aktenschrank / Büroregal / Schreibtischschublade：封闭档案柜 / 开放架 / 可拉出的收纳格。

  3. Dokumentenablage / Briefablage：文件处理位置总称 / 桌面纸张托盘。

  4. Aktenordner / Ringbuch：厚档案夹 / 可灵活增减页的活页本。

  5. Register / Trennblatt：整套分页索引 / 单张分隔页。

  6. Dokumentenmappe / Klarsichthülle / Schnellhefter：携带文件封套 / 透明单页袋 / 薄型压条夹。

  7. Notizbuch / Notizblock / Haftnotiz：装订笔记本 / 可撕便笺块 / 可粘小便签。

  8. Kugelschreiber / Füller / Bleistift：圆珠笔 / 钢笔 / 铅笔。

  9. Textmarker / Filzstift / Permanentmarker：荧光标记 / 纤维彩笔 / 难擦记号笔。

  10. Büroklammer / Heftklammer：不穿纸夹住 / 穿纸订住。

  11. Tacker / Locher：订书钉工具 / 打孔工具。

  12. Briefumschlag / Versandtasche：普通信封 / 可装厚文件的大信封。

  13. Kopierpapier / Firmenbriefpapier：通用打印复印纸 / 带企业固定版式的信纸。

  14. Laserdrucker / Bürokopierer / Dokumentenscanner：打印 / 复制纸张 / 数字化原件。

  15. Druckertoner / Tintenpatrone：Druckertoner说碳粉这种耗材，Tintenpatrone说装墨的墨盒；Toner也常借指碳粉盒，但材料与容器应区分。

易混辨析

  • Ordner / Mappe：可固定大量穿孔文件的厚夹 / 携带少量文件的薄封套。
  • Kopie / Scan：纸质或内容副本 / 通过扫描得到的数字图像。
  • Toner / Tinte：激光打印粉末 / 喷墨打印液体。
  • löschen / vernichten：删除数字内容 / 物理销毁纸张或载体。

语境回收

Im Materialschrank fehlt Kopierpapier, und der Druckertoner ist fast leer. Paula trägt beides in die Bestellliste ein. Danach scannt sie einen unterschriebenen Vertrag, speichert die Datei im richtigen Ordner und legt das Original in eine Aktenmappe. Nicht mehr benötigte Entwürfe mit vertraulichen Daten kommen in den Aktenvernichter. Textmarker, Haftnotizen und Kugelschreiber legt sie griffbereit in den Rollcontainer.

材料柜里缺复印纸，打印机碳粉也快用完了。Paula把两项都加入订购清单。随后她扫描一份已签合同，把文件保存到正确目录，并把原件放进档案夹。含敏感数据且不再需要的草稿放入碎纸机。荧光笔、便签和圆珠笔则放进手边的活动柜。

Paula把电子副本放进数字Ordner，原件放进Aktenmappe；同一份合同在两种载体上有不同存放位置。不再需要的敏感草稿另作销毁，不能据扫描动作就认定原件可丢。

把词放回句子

Im Aktenordner liegen Unterlagen, in der Klarsichthülle bleibt ein einzelnes Blatt geschützt.（厚档案夹放文件，透明文件袋保护单页。）Eine Haftnotiz erinnert an den Termin; mit dem Textmarker hebt sie eine Stelle hervor.（便利贴提醒时间，她用荧光笔突出一处文字。）夹放与标记对应不同动作。

Eine Büroklammer hält Seiten ohne Löcher zusammen.（回形针不穿孔夹住纸页。）Mit dem Locher mache ich Löcher für den Ordner.（我用打孔器为装夹打孔。）Die Versandtasche nimmt größere Unterlagen auf.（文件信封容纳较大材料。）不要把订书钉、回形针和打孔器当成同一种固定方式。

Der Dokumentenscanner erstellt ein digitales Bild; der Aktenvernichter zerkleinert Papier.（扫描仪生成数字图像，碎纸机切碎纸张。）Der Laserdrucker braucht Druckertoner, der Tintenstrahldrucker eine Tintenpatrone.（激光打印机用碳粉，喷墨打印机用墨盒。）是否能销毁、用何种耗材，还须看保留要求与设备规格。
