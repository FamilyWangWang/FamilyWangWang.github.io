11-4 合同、薪资与假期（Arbeitsvertrag, Gehalt und Urlaub）

本组第 4 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 11 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

合同中的时间、金额和申请动作容易被读成一件事。本篇把它们分开核对，再用一次入职后的安排串起来。

读劳动合同时，要把工作内容、地点、时间、报酬、期限和终止条件分开核对。Gehalt 常指按月固定支付的薪酬，Lohn 更容易与实际工时或产量挂钩，但日常使用并非绝对。法定最低标准、集体合同和企业协议可能同时影响具体权益；假期、病假证明和通知流程也会变化，因此本文只固定核心术语，不写死数字。

精讲

  1. Arbeitsvertrag / Arbeitsverhältnis：书面或约定合同 / 由合同形成并持续存在的法律关系。

  2. Arbeitgeber / Arbeitnehmer / Beschäftigte：提供工作的一方 / 受雇劳动者 / 更宽泛的就业人员。

  3. Vertragsbeginn / Vertragsende / Befristung：开始日期 / 结束日期 / 限定期限的安排。

  4. Probezeit / Kündigungsfrist：初期试用阶段 / 终止通知须按规则提前送达的期限；不能只按发送日计算。

  5. Arbeitszeit / Wochenarbeitszeit：工作时间总概念 / 按周汇总的时数。

  6. Vollzeit / Teilzeit：完整标准工时 / 低于可比较全职工时。

  7. Gleitzeit / Kernarbeitszeit：可弹性选择的时段 / 通常必须在岗的时段。

  8. Überstunde / Mehrarbeit：超出个人约定工时 / 法律或特定定义下超出正常界限。

  9. Arbeitsplatz / Arbeitsort / Homeoffice：具体岗位或工位 / 合同地点 / 日常在家办公。

  10. Tätigkeitsbereich / Aufgabenbereich / Stellenbeschreibung：工作领域 / 具体任务范围 / 书面职位说明。

  11. Gehalt / Lohn：常按月固定 / 常与工时产量挂钩，但日常边界并非绝对。

  12. Bruttogehalt / Nettogehalt：扣除前 / 扣除后的实发薪酬。

  13. Bonus / Prämie / Provision：条件性额外支付 / 特定奖励 / 按业务成果比例计酬。

  14. Urlaubsanspruch / Urlaubsantrag / Resturlaub：休假权利 / 具体日期申请 / 尚未使用的余额。

  15. Krankmeldung / Arbeitsunfähigkeitsbescheinigung：员工的病假通知 / 医疗方确认不能工作的证明。

易混辨析

  • befristet / unbefristet：约定终止日期或目的 / 无预设终止日期；后者仍可依法终止。
  • Homeoffice / Telearbeit / mobiles Arbeiten：日常在家办公说法 / 正式固定家庭工位形式 / 地点更灵活的工作。
  • Bonus / Zuschlag：与目标结果相关的额外支付 / 因特定工作条件增加的支付。
  • Urlaub / Freistellung：休息恢复的假期 / 暂时免除工作义务，法律效果可能不同。

语境回收

Im neuen Arbeitsvertrag steht eine unbefristete Vollzeitstelle mit Gleitzeit. Die Kernarbeitszeit ist im Teamhandbuch geregelt, der Arbeitsort kann an zwei Tagen pro Woche das Homeoffice sein. Das Jahresgehalt wird brutto angegeben; mögliche Boni erscheinen getrennt. Nach dem ersten Monat beantragt Daria drei Urlaubstage. Als sie später krank wird, meldet sie sich nach dem internen Verfahren krank und prüft, welche Nachweise benötigt werden.

新劳动合同规定了一份无固定期限的全职岗位，实行弹性工时。核心工作时段写在团队手册中，每周有两天工作地点可以是家中。年薪按税前金额写明，可能的奖金另列。入职一个月后，Daria申请三天假。后来她生病时，按内部流程报告病假，并核对需要哪些证明。

Daria的合同写无固定期限与弹性工时，核心时段另见手册。年薪按brutto列明，奖金另列；休假和病假之后各按流程处理，故事中的安排不能自动代表所有企业规则。

把词放回句子

Der Arbeitsvertrag regelt die Bedingungen; eine Befristung begrenzt die Dauer.（劳动合同规定条件，固定期限安排限制持续时间。）Die Probezeit ist die anfängliche Erprobungsphase.（试用期是开始阶段的合作检验。）unbefristet只说没有预设期限，不说明永远不能结束。

Bei Gleitzeit kann es eine Kernarbeitszeit geben.（弹性工时可设核心时段。）Die Gehaltsabrechnung zeigt das Bruttogehalt, Abzüge und den ausgezahlten Betrag.（工资单列出税前工资、扣除与实付金额。）Gleitzeit说时间框架，Homeoffice说地点，brutto与netto说金额口径，三个维度不能混用。

Ich stelle einen Urlaubsantrag.（我提交休假申请。）Die Arbeitsunfähigkeitsbescheinigung ist ein medizinischer Nachweis; die Krankmeldung ist meine Mitteilung.（不能工作证明是医疗证明，Krankmeldung是我的通知。）Ich melde mich nach dem vorgesehenen Verfahren krank.（我按规定流程报病假。）krankmelden在句中分开；申请、告知和证明各承担不同用途。
