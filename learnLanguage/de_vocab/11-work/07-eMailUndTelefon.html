11-7 邮件与电话（E-Mail und Telefon）

本组第 7 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 7 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

职场邮件要让收件人一眼看出目的：Betreffzeile 写明主题，正文先说请求或结论，Dateianhang 在发送前再次检查。CC 让他人公开知悉，BCC 隐藏各收件地址，二者都不等于把责任交给对方。打电话时，先报姓名和公司，再说明来意；若对方不在，可以请求 Rückruf、留下 Gesprächsnotiz，或约一个双方都方便的 Telefontermin。

精讲

  1. E-Mail / Kurznachricht：可完整记录正式事项 / 聊天或短信中的短消息。
  2. Betreffzeile / E-Mail-Signatur：邮件开头的主题提示 / 末尾的身份联系信息。
  3. Absender / Empfängerin：发送方 / 接收方。
  4. CC-Kopie / Blindkopie：公开显示抄送地址 / 隐藏抄送地址。
  5. E-Mail-Anhang / Dateianhang：邮件附加内容的通称 / 强调作为文件附加。
  6. Lesebestätigung / Empfangsbestätigung：系统或收件人确认打开 / 明确确认收到。
  7. Posteingang / Postausgang：已收到消息 / 正等待或正在发送的消息。
  8. E-Mail-Entwurf / Postausgang：尚未发送并保存的版本 / 正等待或正在发送的消息区域。
  9. Durchwahl / Ortsvorwahl：单位内直达个人的号码部分 / 标识地区的号码部分。
  10. Telefonanlage / Telefonzentrale：管理连接的技术系统 / 接听总机并转接的岗位。
  11. Rückruf / Telefontermin：之后回拨一次 / 提前约定的通话时段。
  12. Freizeichen / Besetztzeichen：对方线路正在响 / 对方线路占用。
  13. Mailboxansage / Sprachnachricht：系统播放的录音提示 / 来电者留下的录音内容。
  14. weiterleiten / durchstellen：转发邮件或信息 / 实时转接电话。
  15. erreichbar / Telefonempfang：某个人或机构能被联系到 / 某地点的电话信号接收状况。

易混辨析

  • antworten / beantworten：auf eine E-Mail antworten / eine E-Mail beantworten。
  • Anhang / Anlage：都可指附件；Anhang 在邮件界面中更常见，Anlage 也常用于正式函件。
  • auflegen / abnehmen：挂断电话 / 接起电话。
  • Rückruf / Rückfrage：回拨电话 / 为澄清而追加的问题。

语境回收

Mara verfasst eine E-Mail mit einer klaren Betreffzeile und hängt den aktuellen Bericht an. Die Projektleitung setzt sie in CC. Danach ruft ein Lieferant in der Telefonzentrale an. Die zuständige Kollegin ist gerade nicht erreichbar, deshalb notiert der Mitarbeiter Name, Telefonnummer und Anliegen. Er richtet einen Rückruf aus und schickt der Kollegin zusätzlich eine kurze Gesprächsnotiz.

Mara 撰写一封主题明确的邮件，附上最新报告，并抄送项目负责人。随后一位供应商打到公司总机。负责此事的同事暂时联系不上，因此接线员工记录姓名、电话号码和来意，转告回电请求，并另发一份简短通话记录。
