11-1 职业名称（Berufsbezeichnungen）

本组第 1 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 3 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语职业名称通常有阳性和阴性形式：Arzt / Ärztin、Lehrer / Lehrerin。招聘广告中的 m/w/d 表示职位面向 männlich、weiblich、divers；实际称呼时应尊重当事人使用的形式。本文把常见男女形式分别列出，既方便掌握构词变化，也让之后的 A–Z 索引能找到两种词头。

精讲

  1. Arzt / Ärztin：不只是一般"医务人员"，而是有诊疗执业资格的医生。
  2. Pflegefachmann / Pflegefachfrau：专业护理人员；Pflegekraft 是更宽泛的中性总称。
  3. Apotheker / Physiotherapeut：以药品调配咨询为主 / 以运动和物理治疗为主。
  4. Lehrer / Erzieher：学校系统教学 / 幼儿与青少年教育照护。
  5. Ingenieur / Architekt：技术系统设计 / 建筑空间设计与实施协调。
  6. Elektriker / Tischler：安装维护电气系统 / 制作安装木制构件。
  7. Tischler / Architekt：直接制作安装木构件的工匠 / 规划建筑的专业人员。
  8. Informatiker / Softwareentwickler：计算机专业总类 / 专注软件实现的岗位。
  9. Journalist / Übersetzer：采访制作新闻内容 / 转换已有书面内容的语言。
  10. Übersetzer / Dolmetscher：处理书面语言 / 处理口头语言。
  11. Rechtsanwalt / Richter：代理当事人 / 独立审理裁判。
  12. Steuerberater / Buchhalter：受监管的税务咨询职业 / 企业账务记录岗位。
  13. Koch / Bäcker：专业烹饪菜肴 / 专业制作面包烘焙品。
  14. Berufskraftfahrer / Pilot：职业道路驾驶 / 航空器驾驶。
  15. Wissenschaftler / Fachkraft：开展科学研究的人员 / 能独立承担某专业任务的合格人员。

易混辨析

  • Beruf / Stelle：一个人受训和长期从事的职业 / 某机构中的具体岗位。
  • selbstständig / freiberuflich：自主经营状态 / 法律和税务上的特定自由职业类别。
  • Ausbildung / Studium：职业培训 / 高等教育学习；两者都可能通向专业资格。
  • Berufsbezeichnung / Tätigkeitsbezeichnung：可能受规则保护的职业称号 / 描述实际工作内容的岗位叫法。
