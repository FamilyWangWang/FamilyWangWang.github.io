11-10 离职与失业（Kündigung und Arbeitslosigkeit）

本组第 10 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 14 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

结束劳动关系时，Kündigung 是一方作出的终止声明，Aufhebungsvertrag 则是双方共同约定结束。Freistellung 只表示免除工作义务，不必然等于劳动关系已经结束。面临失业时还要区分 Arbeitsuchendmeldung 与 Arbeitslosmeldung：前者说明正在寻找后续工作，后者确认已经失业并与申请相关待遇衔接。具体资格、期限和法律后果会因个案变化，应以劳动合同、官方通知和主管机构的最新说明为准。

精讲

  1. Kündigung / Aufhebungsvertrag：一方作出的终止声明 / 双方共同签订的结束协议。
  2. Eigenkündigung / Arbeitgeberkündigung：雇员提出 / 雇主提出。
  3. ordentlich kündigen / außerordentlich kündigen：通常遵守适用期限 / 因重大理由按特殊方式结束。
  4. Kündigungsschreiben / Kündigungsbestätigung：发出终止的文件 / 确认收到和日期的回复。
  5. Kündigungsgrund / Kündigungstermin：为什么终止 / 何时结束。
  6. Abfindung / Freistellung：特定情形下的补偿支付 / 免除工作义务。
  7. Arbeitszeugnis / Zwischenzeugnis / Endzeugnis：工作证明总称 / 任职期间出具 / 结束时出具。
  8. Arbeitsbescheinigung / Arbeitszeugnis：供主管机构处理待遇 / 供求职者证明经历表现。
  9. Arbeitslosigkeit / Erwerbslosigkeit：行政和日常语境的无工作状态 / 统计定义下的无就业状态。
  10. Arbeitsuchendmeldung / Arbeitslosmeldung：登记正在找工作 / 登记已经失业。
  11. Arbeitsagentur / Jobcenter：就业保险和职业服务机构 / 基本保障与就业融入机构。
  12. Arbeitslosengeld / Grundsicherungsgeld：保险型失业待遇 / 由 Jobcenter 按条件提供的基本保障待遇。
  13. Sperrzeit / Bezugsdauer：暂时不支付的期间 / 可领取待遇的总时长。
  14. Vermittlungsvorschlag / Bewerbungsnachweis：机构推荐的具体岗位 / 已进行求职活动的证明。
  15. Weiterbildung / Umschulung / Berufswiedereinstieg：原职业基础上提升 / 为新职业系统培训 / 中断后重返职业。

易混辨析

  • gekündigt / freigestellt：劳动关系被通知结束 / 暂时不必工作，结束日期仍要另看。
  • Entlassung / Kündigung：离开岗位或被解除的结果性说法 / 终止劳动关系的法律声明。
  • arbeitsuchend / arbeitslos：正在寻找工作 / 已没有就业，行政登记也分别处理。
  • Bescheid / Bescheinigung：机构作出的正式决定 / 证明某项事实的文件。

语境回收

Nach der Arbeitgeberkündigung prüft Samira das Schreiben und lässt offene Fragen fachlich beraten. Sie vereinbart eine geordnete Aufgabenübergabe, fordert ihr Endzeugnis an und klärt den Resturlaub. Parallel erledigt sie die Arbeitsuchendmeldung. Als die Beschäftigung endet, nimmt sie ihren Beratungstermin wahr, reicht die erforderlichen Unterlagen ein und bespricht, welche Stellensuche oder Qualifizierung ihren Berufswiedereinstieg unterstützt.

收到雇主终止通知后，Samira 核对文件，并就未决问题寻求专业咨询。她安排有序任务交接，索取最终工作证明并确认剩余假期；同时完成求职登记。就业结束后，她按约参加咨询，提交所需材料，并讨论哪种岗位搜索或技能培训最有利于重新就业。
