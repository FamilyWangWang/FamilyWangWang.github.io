17-4 运动动词（Bewegungsverben）

本组第 4 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 24 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语描述运动时，常同时交代动作、方向和方式：ins Ziel laufen、über ein Hindernis springen、den Ball zum Partner werfen。位移动词在完成时往往用 sein，但带宾语的动作动词通常用 haben。训练口令还常使用副词 vorwärts、rückwärts 和 seitwärts。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. gehen / laufen / rennen / sprinten：普通步行、跑或快走、快速奔跑、短距离全速跑。
  2. joggen / wandern / marschieren：慢跑锻炼、长距离徒步、有节奏行进。
  3. steigen / klettern / kriechen：向上或进入、手脚攀爬、贴近地面爬行。
  4. springen / hüpfen：一次明显跳跃 / 连续轻巧小跳。
  5. Absprung / Landung：离地瞬间 / 重新接触地面。
  6. fallen / stolpern：向下跌落 / 被障碍绊得失去平衡。
  7. drehen / sich wenden：使身体部位转动 / 整体转身改变朝向。
  8. rollen / gleiten / rutschen：滚动、平稳滑行和一般滑动。
  9. schwimmen / tauchen / rudern：水面或水中游、潜水、用桨划船。
  10. werfen / schleudern / stoßen：普通投、用力甩掷、短促推掷。
  11. schieben / ziehen：推离自身 / 拉向自身或某方向。
  12. heben / senken / beugen / strecken：抬高、降低、弯曲、伸直。
  13. greifen / fangen / halten / loslassen：伸手抓、接住、握住、松开。
  14. beschleunigen / bremsen / überholen：加速、减速、超过同向运动者。
  15. ausweichen / balancieren / zielen / treffen：避让、保持平衡、瞄准、命中。

易混辨析

  • laufen / rennen：前者范围更广，部分地区还可指步行；后者明确强调快速奔跑。
  • werfen / stoßen：物体经手臂摆动抛出 / 从肩颈附近用单臂推出。
  • gleiten / rutschen：平稳顺滑地移动 / 一般滑动，可能包含失控。
  • greifen / fangen：主动伸手取或握 / 接住正在运动的物体。
  • beugen / sich bücken：弯曲某个关节或部位 / 整体弯腰。
  • ausweichen / umgehen：在运动中闪避 / 绕开问题或地点，含义更广。

语境回收

Beim Parcours nimmt Amir zuerst Anlauf und springt über ein Hindernis. Er landet sicher auf beiden Füßen, kriecht unter einem Netz durch und balanciert anschließend über einen Balken. Vor der Kurve bremst er kurz, danach beschleunigt er wieder. Zum Schluss greift er nach einem Ball, zielt auf die Mitte und trifft das Ziel. Die Trainerin erinnert ihn daran, die Knie bei der Landung leicht zu beugen.

障碍训练中，Amir 先助跑跳过障碍，双脚稳定落地，再从网下爬过并走过平衡木。他在弯道前短暂减速，随后重新加速。最后他伸手拿球，瞄准中央并命中目标；教练提醒他落地时微屈膝盖。

自测

  1. 跳跃前为了获得速度而助跑是 _______。 2. 离地的瞬间是 _______。
  2. 重新接触地面的过程是 _______。 4. 贴近地面爬行用 _______。
  3. 平稳地在冰面滑行用 _______。 6. 用短促力量推铅球用 _______。
  4. 缩小关节角度用 _______。 8. 松开所握物体用 _______。
  5. 避开障碍物且支配第三格用 _______。 10. 朝身体侧面移动是 _______。
答案
  1. Anlauf 2. Absprung 3. Landung 4. kriechen
  2. gleiten 6. stoßen 7. beugen 8. loslassen
  3. ausweichen 10. seitwärts
