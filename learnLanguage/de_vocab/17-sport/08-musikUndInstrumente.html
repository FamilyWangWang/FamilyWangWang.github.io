17-8 音乐与乐器（Musik und Instrumente）

本组第 8 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 7 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

谈音乐时，可以从作品、声音结构、表演者和乐器四层展开：Melodie 是可辨认的音高线条，Rhythmus 组织时值和重音，Takt 则把节拍分组。参加乐团或合唱团会用到 Probe，公开演出是 Auftritt 或 Konzert；观众要求返场时会喊 Zugabe!。

精讲

  1. Musikstück / Lied：完整音乐作品总称 / 通常带可演唱歌词的作品。
  2. Melodie / Rhythmus / Takt：音高线条、时值重音组织、节拍分组单位。
  3. Ton / Klang：单个有音高的声音 / 声音整体呈现的听感。
  4. Lautstärke / Tempo：声音强弱 / 音乐速度。
  5. Note / Notenblatt / Partitur：音符、单页乐谱、多声部总谱。
  6. Akkord / Tonart / Dur / Moll：和弦、调性、大调、小调。
  7. Instrument / Musikinstrument：语境明确时的乐器简称 / 完整明确说法。
  8. Saiteninstrument / Blasinstrument / Schlaginstrument / Tasteninstrument：按发声或演奏方式分类的四类乐器。
  9. Stimme / Gesang：人的嗓音 / 按音乐组织的演唱。
  10. Sänger / Musiker：主要歌唱者 / 从事音乐的更广泛称谓。
  11. Band / Orchester / Chor：小型流行乐队、大型多声部乐团、合唱团。
  12. Dirigent / Dirigentin：男性 / 女性指挥。
  13. Probe / Auftritt / Konzert：排练、一次公开表演、完整音乐会。
  14. Bühne / Publikum / Zugabe：舞台、观众、返场曲。
  15. stimmen / proben / auftreten：调音、排练、公开演出。

易混辨析

  • Rhythmus / Takt：声音时值和重音的整体组织 / 按规律划分的小节框架。
  • Ton / Klang：可识别音高的单音 / 包含音色和共鸣的整体听觉效果。
  • Note / Ton：书写符号或音乐单位 / 实际发出的声音。
  • Probe / Übung：为共同演出排练 / 为提高某项技能做的练习。
  • Auftritt / Konzert：一次面对观众的表演 / 以音乐为核心的完整活动。
  • Klavier / Keyboard：机械击弦钢琴 / 电子键盘乐器。

语境回收

Vor dem Konzert probt die Band noch einmal auf der Bühne. Die Gitarristin stimmt ihre E-Gitarre, der Keyboarder prüft die Lautstärke und die Sängerin wärmt ihre Stimme auf. Beim ersten Lied hält das Publikum sofort den Rhythmus mit. Nach dem letzten Musikstück applaudieren alle so lange, bis die Band eine Zugabe gibt. Dabei spielt sie eine bekannte Melodie in einem langsameren Tempo.

音乐会前，乐队在舞台上再排练一次。吉他手给电吉他调音，键盘手检查音量，歌手热嗓。第一首歌开始，观众便跟着节奏。最后一曲结束后，大家持续鼓掌，直到乐队返场，并以较慢速度演奏一段熟悉旋律。

自测

  1. 可辨认的一系列音高是 _______。 2. 按固定重音规律划分的单位是 _______。
  2. 记录多个声部的完整总谱是 _______。 4. 多个音同时响起形成 _______。
  3. 多人共同演唱的团体是 _______。 6. 演出前共同练习是 _______。
  4. 正式节目后追加的作品是 _______。 8. 给乐器调音用 _______。
  5. 为演出排练用 _______。 10. 公开登台表演用 _______。
答案
  1. Melodie 2. Takt 3. Partitur 4. Akkord
  2. Chor 6. Probe 7. Zugabe 8. stimmen
  3. proben 10. auftreten
