17-5 比赛与胜负（Wettkampf und Ergebnis）

本组第 5 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 5 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

体育新闻会按时间顺序描述赛事：先是 Qualifikation、Vorrunde 或 Gruppenphase，随后进入淘汰赛，最后产生 Sieger。表达比分时常说 in Führung liegen、den Ausgleich erzielen 和 mit 2:1 gewinnen。Sieg 与 Niederlage 指单场结果，Titel 和 Meisterschaft 则涉及整个赛事。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. Wettbewerb / Turnier / Meisterschaft：竞赛总称、多轮锦标赛、决出冠军的赛事。
  2. Liga / Saison / Spieltag：联赛组织级别、赛季、联赛的一轮比赛日。
  3. Begegnung / Duell：双方的一场比赛 / 两个直接对手的较量。
  4. Qualifikation / Vorrunde / Gruppenphase：资格过程、预赛、分组赛阶段。
  5. Ausscheidungsrunde / Achtelfinale / Viertelfinale / Halbfinale / Finale：淘汰赛及其逐轮阶段。
  6. Favorit / Außenseiter / Titelverteidigerin：热门方、弱势方、卫冕者。
  7. Startnummer / Startliste / Teilnehmerfeld：参赛编号、名单和全部参赛阵容。
  8. Ergebnis / Resultat：中性高频结果 / 较书面或体育报道用结果。
  9. Zwischenstand / Endstand：中途比分 / 最终比分。
  10. Spielstand / Punktestand：单场当前比分 / 累计分数状态。
  11. Rang / Platzierung / Tabelle：排名位置、取得的名次、联赛榜表。
  12. Führung / Rückstand / Gleichstand：领先、落后、相同比分。
  13. Sieg / Niederlage / Unentschieden：胜、负、平。
  14. Rekord / Bestleistung：规定条件下的历史最佳 / 某主体自己的最好成绩。
  15. Medaille / Pokal / Titel：奖牌、奖杯、荣誉称号。

易混辨析

  • gewinnen / siegen：可直接带比赛或奖项作宾语 / 通常不直接带比赛宾语，偏报道语。
  • verlieren / unterliegen：可直接带比赛作宾语 / 正式表达不敌某人，支配第三格。
  • Führung / Sieg：比赛过程中暂时领先 / 比赛结束后获胜。
  • Gleichstand / Unentschieden：某一时刻比分相同 / 以平局结束的结果。
  • Rekord / Bestleistung：在规定范围内超过所有既有成绩 / 某人或某阶段自己的最佳。
  • Rang / Platzierung：排名体系中的位置 / 参赛者实际取得的名次结果。

语境回收

Im Viertelfinale gilt Leas Team als Außenseiter. Zur Halbzeit liegt es mit zwei Punkten im Rückstand, holt diesen aber schnell auf. Kurz vor Schluss erzielt Lea den Ausgleich und ihre Mitspielerin bringt die Mannschaft erstmals in Führung. Das Team gewinnt knapp und zieht ins Halbfinale ein. Dort stellt Lea außerdem eine persönliche Bestleistung auf.

四分之一决赛中，Lea 的队伍被视为弱势方。半场时落后两分，但很快追回差距。终场前不久 Lea 扳平比分，队友又让球队首次领先。队伍最终险胜并晋级半决赛，Lea 还创造了个人最佳成绩。

自测

  1. 多名选手经过若干轮决出结果的赛事是 _______。 2. 分组相互比赛的阶段是 _______。
  2. 剩八方参加的淘汰轮是 _______。 4. 赛前最被看好的一方是 _______。
  3. 比赛尚未结束时的比分是 _______。 6. 双方当前分数相同是 _______。
  4. 规定条件下此前无人超越的成绩是 _______。 8. 正式表达"不敌某人"用 _______。
  5. 获得下一阶段资格用 _______。 10. 被淘汰出局用 _______。
答案
  1. Turnier 2. Gruppenphase 3. Viertelfinale 4. Favorit
  2. Zwischenstand 6. Gleichstand 7. Rekord 8. unterliegen
  3. sich qualifizieren 10. ausscheiden
