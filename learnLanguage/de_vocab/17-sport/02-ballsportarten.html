17-2 球类运动（Ballsportarten）

本组第 2 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 4 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

球类项目共享不少词，但含义随规则变化：Tor 是足球、手球、曲棍球等项目的球门和得分，篮球则投进 Korb，网球和排球要越过 Netz。Pass、Zuspiel 都可表示把球交给队友，前者更广，后者常强调为下一次进攻创造条件。描述动作时注意是用脚 schießen、用手 werfen，还是用球拍 schlagen。

精讲

  1. Ballsport / Ball / Fußball / Basketball / Handball / Volleyball：球类总称和四项高频项目。
  2. Beachvolleyball / Tennis / Tischtennis / Badminton：隔网项目及其场地器材差异。
  3. Hockey / Eishockey / Rugby：曲棍球、冰球和橄榄球。
  4. Baseball / Softball / Golf：棒垒球和高尔夫。
  5. Mannschaft / Spieler / Gegner / Mitspieler：队伍、球员、对手和队友。
  6. Tor / Korb / Netz：球门得分、篮筐目标和隔网器材。
  7. Schläger / Tennisschläger / Tischtennisschläger / Hockeyschläger：球拍球杆总称及项目器材。
  8. Spielfeld / Platz / Halle：比赛区域、具体场地和室内馆。
  9. Linie / Mittellinie / Seitenlinie / Grundlinie：场地标线及三种位置线。
  10. Strafraum：球门前适用点球等特殊规则的区域。
  11. Aufschlag / Rückschlag：开始一分的发球 / 对来球的回击。
  12. Pass / Zuspiel：广义传球 / 为队友下一击创造条件的传送。
  13. Wurf / Schuss / Kopfball：手投、脚或杆射击、头球。
  14. Dribbling / Ballbesitz：连续控球移动 / 控制球权状态。
  15. Punkt / Satz / Runde / Spiel：得分单位、局盘单位、轮次和整场比赛。

易混辨析

  • Ball / Fußball：球的总称 / 足球项目或足球用球。
  • Tor / Korb：球门及其得分 / 篮球的篮筐目标。
  • Pass / Zuspiel：各类团队项目的传球 / 常为下一击或进攻准备的传球。
  • werfen / schießen / schlagen：用手投 / 用脚或器材射 / 用球拍球杆击。
  • Platz / Spielfeld：整座运动场地 / 规则划定的实际比赛区域。
  • Punkt / Satz / Spiel：单个得分 / 中层比赛单位 / 整场对局。

语境回收

Im Sportunterricht spielt die Gruppe zuerst Volleyball. Mia führt den Aufschlag aus, und Jonas nimmt den Ball an. Mit einem präzisen Zuspiel bereitet er den Angriff vor, doch die andere Mannschaft blockt den Angriff. Danach wechseln alle zum Basketball. Mia dribbelt an einer Gegnerin vorbei, passt zum Mitspieler und dieser trifft den Korb. Am Ende gewinnt ihre Mannschaft das Spiel mit zwei Punkten Vorsprung.

体育课上大家先打排球。Mia 发球，Jonas 接球并用精准传球组织进攻，但另一队拦住扣击。随后大家改打篮球。Mia 运球过掉对手，传给队友，队友投篮命中。最终他们的队伍领先两分获胜。
