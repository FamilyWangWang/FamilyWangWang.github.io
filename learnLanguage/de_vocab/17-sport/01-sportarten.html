17-1 运动项目（Sportarten）

本组第 1 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 3 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

谈运动时，Sportart 指具体项目，Breitensport、Leistungssport 和 Freizeitsport 则按参与目的和水平分类。德语把有组织的体育活动常与 Verein 联系起来：加入协会后可参加固定 Training，也可能代表俱乐部参加 Wettkampf。开始高强度运动前应逐步热身，并根据健康状况选择负荷。

精讲

  1. Sport / Sportart / Breitensport / Leistungssport：运动总称、具体项目、大众体育和竞技体育。
  2. Freizeitsport / Mannschaftssport / Einzelsport：休闲、团队和个人运动。
  3. Ausdauersport / Kraftsport / Wassersport / Wintersport：按能力和环境分类的运动。
  4. Kampfsport / Motorsport / Leichtathletik：格斗、赛车和田径体系。
  5. Turnen / Gymnastik：器械地面体操 / 灵活姿态练习。
  6. Schwimmen / Tauchen / Rudern / Segeln / Surfen：五类水上水下运动。
  7. Laufen / Joggen / Sprint / Marathon：跑步总称、慢跑、短跑和马拉松。
  8. Triathlon / Radfahren / Radsport：铁人三项、骑行活动和自行车竞技。
  9. Skifahren / Snowboarden / Eislaufen：双板、单板和冰上滑行。
  10. Klettern / Boxen / Judo / Karate：攀岩和三类格斗项目。
  11. Fechten / Ringen / Reiten / Tanzen / Yoga：剑术、摔跤、骑术、舞蹈和瑜伽。
  12. Sportler / Athlet：一般运动参与者 / 系统竞技训练的运动员。
  13. Verein / Sportverein / Verband / Mitgliedschaft：协会、体育协会、联合组织和成员关系。
  14. Training / Wettkampf：为提高能力的练习 / 正式比较表现的活动。
  15. trainieren / üben / teilnehmen / antreten：训练、练习、参加和出场较量。

易混辨析

  • Sport / Sportart：体育活动总称 / 具体项目。
  • Breitensport / Leistungssport：面向大众参与和健康 / 面向高水平成绩。
  • Freizeitsport / Vereinssport：按目的说休闲运动 / 按组织形式说协会运动。
  • Sportler / Athlet：一般运动者 / 更强调竞技训练和比赛。
  • Training / Übung：系统训练单元 / 其中一个具体练习。
  • teilnehmen / antreten：参加活动 / 作为参赛者出场并面对项目或对手。

语境回收

Mara möchte wieder regelmäßig Sport treiben und tritt einem Sportverein bei. Zunächst probiert sie Schwimmen und Gymnastik aus. Vor jedem Training wärmt sie sich auf und übt die Bewegungen langsam. Nach einigen Monaten ist sie deutlich fitter und nimmt an ihrem ersten Wettkampf teil. Sie erreicht keine Bestleistung, ist aber mit ihrem Fortschritt zufrieden und plant ausreichend Zeit zur Erholung ein.

Mara 想恢复规律运动，于是加入体育协会。她先尝试游泳和体操，每次训练前热身并慢慢练动作。几个月后她的体能明显改善，并参加了第一次比赛。虽然没有达到个人最佳成绩，但她对进步满意，也安排了足够恢复时间。
