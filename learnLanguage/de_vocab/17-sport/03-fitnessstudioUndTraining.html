17-3 健身房与训练（Fitnessstudio und Training）

本组第 3 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

在德国健身房，Trainingsplan 通常按目标安排器械、重量、组数和重复次数。询问器械时可说 Wie stelle ich das Gerät ein?，描述强度则常用 Gewicht、Wiederholung、Satz 和 Pause。初次训练宜先熟悉动作和器械设置，逐步增加负荷；出现疼痛或明显不适时应停止训练并寻求专业意见。

精讲

  1. Fitnessstudio / Fitnesscenter：日常健身房 / 设施较综合的健身中心。
  2. Umkleidekabine / Spind：更衣空间 / 可锁储物柜。
  3. Trainingsfläche / Kursraum：自由器械训练区 / 团体课程房间。
  4. Laufband / Ergometer / Crosstrainer / Rudergerät：四类常见耐力器械。
  5. Hantel / Kurzhantel / Langhantel / Hantelscheibe：重量器材总称及三个具体部件。
  6. Kugelhantel / Widerstandsband / Seilzug：壶铃、弹力带和拉索器械。
  7. Beinpresse / Brustpresse：主要向外推阻力的腿部 / 胸部器械。
  8. Übung / Wiederholung / Satz / Satzpause：动作、一次重复、一组和组间休息。
  9. Aufwärmphase / Abkühlphase：训练开始时逐步升高 / 结束时逐步降低负荷。
  10. Ausdauer / Muskelkraft：持续活动能力 / 克服阻力能力。
  11. Beweglichkeit / Koordination / Gleichgewicht：活动范围、动作配合和稳定能力。
  12. Körperspannung / Körperhaltung / Technik：主动稳定、身体位置和动作方法。
  13. Belastung / Intensität：身体承受的总负荷 / 当次用力程度。
  14. Trainingsdauer / Trainingshäufigkeit：一次训练多长 / 多久练一次。
  15. Muskelkater / Regeneration：延迟肌肉酸痛 / 负荷后的恢复过程。

易混辨析

  • Wiederholung / Satz：完整做一次动作 / 连续若干次组成的一组。
  • Gewicht / Belastung / Intensität：外部负重 / 身体承受的总量 / 当下用力程度。
  • Körperspannung / Körperhaltung：主动稳定身体的状态 / 身体各部分的位置关系。
  • heben / drücken：把负重向上提 / 把阻力推离身体或压向某处。
  • anspannen / lockern：让肌肉产生张力 / 减少紧张和僵硬。
  • Muskelkater / Verletzung：负荷后延迟酸痛 / 组织受损；两者不可简单等同。

语境回收

Lea meldet sich in einem Fitnessstudio an. Die Trainerin zeigt ihr zuerst die Trainingsfläche und erklärt, wie sie die Beinpresse richtig einstellt. Lea beginnt mit niedriger Intensität: drei Sätze mit jeweils zwölf Wiederholungen und einer Satzpause dazwischen. Sie achtet auf ihre Körperhaltung und führt jede Bewegung kontrolliert aus. Sobald ein Gewicht zu schwer wird, reduziert sie die Belastung. Zum Schluss plant sie eine ruhige Abkühlphase ein.

Lea 在健身房注册后，教练先带她看训练区，并讲解如何正确调节腿举机。她从低强度开始，每组十二次，共三组，中间安排组间休息。她注意身体姿态，有控制地完成每个动作；重量过大时便降低负荷，最后安排平缓的整理阶段。
