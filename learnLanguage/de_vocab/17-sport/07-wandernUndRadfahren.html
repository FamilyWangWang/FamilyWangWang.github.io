17-7 徒步与骑行（Wandern und Radfahren）

本组第 7 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 35 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

计划徒步或骑行时，德语路线信息常包含 Strecke、Höhenmeter、Steigung 和路面状况。徒步者会跟随 Wegmarkierung，骑行者则区分 Radweg、Radfahrstreifen 和 Fahrradstraße。出发前应根据路线和天气准备装备，遵守现场标志，并在能力和路况允许的范围内行动。

精讲

  1. Wanderung / Wanderweg / Fernwanderweg / Rundweg：徒步活动、普通徒步道、长距离路线、环线。
  2. Etappe / Route：多日行程的一段 / 整体规划或实际线路。
  3. Wegmarkierung / Wegweiser / Wanderkarte：路线记号、方向牌、徒步地图。
  4. Höhenprofil / Höhenmeter / Steigung：海拔曲线、累计垂直高度、坡度。
  5. Aussichtspunkt / Gipfel / Berghütte / Rastplatz：观景点、山顶、山屋、休息点。
  6. Proviant / Trinkflasche：途中食物 / 饮水容器。
  7. Wanderrucksack / Wanderschuh / Wanderstock：背包、徒步鞋、徒步杖。
  8. Trittsicherheit / Schwindelfreiheit：复杂地面稳定落脚 / 高处不眩晕并稳定行动。
  9. Trekkingrad / Mountainbike / Rennrad / E-Bike：旅行车、山地车、公路车、电助力车。
  10. Luftpumpe / Ersatzschlauch / Flickzeug：充气、换内胎和修补所需装备。
  11. Gepäckträger / Fahrradtasche：车上承重架 / 安装式骑行包。
  12. Sattel / Lenker / Gangschaltung / Bremse：座位、方向控制、变速和制动部件。
  13. Radweg / Radfahrstreifen：独立或指定的自行车道 / 车行道上划线的自行车专用带。
  14. Radfahrstreifen / Fahrradstraße：车道的一部分 / 整条以自行车交通为主的道路。
  15. aufsteigen / absteigen / schieben / radeln：骑上、下车、推行、轻松骑行。

易混辨析

  • Wegmarkierung / Wegweiser：涂色或图形路线记号 / 带方向和地点信息的路牌。
  • Höhenmeter / Höhe：累计上升下降量 / 某一点的海拔或一般高度。
  • Trittsicherheit / Schwindelfreiheit：脚下稳定能力 / 面对高度暴露时稳定行动的能力。
  • Radweg / Radfahrstreifen：道路外或独立划定的自行车道 / 机动车道表面划出的车道。
  • E-Bike / Pedelec：日常语言常混用；法规语境需按具体驱动方式和技术参数区分。
  • abschließen / anschließen：把锁锁上 / 用锁把车与固定物连接起来。

语境回收

Nora plant eine Radtour zu einem Aussichtspunkt. Sie prüft zuerst das Höhenprofil, kontrolliert die Bremsen und packt Luftpumpe, Ersatzschlauch und Regenjacke ein. Bis zum Wald fährt sie auf einem Radweg. An einer steilen, rutschigen Stelle steigt sie ab und schiebt das Fahrrad. Später folgt sie einer gut sichtbaren Wegmarkierung bis zum Gipfel und legt an der Berghütte eine Pause ein.

Nora 计划骑车前往观景点。她先查看海拔曲线、检查刹车，并带上气筒、备用内胎和雨衣。到森林前她沿自行车道骑行；遇到一段陡峭湿滑的路，她下车推行。之后她跟随清晰的路线标记到达山顶，在山屋休息。

自测

  2. Flickzeug 6. Gangschaltung 7. Radfahrstreifen 8. absteigen
