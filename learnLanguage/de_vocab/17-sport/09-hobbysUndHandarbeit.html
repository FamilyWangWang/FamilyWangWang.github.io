17-9 爱好与手工（Hobbys und Handarbeit）

本组第 9 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 14 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

介绍爱好时常用 Mein Hobby ist ...、Ich interessiere mich für ... 或 In meiner Freizeit ...。谈手工时，应先说明材料、工具和技法：aus Wolle stricken、mit der Nähmaschine nähen、nach einer Vorlage basteln。Handarbeit 多指缝纫、编织等手作，Handwerk 则还可指需要专业训练的手工业。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. Hobby / Freizeitbeschäftigung / Interesse：固定爱好、休闲活动总称、对主题的兴趣。
  2. Sammlung / Sammler / Sammlerin：收藏品集合、男性收藏者、女性收藏者。
  3. Handarbeit / Handwerk / Basteln：针织缝纫等手作、手工行业技艺、创意小制作。
  4. Material / Werkzeug / Anleitung：材料、工具、步骤说明。
  5. Vorlage / Entwurf / Werkstück：制作参照、初步设计、加工对象。
  6. Papier / Karton / Pappe：普通纸、厚纸板或盒子、纸板材料。
  7. Stoff / Wolle / Garn / Faden：布料、羊毛或毛线、纺成线材、单根细线。
  8. Nadel / Stricknadel / Häkelnadel：针的总称、棒针、钩针。
  9. Klebstoff / Pinsel / Farbe / Leinwand：粘合、涂画和画布所需材料工具。
  10. Skizze / Zeichnung：快速构思草图 / 较完整的线条图。
  11. Fotografie / Kamera / Objektiv / Motiv：摄影、相机、镜头和表现对象。
  12. Brettspiel / Kartenspiel / Puzzle：棋盘游戏、纸牌游戏、拼图。
  13. Modellbau / Modell：模型制作活动 / 制成的单个模型。
  14. Töpferei / Töpferton / Holzarbeit：陶艺、陶土和木工作业。
  15. Naht / Masche / Muster：缝合线、编织线圈、重复图案或样式。

易混辨析

  • Hobby / Interesse：经常实际进行的业余活动 / 想关注了解某主题，不一定亲自实践。
  • Handarbeit / Handwerk：个人缝织等手作 / 可成为职业并需要专业技能的手工业。
  • Karton / Pappe：前者还可指纸盒；表示纸板材料时日常用法有重叠。
  • Wolle / Garn / Faden：材料或毛线的日常称呼 / 纺成的连续线材 / 单根细线。
  • Skizze / Entwurf：快速视觉草图 / 可包含结构、尺寸和方案的设计稿。
  • stricken / häkeln：通常用两根针编织线圈 / 用一根带钩针逐针钩织。

语境回收

Mina interessiert sich für Handarbeit und Fotografie. Für ein Geschenk zeichnet sie zuerst einen Entwurf und wählt dann Stoff, Garn und ein passendes Muster aus. An der Nähmaschine fädelt sie den Faden ein und näht eine gerade Naht. Später fotografiert sie das handgemachte Werkstück bei Tageslicht. Am Wochenende baut sie außerdem nach einer Anleitung ein kleines Modell aus Karton zusammen.

Mina 对手工和摄影感兴趣。为了做一件礼物，她先画设计稿，再选择布料、线材和合适的图案。她给缝纫机穿线并缝出直线接缝，之后在自然光下拍摄成品。周末她还按照教程用纸板组装了一个小模型。

自测

  1. 按步骤说明操作的文字或图示是 _______。 2. 制作前的初步设计是 _______。
  2. 用于编织的连续线材是 _______。 4. 前端带钩的针是 _______。
  3. 绷在框架上用于绘画的表面是 _______。 6. 相机的光学部件是 _______。
  4. 陶艺使用的陶土是 _______。 8. 编织形成的单个线圈是 _______。
  5. 用两根针把线圈编成织物用 _______。 10. 用相机拍摄对象用 _______。
答案
  1. Anleitung 2. Entwurf 3. Garn 4. Häkelnadel
  2. Leinwand 6. Objektiv 7. Töpferton 8. Masche
  3. stricken 10. fotografieren
