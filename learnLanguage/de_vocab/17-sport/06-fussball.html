17-6 足球（Fußball）

本组第 6 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 7 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

足球在德国的日常对话、俱乐部生活和媒体报道中都很常见。看比赛时需要分清位置、场地区域、比赛阶段和裁判判罚：Abwehr 是整条防线，Strafraum 是罚球区，Nachspielzeit 是因中断补回的时间。表达阵型时常说 mit einer Viererkette spielen，描述进攻则常见 Flanke、Vorlage 和 Konter。

精讲

  1. Kader / Startelf / Ersatzbank：可选球员总名单、首发十一人、替补席。
  2. Torwart / Torhüterin：男性 / 女性守门员，两种词根意义相同。
  3. Abwehr / Innenverteidiger / Außenverteidigerin：防线整体、中后卫、边后卫。
  4. Mittelfeld / Mittelfeldspieler：中场区域或球员群 / 具体中场球员。
  5. Stürmerin / Flügelspieler：中路或综合进攻前锋 / 主要沿边路进攻者。
  6. Cheftrainer / Co-Trainerin：主教练 / 助理教练。
  7. Schiedsrichter / Schiedsrichterassistentin：主裁判 / 边线协助裁判。
  8. Stadion / Tribüne / Fankurve：体育场、看台、核心球迷区。
  9. Strafraum / Torraum：罚球区 / 球门前更小的球门区。
  10. Anstoß / Abpfiff / Halbzeit：开球、终场哨、半场。
  11. Nachspielzeit / Verlängerung：补回中断的伤停补时 / 平局后的加时赛。
  12. Freistoß / Eckstoß / Einwurf / Elfmeter：四种不同的恢复比赛或罚球方式。
  13. Abseits / Foulspiel：越位违规 / 不当身体接触等犯规。
  14. Verwarnung / Platzverweis：黄牌警告 / 被罚离场。
  15. Pressing / Konter / Flanke / Vorlage：逼抢、快速反击、边路传中、直接助攻。

易混辨析

  • Nachspielzeit / Verlängerung：补偿正常比赛中的中断 / 淘汰赛打平后额外进行的比赛阶段。
  • Strafraum / Torraum：较大的罚球区 / 球门前较小的球门区。
  • Freistoß / Elfmeter：一般犯规后的定位球 / 在特定罚球区犯规等情况下判罚的点球。
  • Abseitsposition / Abseitsvergehen：处于越位位置本身 / 从该位置参与比赛而构成违规。
  • Verwarnung / Platzverweis：黄牌警告 / 红牌或累计处罚导致离场。
  • Flanke / Vorlage：从边路送往门前的传球 / 任何直接创造进球的最后一传。

语境回收

Im Stadion beginnt die Heimmannschaft mit hohem Pressing. Eine Außenverteidigerin fängt den Ball ab und spielt ihn zum Flügelspieler. Er schlägt eine Flanke in den Strafraum, die Stürmerin köpft aber knapp am Tor vorbei. In der zweiten Halbzeit geht der Gast durch einen Konter in Führung. Erst in der Nachspielzeit gibt die Kapitänin eine Vorlage zum Ausgleich. Kurz danach folgt der Abpfiff.

主队在体育场以高位逼抢开局。边后卫截下球并传给边锋，边锋把球传入罚球区，但前锋的头球稍稍偏出。下半场客队通过反击领先，直到伤停补时队长才送出助攻扳平，随后比赛结束。
