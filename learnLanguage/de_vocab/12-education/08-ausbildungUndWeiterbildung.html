12-8 培训与继续教育（Ausbildung und Weiterbildung）

本组第 8 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 5 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Berufsausbildung 通常通向一个受认可职业资格；典型 Dualausbildung 在 Ausbildungsbetrieb 实践、在职业学校学习理论。Weiterbildung 是离开基础教育后继续学习的总称，Fortbildung 常围绕现有职业更新或提升能力，Umschulung 则以转入另一职业为目标。课程广告中的 Zertifikat、anerkannt 和 förderfähig 含义不一定相同，报名之前应核对颁发机构、考试方式和证书实际用途。

精讲

  1. Berufsbildung / Ausbildung / Berufsausbildung：职业教育总领域 / 系统训练总称 / 通向职业资格的初始培训。
  2. Dualausbildung / Berufsschulunterricht：企业与学校结合 / 其中学校一侧的理论课程。
  3. Ausbildungsberuf / Ausbildungsplatz / Ausbildungsbetrieb：培训职业 / 一个名额 / 提供培训的单位。
  4. Ausbildungsvertrag / Ausbildungsvergütung：培训关系合同 / 培训期间报酬。
  5. Ausbilder / Azubi：负责培养指导者 / 接受培训者的简称。
  6. Berichtsheft / Ausbildungsnachweis：持续记录册 / 用于证明培训内容的正式材料。
  7. Ausbildungszwischenprüfung / Ausbildungsabschlussprüfung：阶段考试 / 最终职业能力考试。
  8. Handwerkskammer / IHK：手工业领域法定机构 / 工商业协会简称。
  9. Weiterbildung / Fortbildung：继续学习总称 / 围绕已有职业更新或晋升。
  10. Anpassungsfortbildung / Aufstiegsfortbildung：适应变化 / 取得进阶职责资格。
  11. Umschulung / Qualifizierung：转入另一职业 / 有目标提升任务能力。
  12. Zusatzqualifikation / Zertifikatskurs：主资格外补充能力 / 以证书为结业结果的课程。
  13. Lehrgang / Workshop / Schulung：按计划的系统培训 / 参与式短活动 / 具体系统技能教学。
  14. Einarbeitung / Onboarding：熟悉岗位任务 / 更广的组织融入过程。
  15. Teilnahmebescheinigung / Kompetenznachweis：证明参加 / 证明具备能力。

易混辨析

  • Ausbildung / Studium：职业培训 / 高校培养项目；某些职业路径也可能在高校完成。
  • Weiterbildung / Umschulung：继续学习总称 / 以转入另一职业为明确目标。
  • Kurs / Workshop：按课程计划学习 / 参与者共同实践产出。
  • Zertifikat / Teilnahmebescheinigung：可能包含考核或资格信息的证书 / 通常只证明参加。

语境回收

Tariq beginnt eine Dualausbildung in einem Handwerksbetrieb. Seine Ausbilderin erklärt den Ausbildungsplan und zeigt ihm, wie er das Berichtsheft führt. Einen Teil der Woche arbeitet er betrieblich, den anderen besucht er den Berufsschulunterricht. Nach einigen Berufsjahren möchte er sich weiterbilden. Er vergleicht eine Anpassungsfortbildung mit einer Aufstiegsfortbildung und prüft, welcher Kompetenznachweis jeweils anerkannt wird.

Tariq 在一家手工业企业开始双元职业培训。培训师向他解释培训计划，并示范如何填写培训记录。他每周一部分时间在企业实践，另一部分时间上职业学校。工作几年后，他想继续学习，于是比较适应型进修和晋升型进修，并核对各自能力证明的认可情况。
