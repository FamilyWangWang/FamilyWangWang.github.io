12-1 学校类型与教育体系（Schularten und Bildungssystem）

本组第 1 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 3 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德国学校教育主要由各联邦州负责，因此 Schulart、年级划分和毕业证名称可能因州而异。通常先读 Grundschule，之后进入不同形式的继续教育学校；Gymnasium、Gesamtschule、Gemeinschaftsschule 等名称不能只靠中文直译判断课程和毕业路径。Berufsschule 则常与企业实践培训结合。选择学校时，应查看所在州的官方 Bildungsgang、可取得的 Schulabschluss 以及学校自身说明。

精讲

  1. Bildungssystem / Schulwesen：全部教育阶段与机构的整体制度 / 其中学校领域的制度和管理。
  2. Schulpflicht / Einschulung：必须接受学校教育的义务 / 儿童正式开始上学。
  3. Schuljahr / Schulhalbjahr：整个学年 / 学年的一个半期。
  4. Bildungsgang / Schulzweig：通向某资格的完整教育路径 / 一所学校内部的方向分支。
  5. Grundschule / Sekundarschule：初等学校 / 小学后的中等学校总称或特定校名。
  6. Hauptschule / Realschule：传统上侧重基础普通教育 / 通常通向中等毕业资格，具体设置因州而异。
  7. Gesamtschule / Gemeinschaftsschule：整合多种教育路径 / 较长时间共同学习的州级学校模式。
  8. Gymnasium / Fachoberschule：通常通向普通大学入学资格 / 结合专业方向通向相应升学资格。
  9. Berufsschule / Berufsfachschule：常与企业双元培训结合 / 以学校职业教育为主。
  10. Volkshochschule / Abendgymnasium：成人多主题继续教育 / 成人补取大学入学资格。
  11. Ganztagsschule / Halbtagsschule / Internat：较长日程 / 半日日程 / 同时提供住宿生活。
  12. Schulträger / Schulbehörde / Schulamt：承办设施经费 / 行政管理监督 / 地方具体主管机构。
  13. Schulleitung / Lehrerkollegium：学校领导机构 / 全体教师。
  14. Klassenstufe / Jahrgangsstufe / Schulklasse：课程年级层次 / 同届或同阶段年级 / 实际共同上课的班。
  15. Abitur / Realschulabschluss / Hauptschulabschluss：不同学校资格的常见称呼，官方名称和取得路径应按所在州核对。

易混辨析

  • Schüler / Student：中小学或职业学校学生 / 高等院校注册学生。
  • Schulart / Schulform：学校类型 / 学校组织形式，两者在官方文件中可能按州有特定定义。
  • Klasse / Kurs：固定班级群体 / 围绕某门课组成的学习组。
  • Abschluss / Zeugnis：取得的资格 / 记录成绩或证明资格的文件。

语境回收

Familie Demir zieht in ein anderes Bundesland. Ihr Sohn wechselt nach der Grundschule auf eine weiterführende Schule. Weil Schularten und Bildungsgänge nicht überall gleich heißen, informiert sich die Familie beim Schulamt und bei mehreren Schulen. Sie vergleicht Ganztagsangebot, Schulzweige und erreichbare Abschlüsse. Erst danach meldet sie ihn an einer Gesamtschule an.

Demir 一家搬到另一个联邦州。儿子小学毕业后要进入继续教育学校。由于各州学校类型和教育路径名称并不完全相同，全家向教育主管部门和多所学校了解情况，比较全日安排、校内方向和可取得的毕业资格，最后才为他报名一所综合学校。

自测

  1. 学校制度总称是 _______。 2. 正式开始上小学的过程是 _______。
  2. 小学后的中等学校总称是 _______。 4. 与企业培训常结合的学校是 _______。
  3. 成人晚间补取大学入学资格的学校是 _______。 6. 学校全体教师是 _______。
  4. 同校同年级的另一个班是 _______。 8. 较高年级毕业准备阶段是 _______。
  5. 让儿童正式入学用动词 _______。 10. 升入下一年级用动词 _______。
答案
  1. Schulwesen 2. Einschulung 3. Sekundarschule 4. Berufsschule
  2. Abendgymnasium 6. Lehrerkollegium 7. Parallelklasse 8. Oberstufe
  3. einschulen 10. versetzen
