12-2 学科（Schulfächer）

本组第 2 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

课程表里的 Schulfach 不一定在每个州和学校使用同一个名称。例如小学常见 Sachunterricht，高年级可能把政治、经济或社会内容分别设课，也可能合并。Pflichtfach 必须修读，Wahlfach 可自由选择，Wahlpflichtfach 则要求学生从限定范围中选一项。谈自己擅长什么时，可以说 Mein Lieblingsfach ist Biologie；谈具体课程，则常说 im Mathematikunterricht。

精讲

  1. Schulfach / Fachunterricht：课程体系中的学科 / 围绕该学科开展的教学。
  2. Pflichtfach / Wahlfach / Wahlpflichtfach：必须修 / 自由选 / 必须从限定范围选一项。
  3. Hauptfach / Nebenfach：权重或课时较高 / 相对较低，具体划分因学校而异。
  4. Prüfungsfach / Leistungsfach：毕业考试涉及的学科 / 高要求深入学习的学科。
  5. Grundkurs / Leistungskurs：基础要求课程 / 较高课时与要求的课程，名称因州而异。
  6. Stundenplan / Fachraum：课程时间安排 / 为特定学科配备的教室。
  7. Mathematik / Arithmetik / Algebra / Geometrie：数学总学科 / 数与运算 / 符号关系 / 形状空间。
  8. Physik / Chemie / Biologie：物质能量规律 / 物质组成反应 / 生命体与生命过程。
  9. Naturwissenschaft / Informatik / Technik：自然研究总称 / 信息与计算系统 / 技术设计应用。
  10. Geografie / Geschichte / Politik：空间与人地关系 / 过去社会发展 / 公共制度决策。
  11. Sozialkunde / Wirtschaftslehre / Rechtskunde：社会政治基础 / 经济活动 / 法律制度。
  12. Ethik / Philosophie / Religionslehre：道德判断 / 基本思想论证 / 宗教传统与伦理。
  13. Deutschunterricht / Fremdsprache：母语或学校语言课程 / 学习者母语外的语言。
  14. Kunst / Musik / Theaterunterricht：视觉造型 / 声音演奏 / 舞台表演。
  15. Werken / Hauswirtschaft / Sachunterricht：材料制作 / 家庭生活实务 / 小学综合环境学习。

易混辨析

  • Fach / Kurs：学科领域 / 在某时段由某组学生参加的具体课程。
  • Geografie / Geologie：研究空间及人地关系 / 研究地球物质与地质过程。
  • Politik / Geschichte：当前和一般公共制度决策 / 过去事件与发展过程。
  • Ethik / Religion：道德论证与价值问题 / 宗教传统、信仰和文本。

语境回收

Leonie stellt ihren Stundenplan zusammen. Mathematik und Deutsch sind Pflichtfächer. Als Wahlpflichtfach entscheidet sie sich für Informatik, weil sie gern praktisch programmiert. Geschichte wählt sie als Prüfungsfach, Biologie als Leistungsfach. Bevor sie einen Kurs abwählt, prüft sie mit der Fachlehrerin, ob sie trotzdem alle Voraussetzungen für den gewünschten Schulabschluss erfüllt.

Leonie 安排自己的课程表。数学和德语是必修课；限选课中，她因为喜欢实际编程而选择信息学。历史被选为考试科目，生物为高要求课程。退选一门课前，她和任课教师确认，自己是否仍满足目标毕业资格的全部条件。

自测

  1. 必须学习的学科是 _______。 2. 必须从限定范围选择的课是 _______。
  2. 毕业考试涉及的学科是 _______。 4. 课程时间安排是 _______。
  3. 研究生命体的学科是 _______。 6. 研究公共决策制度的是 _______。
  4. 小学综合认识环境的课是 _______。 8. 家庭生活实务课是 _______。
  5. 正式选修课程用动词 _______。 10. 做数学运算用动词 _______。
答案
  1. Pflichtfach 2. Wahlpflichtfach 3. Prüfungsfach 4. Stundenplan
  2. Biologie 6. Politik 7. Sachunterricht 8. Hauswirtschaft
  3. belegen 10. rechnen
