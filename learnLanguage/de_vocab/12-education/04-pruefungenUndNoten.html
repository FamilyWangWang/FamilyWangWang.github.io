12-4 考试与成绩（Prüfungen und Noten）

本组第 4 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 3 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Prüfung 是考试总称；学校里的较大型书面考查可能叫 Klassenarbeit，高年级和大学常说 Klausur，较短考查则常叫 Test 或 Lernkontrolle。德国常见学校分数中 1 通常最好、6 最差，但评分尺度、合格界线和权重会因州、学校、教育阶段和考试规定而不同。看成绩时不要只看 Note，还要看 Punktzahl、Bewertungskriterien 和老师的具体 Korrektur。

精讲

  1. Prüfung / Klassenarbeit / Klausur：考试总称 / 学校较大型书面考查 / 正式限时笔试。
  2. Test / Kurztest / Lernkontrolle：一般测验 / 短测 / 阶段学习效果检查总称。
  3. Prüfungsgespräch / Abschlussprüfung / Zwischenprüfung：口头问答 / 最终资格考试 / 过程阶段考试。
  4. Nachprüfung / Wiederholungsprüfung：因特定规则进行的补充考试 / 未通过后重新考试。
  5. Prüfungsordnung / Prüfungsstoff：考试规则 / 被考查的内容范围。
  6. Prüfungsaufgabe / Fragestellung：具体题目任务 / 题目提出的核心问题。
  7. Auswahlaufgabe / Lückentext：从选项中选 / 填补文本空缺。
  8. Rechenaufgabe / Textaufgabe：直接计算 / 从情境文字提取条件再求解。
  9. Antwortbogen / Lösungsweg / Musterlösung：作答表 / 解题过程 / 参考解答。
  10. Bewertung / Bewertungskriterium：评价过程 / 用于评价的一项标准。
  11. Punktzahl / Gesamtpunktzahl：实际或单项得分 / 全部相加的总分。
  12. Note / Schulnote / Zeugnisnote：等级评价总称 / 学校成绩 / 写入成绩单的成绩。
  13. Halbjahreszeugnis / Jahreszeugnis：学年中期成绩单 / 学年结束成绩单。
  14. Durchschnittsnote / Notendurchschnitt：平均等级 / 成绩平均值，日常常近义。
  15. Nachteilsausgleich / Täuschungsversuch：公平调整考试条件 / 使用未获允许帮助。

易混辨析

  • Prüfung / Test：正式资格或较系统考查 / 范围通常较小的测验。
  • bestehen / absolvieren：达到要求并通过 / 完整参加或完成，后者不必然说明成绩。
  • Punkt / Note：累积计算的分值 / 对表现的等级概括。
  • korrigieren / benoten：检查并标出错误 / 给出等级成绩。

语境回收

Vor der Klausur liest Jonas die Prüfungsordnung und wiederholt den Prüfungsstoff. Im Prüfungsraum erhält er Aufgabenblatt und Antwortbogen. Er liest jede Fragestellung genau, kreuzt Auswahlaufgaben an und schreibt bei Rechenaufgaben den Lösungsweg auf. Nach der Korrektur sieht er Punktzahl, Note und Bewertungskriterien ein. Eine Aufgabe war falsch, die Prüfung hat er trotzdem bestanden.

考前 Jonas 阅读考试规定并复习考试范围。进入考场后，他拿到题目纸和答题卡，仔细阅读每道题，勾选选择题，并为计算题写出步骤。阅卷后，他查看分数、等级和评分标准。虽然有一道题做错，他仍然通过了考试。
