12-5 大学与专业（Universität und Studium）

本组第 5 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 1 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Hochschule 是高等院校总称，Universität 通常研究导向更强并具有相应学位授予权，日常仍常听到 Fachhochschule，许多此类院校如今校名使用 Hochschule für angewandte Wissenschaften。申请 Studiengang 获得 Zulassung 后，还要完成 Immatrikulation 才正式成为注册学生；之后每学期通常需要 Rückmeldung。课程组织以 Modul 为单位，Leistungspunkte 记录预期学习工作量，不等同于成绩。

精讲

  1. Hochschule / Universität / Fachhochschule：高等院校总称 / 研究导向综合院校 / 传统应用导向院校称呼。
  2. Studium / Studiengang / Studienfach：高校学习过程 / 完整培养项目 / 所学学科。
  3. Fachrichtung / Studienschwerpunkt：较宽专业方向 / 专业内部深入重点。
  4. Bachelorstudium / Masterstudium：第一学位阶段 / 通常接续第一学位的后续阶段。
  5. Staatsexamen / Promotion：国家参与规定的专业资格考试路径 / 博士资格过程。
  6. Bachelorgrad / Mastergrad / Doktorgrad：三个不同层级和路径的学术学位。
  7. Hochschulzugang / Hochschulreife：进入高校的资格路径总称 / 学校阶段取得的入学资格。
  8. Zulassung / Immatrikulation：被专业录取 / 正式注册为学生。
  9. Einschreibung / Rückmeldung / Exmatrikulation：注册入学 / 续注册 / 注销学生身份。
  10. Semester / Vorlesungszeit / Semesterferien：学期行政阶段 / 常规上课期 / 日常所谓无课期。
  11. Vorlesung / Seminar / Übung / Tutorium：讲授 / 讨论研究 / 应用练习 / 配套辅导。
  12. Hochschulpraktikum / Laborpraktikum / Exkursion：专业实践 / 实验实践 / 校外考察。
  13. Modul / Lehrveranstaltung：由课程考核组成的学习单元 / 一次具体课程活动。
  14. Vorlesungsverzeichnis / Modulhandbuch：当学期课程目录 / 模块长期规则说明。
  15. Leistungspunkt / Prüfungsleistung / Studienleistung：工作量学分 / 正式考核成果 / 其他规定学习成果。

易混辨析

  • Hochschule / Universität：前者是总称，也可出现在院校正式名称中；后者是一类具体高校。
  • Bewerbung / Einschreibung：申请竞争名额 / 录取后注册身份。
  • Semesterferien / Urlaub：无常规课程期，可能仍有考试论文 / 真正无需履行学习工作的休假。
  • Leistungspunkt / Note：预期学习工作量单位 / 学习表现等级。

语境回收

Nora bewirbt sich für einen zulassungsbeschränkten Masterstudiengang. Nach der Zulassung reicht sie alle Unterlagen zur Immatrikulation ein. Im Modulhandbuch prüft sie Lernziele, Prüfungsleistungen und ECTS-Punkte. Danach wählt sie Vorlesung, Seminar und Tutorium im Vorlesungsverzeichnis aus. Vor dem nächsten Semester muss sie sich fristgerecht zurückmelden.

Nora 申请一个限额录取的硕士项目。收到录取后，她提交注册所需全部材料。她在模块手册中核对学习目标、考核成果和 ECTS 学分，再从课程目录中选择讲座、研讨课和辅导课。下一学期前，她还必须按时完成续注册。

自测

  1. 高等院校总称是 _______。 2. 通向某一资格的完整项目是 _______。
  2. 正式录取决定是 _______。 4. 注册取得学生身份是 _______。
  3. 每学期确认继续就读是 _______。 6. 课程和考核组成的学习单元是 _______。
  4. 说明模块目标规则的文件是 _______。 8. 学习工作量单位是 _______。
  5. 在高校学习用动词 _______。 10. 正式注销学生身份用动词 _______。
答案
  1. Hochschule 2. Studiengang 3. Zulassung 4. Immatrikulation
  2. Rückmeldung 6. Modul 7. Modulhandbuch 8. Leistungspunkt
  3. studieren 10. exmatrikulieren
