12-7 论文与研究（Wissenschaftliches Arbeiten）

本组第 7 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 5 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

学术写作从清楚的 Forschungsfrage 开始，而不是先堆积资料。阅读时要区分 Primärquelle 与 Sekundärquelle，记录完整 Quellenangabe。原文照录是 Zitat，用自己的话准确重述是 Paraphrase；两者都需要可追溯的来源。研究结果 Ergebnis 不应超出方法和数据能够支持的范围，Diskussion 则解释意义、局限和与既有研究的关系。

精讲

  1. Wissenschaft / Forschung：形成和交流系统知识的制度活动 / 针对开放问题产生新知识。
  2. Forschungsfrage / Forschungsziel / Forschungsstand：要回答什么 / 要产生什么 / 已经知道什么。
  3. Studie / Untersuchung / Forschungsprojekt：一项完成的系统研究 / 系统检查过程 / 有资源期限的研究工作。
  4. Experiment / Beobachtung / Befragung：控制条件 / 记录现象 / 通过问题收集信息。
  5. Forschungsinterview / Umfrage：深入访谈 / 面向较多人收集标准化回答。
  6. Stichprobe / Datensatz / Forschungsdaten：纳入研究的对象 / 结构化数据集合 / 研究数据总称。
  7. Quelle / Primärquelle / Sekundärquelle：依据出处 / 原始材料 / 分析解释原始材料的来源。
  8. Fachliteratur / Fachartikel / Zeitschriftenartikel：专业文献总称 / 专业单篇文章 / 期刊中的文章。
  9. Sammelband / Monografie：多作者章节合集 / 围绕一个主题的完整专著。
  10. Bibliografie / Literaturverzeichnis：系统文献清单 / 论文实际引用来源清单。
  11. Zitat / Paraphrase / Beleg：原文引用 / 自己语言重述 / 支持说法的依据。
  12. Quellenangabe / Zitierweise / Plagiat：来源信息 / 统一引用规则 / 未适当归属他人成果。
  13. Hypothese / Theorie：可检验的暂时假设 / 系统解释框架。
  14. Forschungsmethode / Methodik：一种具体程序 / 方法组合及选择理由。
  15. Forschungsergebnis / Befund / Diskussion / Schlussfolgerung：总体结果 / 单项发现 / 解释局限 / 推导判断。

易混辨析

  • Thema / Forschungsfrage：研究领域或话题 / 可由研究具体回答的问题。
  • Zitat / Paraphrase：逐字引用 / 保持原意的改写，二者都需来源。
  • Methode / Methodik：具体收集分析程序 / 整套方法设计及其论证。
  • Ergebnis / Interpretation：数据分析直接得到的结果 / 对结果意义的解释。

语境回收

Für ihre Masterarbeit formuliert Elena zunächst eine enge Forschungsfrage. Sie stellt den Forschungsstand anhand aktueller Fachliteratur dar und wählt qualitative Forschungsinterviews als Methode. Nach der Befragung anonymisiert und wertet sie die Daten aus. Im Ergebnisteil berichtet sie die Befunde, in der Diskussion vergleicht sie diese mit früheren Studien und benennt Grenzen. Jede übernommene Aussage belegt sie mit einer vollständigen Quellenangabe.

Elena 为硕士论文先提出范围明确的研究问题。她根据最新专业文献梳理研究现状，并选择质性研究访谈。访谈后，她对数据匿名化并分析；结果部分呈现发现，讨论部分与既有研究比较并说明局限。每一项采用的外部说法都附有完整来源。

自测

  1. 研究要回答的明确问题是 _______。 2. 已有知识总体情况是 _______。
  2. 实际纳入研究的一组对象是 _______。 4. 原始材料是 _______。
  3. 多作者章节合集是 _______。 6. 用自己语言重述来源是 _______。
  4. 统一引用规则是 _______。 8. 可检验的暂时假设是 _______。
  5. 按程序收集数据用动词 _______。 10. 分析研究数据用动词 _______。
答案
  1. Forschungsfrage 2. Forschungsstand 3. Stichprobe 4. Primärquelle
  2. Sammelband 6. Paraphrase 7. Zitierweise 8. Hypothese
  3. erheben 10. auswerten
