12-6 学习方法动词（Lernmethoden und Lernverben）

本组第 6 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 18 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

有效学习不是只反复 lesen。先确定 Lernziel，把材料 überfliegen 建立整体结构，再 markieren、gliedern 和用自己的话 zusammenfassen。需要长期记忆的内容应隔一段时间主动 abrufen，而不是只看答案觉得熟悉。最后把知识 anwenden、向别人 erklären，并根据错误 reflektieren 和 verbessern，才能发现自己是否真正理解。

精讲

  1. Lernziel / Lernplan：要达到的结果 / 时间和活动安排。
  2. Lernstrategie / Lernmethode：为目标选择的一套整体做法 / 执行任务的具体方法。
  3. Lerntempo / Lernfortschritt：处理内容的速度 / 相对于目标的推进。
  4. Lernphase / Lernpause：集中学习时段 / 恢复注意力的休息。
  5. lesen / überfliegen：完整阅读 / 快速获得结构大意。
  6. markieren / unterstreichen / notieren：用颜色突出 / 画线突出 / 另行写下。
  7. mitschreiben / abschreiben：听讲同步记录 / 照已有内容抄写。
  8. zusammenfassen / gliedern / ordnen：压缩要点 / 划分结构 / 按关系排列。
  9. sortieren / zuordnen：分组排序 / 把项目配给类别对象。
  10. nachschlagen / recherchieren：查一个具体信息 / 从多来源系统搜索。
  11. verstehen / begreifen / erfassen：理解含义 / 深入明白原理 / 抓住整体核心。
  12. einprägen / memorieren / behalten：主动记牢 / 背诵记忆 / 长期保留。
  13. erinnern / abrufen：想起相关经历内容 / 主动从记忆中提取。
  14. analysieren / interpretieren / beurteilen：分解关系 / 说明意义 / 按标准判断。
  15. vertiefen / verknüpfen / übertragen / reflektieren：深入 / 建联系 / 迁移 / 回顾改进。

易混辨析

  • lernen / studieren：学习任何知识技能 / 在高校就读某专业，或深入研究材料。
  • merken / sich einprägen：注意到或记住 / 有意识让内容牢固进入记忆。
  • wiederholen / wiedergeben：再次学习或说一遍 / 按原意复述内容。
  • überprüfen / korrigieren：检查是否正确 / 在发现错误后改正。

语境回收

Mina setzt sich für die Woche drei Lernziele. Zuerst überfliegt sie jedes Kapitel und gliedert den Lernstoff. Dann fasst sie zentrale Aussagen in eigenen Worten zusammen und verknüpft sie mit ihrem Vorwissen. Zwei Tage später ruft sie die Begriffe mit Karteikarten aktiv ab. Falsche Antworten korrigiert sie und nimmt sie früher in den Wiederholungsplan auf. Am Wochenende reflektiert sie ihren Lernfortschritt.

Mina 为本周设定三个学习目标。她先快速浏览各章并划分学习内容，再用自己的话总结核心观点并与已有知识建立联系。两天后，她用记忆卡主动提取词语；答错的内容会被改正，并提前安排复习。周末她回顾自己的学习进度。

自测

  1. 学习后要达到的结果是 _______。 2. 整体学习做法是 _______。
  2. 快速浏览掌握大意用动词 _______。 4. 用短形式保留核心用动词 _______。
  3. 在资料中查具体信息用动词 _______。 6. 主动从记忆提取用动词 _______。
  4. 按标准形成判断用动词 _______。 8. 在新旧知识间建立联系用动词 _______。
  5. 把知识用于新情境用动词 _______。 10. 回顾学习过程用动词 _______。
答案
  1. Lernziel 2. Lernstrategie 3. überfliegen 4. zusammenfassen
  2. nachschlagen 6. abrufen 7. beurteilen 8. verknüpfen
  3. übertragen 10. reflektieren
