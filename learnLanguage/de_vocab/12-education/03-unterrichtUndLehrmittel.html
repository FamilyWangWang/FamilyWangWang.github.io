12-3 课堂与教具（Unterricht und Lehrmittel）

本组第 3 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 2 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

一节课可以说 Unterrichtsstunde，学校时间表中的固定课时也常叫 Schulstunde；连续两课时则是 Doppelstunde。传统 Kreidetafel、可擦写 Whiteboard 和数字 Smartboard 可能同时存在。学生通常把书写用品装在 Federmäppchen，把课程内容记在 Schulheft 或数字设备中。老师说 Schlagt bitte das Buch auf Seite 25 auf，就是让大家把书翻到第 25 页。

精讲

  1. Unterricht / Unterrichtsstunde / Schulstunde：教学活动总称 / 一节具体课程 / 时间表中的课时单位。
  2. Doppelstunde / Unterrichtspause：连续两个课时 / 课间休息。
  3. Klassenraum / Klassenzimmer：较正式的班级教室 / 日常常用的教室说法。
  4. Schultafel / Kreidetafel / Whiteboard / Smartboard：板面总称 / 粉笔板 / 白板笔板 / 数字互动板。
  5. Tafelschwamm / Tafelkreide / Whiteboardmarker：擦黑板工具 / 粉笔 / 白板笔。
  6. Lehrerpult / Schülertisch / Schulbank：教师讲台桌 / 学生桌 / 传统桌椅位置称呼。
  7. Schulranzen / Schulrucksack：较硬挺的小学生书包 / 较软的背包式书包。
  8. Federmäppchen / Schlampermäppchen：笔袋总称 / 无固定笔槽的软式口语称呼。
  9. Schulheft / Arbeitsheft：记录内容作业的本子 / 直接含练习的配套册。
  10. Lehrbuch / Schulbuch：为教学编写的教材 / 学校课程实际采用的学生用书。
  11. Arbeitsblatt / Aufgabenblatt / Lösungsblatt：练习材料 / 题目单 / 答案或步骤单。
  12. Lernkartei / Karteikarte：按复习阶段组织的卡片系统 / 其中一张卡。
  13. Lehrmittel / Unterrichtsmaterial / Anschauungsmaterial：教学工具 / 某课程全部材料 / 帮助直观理解的实物图示。
  14. Geodreieck / Zirkel / Taschenrechner：三角尺 / 圆规 / 计算器。
  15. Dokumentenkamera / Tageslichtprojektor：实时拍摄实物 / 投影透明胶片。

易混辨析

  • Tafel / Brett：教学或公告用板面 / 普通木板等板材。
  • Heft / Buch：薄本、练习册 / 装订成册的书。
  • abschreiben / mitschreiben：照着已有内容抄写 / 听讲时同步记录。
  • Lehrmittel / Lernmittel：教师教学使用的工具 / 学习者完成学习所需的材料，实际范围可重叠。

语境回收

Vor Unterrichtsbeginn legt Herr Özdemir Arbeitsblätter und Experimentierkästen bereit. Die Schülerinnen schlagen das Schulbuch auf und schreiben die Leitfrage von der Schultafel ab. Anschließend zeigt der Lehrer mit der Dokumentenkamera einen Versuchsaufbau. Die Gruppen notieren ihre Beobachtungen auf dem Aufgabenblatt. Am Unterrichtsende sammelt er die Blätter ein und lässt den Klassenraum aufräumen.

上课前，Özdemir 老师摆好练习纸和实验箱。学生翻开课本，抄下黑板上的核心问题。随后老师通过实物投影机展示实验装置，各组把观察结果记在任务纸上。下课时，他收回纸张，并让大家整理教室。
