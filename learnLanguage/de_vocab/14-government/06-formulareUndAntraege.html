14-6 表格与申请用语（Formulare und Anträge）

本组第 6 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 27 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Formular 是填写信息的载体，Antrag 则是请求机关作出某项决定；填完表格但没有按规定 einreichen，申请通常还没有正式到达机关。阅读时先找 Pflichtfeld、Nachweis、Frist 和签名要求。收到 Bescheid 后要区分 Bewilligung、Ablehnung 和附带的 Auflage，并阅读 Rechtsbehelfsbelehrung。正式异议的方式和期限以决定书为准。

精讲

  1. Formular / Antrag / Antragsformular：信息载体 / 正式请求 / 用于提出该请求的表格。
  2. Onlineformular / Vordruck / Merkblatt：电子表格 / 官方预印表单 / 办理说明页。
  3. Pflichtfeld / Eingabefeld / Auswahlfeld：必填栏目 / 输入框 / 选择框。
  4. Kontrollkästchen / Freitextfeld / Unterschriftsfeld：勾选框 / 自由说明栏 / 签名栏。
  5. Anhang / Anlage / Beilage：电子附件 / 申请正式附表附件 / 随附补充材料。
  6. Unterlage / Nachweis / Beleg：材料总称 / 证明资格事实的材料 / 支持陈述的票据记录。
  7. Angabe / Pflichtangabe / Zusatzangabe：单项信息 / 必须信息 / 补充信息。
  8. Erklärung / Einwilligung / Zustimmung：正式声明 / 知情同意 / 同意上位概念。
  9. Vollmacht / Zuständigkeit：代理授权 / 机关处理权限。
  10. Antragseingang / Eingangsbestätigung：申请到达 / 机关确认收到。
  11. Bearbeitung / Bearbeitungsstand / Bearbeitungszeit：处理过程 / 当前阶段 / 所需时间。
  12. Rückfrage / Nachforderung / Mitwirkungspflicht：澄清问题 / 补充要求 / 配合义务。
  13. Frist / Ausschlussfrist / Fristverlängerung：一般期限 / 严格失权期限 / 延期。
  14. Bescheid / Bewilligung / Ablehnung / Teilbewilligung：行政决定 / 全部批准 / 拒绝 / 部分批准。
  15. Auflage / Begründung / Rechtsbehelf / Widerspruch：附加义务 / 理由 / 救济总称 / 行政异议。

易混辨析

  • Formular / Antrag：填写用的载体 / 向机关提出的正式请求。
  • Eingangsbestätigung / Bewilligung：确认收到 / 确认批准，前者不代表结果。
  • Rückfrage / Nachforderung：一般澄清问题 / 正式要求补交材料或信息。
  • Widerspruch / Beschwerde：法定行政异议程序 / 一般投诉或其他法律程序，不能自动互换。

语境回收

Eva liest zuerst das Merkblatt und öffnet dann das Onlineformular. Sie füllt alle Pflichtfelder aus, kreuzt die passende Auswahl an und fügt die verlangten Nachweise bei. Nach dem Absenden speichert sie die Eingangsbestätigung. Später erhält sie einen Bescheid mit Teilbewilligung, Begründung und Auflage. Sie liest auch die Rechtsbehelfsbelehrung und notiert die Frist.

Eva 先读办理说明，再打开在线表格。她填完所有必填项、勾选合适选项并附上所需证明。提交后，她保存收件确认。后来她收到一份部分批准的决定，其中有理由和附加义务；她也阅读救济说明并记下期限。
