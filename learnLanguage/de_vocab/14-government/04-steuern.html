14-4 税务（Steuern）

本组第 4 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 18 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Steuer-ID（正式称 Identifikationsnummer）由联邦中央税务局分配给自然人，通常终身不变；Steuernummer 则由税务机关在具体税务关系中使用，不能混为一谈。雇员在 Lohnabrechnung 上会看到代扣的 Lohnsteuer，年度 Steuererklärung 经审查后形成 Steuerbescheid。税种、申报义务和期限取决于个人情况，本篇只解释语言，不代替税务咨询。

精讲

  1. Steuer / Einkommensteuer / Lohnsteuer：税款总称 / 个人所得税 / 工资代扣形式。
  2. Umsatzsteuer / Mehrwertsteuer：制度和企业申报正式称呼 / 消费价格中的日常称呼。
  3. Finanzamt / Finanzverwaltung / BZSt：地方主管税务机关 / 税务机关体系 / 联邦中央税务局简称。
  4. Steuer-ID / Identifikationsnummer / Steuernummer：个人税号简称 / 正式全称 / 具体税务关系编号。
  5. Umsatzsteuer-ID / Steuer-ID：企业跨境增值税识别号 / 自然人税务识别号。
  6. Steuerklasse / Freibetrag / Pauschbetrag：工资代扣分类 / 免计金额 / 简化固定金额。
  7. Werbungskosten / Sonderausgabe：与取得收入相关支出 / 法定可扣除私人支出。
  8. Einkommen / Einkunft / Arbeitslohn：收入总概念 / 税法来源分类 / 受雇劳动报酬。
  9. Bruttolohn / Nettolohn / Lohnabrechnung：税费前工资 / 实发工资 / 结算明细。
  10. Steuererklärung / Einkommensteuererklärung：税务申报总称 / 个人所得税年度申报。
  11. Hauptvordruck / Anlage / Beleg：主表 / 分类附表 / 支持申报的凭据。
  12. ELSTER-Portal / Benutzerkonto / Zertifikatsdatei：官方门户 / 登录账户 / 一种登录凭证文件。
  13. Abgabefrist / Fristverlängerung：提交截止期限 / 获准或依法延长期限。
  14. Steuerbescheid / Festsetzung：税务行政决定 / 决定中确定税额的行为。
  15. Erstattung / Nachzahlung / Vorauszahlung：退税 / 补缴 / 预缴。

易混辨析

  • Steuer-ID / Steuernummer：个人终身识别号 / 税务机关对具体税务关系使用的号码。
  • Lohnsteuer / Einkommensteuer：工资发放时的代扣形式 / 年度个人所得税整体。
  • Beleg / Steuerbescheid：支持申报内容的凭据 / 税务机关作出的决定。
  • Einspruch / einfache Rückfrage：正式异议程序 / 一般询问，后者不当然保留期限。

语境回收

Jonas meldet sich im ELSTER-Portal an und trägt Steuer-ID und Steuernummer in die Einkommensteuererklärung ein. Er übernimmt die Angaben aus der Lohnsteuerbescheinigung, ergänzt Werbungskosten und bewahrt die Belege auf. Nach der elektronischen Abgabe erhält er einen Steuerbescheid. Er prüft Festsetzung, Erstattung und Einspruchsfrist sorgfältig.

Jonas 登录 ELSTER，在所得税申报中填写个人税号和税务编号。他录入工资税证明数据、补充工作相关支出并保存票据。电子提交后，他收到税务决定，并仔细核对税额确定、退税和异议期限。
