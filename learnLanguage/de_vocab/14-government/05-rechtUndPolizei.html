14-5 法律与警察（Recht und Polizei）

本组第 5 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 9 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

先看文件来自谁、对谁说、要求什么，再读案件内容。本篇沿报案与后续询问展开，特别把受到怀疑、作为调查对象和已经被裁判分开。

Polizei、Staatsanwaltschaft 和 Gericht 在刑事程序中承担不同职责。向警方说明可能发生的犯罪叫 Strafanzeige；它不等于案件已经证明，也不等于提出所有可能的私人请求。收到 Vorladung、Anhörung 或其他正式文件时，应先确认自己的程序身份、发件机关、期限和权利。紧急危险拨打警方 110；不紧急的报案可查询当地警局或官方 Onlinewache。

精讲

  1. Recht / Gesetz / Verordnung / Vorschrift：法律权利上位概念 / 成文法律 / 授权制定规则 / 具体规定。

  2. Straftat / Ordnungswidrigkeit：可受刑罚的犯罪行为 / 通常处行政罚款的违法行为。

  3. Tat / Tatort：被调查的行为 / 行为发生地点。

  4. Polizei / Polizeidienststelle / Streife：警察机关 / 办公受理地点 / 巡逻警力。

  5. Strafanzeige / Anzeige / Anzeigenerstattung：刑事报案正式词 / 多义日常词 / 提交报案过程。

  6. Aussage / Vernehmung / Anhörung：陈述内容 / 刑事程序询问 / 决定前听取意见。

  7. Zeuge / Beschuldigter / Verdächtiger：证人 / 刑事程序针对的涉嫌者 / 受到怀疑者；Beschuldigter可在侦查阶段出现，不要求已提起公诉。

  8. Geschädigter / Opfer / Täter：权益受损者程序词 / 受害者援助词 / 行为实施者。

  9. Personalien / Identitätsfeststellung：身份基本信息 / 依法核验身份的措施。

  10. Durchsuchung / Beschlagnahme / Sicherstellung：搜查 / 强制扣押 / 为特定目的控制物品。

  11. Festnahme / Gewahrsam：刑事拘捕措施 / 警方暂时控制状态。

  12. Polizei / Staatsanwaltschaft / Gericht：调查执行 / 领导侦查起诉 / 审理裁判。

  13. Rechtsanwalt / Verteidiger / Rechtsberatung：律师总称 / 刑事辩护律师 / 专业法律建议。

  14. Beratungshilfe / Prozesskostenhilfe：法院外咨询帮助 / 诉讼费用帮助。

  15. Aussageverweigerungsrecht / Zeugnisverweigerungsrecht：被指控者拒绝陈述权 / 特定证人拒绝作证权。

易混辨析

  • Anzeige / Strafantrag：告知可能犯罪事实 / 对特定罪名要求追诉；不是所有案件都需要后者。
  • Beschuldigter / Täter：程序中被指控的人 / 已确认或叙述中的实施者，未判决前避免混用。
  • Vorladung / Urteil：要求到场的通知 / 法院裁判结果。
  • Rechtsmittel / Rechtsbehelf：主要指对法院裁判的法定审查程序 / 范围更广，也包括行政异议等。

语境回收

Nach einem Fahrraddiebstahl erstattet Nora bei der Onlinewache Strafanzeige. Sie nennt Tatort, Tatzeit und Aktenzeichen der Versicherung und lädt Fotos als Beweismittel hoch. Später erhält sie eine Vorladung als Zeugin. Sie prüft Absender und Termin und fragt bei Unsicherheit nach, welche Unterlagen sie zur Vernehmung mitbringen soll.

自行车被盗后，Nora 通过网上警局报案。她说明案发地点和时间，填写保险案件号并上传照片作为证据。后来她收到以证人身份到场的通知，于是核对发件方和时间，并询问做笔录时需要带哪些材料。

Nora上传的是自己掌握的事实与照片，后来以Zeugin身份收到通知。她核对发件方和材料，而没有把报案成功理解成案件已证实，或把所有来信都当成法院判决。

把词放回句子

Eine Straftat kann strafrechtlich verfolgt werden.（犯罪行为可受到刑事追究。）Die Polizeidienststelle nimmt eine Strafanzeige entgegen.（警局接收刑事报案。）Ein Zeuge oder eine Zeugin kann Wahrnehmungen zum Sachverhalt mitteilen.（证人可陈述与事实有关的见闻。）Strafanzeige是报告可能的犯罪，不等于法院已确认犯罪成立。

Ein Beschuldigter oder eine Beschuldigte ist die Person, gegen die sich das Strafverfahren richtet.（Beschuldigter或Beschuldigte是刑事程序针对的涉嫌者。）Das bedeutet noch nicht, dass Anklage erhoben oder Schuld festgestellt wurde.（这不表示已经提起公诉或认定有罪。）Die Polizei nimmt die Personalien auf.（警方记录身份信息。）程序身份与身份基本信息是两类信息，不能把Beschuldigter直接译成已正式起诉的人。

Die Staatsanwaltschaft leitet das Ermittlungsverfahren; ein Verteidiger oder eine Verteidigerin unterstützt die beschuldigte Person.（检察机关领导侦查，辩护律师帮助程序中的涉嫌者。）Nora kann einen Diebstahl anzeigen.（Nora可以报告盗窃。）Sie fragt, wie sie von einem Recht Gebrauch machen kann.（她询问如何行使某项权利。）von接第三格；具体权利须结合自己的程序身份，不能由另一人的通知推定。
