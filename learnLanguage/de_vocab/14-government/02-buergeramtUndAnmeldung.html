14-2 Bürgeramt 与登记（Bürgeramt und Anmeldung）

本组第 2 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 18 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

搬入德国的一套住房后，通常要在两周内向当地 Meldebehörde 办理 Anmeldung；搬到德国境内的新地址一般办理登记或 Ummeldung，离开德国且不再保留境内住所时才通常需要 Abmeldung。办理时常见材料包括身份证件和 Wohnungsgeberbestätigung。Bürgeramt 是许多城市的综合服务窗口，但名称和可办理事项因地区而异，应以所在地机关说明为准。

精讲

  1. Behörde / Bürgeramt / Meldebehörde：行政机关总称 / 综合居民服务机关 / 负责住址登记的机关。
  2. Einwohnermeldeamt / Melderegister：居民登记机关常用旧称 / 机关维护的登记信息系统。
  3. Wohnsitz / Wohnung：居住地法律或日常概念 / 实际居住空间。
  4. Hauptwohnung / Nebenwohnung / Zweitwohnung：主要住所 / 次要住所 / 第二住所日常或地方税务称呼。
  5. Anmeldung / Ummeldung / Abmeldung：迁入登记 / 境内地址变更 / 符合条件时迁出注销。
  6. Meldepflicht / Anmeldefrist：登记义务 / 完成登记的期限。
  7. Wohnungsgeberbestätigung：确认实际入住的规定文件；普通租赁合同不能自动替代它。
  8. Wohnungsgeber / Vermieter：实际提供住房并确认入住的一方 / 租赁合同出租方，可能不是同一主体。
  9. Einzug / Auszug：开始实际居住 / 结束实际居住。
  10. Einzugsdatum / Auszugsdatum：实际入住日期 / 实际迁出日期。
  11. Anschrift / Adressänderung：完整正式地址 / 地址发生变化。
  12. Terminbuchung / Wartenummer / Aufruf：预约过程 / 排队号码 / 被叫到窗口的通知。
  13. Sachbearbeiter / Vorsprache：经办人员 / 到机关现场办理说明。
  14. Gebühr / Gebührenbefreiung：行政服务收费 / 符合条件时免收。
  15. Online-Ausweisfunktion / PIN / AusweisApp：在线身份功能 / 识别码 / 配套应用。

易混辨析

  • Anmeldung / Antrag：申报住址登记 / 请求机关作出某项决定。
  • Abmeldung / Auszug：行政注销手续 / 实际搬离行为；搬出不总意味着必须单独注销。
  • Hauptwohnung / Nebenwohnung：依法确定的主要住所 / 其他住所，不只是个人随意命名。
  • Bürgeramt / Ausländerbehörde：居民综合事务窗口 / 负责外国人居留事务的机关。

语境回收

Nach dem Einzug bucht Amir beim Bürgeramt einen Termin zur Anmeldung. Er bringt seinen Reisepass und die Wohnungsgeberbestätigung mit. Am Eingang zieht er eine Wartenummer und wartet auf den Aufruf. Die Sachbearbeiterin trägt Einzugsdatum, Anschrift und Hauptwohnung ins Melderegister ein. Anschließend erhält Amir eine Meldebescheinigung.

Amir 搬入后预约去 Bürgeramt 办住址登记。他带上护照和住房提供者确认书，在入口取排队号等待叫号。经办人员把入住日期、地址和主要住所录入登记簿，随后他获得住址登记证明。

自测

  1. 负责住址登记的机关是 _______。 2. 主要住所是 _______。
  2. 境内地址变更手续是 _______。 4. 住房提供者入住确认文件是 _______。
  3. 实际搬入是 _______。 6. 完整正式地址是 _______。
  4. 现场排队号码是 _______。 8. 经办人员是 _______。
  5. 迁往国外办理注销用 _______。 10. 对某事有权限是 _______。
答案
  1. Meldebehörde 2. Hauptwohnung 3. Ummeldung 4. Wohnungsgeberbestätigung
  2. Einzug 6. Anschrift 7. Wartenummer 8. Sachbearbeiter / Sachbearbeiterin
  3. sich abmelden 10. zuständig
