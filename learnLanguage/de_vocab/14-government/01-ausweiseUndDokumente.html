14-1 证件与文件（Ausweise und Dokumente）

本组第 1 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 25 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

在德国办事时，Ausweis 是身份证明文件的总称，Personalausweis 和 Reisepass 则是具体证件。机关要求 Original、Kopie、beglaubigte Abschrift 时，三者不能互换；Beglaubigung 通常只确认副本或签名与所见材料相符，并不自动证明内容真实。提交前应核对证件是否 gültig、是否需要翻译，以及签发机关对格式的具体要求。

精讲

  1. Dokument / Unterlage：单份正式文件 / 某项手续所需材料的集合性说法。
  2. Ausweis / Personalausweis / Reisepass：身份证明总称 / 德国卡式身份证 / 护照。
  3. eID-Karte / Aufenthaltstitel：在线身份证明卡 / 证明特定居留权利的许可文件。
  4. Urkunde / Bescheinigung / Nachweis：正式证明书 / 书面确认 / 用来证明条件的材料。
  5. Geburtsurkunde / Eheurkunde / Sterbeurkunde：出生 / 婚姻 / 死亡登记证明。
  6. Führungszeugnis / Behördenführungszeugnis：交给本人或指定方的证明 / 按规定直接供机关使用的类型。
  7. Original / Kopie / Abschrift / Ausfertigung：原件 / 复制件 / 文字副本 / 正式交付版本。
  8. Beglaubigung / Beglaubigungsvermerk：认证程序 / 文件上的认证说明。
  9. Apostille / Übersetzung：公文来源的国际简化认证 / 语言转换文本。
  10. Übersetzer / Dolmetscher：主要处理书面语言 / 主要处理口头或手语。
  11. Unterschrift / Siegel / Stempel：个人签名 / 正式印章 / 一般处理印记。
  12. Passfoto / Lichtbild：日常证件照说法 / 法规表格常用正式词。
  13. Gültigkeitsdauer / Ablaufdatum / Ausstellungsdatum：有效期长度 / 失效日期 / 签发日期。
  14. Dokumentennummer / Aktenzeichen / Vorgangsnummer：文件编号 / 档案案件编号 / 办理流程编号。
  15. beglaubigen / beurkunden：确认副本或签名 / 以规定形式正式记录法律事实。

易混辨析

  • Personalausweis / Reisepass：德国国内常用身份证件 / 跨境旅行证件；是否可替代取决于具体手续。
  • beglaubigte Kopie / Original：经认证的复制件 / 原始正式文件，机关要求哪个就提交哪个。
  • Geburtsname / Familienname：出生登记姓氏 / 当前姓氏，两者可能相同也可能不同。
  • Übersetzung / Apostille：转换语言 / 认证公文来源，不解决同一个问题。

语境回收

Für einen Antrag braucht Leila ihre Geburtsurkunde, eine beglaubigte Kopie des Reisepasses und eine deutsche Übersetzung. Sie prüft zuerst, ob eine Apostille verlangt wird. Auf dem Formular trägt sie Dokumentennummer, Ausstellungsdatum und Geburtsnamen ein. Das Original nimmt sie zum Termin mit; die Kopien fügt sie den Unterlagen bei.

Leila 办申请需要出生证明、护照认证副本和德语翻译。她先确认是否需要海牙认证，然后在表格中填写文件编号、签发日期和出生姓氏。她预约时带原件，复印件则附在申请材料中。
