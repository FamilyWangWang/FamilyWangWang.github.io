14-3 居留与国籍（Aufenthalt und Staatsangehörigkeit）

本组第 3 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 17 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Visum 通常涉及入境前的许可，入境后的长期居留则要区分 Aufenthaltserlaubnis、Niederlassungserlaubnis、Blaue Karte EU 等不同 Aufenthaltstitel。居留目的、工作权限和附加条件会写在决定或电子居留证上。Einbürgerung 是取得德国国籍的程序，并不等同于获得永久居留。相关条件会随法律和个人情况变化，实际办理应以主管机关当时的书面说明为准。

精讲

  1. Ausländerbehörde / Auslandsvertretung：境内居留主管机关 / 德国设在国外的官方机构。
  2. Botschaft / Konsulat：使馆 / 领馆，具体服务范围和辖区应事先核对。
  3. Drittstaat / Unionsbürger / Freizügigkeit：非欧盟国家 / 欧盟成员国公民 / 欧盟法下自由迁移居留权。
  4. Visum / Einreisevisum：签证总称 / 为入境和特定目的签发的签证。
  5. Aufenthalt / Aufenthaltsrecht / Aufenthaltstitel：停留事实 / 居留法律地位 / 许可形式。
  6. Aufenthaltserlaubnis / Niederlassungserlaubnis：特定目的有期许可 / 无期限许可。
  7. Daueraufenthalt / Daueraufenthalt-EU：长期居留概念 / 欧盟规则下特定身份。
  8. Aufenthaltszweck / Erwerbstätigkeit / Beschäftigungserlaubnis：居留目的 / 工作上位概念 / 受雇工作权限。
  9. Nebenbestimmung / Gültigkeit / Verlängerung：附加条件 / 有效状态 / 延期。
  10. Erteilung / Ablehnung / Fiktionsbescheinigung：授予 / 拒绝 / 待决期间特定法律效果证明。
  11. Einreise / Ausreise / Wiedereinreise：入境 / 离境 / 再次入境。
  12. Familiennachzug / Ehegatte / Lebensunterhalt：家庭团聚 / 配偶正式称呼 / 基本生活费用。
  13. Einbürgerung / Staatsangehörigkeit / Mehrstaatigkeit：入籍程序 / 国籍关系 / 多重国籍状态。
  14. Einbürgerungstest / Loyalitätserklärung / Grundgesetz：知识测试 / 忠诚声明 / 德国宪法。
  15. Einbürgerungsurkunde / Staatsangehörigkeitsausweis：完成入籍的授予文件 / 专门确认德国国籍的证明。

易混辨析

  • Visum / Aufenthaltserlaubnis：常用于入境前许可 / 入境后特定目的的有期居留许可。
  • Aufenthaltserlaubnis / Niederlassungserlaubnis：通常有期限且绑定目的 / 无期限，但仍受法律规定约束。
  • Niederlassungserlaubnis / Einbürgerung：永久居留身份 / 取得德国国籍的程序。
  • Staatsangehörigkeit / Reisepass：国籍法律关系 / 证明身份和旅行资格的证件。
  • Mehrstaatigkeit：德国法允许入籍者保留原国籍，但原国籍国的法律可能规定不同后果。

语境回收

Mina reist mit einem Visum zum Studium ein und beantragt bei der Ausländerbehörde eine Aufenthaltserlaubnis. Vor dem Ablaufdatum prüft sie die Gültigkeit und beantragt rechtzeitig die Verlängerung. Später informiert sie sich über die Niederlassungserlaubnis. Die Behörde erklärt ihr, welche Sprachkenntnisse, Nachweise und Nebenbestimmungen in ihrem konkreten Fall gelten.

Mina 持学习签证入境，并向外国人管理局申请居留许可。到期前，她核对有效期并及时申请延期。后来她了解永久居留许可，主管机关向她说明其个案适用的语言能力、证明材料和附加条件。
