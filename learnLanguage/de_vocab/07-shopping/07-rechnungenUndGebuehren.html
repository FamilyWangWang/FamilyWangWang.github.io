07-7 账单与费用（Rechnungen und Gebühren）

本组第 7 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

收到 Rechnung 后先核对开票方、合同或订单、项目、金额和付款期限。Zahlungserinnerung 语气通常比 Mahnung 温和，但文件标题本身不决定法律效果；Fälligkeit、是否已进入 Verzug 以及费用依据要结合合同和具体情况判断。对陌生或错误款项应书面提出异议，而不是直接忽略。

精讲

  1. Rechnungsdatum / Leistungsdatum：开票日 / 商品交付或服务完成日。
  2. Rechnungsposition / Beschreibung：单独计费项目 / 对项目内容的说明。
  3. Einzelpreis / Gesamtbetrag：单个单位价格 / 所有部分相加总额。
  4. Zwischensumme / Rechnungsbetrag：计算过程中的小计 / 最终要求支付金额。
  5. Umsatzsteuer / Mehrwertsteuer：法律税种用语 / 日常常用称呼。
  6. Zahlungsziel / Zahlungsfrist：最后付款点或约定期间 / 可付款的时间窗口。
  7. Fälligkeit / Verzug：债权已可要求履行 / 满足条件后的迟延状态。
  8. Forderung / Rechnung：请求给付的权利 / 列出项目金额的单据。
  9. Gutschrift / Korrekturrechnung：记入有利方或减少应付 / 更正原账单。
  10. Abschlagsrechnung / Schlussrechnung：过程中先收部分 / 最终结算。
  11. Grundgebühr / Verbrauchskosten：固定部分 / 随实际用量变化的部分。
  12. Zahlungserinnerung / Mahnung：温和提醒用语 / 较正式催告；应看内容而非标题。
  13. Mahnung / Mahnbescheid：债权人催告 / 法院程序正式文书。
  14. beanstanden / widersprechen：指出具体错误 / 明确不接受某项要求。
  15. begleichen / stunden：付清 / 经债权人同意延期。

易混辨析

  • Versandkosten / Lieferkosten：寄运过程费用 / 配送到指定地点的费用。
  • Mahngebühr / Verzugszins：催告产生的成本项目 / 迟延期间的利息。
  • offen / strittig：尚未付款 / 是否应付或金额本身有争议。
  • Inkassoschreiben / Mahnbescheid：催收机构来信 / 法院正式文书，后者尤其不能搁置。

语境回收

Ela erhält eine Mahnung, obwohl sie den Rechnungsbetrag bereits überwiesen hat. Sie prüft Rechnungsnummer, Verwendungszweck und Buchungsdatum und entdeckt, dass eine Ziffer fehlte. Sie widerspricht der Forderung nicht pauschal, sondern sendet dem Rechnungsaussteller den Zahlungsbeleg und bittet um Zuordnung der Buchung. Die Mahngebühr beanstandet sie schriftlich und verlangt eine korrigierte Abrechnung.

Ela明明已经转账，却收到催款。她核对账单号、用途栏和记账日，发现少填了一位数字。她没有笼统否认债权，而是把付款凭证发给开票方，请对方匹配该笔入账；同时书面质疑催款费并要求更正结算。
