07-2 购物与订购（Einkaufen und Bestellen）

本组第 2 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 15 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

一次购物从列清单、找商品、比较到下单和收货，线上线下会用到不同词。店内的 kaufen 是完成购买，网购更常围绕 bestellen、Warenkorb、Lieferung 和 Sendungsverfolgung 展开；在付款前还要分清商品是否真的 verfügbar。

精讲

  1. Einkauf / Einkaufsliste：一次采购或买回的东西 / 事先列出的待买项目。
  2. Ware / Artikel / Produkt：买卖对象总称 / 系统中的单项 / 制造出来的产品。
  3. Marke / Modell：品牌来源 / 同品牌下的具体版本。
  4. Stück / Packung / Menge：单件 / 整包 / 不限定单位的数量。
  5. Verkäufer / Beratung：销售人员 / 其提供的选购建议过程。
  6. Auswahl / Qualität：可选范围 / 商品本身的品质水平。
  7. Warenkorb / Wunschliste：准备结算 / 暂时收藏。
  8. Bestellung / Bestellbestätigung：已提交的购买请求 / 商家确认已收到。
  9. Lieferzeit / Liefertermin：所需时长 / 具体日期。
  10. Lieferadresse / Rechnungsadresse：实际送达地址 / 付款方账单地址。
  11. Lieferung / Versand：一次送货或货物 / 寄运过程。
  12. Quittung / Kassenbon / Rechnung：收款证明 / 零售小票 / 列项付款单据。
  13. einkaufen / kaufen / besorgen：采购过程 / 完成购买 / 设法弄到所需物。
  14. erhältlich / verfügbar / lieferbar：某处有售 / 系统可用 / 能够发货。
  15. bestellen / vorbestellen：现在下单 / 到货或上市前预订。

易混辨析

  • auswählen / bestellen：先从选项中选定 / 再把购买请求正式交给商家。
  • abholen / annehmen：自己去取 / 在送达地点接收。
  • gebraucht / beschädigt：使用过不代表有缺陷 / 实际存在破损。
  • Bestellnummer / Artikelnummer：识别一笔订单 / 识别一种商品。

语境回收

Lukas vergleicht in mehreren Onlineshops ein Kopfhörermodell. Ein Angebot ist günstiger, aber nicht sofort lieferbar. Er wählt deshalb einen verfügbaren Artikel, legt ihn in den Warenkorb und prüft Liefer- und Rechnungsadresse. Nach dem Abschicken erhält er eine Bestellbestätigung. Zwei Tage später zeigt die Sendungsverfolgung, dass das Paket an der Abholstation liegt; den Kassenbon bewahrt er sicherheitshalber auf.

Lukas在几家网店比较同一款耳机。一个报价更便宜，但不能立即发货，所以他选择了有货商品，放入购物车并核对送货和账单地址。提交后他收到订单确认；两天后物流追踪显示包裹已到自提点，他为稳妥起见保留了购物凭证。

自测

  1. Eine Liste vor dem Einkaufen heißt _______. 2. Online legt man Artikel in den _______.
  2. Eine konkrete Ausführung eines Produkts heißt _______. 4. Die Nummer einer Bestellung ist die _______.
  3. Der Zeitraum bis zur Zustellung ist die _______. 6. Ein Paket kann man an einer Station _______.
  4. "Kann versendet werden" heißt _______. 8. Ein bereits benutzter Artikel ist _______.
  5. Nach dem Abschicken kommt die _______. 10. Für eine spätere Rückgabe bewahrt man den _______ auf.
答案
  1. Einkaufsliste 2. Warenkorb 3. Modell 4. Bestellnummer 5. Lieferzeit
  2. abholen 7. lieferbar 8. gebraucht 9. Bestellbestätigung 10. Kassenbon
