07-1 商店与部门（Geschäfte und Abteilungen）

本组第 1 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 9 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德国购物既有市中心的 Fachgeschäft，也有城郊的大型 Einkaufszentrum。同一商品在 Supermarkt、Discounter 和 Kaufhaus 的选择、服务与价格可能不同；找货时先说商品类别，再问具体 Abteilung 或楼层，通常比只说品牌更有效。

精讲

  1. Geschäft / Laden：中性通用店铺 / 更日常口语的商店。
  2. Kaufhaus / Einkaufszentrum：一家多部门百货 / 集合许多独立店铺的场所。
  3. Fachgeschäft：品类较窄，但通常提供更深入的专业咨询。
  4. Filiale / Kette：单个分店 / 经营多个分店的连锁体系。
  5. Supermarkt / Discounter：品类较完整 / 精简选择并突出低价。
  6. Wochenmarkt / Flohmarkt：定期生鲜市场 / 二手与旧物市场。
  7. Metzgerei / Fleischerei：同类肉店，地区用词不同。
  8. Drogerie / Apotheke：日化护理用品店 / 依法提供药品与药学咨询。
  9. Baumarkt / Gartencenter：装修工具材料为主 / 植物园艺为主。
  10. Abteilung / Etage：按商品划分的部门 / 建筑楼层。
  11. Information / Kundendienst：一般问询 / 售后和较复杂事务。
  12. Sortiment / Bestand：经营范围 / 当下实际库存。
  13. öffnen / geöffnet：开门的动作 / 当前营业状态。
  14. führen / anbieten：长期经销某类商品 / 提供某个商品或服务。
  15. vorrätig：表示商品当前确实在库存中，不等于每家分店都有。

易混辨析

  • Laden / Lager：面向顾客的店铺 / 存放库存的后台空间。
  • Erdgeschoss / erster Stock：临街底层 / 再上一层；中文楼层叫法易错位。
  • Auslage / Schaufenster：被陈列的商品 / 面向街道的玻璃展示窗。
  • geöffnet / offen：前者直接表示营业，后者还可泛指门窗或状态敞开。

语境回收

Mina sucht in einem Einkaufszentrum ein Fachgeschäft für Wanderschuhe. An der Information erfährt sie, dass es sich im ersten Stock gegenüber der Haushaltswarenabteilung befindet. Das gewünschte Modell steht nicht in der Auslage, ist aber laut Bestand noch im Lager vorrätig. Ein Mitarbeiter sieht nach und bringt ihre Größe. Danach geht Mina ins Erdgeschoss zur Kasse.

Mina在购物中心找一家登山鞋专卖店。问询台告诉她，店在二层、家居用品部对面。她想要的型号没有陈列出来，但库存系统显示库房还有。店员去查看并拿来她的尺码，之后Mina下到底层收银台。

自测

  1. Eine Niederlassung einer Kette heißt _______. 2. Ein Geschäft mit Fachberatung ist ein _______.
  2. Billige, eher kleine Sortimente findet man oft beim _______. 4. Die Etage auf Straßenhöhe heißt _______.
  3. Für Fragen geht man zur _______. 6. Noch vorhandene Ware ist _______.
  4. Die gesamte Warenauswahl heißt _______. 8. Ware hinter den Kulissen liegt im _______.
  5. Ein Markt für gebrauchte Sachen ist ein _______. 10. Sonntags kann ein Laden _______ sein.
答案
  1. Filiale 2. Fachgeschäft 3. Discounter 4. Erdgeschoss 5. Information
  2. vorrätig 7. Sortiment 8. Lager 9. Flohmarkt 10. geschlossen
