07-6 保险与合同（Versicherungen und Verträge）

本组第 6 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 4 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

签合同前至少要看清 Laufzeit、费用、保障或服务范围以及 Kündigungsfrist。Widerruf 通常让符合条件的合同从源头撤回，Kündigung 则让持续性合同在某个时间点结束，两者不能随意互换。保险还要区分投保人、保险公司、保障范围、自付额和免责条款。

精讲

  1. Vertrag / Vertragsbedingung / Klausel：整个协议 / 一项适用条件 / 文本中的具体条款。
  2. Laufzeit / Mindestlaufzeit：总持续时间 / 普通解除通常不能早于的期间。
  3. Vertragsbeginn / Vertragsabschluss：约定开始日期 / 双方形成合同的时点。
  4. Kündigungsfrist / Kündigungstermin：须提前多久 / 实际在哪天结束。
  5. Kündigung / Widerruf：向将来终止持续合同 / 在适用权利下撤回合同声明。
  6. Widerruf / Rücktritt：消费者撤回等特定权利 / 基于法定或约定原因解除。
  7. Vertragsnummer / Kundennummer：识别一份合同 / 识别整个客户关系。
  8. Beitrag / Prämie：持续性缴费总称 / 保险合同中的专业用语。
  9. Versicherer / Versicherungsnehmer：承担风险的公司 / 与其签约的人。
  10. Versicherungsschutz / Deckung：整体保障状态 / 对具体风险和范围的承保。
  11. Versicherungssumme / Selbstbeteiligung：保险方约定给付上限或金额 / 自付部分。
  12. Schadensfall / Schadenmeldung：事故本身 / 向保险方提交的报告。
  13. Ausschluss / Obliegenheit：不保的情形 / 被保险方应遵守的行为要求。
  14. abschließen / verlängern / kündigen：建立 / 延续 / 终止合同关系。
  15. wirksam / verbindlich：法律上有效 / 内容对一方有约束力。

易混辨析

  • Police / Vertrag：保险合同证明文件 / 双方完整法律关系。
  • Haftpflicht / Hausrat：对第三人的法定赔偿责任 / 自家动产的约定风险。
  • ordentlich / außerordentlich kündigen：按正常期限 / 因特别理由提前解除。
  • Beitragserhöhung / Tarifwechsel：保费上涨 / 换到另一套价格保障条件。

语境回收

Noah prüft seine Versicherungspolice. Der Beitrag steigt, doch Versicherungssumme und Deckung ändern sich nicht. Er vergleicht andere Tarife, liest Ausschlüsse und Selbstbeteiligung und fragt nach dem Kündigungstermin. Seine Kündigung sendet er fristgerecht unter Angabe der Vertragsnummer und bittet um eine Bestätigung. Den alten Schutz beendet er erst, nachdem der neue Versicherer den Vertragsbeginn bestätigt hat.

Noah查看保险单。保费上涨了，但保险金额和保障范围没有变化。他比较其他方案，阅读免责和自付额，并询问可解除日期。他在期限内注明合同号发出解除通知并要求确认；直到新保险公司确认保障开始日后，他才结束旧保障。

自测

  1. Die Dauer eines Vertrags heißt _______. 2. Die Frist vor Vertragsende ist die _______.
  2. Eine Erklärung zur Vertragsrückabwicklung heißt _______. 4. Die Firma, die das Risiko trägt, ist der _______.
  3. Eigener Anteil im Schadensfall heißt _______. 6. Nicht gedeckte Fälle sind _______.
  4. Einen Vertrag beginnt man durch _______. 8. Einen Schaden muss man _______.
  5. Für einen Schaden muss man unter Umständen _______. 10. Eine gültige Kündigung ist _______.
答案
  1. Laufzeit 2. Kündigungsfrist 3. Widerruf 4. Versicherer 5. Selbstbeteiligung
  2. Ausschlüsse 7. abschließen 8. melden 9. haften 10. wirksam
