07-8 退换货与投诉（Rückgabe und Reklamation）

本组第 8 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

商品"不喜欢""买错"和"有缺陷"对应的依据不同。实体店对无瑕疵商品的 Umtausch 往往取决于商家自愿规则；适用远程交易撤回权时走 Widerruf；商品存在 Mangel 时则先围绕法定 Nacherfüllung 与卖家沟通。厂家 Garantie 是额外承诺，不能与法定瑕疵责任混为一谈。

精讲

  1. Rückgabe / Rücksendung：交还商品总过程 / 通过物流寄回。
  2. Retoure / Rücksendung：电商物流用语 / 中性通用说法。
  3. Umtausch / Widerruf：换货安排 / 在适用权利下撤回合同。
  4. Reklamation / Beschwerde：针对具体问题要求处理 / 表达对服务体验不满。
  5. Mangel / Defekt / Beschädigung：不符要求的瑕疵 / 功能失灵 / 外力破损。
  6. Abnutzung / Mangel：正常使用损耗 / 商品不符合应有状态。
  7. Falschlieferung / Minderlieferung：送错品类 / 数量少于订单。
  8. Widerrufsrecht / Widerrufsbelehrung：撤回权本身 / 商家必须提供的相关说明。
  9. Rücksendeetikett / Retourenschein：贴在外部的物流标签 / 放入或填写的退货单。
  10. Versandnachweis / Einlieferungsbeleg：寄出证明总称 / 承运网点具体收件凭证。
  11. Erstattung / Rückzahlung：费用返还概念 / 实际把钱退回。
  12. Nacherfüllung / Nachbesserung：法定补救总称 / 其中的修理路径。
  13. Ersatzlieferung / Ersatzgerät：交付替换商品 / 临时或永久替代设备。
  14. Gewährleistung / Garantie：卖家的法定瑕疵责任 / 额外自愿承诺。
  15. Kaufnachweis / Originalverpackung：证明购买关系 / 原厂包装；二者功能不同。

易混辨析

  • Verkäufer / Hersteller：法定瑕疵请求通常先找卖家 / 厂家可能是保证承诺方。
  • Geld zurück / Gutschein：退回价款 / 只能再次消费的凭证。
  • mangelhaft / nicht gefallen：存在客观瑕疵 / 单纯主观不喜欢。
  • Frist / Garantiezeit：某一步必须完成的期限 / 保证承诺覆盖期间。

Der Händler sendet ein Rücksendeetikett und bietet eine Ersatzlieferung an. Rita legt den Retourenschein bei, bewahrt den Einlieferungsbeleg auf und erhält nach Eingang der Retoure ein mangelfreies Ersatzgerät.

Rita网购的电热水壶有明显破损。她拍下包装和瑕疵，向卖家报修并注明订单号和投诉编号。商家发送退货标签并提出替换交付；Rita附上退货单、保留寄件凭证，商家收到退件后给她寄来无瑕疵替代设备。
