07-4 支付方式（Zahlungsarten）

本组第 4 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 14 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

付款失败时，先读提示，再区分卡种、技术与限额。本篇让“用什么付”和“这一次有没有获批”各自清楚。

付款时先确认商家接受哪些 Zahlungsarten。girocard属于Debitkarte；Debitkarte是较宽的借记卡类别，不能与girocard排成互斥类型。Kreditkarte的结算方式和可用额度又需看发卡条件，各支付体系的接受范围也可能不同。刷卡失败也不一定是余额不足，可能是终端、限额、网络或卡片状态造成，最好先看屏幕提示再换方式。

精讲

  1. Zahlung / Zahlungsmittel / Zahlungsart：一笔付款 / 使用的工具 / 付款方式类别。

  2. Bargeld / Münze / Banknote：现金总称 / 硬币 / 正式说法的纸币。

  3. Schein / Kleingeld / Wechselgeld：一张纸币 / 小面额硬币 / 应找回的钱。

  4. Girocard / Debitkarte：德国支付体系品牌 / 账户快速扣款的卡类别。

  5. Debitkarte / Kreditkarte：通常即时或很快扣账户 / 按账期或额度结算。

  6. PIN / Geheimzahl：正式缩写 / 日常解释性同义词。

  7. Kartenlesegerät / Terminal：读卡硬件 / 完成整个交易授权的设备。

  8. Rechnungskauf / Vorkasse：收货后付款 / 发货前付款。

  9. Ratenzahlung / Teilzahlung：按计划分期 / 泛指只付一部分。

  10. Anzahlung / Restbetrag：先付的一部分 / 之后仍欠的余额。

  11. Quittung / Zahlungsbeleg：收款方开具证明 / 更宽泛的付款证据。

  12. bezahlen / zahlen：常带被付清的对象 / 也常直接带金额。

  13. abbuchen / belasten：从账户扣款 / 把交易记到卡或账户。

  14. abgelehnt / ungültig：本次交易未批准 / 卡本身已不有效。

  15. kontaktlos / bargeldlos：一种无接触技术 / 所有不使用现金的方式。

易混辨析

  • Kassenbon / Quittung / Rechnung：零售小票 / 收款证明 / 列项付款要求。
  • Kartenlimit / Tageslimit：单卡或交易限制 / 当天累计限制。
  • zurückzahlen / Wechselgeld geben：退回原付款 / 现金交易中正常找零。
  • fällig / bezahlt：已到付款期 / 已完成付款。

语境回收

An der Kasse möchte Sam kontaktlos mit seiner Debitkarte bezahlen. Das Terminal zeigt jedoch eine Fehlermeldung und lehnt die Zahlung ab. Er steckt die Karte ein, gibt die PIN ein und versucht es erneut. Weil sein Tageslimit erreicht ist, bezahlt er schließlich bar. Die Kassiererin gibt ihm Wechselgeld und auf Wunsch eine Quittung.

Sam在收银台想用借记卡非接触付款，但终端显示错误并拒绝交易。他插卡、输入密码再试一次；由于当天限额已用完，最后改付现金。收银员找零，并按他的要求开了收款证明。

Sam先非接触，再插卡输入PIN，但达到Tageslimit使第二种读取方式也不能改变限额。他最后付现金，Wechselgeld是找零，Quittung则是已收款的证明。

把词放回句子

Münzen und Scheine zusammen heißen Bargeld.（硬币与纸币统称现金。）Wechselgeld bekommt man beim Barzahlen zurück.（现金付款时找回的是Wechselgeld。）Eine Debitkarte belastet gewöhnlich zeitnah das Konto.（借记卡通常较快记扣账户。）girocard也属于Debitkarte，不是互斥的另一类。

Der Zahlen-Code heißt PIN.（数字识别码叫PIN。）Beim kontaktlosen Bezahlen wird die Karte nicht eingesteckt.（非接触刷卡不用插卡。）Die Bank kann eine Zahlung ablehnen.（银行可以拒绝付款。）Das Tageslimit ist die tägliche Obergrenze.（Tageslimit是当日上限。）改变读取方式不等于改变额度。

Zahlung vor dem Versand heißt Vorkasse.（发货前付款叫预付款。）Ein erster Teilbetrag ist eine Anzahlung.（先付一部分叫Anzahlung。）Gebührenfrei heißt ohne die betreffende Gebühr.（gebührenfrei说不收相应手续费。）要看“免”的是哪项，不能由此推断整个商品或所有服务都免费。
