07-3 价格与折扣（Preise und Rabatte）

本组第 3 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 6 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

看价格不能只看醒目的红色数字：德国商品标签常同时标 Verkaufspreis 和按公斤、升等计算的 Grundpreis。Rabatt 是一般折扣，Ermäßigung 多与身份或条件有关，Skonto 则是按约定提前付款获得的扣减；比较时还要确认税费、押金和运费是否包含在最终价格里。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. Preis / Grundpreis：应付金额 / 按统一计量单位换算的比较价。
  2. Gesamtpreis / Endpreis：各项目之和 / 含所有必付项目的最终金额。
  3. Normalpreis / Originalpreis：平时售价 / 本次降价前被对照的旧价。
  4. Rabatt / Preisnachlass：折扣概念 / 具体减去的金额或让价。
  5. Rabatt / Skonto：一般优惠 / 按约定及时付款才获得的扣减。
  6. Rabatt / Ermäßigung：促销或客户优惠 / 年龄、身份等条件优惠。
  7. Sonderangebot / Aktionspreis：优惠商品或方案 / 活动期间的具体价格。
  8. Schnäppchen / billig：主观上买得划算 / 只强调价格低并可能贬质。
  9. Ausverkauf / Räumungsverkauf：清库存 / 因场地或停业而清空。
  10. Gutschein / Rabattcode：抵扣凭证 / 触发特定优惠的字符代码。
  11. Nettopreis / Bruttopreis：未含税 / 已含税。
  12. Pfand：暂时收取，返还合格包装或物品后可退。
  13. kosten / betragen：日常问商品价格 / 正式说明金额和比例。
  14. reduzieren / senken：把单一价格降低 / 也可描述总体价格水平下降。
  15. günstig / preiswert：便宜或条件有利 / 强调价格与价值匹配。

易混辨析

  • inklusive / exklusive：已经包括 / 尚未包括，报价中方向相反。
  • reduziert / rabattiert：已降价 / 因规则或身份享受折扣。
  • Stückpreis / Grundpreis：每件价格 / 法定或统一计量单位价格。
  • Listenpreis / Endpreis：基准价目价格 / 顾客最终必须支付的价格。

语境回收

Lea vergleicht zwei Packungen Kaffee. Die größere Packung kostet insgesamt mehr, hat aber den niedrigeren Grundpreis. Mit der Kundenkarte gilt zusätzlich ein Aktionspreis; einen Rabattcode kann sie jedoch nicht gleichzeitig einlösen. Auf dem Preisschild steht, dass der Bruttopreis die Mehrwertsteuer enthält. So spart Lea vier Euro und findet das Angebot preiswert.

Lea比较两包咖啡。大包装总价更高，但单位价格更低；会员卡还能享受活动价，不过不能同时使用优惠码。价格牌说明含增值税的总价已包含税款。这样Lea省下四欧元，觉得这项优惠很划算。

自测

  1. Der Preis pro Kilogramm heißt _______. 2. Der Preis einschließlich Steuer ist der _______.
  2. Eine Vergünstigung für Studierende heißt _______. 4. Abzug für schnelle Zahlung heißt _______.
  3. Einen Gutscheincode kann man _______. 6. Eine besonders günstige Ware ist ein _______.
  4. Geld für eine Mehrwegflasche heißt _______. 8. "Ohne Versand" heißt _______ Versand.
  5. Der Händler kann den Preis _______. 10. Preis und Qualität zusammen ergeben das _______.
答案
  1. Grundpreis 2. Bruttopreis 3. Ermäßigung 4. Skonto 5. einlösen
  2. Schnäppchen 7. Pfand 8. exklusive 9. senken 10. Preis-Leistungs-Verhältnis
