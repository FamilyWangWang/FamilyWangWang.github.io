07-5 银行与账户（Bank und Konto）

本组第 5 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 5 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

在德国处理日常收支，核心是 Girokonto：工资转入、房租转出、账单扣款通常都围绕它进行。Überweisung 是付款人主动发起，Lastschrift 是收款人凭授权扣款；遇到陌生交易时，应先核对 Verwendungszweck、收款方和记账日期，再联系银行。

精讲

  1. Bankinstitut / Bankfiliale：金融机构 / 某地实体网点。
  2. Filialbank / Direktbank：以实体网点服务 / 主要远程服务。
  3. Konto / Girokonto：账户总称 / 用于日常收支的往来账户。
  4. Tagesgeldkonto / Sparkonto：可灵活转入转出的储蓄账户 / 储蓄账户总称。
  5. Kontoinhaber / Kunde：法律登记持有人 / 使用银行服务的人。
  6. IBAN / BIC：识别账户 / 识别银行；多数日常欧元区转账以 IBAN 为核心。
  7. Kontostand / Guthaben：账面余额 / 可用的正余额。
  8. Dispokredit / Kreditrahmen：活期透支额度 / 更宽泛的信用上限。
  9. Habenzins / Sollzins：银行付给客户 / 客户付给银行。
  10. Kontoauszug / Kontobewegung：一段时间的正式记录 / 其中一笔进出。
  11. Buchungsdatum / Zahlungseingang：银行入账日 / 款项进入账户。
  12. Überweisung / Lastschrift：付款人主动发起 / 收款人凭授权发起。
  13. Dauerauftrag / Lastschrift：固定金额定期转账 / 金额可由账单变化的扣款。
  14. einzahlen / abheben：把钱存入 / 从账户取出。
  15. sperren / kündigen：暂停使用以防风险 / 正式终止合同。

易混辨析

  • Kontonummer / IBAN：传统国内号码 / 标准化国际账户号码。
  • gutschreiben / überweisen：把金额记入某账户 / 主动发出转账指令。
  • gedeckt / Guthaben：足够完成当前交易的状态 / 账户正余额。
  • Buchung / Rechnung：账户中的资金记录 / 商家要求付款的单据。

语境回收

Mara prüft ihren Kontoauszug und entdeckt eine unberechtigte Lastschrift. Im Verwendungszweck findet sie keine bekannte Vertragsnummer. Sie sperrt nicht sofort das ganze Girokonto, sondern meldet die Buchung ihrer Bank und lässt die Lastschrift zurückgeben. Danach kontrolliert sie Daueraufträge, verfügbares Guthaben und Kontostand und ändert vorsorglich ihren Onlinezugang.

Mara查看银行对账单，发现一笔未经授权的自动扣款。用途栏里没有熟悉的合同号。她没有立即冻结整个活期账户，而是向银行报告这笔交易并申请退回扣款；随后检查定期转账、可用余额和账户余额，并预防性修改网银登录设置。
