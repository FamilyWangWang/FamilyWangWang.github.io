场景导入

洗衣前先看 Pflegeetikett，再按颜色、材质和温度分类。Waschprogramm 决定滚筒运动和时长，Waschtemperatur 决定水温，Schleuderzahl 决定脱水转速。污渍最好先 vorbehandeln，洗涤剂则要按水质、衣量和说明 dosieren。

精讲

  1. Wäsche / Schmutzwäsche：处于任何洗护阶段的衣物总称 / 明确指脏衣物。
  2. Buntwäsche / Weißwäsche：有色衣物 / 白色衣物。
  3. Feinwäsche / Wollwäsche：精细织物类别 / 羊毛类别。
  4. Waschprogramm / Waschgang：预设方式 / 一次实际运行过程。
  5. Waschtemperatur / Schleuderzahl：水温 / 脱水转速。
  6. Vollwaschmittel / Colorwaschmittel：白色耐洗衣物用 / 有色衣物用。
  7. Waschpulver / Flüssigwaschmittel：粉末形态 / 液体形态。
  8. Wäschekorb / Wäschetonne：搬运篮 / 长期收集脏衣容器。
  9. beladen / überladen：正常装入 / 装得超过合适容量。
  10. dosieren：用量要结合衣量、污渍程度和水硬度。
  11. schleudern / auswringen：机器旋转脱水 / 手动扭挤水分。
  12. eingehen / einlaufen：表示衣物缩水时基本同义。
  13. verfärben / abfärben：自身或其他衣物变色 / 染料转移出去。
  14. flicken / stopfen：一般补洞 / 用密集线迹补袜子等。
  15. waschbar / trocknergeeignet：可以水洗 / 可以机器烘干，是两个独立条件。

易混辨析

  • Spülung / Schleudergang：用清水去洗涤剂的漂洗 / 高速转动脱水。
  • Wäscheständer / Wäscheleine：可移动晾衣架 / 固定或拉设的晾衣绳。
  • Fleckenentferner / Waschmittel：局部污渍处理品 / 整体洗涤剂。
  • Verfärbung / Verblassen：颜色意外改变 / 颜色逐渐变淡。

语境回收

Vor dem Waschen sortiert Eva die Wäsche nach Farbe und Material. Sie liest die Pflegeetiketten, leert alle Taschen und behandelt Flecken vor. Für die Buntwäsche dosiert sie Colorwaschmittel nach der Wasserhärte. Empfindliche Teile kommen ins Wäschenetz. Nach dem Waschgang schüttelt sie die Hemden aus und hängt sie möglichst glatt auf.

洗衣前Eva按颜色和材质分类，阅读护理标签、掏空口袋并预处理污渍。彩色衣物按水硬度计量彩色洗衣剂，精细衣物放进洗衣网袋。洗完后她抖开衬衫，尽量平整地挂起。
