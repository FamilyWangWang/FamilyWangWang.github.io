05-4 厨房设备（Küchengeräte）

本组第 4 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

住宅中的厨房既包括固定安装的 Spüle、Arbeitsplatte 和 Hängeschränke，也包括可移动的电器。看房和报修时，最重要的是分清 Herd、Kochfeld、Backofen，并能说明设备是 eingebaut 还是 freistehend。

精讲

  1. Einbauküche / Küchenzeile：固定安装的整套厨房 / 沿一面墙排列的一排设备。
  2. Arbeitsplatte / Arbeitsfläche：实体台面 / 其中实际可操作的面积。
  3. Spüle / Spülbecken：水槽安装单元 / 其中盛水的槽体。
  4. Herd / Kochfeld / Backofen：传统组合灶具 / 顶部加热平面 / 封闭烘烤设备。
  5. Kühlschrank / Gefrierschrank / Gefrierfach：冷藏柜 / 独立冷冻柜 / 冰箱内冷冻格。
  6. Geschirrspüler / Spüle：机器洗餐具 / 手洗水槽。
  7. Mixer / Pürierstab：容器式搅拌机 / 手持搅拌棒。
  8. Mülleimer / Biomülleimer：一般垃圾桶 / 厨余垃圾桶。
  9. Alufolie / Frischhaltefolie / Backpapier：铝箔 / 保鲜膜 / 烘焙纸。
  10. anschließen an + A：Die Maschine wird an den Wasseranschluss angeschlossen.
  11. einschalten / ausschalten：启动 / 关闭设备，前缀均可分。
  12. vorheizen：烤箱到达温度后才开始计算某些食谱的烘烤时间。
  13. abtauen：及物时用 haben；食物自行解冻常用 sein。
  14. eingebaut / freistehend：嵌入橱柜 / 独立摆放。
  15. spülmaschinenfest：说明可以机洗，不等于适用于微波炉或烤箱。

易混辨析

  • Küchenschrank / Schrankfach：整个厨房柜 / 柜内一个格层。
  • Waage / Messbecher：测重量 / 测液体体积。
  • Dosenöffner / Flaschenöffner：开罐头 / 开瓶盖。
  • Steckdose / Anschluss：普通电源插座 / 也可能是水、燃气等专用接驳点。

语境回收

In der neuen Einbauküche ist der Backofen auf Augenhöhe eingebaut, während das Kochfeld in der Arbeitsplatte sitzt. Neben der Spüle gibt es einen Anschluss für den Geschirrspüler. Kleine Geräte wie Wasserkocher, Toaster und Kaffeemaschine stehen auf einer zusätzlichen Abstellfläche. Unter den Hängeschränken sorgt eine helle Beleuchtung für gute Sicht.

新的整体厨房里，烤箱嵌在视线高度，灶面装在操作台中。水槽旁有洗碗机接口。烧水壶、烤面包机和咖啡机等小电器放在额外台面上。吊柜下的明亮照明保证良好视野。

自测

  1. Das Wasser läuft aus dem _______. 2. Der Backofen muss auf 180 Grad _______ werden.
  2. Teller kommen in den _______. 4. Tiefkühlkost liegt im _______.
  3. Der Herd ist noch an; bitte _______ ihn aus. 6. Für Käse benutze ich eine _______.
  4. Das Gerät wird an eine Steckdose _______. 8. Ein Backofen im Schrank ist _______.
  5. Die Unterseite des Hängeschranks braucht eine gute _______. 10. Kalk entfernt man, indem man das Gerät _______.
答案
  1. Wasserhahn 2. vorgeheizt 3. Geschirrspüler 4. Gefrierfach
  2. schalte 6. Reibe 7. angeschlossen 8. eingebaut
  3. Beleuchtung 10. entkalkt
