05-9 维修与故障（Reparaturen und Defekte）

精讲

  1. Defekt / Störung：部件或设备损坏 / 正常运行受到干扰。
  2. Schaden / Mangel：实际损害 / 未达到约定或应有状态。
  3. Verschleiß / Bruch：逐渐磨损 / 突然或明确断裂。
  4. Leck / Verstopfung：产生泄漏的破口 / 通道堵塞。
  5. Garantie / Gewährleistung：额外自愿承诺 / 法定瑕疵责任；具体适用应看当前规则。
  6. Reparatur / Wartung / Inspektion：修复 / 预防性维护 / 状态检查。
  7. kaputtgehen / ausfallen：物品损坏 / 功能或服务停止。
  8. ausfallen / aussetzen：完全停止 / 间歇停止。
  9. klemmen / quietschen：机械卡住 / 发出摩擦尖声。
  10. tropfen / lecken：一滴滴漏 / 系统存在泄漏。
  11. platzen / reißen / brechen：爆裂 / 撕裂断开 / 折断。
  12. reparieren / austauschen：修好现有部件 / 换成新部件。
  13. melden / beauftragen：报告问题 / 正式委托工作。
  14. beheben / diagnostizieren：排除问题 / 确定问题原因。
  15. Kostenvoranschlag / Rechnung：事前估算 / 工作完成后的收费文件。

易混辨析

  • Fehlermeldung / Fehlercode：完整错误提示 / 用于识别类型的短代码。
  • Handwerker / Hausverwaltung：实施技术工作的人 / 协调管理建筑的机构。
  • Notdienst / Reparaturtermin：紧急服务 / 可等待的预约维修。
  • Geräusch / Geruch：声音线索 / 气味线索。

语境回收

Seit gestern fällt die Heizung immer wieder aus und zeigt den Fehlercode E04. Nora fotografiert die Anzeige und meldet die Störung der Hausverwaltung schriftlich. Ein Handwerker diagnostiziert eine defekte Pumpe und erstellt einen Kostenvoranschlag. Weil kein akuter Wasserschaden besteht, wird ein regulärer Reparaturtermin für den nächsten Morgen vereinbart.

从昨天起暖气反复停机并显示E04。Nora拍下显示屏，书面向物业报告故障。维修人员诊断为水泵损坏并出具费用估算。因为没有紧急水损，双方约定第二天上午正常维修。

自测

  4. Der Fehlercode sollte _______ werden. 8. Eine Firma wird mit der Reparatur _______.
