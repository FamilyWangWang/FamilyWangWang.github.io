05-5 卫浴（Bad und Sanitär）

本组第 5 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 1 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

卫浴空间同时涉及日常用品和给排水设施。报修时不要只说"坏了"，而要指出 Wasserhahn tropft、Ablauf ist verstopft、Dichtung ist undicht 或 Spülkasten läuft nach。高湿环境还要及时处理 Kondenswasser 和 Schimmel。

精讲

  1. Badewanne / Dusche：浸泡洗浴设备 / 站立或坐着淋浴的设备。
  2. Dusche / Duschkabine：淋浴设备整体 / 围住淋浴区的隔间。
  3. Waschbecken / Spüle：卫浴洗手盆 / 厨房水槽。
  4. Armatur / Mischbatterie：水龙头组件总称 / 混合冷热水的具体装置。
  5. Stöpsel / Siphon：封住排水口的塞子 / 防异味回流的弯管。
  6. Handtuch / Badetuch / Waschlappen：普通毛巾 / 大浴巾 / 小洗脸巾。
  7. Fliese / Fuge：瓷砖本体 / 瓷砖之间的缝。
  8. Kalk / Schimmel：硬水矿物沉积 / 潮湿环境中的霉菌。
  9. feucht / nass：含少量水分或潮湿 / 表面有明显水。
  10. Ablauf / Überlauf：正常排水口 / 防止水位过高的备用开口。
  11. ablaufen：完成时用 sein：Das Wasser ist vollständig abgelaufen.
  12. verstopfen：既可说原因堵住管道，也可说管道变堵。
  13. abdichten / Dichtung：实施密封的动作 / 承担密封作用的部件。
  14. lüften / Lüftung：开窗换气的动作 / 换气系统或过程。
  15. barrierefrei：比"无障碍淋浴"更广，还涉及门宽、活动空间和扶手等。

易混辨析

  • Toilettensitz / Toilettendeckel：坐的环形部件 / 上方盖板。
  • Spülkasten / Toilettenspülung：储水箱 / 冲水装置或动作。
  • Rohr / Leitung：一段实体管 / 完整输送线路。
  • Lüftung / Abluft：换气系统或过程 / 被排出室外的空气。

语境回收

Nach dem Duschen bleibt viel Kondenswasser an den Fliesen. Amir wischt es ab und lüftet kurz und kräftig. Heute bemerkt er außerdem, dass der Wasserhahn tropft und das Wasser im Waschbecken nur langsam abläuft. Er reinigt den Ablauf; für die undichte Armatur meldet er dem Vermieter eine Reparatur.

淋浴后瓷砖上留下很多冷凝水。Amir把水擦掉并短时充分通风。今天他还发现水龙头滴水，洗手盆排水很慢。他清理排水口，并把漏水的龙头报给房东维修。
