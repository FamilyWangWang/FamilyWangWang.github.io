05-3 家具（Möbel）

本组第 3 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

家具名称不仅用于购物，也用于描述搬家和布置空间。德语通过复合词清楚区分用途：Esstisch、Schreibtisch、Couchtisch，以及 Stehlampe、Tischlampe、Deckenleuchte。摆放时要分清 stellen、legen 和 hängen。

精讲

  1. Möbel / Möbelstück：家具通常整体用复数 / 一件具体家具。
  2. Einrichtung / Möbel：空间整体布置 / 其中的家具。
  3. Tisch / Schreibtisch / Couchtisch：桌子总称 / 工作桌 / 沙发前矮桌。
  4. Stuhl / Sessel / Hocker：有靠背座椅 / 带扶手软椅 / 无靠背凳子。
  5. Sofa / Couch：日常基本同义，Sofa 略中性。
  6. Matratze / Lattenrost：直接承托身体的床垫 / 床垫下的条板床架。
  7. Kopfkissen / Kissen：睡眠枕头 / 坐靠或装饰软垫的宽泛说法。
  8. Schrank / Regal：通常有门的柜子 / 开放层架。
  9. Kommode / Sideboard：抽屉矮柜 / 横向更宽的低柜。
  10. Vorhang / Rollo：布帘横向拉合 / 卷帘上下收放。
  11. einrichten / möblieren：完成整体布置 / 较正式地配置家具。
  12. stellen / legen：把可直立物放置 / 把物品平放。
  13. hängen：静态常用 hat gehangen；使某物挂起常用 hat gehängt。
  14. aufbauen / montieren：组装整件家具 / 安装并固定部件。
  15. beziehen：在 das Bett beziehen 中表示套上床单和被套。

易混辨析

  • Bettdecke / Decke：专指睡觉盖的被子 / 也可指毯子或天花板。
  • Lampe / Leuchte：日常都可说灯；Leuchte 更强调完整灯具。
  • Garderobe / Kleiderschrank：入口挂外套处 / 房间内存放衣物的大柜。
  • Bezug / Bettwäsche：单件可拆外套 / 床单、枕套、被套的总称。

语境回收

Wir richten das kleine Gästezimmer platzsparend ein. Das ausziehbare Sofa stellen wir an die lange Wand; daneben kommt ein schmaler Beistelltisch mit Tischlampe. Über dem Sofa montieren wir ein Regal. Ein klappbarer Schreibtisch beansprucht nur wenig Platz. Helle Vorhänge und ein kleiner Teppich machen den Raum trotzdem bequem und freundlich.

我们以节省空间的方式布置小客房。可展开沙发放在长墙边，旁边放一张带台灯的窄边桌。沙发上方安装搁板。折叠书桌占地很少。浅色窗帘和小地毯仍让房间舒适宜人。

自测

  1. Ein einzelner Gegenstand heißt ein _______. 2. Unter der Matratze liegt der _______.
  2. Bücher stehen in einem _______. 4. Den Tisch _______ wir ans Fenster.
  3. Das Kissen _______ ich aufs Sofa. 6. Ein Sitz ohne Rückenlehne ist ein _______.
  4. Ein Sofa, das zum Bett werden kann, ist _______. 8. Das Bild hängt _______ der Wand.
  5. Wir müssen den Schrank noch _______. 10. Vor dem Schlafen beziehe ich das _______ frisch.
答案
  1. Möbelstück 2. Lattenrost 3. Bücherregal 4. stellen 5. lege
  2. Hocker 7. ausziehbar 8. an 9. aufbauen 10. Bett
