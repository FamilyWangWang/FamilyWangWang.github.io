05-2 房间与空间（Zimmer und Bereiche）

本组第 2 篇 · 共 10 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 4 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

介绍住宅布局时，德语会区分有明确用途的 Zimmer 和更宽泛的 Raum。连接各房间的是 Flur、Diele、Treppe 和 Durchgang；储藏空间则可能是 Abstellraum、Speisekammer、Kellerabteil 或墙体中的 Nische。

精讲

  1. Raum / Zimmer：空间的宽泛概念 / 通常可居住且有明确边界的房间。
  2. Wohnzimmer / Wohnbereich：独立起居室 / 开放户型中的起居区域。
  3. Flur / Diele：连接房间的走廊 / 入口附近较宽的门厅。
  4. Badezimmer / Toilette：带洗浴设施的房间 / 便器或独立厕所间。
  5. Abstellraum / Speisekammer：杂物储藏间 / 食品储藏空间。
  6. Kellerraum / Kellerabteil：完整地下房间 / 分配给住户的小隔间。
  7. Dachboden / Dachkammer：屋顶下空间整体 / 屋顶下的一间小房。
  8. Decke / Zimmerdecke：毯子或天花板 / 明确指房间天花板。
  9. Treppe / Stufe：整组楼梯 / 其中一级台阶。
  10. Stockwerk / Raumhöhe：建筑楼层 / 单个空间的净高度。
  11. Wohnfläche / Nutzfläche：按规则计入居住的面积 / 其他功能面积。
  12. eintreten / hineingehen：较正式地进入 / 日常走进去。
  13. hinauf / hinunter：向上 / 向下，都是说话人视角下的方向。
  14. angrenzen an + A：Das Arbeitszimmer grenzt an das Wohnzimmer.
  15. Stauraum schaffen：可以靠壁柜、床下空间和墙面搁板实现。

易混辨析

  • Eingang / Eingangsbereich：进入点或门口 / 门口周围整个功能区域。
  • Galerie / Empore：住宅中开放上层 / 一般建筑里高于主空间的平台。
  • Wand / Mauer：房间或建筑的墙面 / 较厚、独立或承重的墙体。
  • Ecke / Nische：两个边界相交处 / 向内凹入的局部空间。

语境回收

Vom Eingangsbereich führt ein schmaler Flur in den offenen Wohn- und Essbereich. Die Küche grenzt direkt daran an. Eine Treppe führt hinauf zur Galerie, die als Arbeitsbereich genutzt wird. Unter der Treppe schafft eine tiefe Nische zusätzlichen Stauraum. Das fensterlose Kellerabteil liegt eine Etage tiefer und ist nur über das Treppenhaus erreichbar.

从入口区域，一条狭窄走廊通向开放式起居和用餐区，厨房与其直接相邻。楼梯向上通往作为工作区的挑空平台。楼梯下的深壁龛增加了收纳空间。无窗的地下储藏隔间在下一层，只能经楼梯间到达。

自测

  1. Ein Raum zum Schlafen ist das _______. 2. Lebensmittel lagern wir in der _______.
  2. Die Küche grenzt _______ das Esszimmer. 4. Eine einzelne Einheit der Treppe heißt _______.
  3. Im _______ wäscht man häufig die Wäsche. 6. Ein Raum ohne Fenster ist _______.
  4. Wir gehen die Treppe _______ in den Keller. 8. Die Fläche für Lagerung zählt oft zur _______.
  5. Bilder hängen an der _______. 10. Unter der Treppe schaffen wir zusätzlichen _______.
答案
  1. Schlafzimmer 2. Speisekammer 3. an 4. Stufe 5. Waschküche
  2. fensterlos 7. hinunter 8. Nutzfläche 9. Wand 10. Stauraum
