18-3 数字与运算（Zahlen und Rechnen）

本组第 3 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语算式会说 drei plus fünf ist acht，正式说明结果也常用 ergibt。要分清 Zahl、Ziffer 和 Nummer：数是抽象数量，数字是书写符号，号码主要用于识别。小数用 Komma 读出，百分数用 Prozent。

精讲

  1. Zahl / Ziffer / Nummer：抽象数值、单个书写符号、识别号码。
  2. Null / Eins / Stellenwert：零、一和数字所在位置的值。
  3. Komma / Dezimalstelle：小数分隔符 / 小数位置。
  4. Pluszeichen / Minuszeichen / Gleichheitszeichen：加号、减号、等号。
  5. Addition / Summe：加法过程 / 加法结果。
  6. Subtraktion / Differenz：减法过程 / 相减结果。
  7. Multiplikation / Faktor：乘法过程 / 参与相乘的每一个数。
  8. Division / Quotient / Rest：除法、商和余数。
  9. Zähler / Nenner / Dezimalbruch：分子、分母、可写成小数的十进分数。
  10. Prozent / Prozentsatz / Anteil：百分单位、百分比值、部分占比。
  11. Verhältnis / Prozentsatz / Anteil：两个量的比、具体百分比、部分占比。
  12. Durchschnitt / Mittelwert：日常平均水平 / 按方法计算的平均数。
  13. Minimum / Maximum：最小值 / 最大值。
  14. Hälfte / Drittel / Viertel：二分之一、三分之一、四分之一。
  15. Rechenweg / Formel / Klammer：运算步骤、数量关系式、优先计算范围符号。

易混辨析

  • Zahl / Ziffer：数可以有多位 / 数字只是零至九的单个符号。
  • Nummer / Zahl：号码用于识别，不一定表示数量 / 数表示数学值。
  • Prozent / Prozentsatz：百分之一的单位 / 具体百分比数值。
  • Durchschnitt / Mittelwert：日常概括平均 / 数学上按特定方法计算。
  • Ergebnis / Lösung：计算所得值 / 满足问题要求的完整答案。
  • schätzen / runden：根据有限信息估计 / 从精确值改成指定精度。

语境回收

Für die Auswertung addiert Noor zuerst alle Werte und dividiert die Summe durch die Zahl der Messungen. So erhält sie den Mittelwert. Danach rundet sie das Ergebnis auf zwei Dezimalstellen. Ein negativer Wert wird getrennt geprüft. Schließlich berechnet sie den Prozentsatz und vergleicht ihn mit dem Maximum aus dem Vorjahr.

Noor 先把所有数值相加，再用总和除以测量次数，得到平均值。随后她把结果四舍五入到小数点后两位，单独检查负值，最后计算百分比并与去年的最大值比较。

自测

  1. 书写数所用的单个符号是 _______。 2. 加法所得结果是 _______。
  2. 除法所得结果是 _______。 4. 分数线上方的数是 _______。
  3. 一组数中的最小值是 _______。 6. 某数量的三倍是 _______。
  4. 把数相加用 _______。 8. 除以另一个数用 _______。
  5. 改成指定精度近似值用 _______。 10. 能被二整除是 _______。
答案
  1. Ziffer 2. Summe 3. Quotient 4. Zähler
  2. Minimum 6. Dreifache 7. addieren 8. dividieren
  3. runden 10. gerade
