本组第 5 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 17 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述物体时，可以先说二维或三维 Form，再说明 Position 和相对方向：in der Mitte、am Rand、parallel zur Wand。liegen、stehen、hängen 不仅表示地点，也反映物体是平放、有支撑直立，还是悬挂。

精讲

  1. Form / Körper：外形或构造总称 / 三维物体。
  2. Kreisbogen / Kreislinie / Schnittpunkt：圆周的一段、完整圆周、线的交点。
  3. Kreis / Halbkreis / Oval / Ellipse：圆、半圆、椭圆状轮廓、数学椭圆。
  4. Dreieck / Viereck / Vieleck：三边、四边和多边图形。
  5. Quadrat / Rechteck / Raute / Trapez：四类常见四边形。
  6. Würfel / Quader：六个正方形面 / 六个矩形面。
  7. Kugel / Zylinder / Kegel / Pyramide：球、圆柱、圆锥、棱锥。
  8. Kante / Innenwinkel / Außenwinkel：两面交线、多边形内角、延长线形成的外角。
  9. Mittelpunkt / Zentrum / Scheitelpunkt：精确中心点、中心区域、角或曲线顶点。
  10. Inneres / Äußeres / Zwischenraum：内部、外部外观、两物之间的空隙。
  11. Ort / Stelle / Koordinate：可识别地点、范围中的小位置、坐标数值。
  12. Umgebung / Symmetrie / Symmetrieachse：周边区域、对称性质、对称轴。
  13. Oberseite / Unterseite / Innenseite / Außenseite：上、下、内、外表面。
  14. Reihe / Spalte / Achse / Quadrant：行、列、轴线、坐标平面分区。
  15. liegen / stehen / grenzen / umgeben：平放、直立、接壤、环绕。

易混辨析

  • Form / Figur：外形或构造总称 / 可识别的具体几何图形。
  • Kreis / Kugel：二维圆 / 三维球体。
  • Quadrat / Rechteck：四边等长且四角为直角 / 只要求四个直角。
  • Ecke / Kante：边或面相交的角部 / 两个面相交形成的线。
  • Mittelpunkt / Mitte：数学上精确的中心点 / 中央区域。
  • Position / Lage：具体位置 / 相对环境的方位或状态。

语境回收

Auf der Zeichnung liegt ein Rechteck in der Mitte. Links davon steht ein Kreis, rechts ein Dreieck. Zwei waagerechte Linien verlaufen parallel zum unteren Rand. In der oberen rechten Ecke markiert ein Punkt die Position der Achse. Die Rückseite des späteren Körpers bleibt glatt, während an der Vorderseite mehrere Kanten sichtbar sind.

图纸中央是一个长方形，左侧是圆，右侧是三角形。两条水平线与下边缘平行，右上角的点标出轴线位置。之后制成立体时，背面保持平整，正面则可看到多条棱边。
