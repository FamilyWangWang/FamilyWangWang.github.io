18-4 度量衡与单位（Maße und Einheiten）

本组第 4 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 25 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述测量结果时，数字和单位之间通常留空格，如 5 km、20 °C。Gewicht 是日常高频说法，物理语境则区分 Masse 和重量力。Kilowatt 表示功率，Kilowattstunde 表示能量，不能互换。

精讲

  1. Maß / Maßeinheit / Messwert / Messgröße：尺寸或尺度、单位、所得数值、待测物理量。
  2. Länge / Breite / Höhe / Tiefe：长、宽、高、深。
  3. metrisch / exakt / präzise / maßstabsgetreu：公制、数值恰好、低误差、按比例。
  4. Umfang / Fläche / Volumen：周长、面积、体积。
  5. Masse / Genauigkeit / Toleranz：物理质量、接近参考值的程度、允许偏差范围。
  6. Geschwindigkeit / Druck：单位时间内移动距离 / 单位面积上的作用力。
  7. Messbereich / Messskala / Messfehler：可测范围、读取刻度、测量偏差。
  8. Meter / Millimeter / Kilometer / Nanometer：四种不同尺度的长度单位。
  9. Kubikmeter / Hektar / Kubikzentimeter：体积、土地面积和小体积单位。
  10. Liter / Milliliter：升 / 毫升。
  11. Gramm / Milligramm / Mikrogramm / Tonne：克、毫克、微克、吨。
  12. Watt / Kilowatt / Kilowattstunde：功率单位、千瓦、能量单位。
  13. Volt / Ampere / Bar：电压、电流、压力单位。
  14. Dutzend / Stückzahl：十二个组成的一组 / 单件物品总数量。
  15. Kalibrierung / Anzeigeauflösung：与参考值比较的过程 / 显示可区分的最小步进。

易混辨析

  • Maß / Messwert：尺寸或衡量尺度 / 一次测量得出的具体值。
  • Entfernung / Strecke：两点相隔多远 / 实际走过或规划的路线长度。
  • Gewicht / Masse：日常常混用；精确物理语境中并非同一物理量。
  • Leistung / Energie：能量转换的速率 / 能够做功的量。
  • Kilowatt / Kilowattstunde：功率 / 能量，不能互换。
  • exakt / präzise：值恰好一致 / 测量方法细致且误差小。

语境回收

Für den Schrank misst Lena zuerst Länge, Breite und Höhe mit einem Maßband. Die Breite beträgt exakt achtzig Zentimeter. Danach liest sie das Gewicht der Teile auf einer Waage ab und rechnet Gramm in Kilogramm um. In der Anleitung stehen außerdem die elektrische Leistung in Watt und der jährliche Verbrauch in Kilowattstunden.

Lena 先用卷尺测量柜子的长、宽、高，宽度正好八十厘米。随后她从秤上读取部件重量，把克换算成千克。说明书还列出了以瓦表示的功率和以千瓦时表示的年度能耗。

自测

  1. 一次测量所得并带单位的数值是 _______。 2. 围绕边界一周的长度是 _______。
  2. 三维空间大小是 _______。 4. 一米的千分之一是 _______。
  3. 一米乘一米的面积单位是 _______。 6. 功率一千瓦持续一小时的能量是 _______。
  4. 测定质量用 _______。 8. 换算到另一单位用 _______。
  5. 从显示屏读取数值用 _______。 10. 按统一比例制作是 _______。
答案
  1. Messwert 2. Umfang 3. Volumen 4. Millimeter
  2. Quadratmeter 6. Kilowattstunde 7. wiegen 8. umrechnen
  3. ablesen 10. maßstabsgetreu
