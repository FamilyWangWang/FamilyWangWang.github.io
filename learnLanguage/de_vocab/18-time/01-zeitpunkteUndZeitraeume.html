18-1 时间点与时段（Zeitpunkte und Zeiträume）

本组第 1 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 9 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语用 Zeitpunkt 表示时间轴上的一点，用 Zeitraum 或 Zeitspanne 表示一段时间，用 Dauer 说明持续多久。约会和办事还要区分 Termin、Frist 与 Uhrzeit：前者是约定事项，中间词是最晚期限，后者只是钟表时间。

精讲

  1. Zeit / Zeitpunkt：时间总概念或可支配时间 / 时间轴上的一点。
  2. Moment / Augenblick：都指很短的时刻，前者口语更高频。
  3. Gegenwart / Vergangenheit / Zukunft：现在、过去、未来三种时间范围。
  4. Beginn / Anfang：正式开始时点 / 最初阶段或起点。
  5. Ende / Dauer：结束界点 / 从开始到结束的长度。
  6. Zeitraum / Zeitspanne：被界定的时段 / 强调两点之间的长度。
  7. Stichtag / Ablauffrist / Geltungsdauer：判断所用指定日期、到期前期限、保持有效的时长。
  8. Uhrzeit / Stunde：具体几点几分 / 六十分钟或钟点。
  9. Morgen / Vormittag / Mittag：早晨、上午、正午前后。
  10. Nachmittag / Abend / Nacht：下午、傍晚至晚间、夜间。
  11. Mitternacht / Morgengrauen / Tagesanbruch：午夜、破晓时段、天亮时刻。
  12. Wochentag / Werktag / Feiertag：星期中的一天、工作日概念、法定或传统节日。
  13. Woche / Monat / Quartal / Halbjahr：七天、约四周、三个月、六个月。
  14. Jahr / Jahrzehnt / Jahrhundert：一年、十年、一百年。
  15. früh / spät / rechtzeitig：时间靠前、靠后、在需要前来得及。

易混辨析

  • Zeitpunkt / Zeitraum：一个时间点 / 有起止范围的一段时间。
  • Dauer / Frist：某事实际或计划持续多久 / 最迟何时必须完成。
  • Termin / Uhrzeit：包含事项和约定的时间 / 单纯钟表时间。
  • Beginn / Anfang：偏正式的开始时点 / 也可指事物最初部分。
  • Morgen / Vormittag：一天较早的时段 / 早晨之后到中午之前。
  • pünktlich / rechtzeitig：正好按约定时间 / 提前到仍来得及。

语境回收

Der Kurs beginnt am Montag und dauert ein Halbjahr. Die genaue Uhrzeit steht noch nicht fest, aber der erste Termin soll am Vormittag stattfinden. Die Anmeldung muss rechtzeitig vor Beginn erfolgen, denn die Frist endet am Freitag um Mitternacht. Im Laufe des Schuljahres gibt es zwei ganztägige Workshops. Gegen Ende des Kurses vereinbart die Gruppe einen weiteren Zeitpunkt für die Abschlussfeier.

课程星期一开始，持续半年。具体时间尚未确定，但第一次课计划安排在上午。报名必须在开课前及时完成，因为截止期限是星期五午夜。整个学年中有两次全天工作坊，临近课程结束时，小组还会为结业活动另约时间。

自测

  1. 时间轴上明确的一点是 _______。 2. 从开始到结束的长度是 _______。
  2. 必须在结束前完成事项的期限是 _______。 4. 预先约定的办事时间是 _______。
  3. 中午之后到傍晚之前是 _______。 6. 日期交替的夜间十二点是 _______。
  4. 连续三个月是 _______。 8. 连续十年是 _______。
  5. 时间流逝用 _______。 10. 在需要前留有足够时间是 _______。
答案
  1. Zeitpunkt 2. Dauer 3. Frist 4. Termin
  2. Nachmittag 6. Mitternacht 7. Quartal 8. Jahrzehnt
  3. vergehen 10. rechtzeitig
