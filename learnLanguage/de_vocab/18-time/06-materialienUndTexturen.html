18-6 材料与质地（Materialien und Texturen）

本组第 6 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 17 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述商品、建筑或手工作品时，先说它 aus 什么材料制成，再说表面和触感：aus Edelstahl bestehen、sich rau anfühlen。Material 是最宽泛的日常词，Werkstoff 强调加工时利用其性能的材料，Rohstoff 则是进一步生产加工的原料。

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. Werkstoff / Naturstoff / Verbundstoff：技术加工材料、天然材料、复合材料。
  2. Struktur / Beschaffenheit / Porosität：组织方式、综合性质、孔隙程度。
  3. Metall / Stahl / Edelstahl / Eisen：金属总类、钢、不锈或高品质钢类、铁。
  4. Aluminium / Kupfer / Messing / Bronze：四种常见金属或合金。
  5. Keramik / Porzellan / Silikon：陶瓷类别、精细瓷器、含硅聚合物材料。
  6. Kunststoff / Gummi / Silikon：塑料、橡胶类材料、硅氧聚合物材料。
  7. Faser / Gewebe / Folie：单根纤维、交织结构、薄膜。
  8. Leder / Baumwolle / Leinen / Seide：皮革、棉、亚麻布、丝绸。
  9. Leinen / Seide / Filz：亚麻布、丝绸、毡。
  10. Beton / Zement / Ziegel：混凝土、水泥、砖。
  11. Lehm / Sand / Kies / Marmor：混合黏土、砂、砾石、大理石。
  12. Marmor / Kork / Schaumstoff：大理石、软木、泡沫材料。
  13. Folie / Beschichtung / Lack：薄膜、覆盖层、漆膜材料。
  14. Faser / Gewebe：单根纤维 / 交织形成的织物结构。
  15. rau / hart / elastisch：粗糙、坚硬、有弹性。

易混辨析

  • Material / Werkstoff：一般制作材料 / 工程制造中按性能选用的材料。
  • Stahl / Eisen：以铁为主的合金 / 化学元素和日常铁质材料。
  • Keramik / Porzellan：烧制无机非金属材料总类 / 其中致密精细的一类。
  • Kunststoff / Gummi：聚合物材料总称 / 日常强调弹性的橡胶类材料。
  • Beton / Zement：硬化后的混合建材 / 其中起胶结作用的粉料。
  • Struktur / Textur：内部或整体组织 / 表面视觉和触觉细节。

语境回收

Die Arbeitsplatte besteht aus Granit und fühlt sich glatt und hart an. Der Rahmen ist aus nichtrostendem Stahl; seine Passivschicht verbessert die Korrosionsbeständigkeit. Eine dünne Beschichtung schützt die Oberfläche zusätzlich. Für die Schubladen verwendet der Hersteller Holz, Filz und elastischen Kunststoff. Zerbrechliche Teile aus Glas werden getrennt verpackt.

台面由花岗岩制成，摸起来光滑坚硬。框架使用耐腐蚀钢，其钝化层可提高耐蚀性，表面另有薄涂层保护。抽屉使用木材、毡和弹性塑料，易碎玻璃部件则单独包装。

自测

  1. 制造中按性能选用的材料是 _______。 2. 表面视觉触觉细节是 _______。
  2. 以铁为主并含碳的合金是 _______。 4. 铜和锌为主的合金是 _______。
  3. 精细致密的陶瓷是 _______。 6. 混凝土中的粉状胶凝材料是 _______。
  4. 纤维交织形成的结构是 _______。 8. 由某材料组成用 _______。
  5. 摸起来有某种触感用 _______。 10. 受力后能恢复原状是 _______。
答案
  1. Werkstoff 2. Textur 3. Stahl 4. Messing
  2. Porzellan 6. Zement 7. Gewebe 8. bestehen
  3. sich anfühlen 10. elastisch
