18-2 频率与顺序（Häufigkeit und Reihenfolge）

本组第 2 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述习惯时，德语用 immer、oft、manchmal、selten、nie 表示从高到低的频率；说明流程则常用 zuerst、danach、anschließend 和 schließlich。regelmäßig 强调按稳定节奏重复，häufig 只说明次数多，不保证间隔均匀。

精讲

  1. Häufigkeit / Frequenz：一般出现次数 / 偏技术的单位时间重复次数。
  2. Regelmäßigkeit / Wiederholungsrate / Taktung：稳定重复、单位时间重复率、预定时间节奏。
  3. Reihenfolge / Abfolge / Ablaufreihenfolge：排列次序、连续过程、流程执行顺序。
  4. Intervall / Abstand：规定或测量的间隔 / 一般时间或空间距离。
  5. Turnus / Zyklus：规定周期 / 完整循环。
  6. Zwischenschritt / Endphase：通向结果的中间步骤 / 临近完成的阶段。
  7. Rangfolge / Priorität：全部项目的排序 / 某项优先程度。
  8. Auftakt / Fortsetzung / Abschluss：开端、继续部分、收尾。
  9. Routine / Bearbeitungsfolge：熟练固定流程 / 多项工作的处理次序。
  10. immer / ständig / häufig / oft：总是、不断、频繁、经常。
  11. gelegentlich / manchmal / selten / nie：偶尔、有时、很少、从不。
  12. gewöhnlich / normalerweise / meistens：按通常习惯、正常情况下、大多数时候。
  13. zuerst / zunächst / vorher：首先、暂先、此前。
  14. danach / anschließend / inzwischen：之后、紧接着、此期间或如今。
  15. schließlich / zuletzt：经过过程最终 / 排在最后或最近一次。

易混辨析

  • häufig / regelmäßig：次数多 / 间隔或模式稳定。
  • immer / ständig：每次都或始终 / 持续不断，常带主观强调。
  • gelegentlich / selten：偶尔会发生 / 发生次数很少。
  • zuerst / vorher：流程中的第一步 / 相对于某事件更早。
  • danach / anschließend：之后 / 紧接着且偏正式。
  • schließlich / zuletzt：经过发展后最终 / 顺序最后或最近一次。

语境回收

Die Geräte werden in regelmäßigen Abständen kontrolliert. Zuerst prüft die Technikerin die Sicherheit, danach reinigt sie die beweglichen Teile. Anschließend dokumentiert sie jeden Schritt. Normalerweise dauert die Kontrolle eine Stunde; gelegentlich muss sie eine Reparatur nachholen. Zum Schluss legt sie die Reihenfolge für den nächsten Termin fest.

设备会按固定间隔检查。技术人员先检查安全性，之后清洁活动部件，再记录每一步。检查通常持续一小时，偶尔还要补做维修。最后，她确定下次预约的操作顺序。

自测

  1. 一定时间内出现次数的多少是 _______。 2. 多个项目的先后次序是 _______。
  2. 按规定间隔循环的周期是 _______。 4. 处理顺序上的优先程度是 _______。
  3. 补做错过事项用 _______。 6. 次数多但不强调规律是 _______。
  4. 按稳定模式重复是 _______。 8. 在所有步骤前首先是 _______。
  5. 紧接前一事件之后是 _______。 10. 经过若干步骤最终是 _______。
答案
  1. Häufigkeit 2. Reihenfolge 3. Turnus 4. Priorität
  2. nachholen 6. häufig 7. regelmäßig 8. zuerst
  3. anschließend 10. schließlich
