20-7 vor- 可分动词（Trennbare Verben mit vor-）

本组第 7 篇 · 共 10 篇 | 本篇 50 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 15 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

构词导入

vor- 常表示"在前面"：时间上提前（vorbestellen）、空间上向前（vortreten）、在别人面前展示（vorführen）或把范例放在前面让人照做（vormachen）。主句说 Sie schlägt eine Lösung vor.，完成时说 Sie hat eine Lösung vorgeschlagen.。

精讲

  1. 提出展示：vorschlagen / vorführen / vormachen / vortragen：提议、演示、示范、陈述。
  2. 发生存在：vorkommen / vorliegen / vorherrschen：发生或存在、资料已具备、状态占主导。
  3. 行动程序：vorgehen / vorladen / vorschreiben：按方式处理、正式传唤、规定必须做法。
  4. 预先安排：vorsehen / vormerken / vorbestimmen / vorprogrammieren：计划预留、暂记、预先决定、预设程序。
  5. 提前资源：vorfinanzieren / vorsorgen / vorstrecken：预先垫资、为未来准备、替人垫款。
  6. 发现证明：vorfinden / vorweisen：到场时发现既有状态 / 正式出示资格成果。
  7. 空间向前：vorfahren / vordringen / vorrücken / vortreten：驶到前方、深入、推进、走到前面。
  8. 设备工序：vormontieren / vorschalten / vorsortieren / vorwärmen：预装、前置接入、预分类、预热。
  9. 榜样假象：vorleben / vortäuschen / vorgaukeln：以行为示范 / 制造假象 / 让人误信。
  10. 话语时间：vorgreifen / vorwegnehmen / vorformulieren：提前涉及后文、先说出结果、预拟措辞。
  11. 试探抢先：vorfühlen / vorpreschen：谨慎试探 / 未协调便抢先行动。
  12. vorgeben / vorschieben：规定框架或佯称 / 拿理由作借口。
  13. vorenthalten / vorsetzen：不给应得内容 / 把食物任务摆到某人面前。
  14. vorkochen / vorverlegen / vorhersagen：提前做饭、提前日期、预测未来。
  15. 时间方向：vor- 常指先于主事件完成准备，但 vorkommen、vorliegen 已形成独立高频义。

易混辨析

  • vorschlagen / vorbringen：提出供考虑的方案 / 在正式讨论中陈述理由意见。
  • vorlegen / vorweisen：提交材料供处理 / 出示可证明身份资格的材料。
  • vormachen / vortäuschen：示范做法，也可骗某人 / 明确制造假象。
  • vorsehen / planen：在方案中预留安排 / 统筹未来步骤资源。
  • vorwarnen / warnen：提前警告 / 一般警告，不强调时间领先。
  • vorverlegen / verschieben：明确移到更早时间 / 改期，方向可早可晚。
