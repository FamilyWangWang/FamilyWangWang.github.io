20-1 an- 可分动词（Trennbare Verben mit an-）

本组第 1 篇 · 共 10 篇 | 本篇 50 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 15 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

构词导入

可分前缀 an- 常带三类空间图像：朝某个目标靠近（ankommen）、与表面接触或连接（anbringen、anschließen）、让过程开始或设备进入工作状态（anfangen、anmachen）。陈述句中前缀移到句末：Der Kurs fängt morgen an.；不定式加 zu 时写在前缀和词干之间：anzufangen。但意义不能只靠前缀猜，仍须连同支配和搭配一起学。

精讲

  1. 空间图像：anreisen / anliefern / anwachsen：为活动抵达、把货物送达、数量向某水平增长。
  2. 接触图像：anfassen / anbringen / anheften / sich anlehnen：触碰、固定、附上、靠住。
  3. 启动图像：anfangen / anmachen / anschalten / anschieben：开始活动、打开设备、接通设备、推动启动。
  4. 沟通图像：anlächeln / anhören / andeuten / anspielen：面向某人微笑、听取、透露线索、暗指。
  5. anfordern / anliefern：正式请求对方提供 / 把货物运送到指定地点。
  6. anstellen / anschaffen / anfertigen：雇用、为长期使用购置、按要求制作。
  7. anpassen / angehen / anbringen：调整到适合、着手处理、固定物体或提出意见。
  8. anweisen / anordnen：向具体人员下达指示 / 有权者正式命令措施。
  9. anregen / anspornen / antreiben：提出推动、激励努力、持续驱动。
  10. anfallen / andauern / anwachsen：产生或到期、持续存在、逐渐增长。
  11. anfechten / anklagen / anlasten：质疑法律效力、正式起诉、归责于某人。
  12. anbahnen / anknüpfen / angliedern：促成开端、接续已有内容、并入更大单位。
  13. andeuten / anspielen / anschneiden：给出线索、暗指旧事、简短提出话题。
  14. sich etwas aneignen / sich anstrengen：把知识技能学到手 / 集中力量努力。
  15. 可分规则：主句 fängt ... an，完成时 hat angefangen，带 zu 的不定式 anzufangen。

易混辨析

  • ankommen / anreisen：一般到达 / 强调为入住、会议或活动从外地抵达。
  • anmachen / anschalten：日常「打开」 / 明确接通开关；两者在设备语境常可互换。
  • anfordern / anfragen：请求寄送具体资料或物品 / 询问是否有空位、能力或可能性。
  • anordnen / anweisen：有权者命令措施 / 指示具体人员执行任务。
  • anbringen / anhängen：把物体固定在表面 / 把文件附在邮件或对象之后。
  • andeuten / anspielen：只透露一部分 / 通过暗示指向已知的人或事件。
