20-6 nach- 可分动词（Trennbare Verben mit nach-）

本组第 6 篇 · 共 10 篇 | 本篇 50 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 15 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

构词导入

nach- 常表示"在之后补做"（nachbestellen、nachzahlen）、"沿着原样重复"（nachmachen、nachzeichnen）或"追在后面查清"（nachfragen、nachforschen）。主句说 Ich frage noch einmal nach.，完成时说 Ich habe nachgefragt.。有些词保留"跟在后面移动"的空间义，如 nachlaufen、nachrücken。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. 核实信息：nachsehen / nachschauen / nachlesen / nachhören：查看、口语查看、从文字核实、通过再问核实。
  2. 复核数值：nachprüfen / nachmessen / nachrechnen / nachzählen：再检查、测量、计算、计数。
  3. 调查追踪：nachforschen / nachgehen / nachspüren：调查事实、追查线索、细致追寻痕迹感受。
  4. 模仿复现：nachmachen / nachahmen / nachspielen / nachsprechen：照做、模仿特征、重演、跟读。
  5. 补充采购：nachbestellen / nachkaufen / nachliefern / nachsenden：追加订购、再买、补送、随后转寄。
  6. 补充内容：nachgießen / nachschenken / nachwürzen：添液体、添饮料、再调味。
  7. 技术修正：nachjustieren / nachsteuern / nachrüsten / nachlackieren：微调、追加控制、补装、补漆。
  8. 再次加工：nachbehandeln / nachschneiden / nachschulen：后续处理、修剪、补充培训。
  9. 人际跟进：nachfassen / nachfordern / nachverhandeln：再次催问、正式追要、重新谈条款。
  10. 履行跟随：nachkommen / nachlaufen / nachziehen / nachrücken：履行或随后到、跟跑、随后迁居、递补。
  11. 学习表达：nacherzählen / nachempfinden / nachzeichnen：复述、体会、重构轨迹。
  12. 持续余效：nachklingen / nachsagen：留下余韵 / 传说某人具有某特征。
  13. 制造复制：nachbauen / nachdrucken：仿造结构 / 再版印刷。
  14. 帮助与榜样：nachhelfen / nacheifern：额外干预帮助结果 / 努力向榜样看齐。
  15. 助动词：跟随移动或递补常用 sein（ist nachgerückt），及物补做通常用 haben。

易混辨析

  • nachsehen / nachschauen：中性查看，也可表示宽容 / 更口语的查看核实。
  • nachfragen / nachhaken：一般继续询问 / 对不充分回答紧追不放。
  • nachweisen / belegen：用材料证明事实成立 / 提供支持资料或占用表面。
  • nachmachen / nachahmen：照着动作做 / 模仿人物或自然过程的特征。
  • nachfüllen / nachgießen：把容器补充到需要水平 / 再倒入液体。
  • nachbessern / ausbessern：对整体结果补做改进 / 修补局部损坏。

语境回收

Bei der Endkontrolle misst das Team alle Teile nach und rechnet die Materialmenge nach. Fehlende Schrauben werden nachbestellt und später nachgeliefert. Ein Techniker justiert die Sensoren nach, während die Verwaltung fehlende Nachweise nachfordert. Danach zeichnet der Bericht den Ablauf genau nach und zeigt, an welchen Stellen künftig früher nachgesteuert werden muss.

最终检查时，团队重新测量所有部件并复核材料用量。缺少的螺丝会追加订购并随后补送；技术人员微调传感器，行政人员则追要缺失证明。之后报告准确重构整个过程，并指出今后应在哪些环节更早追加调控。

自测

  2. 调查某事的原因用 _______。 4. 按原故事主要内容复述用 _______。
  3. 首次交付后补送缺件用 _______。 6. 给旧设备补装功能用 _______。
  4. 首次联系无结果后再次催问用 _______。 8. 排在后面的人递补空位用 _______。

  2. nachliefern 6. nachrüsten 7. nachfassen 8. nachrücken
