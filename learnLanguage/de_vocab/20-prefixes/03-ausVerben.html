20-3 aus- 可分动词（Trennbare Verben mit aus-）

本组第 3 篇 · 共 10 篇 | 本篇 50 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 15 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

构词导入

aus- 常表示从内部向外或离开原处（aussteigen、auswandern），也可表示做到结束或把资源用完（ausschlafen、ausschöpfen），以及从一组中挑出、排除（auswählen、aussortieren）。主句说 Der Zug fällt aus.，完成时是 Der Zug ist ausgefallen.；以 -ieren 结尾的 ausprobieren 虽然可分，完成分词仍没有额外的 ge-。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

精讲

  1. 离开图像：auswandern / austreten / ausbrechen：移居国外、退出组织、逃出或突然爆发。
  2. 向外动作：ausladen / ausliefern / auswerfen：卸下、交付、抛出。
  3. 完成图像：ausschlafen / ausdiskutieren / ausschöpfen：睡够、讨论充分、利用到上限。
  4. 资源边界：ausreichen / auskommen / ausgeben：足够、靠现有条件应付、花费或发放。
  5. 扩大图像：ausbauen / ausdehnen / ausweiten / sich ausbreiten：扩建发展、延展范围、扩大活动、自然扩散。
  6. 思考表达：sich ausdenken / ausarbeiten / auslegen：想出、细化、解释。
  7. 交付动作：aushändigen / ausrichten / ausrüsten：递交、转告或举办、配备。
  8. 清理选择：ausmisten / aussortieren / ausgrenzen：清除无用物、挑出不合格项、排斥人群。
  9. 时间结果：ausbleiben / auslaufen：预期事件未出现 / 合同到期或液体漏出。
  10. 信息控制：ausblenden / ausfragen / ausplaudern：隐藏忽略、详细追问、泄露秘密。
  11. 社会制度：austragen / ausüben / ausweisen：处理冲突或举办、行使、正式列示或证明。
  12. 休息恢复：sich ausruhen / ausspannen：活动后恢复体力 / 暂离压力放松。
  13. 实际技能：sich auskennen / ausrechnen / ausbessern：熟悉领域、算出结果、局部修补。
  14. sich auswirken / ausnutzen：产生影响 / 利用机会；后者对人使用常带负面评价。
  15. 完成分词：普通可分动词把 ge 放在中间（ausgewandert），-ieren 词仍无 ge（ausdiskutiert）。

易混辨析

  • ausleihen / leihen：在日常语境可表示借出或借来，最好用支配说明方向 / 中性"借"。
  • ausreichen / genügen：对数量和实际用途足够 / 达到要求或标准。
  • ausbauen / erweitern：进一步发展既有结构 / 一般扩大范围或功能。
  • aushändigen / abgeben：正式交到某人手中 / 把物品交出，不强调接收者身份。
  • aussortieren / auswählen：挑出不要的或不合格的 / 按标准挑出要的。
  • ausweisen / nachweisen：证件证明或正式列示 / 用材料证明事实成立。

语境回收

Das Unternehmen arbeitet einen neuen Lieferplan aus und weitet sein Angebot aus. Bestellungen werden im Lager aussortiert, mit Zubehör ausgestattet und täglich ausgeliefert. Bleibt eine Zahlung aus, weist die Rechnung den offenen Betrag getrennt aus. Trotz knapper Mittel kommt das Team gut aus, weil es vorhandene Möglichkeiten ausschöpft und kleine Schäden selbst ausbessert.

公司制定了新的配送方案并扩大服务范围。订单在仓库中完成分拣、配件配置，并每日发出；若付款未到账，账单会单独列出未付金额。尽管资源有限，团队仍能应付，因为它充分利用现有可能并自行修补小故障。
