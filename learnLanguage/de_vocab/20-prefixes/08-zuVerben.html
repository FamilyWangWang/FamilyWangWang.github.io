20-8 zu- 可分动词（Trennbare Verben mit zu-）

本组第 8 篇 · 共 10 篇 | 本篇 50 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 12 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

构词导入

zu- 常表示"朝目标靠近"（zugehen、zuströmen）、"由开到关"（zumachen、zudrehen）或"把某物分给某人"（zuteilen、zuschreiben）。主句中说 Die Tür fällt zu.，完成时说 Die Tür ist zugefallen.。要注意方向结构常由动词决定：auf jemanden zugehen 用第四格，而 jemandem zuhören 用第三格。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

固定表达

jemandem zuhören + D 专注听某人说话 人用第三格 A1
einem Vorschlag zustimmen + D 同意一项建议 建议用第三格 A2
auf jemanden zugehen auf + A 主动走近或接触某人 可用于解决冲突 B1
etwas offen zugeben + A；dass 坦率承认事实 常涉及错误 A2
eine Ausnahme zulassen + A 允许例外 不表示例外自动适用 B1
mit etwas zurechtkommen mit + D 能够应付某事 可指系统或处境 B1
jemandem etwas zutrauen + D + A 相信某人能做到某事 与 vertrauen 不同 B1
jemandem Schaden zufügen + D + A 给某人造成损害 正式中性 B1
jemandem etwas zusichern + D + A 正式向某人保证某事 比口头随意承诺强 B2
jemandem Verantwortung zuschieben + D + A 把责任推给某人 常含批评 B2
sich auf etwas zuspitzen sich⁴；auf + A 逐渐集中并恶化为某结果 冲突危机常用 B2
auf eine Krise zusteuern auf + A 明显走向危机 仍不表示结果必然发生 B2

精讲

  1. 关闭动作：zumachen / zudrehen / zubinden / zukleben / zuklappen：一般关上、旋紧、绑紧、粘封、折合。
  2. 朝向目标：zugehen / zufahren / zusteuern / zuströmen：走近、驶近、明显走向、大量流向。
  3. 观察互动：zusehen / zuschauen / zulächeln / zuwinken / zurufen：观看、口语观看、微笑、挥手、远处喊话。
  4. 承认允许：zugeben / zulassen / zubilligen：承认事实、允许发生、正式承认权益。
  5. 能力负担：zutrauen / zumuten / zurechtkommen：相信能做到、要求承受、能够应付。
  6. 分配归属：zuteilen / zuschreiben / zusprechen：分配资源、归因归性、正式判给。
  7. 交付保证：zuschicken / zustecken / zusichern：发送、私下递交、正式保证。
  8. 切割定制：zuschneiden / zuspitzen：按尺寸裁剪或定制 / 使表述尖锐或局势恶化。
  9. 损害压力：zufügen / zusetzen：造成具体损害 / 长期压力使人难受。
  10. 关闭与归属：zufallen / zufrieren / zuwachsen：自行关上或归于某人、冻封、逐渐长满封闭。
  11. 资金流动：zufließen / zuzahlen：资金流入 / 在已有付款之外补付。
  12. 共同接通：zuschalten / zuschieben：接入设备或人员 / 推物或推卸责任。
  13. 立即行动：zugreifen / zuschlagen / zupacken：取用访问、抓住机会或猛击、用力动手。
  14. 事件发生：zustoßen / sich zutragen：意外发生在某人身上 / 事件以某方式发生。
  15. 格的方向：jemandem etwas zusprechen 中人用第三格、事物用第四格；auf etwas zusteuern 的目标用第四格。

易混辨析

  • zusehen / zuschauen：中性观看，也可指袖手旁观 / 更口语地观看活动。
  • zugehen / sich nähern：可表示走近、关闭或收到 / 中性地逐渐接近。
  • zutrauen / vertrauen：相信某人有能力做具体事 / 信任某人的可靠性。
  • zuteilen / zuweisen：从总量中分配份额 / 由有权主体指定任务位置。
  • zusichern / versprechen：较正式地保证给予或发生 / 一般承诺。
  • zustoßen / sich zutragen：意外发生在某人身上 / 叙述事件如何发生。

语境回收

Die Leitung teilt jedem Team einen Raum zu und schickt allen den Plan zu. Neue Mitglieder dürfen zunächst zuschauen; später traut man ihnen eigene Aufgaben zu. Ein Experte wird per Video zugeschaltet und wendet sich den Sicherheitsfragen zu. Als sich die Lage zuspitzt, sichert die Leitung zusätzliche Hilfe zu, statt einzelnen Personen die Verantwortung zuzuschieben.

负责人给每个团队分配房间并把计划发给所有人。新成员起初可以旁观，之后会被信任承担自己的任务。一名专家通过视频接入并转而处理安全问题。局势加剧时，负责人保证提供额外帮助，而不是把责任推给个人。

自测

  1. 朝某人主动走近用 _______。 2. 承认一个错误用 _______。
  2. 相信某人能完成任务用 _______。 4. 给团队分配房间用 _______。
  3. 给某人造成损害用 _______。 6. 正式保证提供帮助用 _______。
  4. 远程把专家接入会议用 _______。 8. 把责任推给别人用 _______。

  2. zufügen 6. zusichern 7. zuschalten 8. zuschieben
