20-2 auf- 可分动词（Trennbare Verben mit auf-）

本组第 2 篇 · 共 10 篇 | 本篇 50 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 15 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

构词导入

auf- 的核心图像是"向上"或"从关闭到打开"：aufstehen 是站起来，aufschließen 是打开锁，aufleben 是重新活跃。它还可表示事件突然进入可见状态（auftauchen、auffliegen）或把事情完成、耗尽（aufessen、aufbrauchen）。主句说 Sie steht früh auf.，完成时是 Sie ist früh aufgestanden.。

精讲

  1. 向上动作：aufstehen / aufspringen / aufrichten：起身、突然跳起、扶起或竖直。
  2. 打开动作：aufmachen / aufschließen / aufschneiden / aufbrechen：一般打开、用钥匙开、切开、强行打开。
  3. 醒来与恢复：aufwachen / aufleben / aufblühen / auftanken：醒来、重新活跃、焕发生机、恢复能量。
  4. 停止与延迟：aufhören / aufhalten / aufschieben：停止活动、阻碍前进、推迟到以后。
  5. 出现与可见：auftauchen / auffallen / aufleuchten / auffliegen：出现、显眼、短暂亮起、秘密暴露。
  6. 查明与发现：aufklären / aufdecken / aufspüren：查清事实、揭露问题、搜索出隐藏对象。
  7. 用尽与补足：aufbrauchen / aufessen / auffüllen：耗尽资源、吃完、补充到所需水平。
  8. 收集与筹措：auffangen / aufbringen / auftreiben：接住或缓冲、筹集、设法找到。
  9. 理解与继续：auffassen / aufgreifen / aufzeigen：以某方式理解、接过话题、清楚指出路径。
  10. 正式动作：auffordern / aufrufen / aufheben：要求个人、公开号召、依法取消。
  11. 建立与扩充：aufstellen / aufstocken / aufziehen：摆放制定、增加规模、抚养或拉开。
  12. 负担与投入：aufbürden / aufwenden：把负担强加给人 / 为目标投入资源。
  13. 注意反应：aufpassen / aufhorchen：持续留意 / 因重要信息突然警觉。
  14. sich aufraffen / sich aufrichten：克服不情愿开始行动 / 身体挺直或精神振作。
  15. 助动词选择：状态变化和移动常用 sein（ist aufgewacht），及物动作通常用 haben（hat aufgeweckt）。

易混辨析

  • aufmachen / öffnen：日常口语的打开 / 中性且可用于正式语境。
  • aufwachen / aufwecken：自己醒来 / 把别人叫醒。
  • auffallen / bemerken：某物引起注意，某物作主语 / 某人主动注意到某物。
  • aufklären / erklären：查明或告知背景风险 / 解释原因、意义或运作方式。
  • aufheben / absagen：取消决定、规则或效力 / 取消约会、活动或邀请。
  • aufbringen / aufwenden：设法筹得或鼓起 / 为目标实际投入。
