20-10 不可分前缀（Untrennbare Präfixe）

本组第 10 篇 · 共 10 篇 | 本篇 50 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 23 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

构词导入

典型不可分前缀是 be-、emp-、ent-、er-、ge-、miss-、ver-、zer-。它们通常不承重音，主句中不移到句末，完成分词也不加 ge-：bearbeiten → hat bearbeitet，不是 hat gebearbeitet。带 zu 的不定式同样不拆开：zu bearbeiten。少数外形相同的前缀会因重音和意义而改变可分性，应逐词确认。

精讲

  1. be- 不能机械翻译：bedeuten、bekommen、betreiben 的意义差异很大；前缀规律只能辅助理解，实际使用仍要把整词和支配一起记。
  2. bedauern / beruhigen / bestrafen：表示遗憾、使平静、施加处罚。
  3. begrenzen / bekämpfen / beseitigen：限制范围、主动对抗、清除障碍。
  4. benachteiligen / berechtigen：使处于不利 / 使依法依约有权。
  5. ent- 的离开与去除：entziehen / entgehen / entkommen / entwenden：撤走、未被注意或避开、逃脱、盗取。
  6. ent- 的产生变化：entwickeln / entfachen / entgleisen：发展开发、点燃引发、脱轨失控。
  7. er- 的达到结果：erhalten / ergreifen / erwerben / erzielen：获得、采取抓住、取得、达成结果。
  8. erneuern / ernennen / erproben / erstellen：更新、任命、试验、制作。
  9. ver- 的变化与过程：verändern / verarbeiten / verbringen：改变、加工处理、度过时间。
  10. verkaufen / verdienen / versprechen：出售、赚得、承诺。
  11. verschwinden：描述对象不再可见或不在原处，完成时使用 sein。
  12. zer- 的分解破坏：zerfallen / zerreißen / zerstören / zersetzen：自行分解、撕裂、摧毁、使物质分解。
  13. miss- 的错误失败：missdeuten / misslingen：误解 / 未能成功。
  14. missbrauchen / misstrauen：不当使用 / 持续不信任；前者带第四格，后者带第三格。
  15. 形式规则：不可分前缀不移位、不在词干前插入 zu、分词不加 ge-：zu verarbeiten、hat verarbeitet。

易混辨析

  • bekommen / erhalten：日常获得收到 / 较正式地收到或维持。
  • entgehen / entkommen：未被注意或避开损失 / 从危险控制中逃脱。
  • erwerben / kaufen：通过购买、学习或法律行为取得 / 单纯购买。
  • erstellen / herstellen：制作文件、计划、数字对象 / 制造实体产品。
  • zerfallen / zerstören：整体自行分解 / 外力主动使对象失去功能。
  • missdeuten / missverstehen：错误解释迹象意图 / 没听懂或误解话语内容。

语境回收

Die Behörde bearbeitet den Antrag und beauftragt eine Fachstelle mit der Prüfung. Sie erfasst die Unterlagen, erprobt das vorgeschlagene Verfahren und erstellt einen Bericht. Werden Risiken erkannt, ergreift sie Maßnahmen, um Missbrauch zu verhindern. Fehlende Nachweise müssen erbracht werden; gelingt das nicht, kann die Behörde eine bereits erteilte Erlaubnis entziehen.

主管机关处理申请，并委托专业部门审查。部门收集材料、试验所提流程并制作报告。若识别出风险，便采取措施防止滥用；缺失证明必须补齐，若未能做到，机关可以撤销已经授予的许可。
