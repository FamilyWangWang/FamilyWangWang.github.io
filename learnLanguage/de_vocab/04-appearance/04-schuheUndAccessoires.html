04-4 鞋帽与配饰（Schuhe und Accessoires）

本组第 4 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

鞋子通常成对购买，但德语商品标签仍会写单数 der Schuh；说"一双"用 ein Paar Schuhe。帽子、眼镜、腰带和首饰既有实用功能，也能改变整体穿搭。选购时最常问尺寸、鞋底、防水性和扣带能否调节。

精讲

  1. Schuh / Schuhpaar：单只或鞋类基本词 / 配成一双的两只鞋。
  2. Turnschuh / Sneaker：传统运动鞋称呼 / 偏休闲时尚的运动鞋。
  3. Stiefel / Stiefelette：高过脚踝的靴子 / 到脚踝附近的短靴。
  4. Sandale / Pantolette：通常有后部固定 / 后跟开放、直接套穿。
  5. Absatz / Sohle：后跟下方抬高部分 / 整个鞋底。
  6. Mütze / Kappe / Hut：软帽 / 有帽舌便帽 / 有帽檐和帽冠的帽子。
  7. Schal / Halstuch：较长保暖围巾 / 较薄小方巾。
  8. Handschuh / Fäustling：分指手套 / 连指手套。
  9. Krawatte / Fliege：长领带 / 蝴蝶领结。
  10. Schmuck / Accessoire：首饰总称 / 包括更多穿搭配件。
  11. aufsetzen：用于帽子、眼镜；衣服和鞋一般用 anziehen。
  12. umbinden / umhängen：围住并系好 / 挂在肩或颈部。
  13. schnüren / zuschnüren：用鞋带系 / 系到关闭状态。
  14. flach / hochhackig：低跟或平底 / 高跟。
  15. wasserdicht / wasserabweisend：完全防水 / 只能短时抗水。

易混辨析

  • Rucksack / Handtasche：双肩背 / 手提或单肩背。
  • Ring / Ohrring：手指上的戒指 / 耳朵上的耳环。
  • Brille / Sonnenbrille：视力或防护眼镜 / 遮挡强光的太阳镜。
  • Gürtel / Hosenträger：从腰部固定裤子 / 从肩部吊住裤子。

语境回收

Für die Wanderung wählt Nina wasserdichte Wanderschuhe mit rutschfesten Sohlen. Sie schnürt sie fest zu und steckt zusätzliche Schnürsenkel in den Rucksack. Wegen der Sonne setzt sie eine Kappe und eine Sonnenbrille auf. Ein leichtes Halstuch schützt den Nacken, und der verstellbare Riemen hält ihre kleine Tasche sicher an der Schulter.

徒步时Nina选择鞋底防滑的防水徒步鞋。她把鞋带系紧，并在背包里放了备用鞋带。因为阳光强，她戴上鸭舌帽和太阳镜。轻薄方巾保护颈后，可调肩带让小包稳稳挂在肩上。

自测

  1. Zwei Schuhe bilden ein _______. 2. Zum Wandern trage ich feste _______.
  2. Die Unterseite des Schuhs heißt _______. 4. Bitte _______ deine Schuhe zu.
  3. Eine Mütze wird _______. 6. Eine Tasche kann man sich über die Schulter _______.
  4. Eine Fliege ist keine _______. 8. Bei Regen brauche ich wasserdichte _______.
  5. Der Riemen lässt sich verstellen; er ist _______. 10. Eine Schuhsohle sollte im Winter _______ sein.
答案
  1. Paar 2. Wanderschuhe 3. Sohle 4. schnür 5. aufgesetzt
  2. umhängen 7. Krawatte 8. Stiefel 9. verstellbar 10. rutschfest
