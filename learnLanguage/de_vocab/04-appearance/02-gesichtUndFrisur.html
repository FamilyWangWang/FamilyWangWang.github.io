04-2 面容与发型（Gesicht und Frisur）

本组第 2 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

辨认一个人时，最实用的是能准确说出脸型、眼睛、头发长度和发型。Haare 通常用复数，单根才是 das Haar。颜色和造型可以客观描述；对皱纹、秃发等特征则应避免未经请求的评价。

精讲

  1. Gesicht / Gesichtsform：脸部整体 / 脸的轮廓类型。
  2. Haar / Haare：一根头发 / 日常所说的整头头发。
  3. Frisur / Haarschnitt：造型完成后的发式 / 剪发形成的款式。
  4. Stirn / Schläfe：额头正面 / 额头两侧太阳穴。
  5. Mund / Lippe：嘴部整体 / 上下嘴唇。
  6. Bart / Schnurrbart：胡须统称 / 只在上唇的胡须。
  7. Pony：发型中的刘海，不要与英语"矮种马"语义混淆。
  8. Zopf / Pferdeschwanz：编成的辫子 / 未编、只扎起的马尾。
  9. kämmen / bürsten：用梳子整理 / 用发刷刷顺。
  10. färben / tönen：持久染色 / 相对短效的染色。
  11. rasieren：Er rasiert sich. 或 Er rasiert sich den Bart ab.
  12. blond / brünett：金发 / 深棕发；brünett 常描述人。
  13. grau / grauhaarig：头发颜色灰白 / 人已经有灰白头发。
  14. markant：突出的是辨识度，不必然等于"漂亮"。
  15. sich die Haare schneiden lassen：自己是服务接受者，用第三格反身代词。

易混辨析

  • Wange / Wangenknochen：脸颊软组织 / 颧骨。
  • Falte / Grübchen：皮肤皱纹 / 笑时形成的凹陷。
  • Glatze / kurz geschnitten：没有头发或剃光 / 头发剪得很短。
  • glätten / hochstecken：把头发弄直 / 把长发盘起。

语境回收

Die gesuchte Person hat ein ovales, sommersprossiges Gesicht und markante Wangenknochen. Ihre Augen sind grün, die Augenbrauen dunkel und dicht. Sie trägt ihre roten, lockigen Haare meist offen; heute hat sie sie jedoch zu einem lockeren Dutt hochgesteckt. Auf der linken Wange hat sie einen kleinen Leberfleck.

要找的人是椭圆脸、有雀斑，颧骨明显。她眼睛绿色，眉毛深而浓。她通常披着红色卷发，但今天盘成了松松的发髻。左脸颊有一颗小痣。

自测

  1. Eine einzelne _______ lag auf der Jacke. 2. Sie trägt ihre Haare heute _______.
  2. Er lässt sich einen Bart _______. 4. Die Haare werden zu einem Zopf _______.
  3. Ein Pony bedeckt einen Teil der _______. 6. Sie hat grüne Augen und dichte _______.
  4. Beim Friseur lasse ich mir die Spitzen _______. 8. Ein Schnurrbart wächst über der _______.
  5. Seine Haare sind nicht glatt, sondern _______. 10. Das Kind ist der Mutter wie aus dem Gesicht _______.
答案
  1. Haar 2. offen 3. wachsen 4. geflochten 5. Stirn
  2. Augenbrauen 7. schneiden 8. Lippe 9. lockig 10. geschnitten
