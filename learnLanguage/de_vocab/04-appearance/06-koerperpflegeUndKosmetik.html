04-6 个人护理与化妆（Körperpflege und Kosmetik）

本组第 6 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 5 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

个人护理从清洁、保湿、防晒延伸到剃须、护发和化妆。德语产品名常直接说明用途：Gesichtsreinigung、Feuchtigkeitscreme、Lippenpflege。描述使用顺序时，掌握 auftragen、einmassieren、einwirken lassen 和 abspülen 就能读懂大部分包装说明。

精讲

  1. Körperpflege / Hygiene：个人清洁护理活动 / 防止污染和传播的卫生原则。
  2. Hauttyp：常见区分包括 trocken、fettig、normal 和 Mischhaut。
  3. Tagescreme / Nachtcreme：白天使用 / 夜间使用；实际功能以配方为准。
  4. Spülung / Haarkur：短时护发并冲洗 / 停留更久、护理更强。
  5. Deodorant / Parfüm：处理汗味 / 提供香气。
  6. Make-up / Kosmetik：彩妆或底妆 / 更广泛的美容护理领域。
  7. Grundierung / Concealer：整体打底 / 局部遮盖。
  8. Wimperntusche / Mascara：两个词都指睫毛膏，后者在商品上很常见。
  9. waschen / reinigen：普通水洗 / 更系统或彻底地清洁。
  10. eincremen / auftragen：把乳霜涂匀 / 涂产品的通用动作。
  11. einmassieren：Die Pflege sanft in die Haut einmassieren.
  12. einziehen / einwirken：产品被皮肤吸收 / 产品停留并发挥作用。
  13. schminken / abschminken：化妆 / 卸妆。
  14. sich die Zähne putzen：身体部位用定冠词，反身代词用第三格。
  15. parfümfrei / geruchlos：不含香精 / 本身没有气味，不完全相同。

易混辨析

  • Seife / Duschgel：皂类清洁品 / 专用于淋浴的液体清洁品。
  • Shampoo / Spülung：清洗头皮头发 / 洗后改善顺滑度。
  • Rasierer / Rasierklinge：完整剃须工具 / 需要更换的刀片。
  • Lippenpflege / Lippenstift：护理防干裂 / 主要用于上色。

语境回收

Am Abend reinigt Samira zuerst ihr Gesicht und entfernt das Make-up. Danach trägt sie eine parfümfreie Feuchtigkeitscreme dünn auf und lässt sie vollständig einziehen. Zweimal pro Woche verwendet sie eine Haarkur: Sie massiert das Produkt in die feuchten Haare ein, lässt es kurz einwirken und spült es dann mit klarem Wasser aus.

晚上Samira先清洁面部并卸妆，然后薄涂无香保湿霜，等待完全吸收。每周两次她使用发膜：将产品按摩进湿发，停留片刻，再用清水冲净。
