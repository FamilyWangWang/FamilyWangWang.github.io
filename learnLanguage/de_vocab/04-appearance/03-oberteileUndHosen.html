04-3 上衣与裤装（Oberteile und Hosen）

本组第 3 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项

场景导入

德语服装词常通过组合直接说明用途或形状：Kapuzenpullover 有帽子，Rollkragenpullover 有高领，Stoffhose 强调不是牛仔布。买衣服时除了名称，还要会说衣长、袖长、松紧和版型是否合适。

精讲

  1. Kleidung / Kleidungsstück：衣物总称 / 一件具体衣服。
  2. Hemd / Bluse：常见男式或中性衬衫 / 女式或更精致的衬衫式上衣。
  3. Pullover / Sweatshirt：针织或毛衣 / 棉质运动卫衣。
  4. Sakko / Anzug：一件西装上衣 / 成套西装。
  5. Rock / Kleid：半身裙 / 连衣裙。
  6. Socke / Strumpf：普通短袜 / 较长袜子或复合词成分。
  7. Jeans：单数仍说 eine Jeans，复数可说 zwei Jeans。
  8. Shorts / Leggings：形式上都通常只用复数。
  9. tragen：Heute trägt sie einen dunklen Blazer.
  10. sitzen：衣服"合身"时不用 passen 也常用 sitzen。
  11. kneifen / rutschen：太紧处勒人 / 太松而滑落。
  12. einlaufen / ausleiern：洗后缩水 / 使用后失去弹性。
  13. eng / hauteng：一般紧 / 紧贴皮肤。
  14. ärmellos / kurzärmlig / langärmlig：无袖 / 短袖 / 长袖。
  15. wie angegossen sitzen：非常合身，但不表示穿着一定舒适。

易混辨析

  • Jacke / Mantel：通常较短的外套 / 通常覆盖到大腿或更长。
  • Strickjacke / Weste：有袖针织开衫 / 无袖背心。
  • Unterhemd / T-Shirt：贴身打底背心 / 可单穿的短袖上衣。
  • Arbeitskleidung / Uniform：适应工作的服装 / 表明组织身份的统一制服。

语境回收

Für das Vorstellungsgespräch wählt Tom eine dunkle Stoffhose, ein helles Hemd und ein Sakko. Die Hose sitzt an den Beinen gut, kneift aber noch etwas am Bund. Deshalb probiert er eine Nummer größer. Das Sakko passt zum Anlass, und unter dem Hemd trägt er ein dünnes Unterhemd. So wirkt die Kleidung ordentlich, ohne zu feierlich zu sein.

面试时Tom选择深色西裤、浅色衬衫和西装上衣。裤腿合适，但腰头还有点勒，所以他试大一码。西装上衣适合场合，衬衫里面穿一件薄背心。整套衣服显得整洁，又不过分隆重。

自测

  1. Eine Bluse ist ein _______. 2. Die Hose ist zu eng und _______ am Bund.
  2. Nach dem Waschen ist der Pullover _______. 4. Ein Sakko gehört oft zu einem _______.
  3. Ein Rock ist kein _______. 6. Bitte probieren Sie die Hose eine Nummer _______.
  4. Ein Oberteil ohne Ärmel ist _______. 8. Die Jeans sitzt wie _______.
  5. Im Winter trage ich einen langen _______. 10. Die Ärmel sind zu lang; ich muss sie _______.
答案
  1. Oberteil 2. kneift 3. eingelaufen 4. Anzug 5. Kleid
  2. größer 7. ärmellos 8. angegossen 9. Mantel 10. hochkrempeln
