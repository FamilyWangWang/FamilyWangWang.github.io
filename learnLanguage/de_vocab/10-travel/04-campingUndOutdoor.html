10-4 露营与户外（Camping und Outdoor）

本组第 4 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 6 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

露营用语首先区分地点、住宿装备和营地设施。Campingplatz 是整个营地，Stellplatz 是分配给车辆或住客的具体位置，Zeltplatz 则明确用于搭帐篷。生火、野营、排放污水等规则因地区和场地而异；看到 Platzordnung、禁火标志或自然保护提示时，应按现场规定执行。

精讲

  1. Campingplatz / Zeltplatz / Campingparzelle：整个正规营地 / 帐篷专用区域 / 边界较明确的营地地块。
  2. Campingparzelle / Zeltwiese：单组住客使用的划分地块 / 多顶帐篷共享的草地区域。
  3. Kuppelzelt / Tunnelzelt：自立性较好的圆顶结构 / 空间利用率较高的长条结构。
  4. Vorzelt / Markise：可形成封闭附加空间的篷体 / 从车侧展开的遮篷。
  5. Zelthering / Zeltstange / Abspannleine：地钉 / 支撑杆 / 提供张力的拉绳。
  6. Zeltplane / Bodenplane：外部遮蔽布 / 地面隔潮层。
  7. Schlafsack / Isomatte / Luftmatratze：保温睡袋 / 隔冷薄垫 / 充气厚垫。
  8. Campingkocher / Gaskartusche：便携炉具 / 配套燃气容器。
  9. Taschenlampe / Stirnlampe / Campinglaterne：手持定向光 / 头戴光 / 营位环境照明。
  10. Grillstelle / Feuerstelle：烧烤专用点 / 一般受控明火点。
  11. Campingdusche / Waschraum：营地淋浴设施 / 公共洗漱空间。
  12. Trinkwasserstelle / Abwasserstelle：取清洁饮水 / 排放生活污水。
  13. Wohnwagen / Wohnmobil / Campervan：牵引式 / 自走大型 / 紧凑厢式露营车。
  14. Windschutz / Gummihammer / Reparaturhülse：挡风装备 / 敲地钉工具 / 临时加固断杆的管件。
  15. campen / zelten：使用各种露营住宿方式 / 明确用帐篷住宿。

易混辨析

  • wasserdicht / wasserabweisend：防水可承受更强水压 / 仅能让少量水暂时滑落。
  • Trinkwasser / Brauchwasser：可饮用水 / 只供清洗等用途的水。
  • Stellplatz / Parkplatz：可住宿停驻的营位 / 只用于停车的位置。
  • Feuerstelle / offenes Feuer：指定控火地点 / 所有裸露明火的总称。

语境回收

Am Campingplatz bekommt Nora eine Parzelle mit Stromanschluss. Sie baut das Tunnelzelt auf, schlägt die Zeltheringe ein und spannt es windfest ab. Schlafsack und Isomatte bleiben trocken auf der Bodenplane. Trinkwasser holt sie an der gekennzeichneten Stelle. Am Abend benutzt sie den Campingkocher; wegen der hohen Waldbrandgefahr ist offenes Feuer heute verboten.

Nora在营地分到一块带电源接口的营位。她搭起隧道帐篷，敲入地钉并用拉绳稳固。睡袋和隔温垫放在防潮地布上保持干燥。她在标明的地点取饮用水。晚上她使用露营炉；由于森林火险很高，当天禁止露天明火。
