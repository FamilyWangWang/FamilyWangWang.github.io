10-2 酒店与民宿（Hotel und Unterkunft）

本组第 2 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

预订住宿时，房型名称只是第一层，真正需要确认的是床型、入住人数、餐食、取消条款和额外费用。Doppelzimmer 通常强调可住两人，不必然保证是一张双人床；需要两张分开的床时应明确问 Zweibettzimmer。抵达后使用 einchecken，离店手续则是 auschecken，书面信息里也常直接出现名词 Check-in 和 Check-out。

精讲

  1. Hotel / Pension / Herberge：专业酒店 / 小型住宿 / 服务较简单的住宿场所总称。
  2. Jugendherberge / Hostel：会员制青年旅舍体系 / 市场化经济住宿。
  3. Ferienwohnung / Apartment：度假整套住房 / 带生活设施的住宿单元。
  4. Einzelzimmer / Doppelzimmer：单人入住 / 两人入住，后者不自动说明床型。
  5. Doppelzimmer / Zweibettzimmer：双人房总类 / 明确两张分开单人床。
  6. Mehrbettzimmer / Familienzimmer：多人共享床位房 / 按家庭配置的客房。
  7. Rezeption / Lobby：办理住客事务的柜台部门 / 会面休息的公共空间。
  8. Hotelbuchung / Zimmerreservierung：完整酒店预订 / 专门保留客房的安排。
  9. Hotelaufenthalt / Übernachtung：整段入住期间 / 按夜计算的住宿单位。
  10. Anreise / Abreise：抵达住宿地 / 离开住宿地。
  11. Frühcheck-in / Spätanreise：常规时段前入住 / 在前台常规时段后抵达。
  12. Halbpension / Vollpension：早餐加一顿正餐 / 通常每日三餐。
  13. Übernachtungspreis / Kurtaxe：住宿标价 / 旅游地按当地规则另收的费用。
  14. Zimmerservice / Zimmerreinigung：送到客房的服务 / 客房清洁整理。
  15. auschecken / übernachten：办理离店手续 / 在外住宿一晚或数晚。

易混辨析

  • inklusive / gegen Aufpreis：已经包含在价格中 / 需要额外付费。
  • Kaution / Zahlung：可退还或解除的担保 / 最终支付的费用。
  • Frühcheck-in / Gepäckaufbewahrung：提前取得客房 / 房间未好时只寄存行李。
  • reklamieren / sich beschweren：针对具体缺陷要求处理 / 表达一般不满。

语境回收

Luis hat ein Doppelzimmer mit getrennten Betten reserviert und kündigt seine Spätanreise vorher an. An der Rezeption zeigt er die Buchungsbestätigung und erhält zwei Schlüsselkarten. Das Frühstücksbuffet ist inklusive, die Kurtaxe wird beim Check-out berechnet. Weil die Klimaanlage nicht funktioniert, wendet er sich an die Rezeption. Am Abreisetag lässt er seinen Koffer noch zwei Stunden in der Gepäckaufbewahrung.

Luis预订了一个带两张分开床的双人房，并提前告知会晚到。他在前台出示预订确认，拿到两张房卡。自助早餐已包含，旅游税在退房时计算。由于空调不能工作，他联系前台处理。离店当天，他又把箱子寄存了两个小时。
