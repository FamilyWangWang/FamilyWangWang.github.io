10-5 边境与证件（Grenze und Reisedokumente）

本组第 5 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 8 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

边境场景中必须分清人员检查与货物检查：Passkontrolle 核对身份和入境条件，Zollkontrolle 处理货物、现金等申报问题。所需证件取决于国籍、目的地、过境路线和停留目的，并可能临时变化；visumfrei 也不等于可以无条件入境。准备时应以目的地政府、领事机构和承运方的当前信息为准。

精讲

  1. Staatsgrenze / Grenzübergang：国家领土分界 / 获准跨越该分界的具体地点。
  2. Binnengrenze / Außengrenze：共同区域内部边界 / 与外部国家相接的边界。
  3. Zollstelle / Zollanmeldung：办理海关事务的地点 / 正式申报程序或文件。
  4. Durchreise / Transit：经过一国继续旅行 / 经枢纽或国家前往第三地。
  5. Visumpflicht / Visumfreiheit：必须预先取得签证 / 特定条件下免签。
  6. Aufenthaltsdauer / Aufenthaltszweck：停留时长 / 停留原因。
  7. Reisedokument / Reiseausweis / Notreiseausweis：旅行证件总称 / 特定替代证件 / 紧急临时证件。
  8. Gültigkeitsdatum / Passablaufdatum：有效状态所关联日期 / 护照明确终止有效的日期。
  9. Ausstellungsdatum / Ausstellungsbehörde：签发日期 / 签发机关。
  10. Passfoto / Fingerabdruck / Dokumentenchip：证件照片 / 生物特征记录 / 存储证件数据的芯片。
  11. Einreiseerlaubnis / Aufenthaltserlaubnis / Arbeitserlaubnis：入境 / 居留 / 工作许可。
  12. Zollanmeldung / Einfuhr / Ausfuhr：申报程序 / 带入 / 带出关税区域。
  13. Reisefreimenge / Warenwert：特定条件下免税额度 / 实际货物价值。
  14. Unterkunftsnachweis / Rückreiseticket：证明住处 / 证明后续离境安排。
  15. vorzeigen / abstempeln / verzollen：出示供核验 / 加盖处理印章 / 完成海关计税手续。

易混辨析

  • Pass / Visum：证明身份国籍的旅行证件 / 目的国给予的入境停留许可。
  • Botschaft / Konsulat / Auslandsvertretung：使馆 / 领馆 / 两者等机构的总称。
  • visumfrei / bedingungslos：免于预先签证 / 无任何条件；两者绝不等同。
  • Reisefreimenge / Freigepäck：海关免税额度 / 交通票价包含的行李额度。

语境回收

Vor der Reise prüft Amir die Einreisebestimmungen und das Passablaufdatum. An der Außengrenze zeigt er sein Reisedokument vor und nennt den Aufenthaltszweck. Als Unterkunftsnachweis hat er die Hotelbestätigung gespeichert. Danach geht er zur Zollkontrolle, weil er eine Ware anmelden muss. Den Kaufbeleg nutzt er, um den Warenwert nachzuweisen.

出发前，Amir核对入境规定和护照到期日。在外部边境，他出示旅行证件并说明停留目的。他保存了酒店确认作为住宿证明。之后他前往海关检查，因为有一件商品需要申报。他用购买凭证证明商品价值。
