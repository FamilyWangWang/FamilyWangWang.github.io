10-6 旅途问题（Probleme unterwegs）

本组第 6 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 18 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

旅途出问题时，先处理安全和医疗，再保存证据、联系正确责任方。Notruf 用于急迫危险，普通延误、行李查询或合同投诉应联系承运方、住宿方或旅行组织者。要求退款或赔偿时要区分 Erstattung（退回已付费用）和 Entschädigung（对损失或不便的补偿），具体权利取决于交通方式、合同和事发情况。

精讲

  1. Flugunregelmäßigkeit / Betriebsstörung：航空计划偏离事件总称 / 影响系统正常运行的问题。
  2. Fehlbuchung / Doppelbuchung / Überbuchung：预订内容错误 / 重复预订 / 接单超过容量。
  3. Reiseunterbrechung / Zwangsübernachtung：行程中途暂停 / 因无法继续而被迫住宿。
  4. Gepäckverlust / Gepäckverspätung / Gepäckschaden：最终遗失 / 晚到 / 受损。
  5. Wertsachenverlust / Diebstahl：贵重物品无意遗失 / 被他人非法取走。
  6. Taschendiebstahl / Buchungsbetrug：秘密偷取贴身财物 / 通过虚假预订骗取付款。
  7. Reisekrankheit / Lebensmittelvergiftung：乘行引起的晕动不适 / 污染食物引起的急性中毒。
  8. Hitzschlag / Dehydrierung：体温调节失效的急症 / 身体缺水状态。
  9. Bereitschaftsdienst / Notfallaufnahme：非门诊时段紧急但非致命医疗 / 医院急症接收区域。
  10. Fundbüro / Polizeibericht：查询拾得物的机构 / 警方记录事件的正式文件。
  11. Schadensmeldung / Reisereklamation：向责任方或保险报告损害 / 针对旅行服务缺陷要求处理。
  12. Entschädigung / Ersatzbeförderung：对损失或不便补偿 / 原交通失效后的替代运输。
  13. Gepäckermittlung / Schadensnummer：追查未到行李 / 识别一项损害报告的编号。
  14. Reiseveranstalter / Reisekundenservice：组合并销售整体旅行的企业 / 处理旅客查询与变更的服务部门。
  15. umbuchen / entschädigen：改到另一班次或日期 / 就损失或不便提供补偿。

易混辨析

  • verloren / verspätet：已确认遗失 / 暂时未随旅客到达。
  • Erstattung / Gutschein：返还费用 / 未来消费凭证，法律和合同效果不同。
  • Notruf / Hotline：公共紧急救援 / 企业或保险服务电话。
  • Quittung / Rechnung：证明已收款 / 列明应付项目；报销时可能都需要。

语境回收

Nach der Landung kommt Saras Koffer nicht am Gepäckband an. Sie meldet die Gepäckverspätung sofort und notiert das Aktenzeichen. Für notwendige Kleidung bewahrt sie alle Zahlungsbelege auf. Später entdeckt sie außerdem, dass ihre Geldbörse gestohlen wurde. Sie lässt die Bankkarte sperren, zeigt den Diebstahl bei der Polizei an und informiert ihre Reiseversicherung.

落地后，Sara的箱子没有出现在行李转盘上。她立即报告行李延误并记下案件编号。购买必需衣物时，她保存所有付款凭证。之后她还发现钱包被盗，于是冻结银行卡、向警方报案，并通知旅行保险。

自测

  1. 交通晚点是 _______。 2. 航班正式取消是 _______。
  2. 行李晚到是 _______。 4. 被秘密偷走贴身财物是 _______。
  3. 正式报告损害是 _______。 6. 退回已付费用是 _______。
  4. 对损失作补偿是 _______。 8. 查询拾得物去 _______。
  5. 冻结银行卡是 die Karte _______。 10. 向警方报案盗窃是 den Diebstahl _______。

  2. Schadensmeldung 6. Erstattung 7. Entschädigung 8. Fundbüro 9. sperren 10. anzeigen
