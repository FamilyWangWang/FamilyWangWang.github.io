10-3 景点与观光（Sehenswürdigkeiten und Besichtigung）

本组第 3 篇 · 共 6 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 7 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

先选景点，再安排入场和导览，最后看想怎样记录旅行。本篇让建筑名词与参观动作互相解释，而不是孤立记一串景点。

Sehenswürdigkeit 是值得参观的历史、文化或自然地点；Attraktion 更强调吸引游客的项目，不一定有历史价值。计划参观时，要分清 Öffnungszeit、最后入场时间和导览开始时间。拍照、使用三脚架或商业摄制的规定可能不同，看到 Fotografieren verboten 或需要 Drehgenehmigung 时应按现场规则执行。

精讲

  1. Sehenswürdigkeit / Touristenattraktion：因价值值得看 / 以吸引游客为特征。

  2. Wahrzeichen / Welterbestätte：代表城市的标志 / 被列入世界遗产名录的地点。

  3. Schloss / Burg / Palast：贵族代表性居所 / 防御性城堡 / 宏大的统治者宫殿。

  4. Kathedrale / Basilika：设有主教座位 / 因形制或教会称号得名。

  5. Gedenkstätte / Freilichtmuseum：纪念历史事件和受害者 / 在室外展示建筑和生活方式的博物馆。

  6. Stadtführung / Themenführung：综合城市导览 / 围绕单一主题的导览。

  7. Rundgang / Stadtrundfahrt / Bootsrundfahrt：步行参观线路 / 乘车观光 / 乘船观光。

  8. Tagesausflug / Ausflugsziel：当天往返的活动 / 适合短途出游的地点。

  9. Eintritt / Eintrittskarte / Eintrittspreis：入场资格或费用 / 入场凭证 / 标示金额。

  10. Startzeit / Zeitfenster：活动开始时刻 / 允许进入的限定时间段。

  11. Audioguide / Reiseführer：按点位播放的语音服务 / 旅行书、应用或带团人员。

  12. Aussicht / Panorama：从某点看到的视野 / 宽广连续的整体景观。

  13. Hauptsaison / Nebensaison：游客需求高峰期 / 旺季之外的较淡时期。

  14. entdecken / erkunden：首次注意到某物 / 主动走访并系统了解区域。

  15. anschauen / ansehen：都可说有意识地观看；语境、地区习惯会影响选择，不能据动词给认真程度固定排名。

易混辨析

  • Führung / Rundgang：有人或设备讲解的导览 / 按路线走完的参观过程。
  • Foto / Aufnahme：日常照片 / 可指照片、录音或视频的记录。
  • kostenlos / frei：无需付费 / 在 freier Eintritt 中固定表示免票。
  • fotografieren / filmen：拍静态照片 / 拍摄连续视频，现场许可可能不同。

语境回收

Am Vormittag nimmt Mei an einer Stadtführung durch das Altstadtviertel teil. Der Treffpunkt liegt vor der Kathedrale. Danach besichtigt sie das Schloss und leiht einen Audioguide aus. Auf dem Aussichtsturm genießt sie das Panorama, fotografiert aber ohne Blitz. Weil vor der Sonderausstellung eine lange Warteschlange steht, kauft sie online eine Eintrittskarte für den nächsten Morgen.

上午，Mei参加了穿过老城片区的城市导览，集合点在大教堂前。之后她参观宫殿并借用语音导览。她在观景塔上欣赏全景，拍照时不用闪光灯。由于特展前排着长队，她在网上购买了第二天早晨的门票。

Mei先参加Stadtführung，再自行参观Schloss；Führung突出有讲解带领，参观方式可以在同一天切换。特展排长队后改订次日上午门票，是票务选择，并不保证其他时段一定不排队。

把词放回句子

Das Wahrzeichen ist leicht wiederzuerkennen.（城市标志容易认出。）Eine Burg betont die Verteidigungsfunktion; eine Kathedrale ist eine Bischofskirche.（Burg突出防御性，Kathedrale是主教座堂。）Eine Themenführung behandelt ein bestimmtes Thema.（专题导览围绕特定主题。）建筑名称与导览安排回答不同问题。

Wir machen einen Tagesausflug und haben freien Eintritt.（我们当天往返游玩，并可免费入场。）Ein Audioguide erklärt die Stationen der Besichtigung.（语音导览讲解参观点位。）Vom Turm sehen wir ein weites Panorama.（从塔上能看到宽广全景。）Eintritt说入场或费用，Eintrittskarte是入场凭证。

Ich nehme an einer Führung teil und erkunde danach die Stadt.（我参加导览，之后探索城市。）teilnehmen可分，an引活动并接D；erkunden直接接A。Ich sehe mir das Schloss an.（我看看这座宫殿。）也可用schaue mir ... an；不能仅凭这两个动词就给观看认真程度固定排名。
