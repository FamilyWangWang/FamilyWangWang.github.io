19-4 说与问的动词（Sprechen und Fragen）

本组第 4 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 29 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

提问的价值在于得到对方真正想表达的信息。下面先看如何开口和追问，再区分引用原话与说明大意。

sprechen 可表示语言能力或较中性的谈话，reden 更口语，sagen 通常带具体内容。提问时，fragen 面向某人提出问题，nachfragen 是进一步追问，anfragen 则常指向机构正式询问是否可行。

精讲

  1. Redebeitrag / Gesprächsbeitrag：相对完整的一段发言 / 推进共同谈话的一次内容贡献。

  2. Gegenfrage / Fangfrage / Suggestivfrage：以问回应 / 诱使失误 / 通过措辞暗示答案。

  3. Sprechweise / Aussprache：措辞、节奏和语气的方式 / 词语发音方式。

  4. Gesprächsverlauf / Sprecherwechsel：谈话的实际进程 / 发言权从一人转到另一人。

  5. Redewendung / Umschreibung：整体意义固定的表达 / 不直接用目标词的转述。

  6. Rederecht / Redezeit：程序中获准发言的权利 / 一次发言可用的时间。

  7. Gesprächseinstieg / Gesprächsabschluss：引出主题的开始阶段 / 总结并结束谈话的阶段。

  8. Gesprächsführung / Gesprächsebene：有目的地组织谈话 / 谈话的内容、关系或情感层面。

  9. Redeabsicht / Ausdrucksweise：发言希望实现的交际目的 / 选择词句表达思想的方式。

  10. Redetempo / Gesprächspause：说话速度 / 谈话中暂时无人发言的停顿。

  11. Unterton / Andeutung：可听出的附加态度 / 没有完全明说的提示。

  12. Erwiderung：针对前一发言作出的直接回应，语体比普通回答更书面。

  13. verkünden / kundtun：正式公开宣布消息 / 公开表达态度或意愿。

  14. artikulieren：清楚地用语言表达需求、利益或立场，也可指清晰发音。

  15. sinngemäß / unausgesprochen：按整体意义转述 / 未说出口但可由情境理解。

易混辨析

  • sprechen / reden / sagen：谈话或语言能力 / 口语交谈 / 说出具体内容。
  • erzählen / berichten：按情节讲述 / 较正式、按事实报告。
  • fragen / nachfragen / anfragen：一般提问 / 信息不足再问 / 正式询问能否提供。
  • antworten / erwidern / entgegnen：中性作答 / 直接回应 / 常带反方意见。
  • hören / zuhören：听见或得知 / 有意识专注听某人。
  • wiedergeben / zitieren：复述内容 / 准确引用原话。

语境回收

Im Gespräch stellt die Journalistin zuerst eine offene Frage. Der Zeuge beschreibt den Ablauf und erwähnt ein wichtiges Detail. Als etwas undeutlich bleibt, fragt sie nach und bittet um den genauen Wortlaut. Sie lässt ihn ausreden, hört aufmerksam zu und gibt seine Aussage anschließend mit eigenen Worten wieder.

谈话中，记者先提出开放式问题。证人描述过程并提到一个重要细节；有些内容不清楚时，她继续追问准确原话。她让对方说完、专心倾听，随后用自己的话复述证词。

采访者发现措辞含糊便请对方说清，听完才复述。这样能核对意思，也保留逐字引用与转述之间的差别。
