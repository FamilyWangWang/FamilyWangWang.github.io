19-6 同意与反对（Zustimmen und Ablehnen）

本组第 6 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 23 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

不阻止某件事未必表示赞同，有权批准也不同于个人认可。把同意的对象和主体说清，分歧才不会被一句“大家同意了”盖住。

同意观点时用 jemandem zustimmen，同意方案可用 etwas befürworten，涉及本人知情许可则是 in etwas einwilligen。反对的强度也不同：Vorbehalt 是保留，Ablehnung 是拒绝，Protest 是公开反对。

精讲

  1. Einigkeit / Einmütigkeit：核心问题上没有分歧 / 所有人自愿持相同立场的高度一致。

  2. Zustimmungserklärung / Einverständniserklärung：明确同意的声明 / 当事人知情同意安排的文件。

  3. Vetorecht / Widerspruchsrecht：阻止决定生效的权限 / 对决定正式提出异议的权利。

  4. Gegenposition / Abgrenzung：与当前主张相反的立场 / 明确说明自身与另一立场不同。

  5. Boykott / Verweigerung：有组织地拒绝参加或合作 / 个体或机构有意拒绝履行。

  6. Zustimmungsrate：同意人数或票数所占比例，不等同于意见完全一致。

  7. Konsensfindung / Konsensfähigkeit：寻找共同方案的过程 / 能在差异中达成方案的能力。

  8. Widerspruchsfreiheit：多个陈述或规则能够同时成立、彼此没有逻辑冲突。

  9. Kompromissbereitschaft：愿意为共同方案在部分要求上作出让步。

  10. Unvereinbarkeit：两个职位、原则或要求不能同时成立或履行的状态。

  11. bejahen / verneinen：明确肯定问题或主张 / 明确否定。

  12. zugestehen：承认对方某一点成立，或允许其享有某种权利、利益。

  13. opponieren / boykottieren：公开持续反对 / 以拒绝参加、购买或合作进行抵制。

  14. votieren：在正式讨论或表决中投票、明确表态，常接 für / gegen + A。

  15. vorbehaltlos / unvereinbar：没有附加保留 / 无法与另一要求同时成立。

易混辨析

  • Zustimmung / Einwilligung：一般赞同 / 对涉及自身的措施作出正式许可。
  • zustimmen / befürworten：同意某人或提案，支配第三格 / 支持某方案，带第四格。
  • akzeptieren / tolerieren：接受条件或事实 / 虽有差异仍允许存在。
  • ablehnen / absagen：拒绝请求观点 / 取消约定或谢绝邀请。
  • widersprechen / bestreiten：表达相反意见 / 否认某事实主张。
  • Enthaltung / Gegenstimme：不投赞成也不投反对 / 明确投反对票。

语境回收

Im Ausschuss befürwortet die Mehrheit den Antrag. Zwei Mitglieder stimmen nur unter Vorbehalt zu, eines widerspricht und stimmt dagegen. Eine weitere Person enthält sich der Stimme. Obwohl die Meinungen geteilt sind, akzeptiert die Gruppe die Mehrheitsentscheidung. Von einer umstrittenen Aussage distanzieren sich anschließend alle einstimmig.

委员会多数支持申请，两名成员有保留地赞同，一人反对并投反对票，另一人弃权。尽管意见分裂，小组仍接受多数决定；之后所有人一致与一项有争议的说法划清界限。

多数票使决定通过，但保留、弃权与反对仍在。后来共同与另一声明划清界限，不能倒推出此前所有人意见相同。

把词放回句子

Eine Einwilligung ist Zustimmung zu einer Handlung; ein Vorbehalt begrenzt die Zustimmung.（Einwilligung表示对行动的同意，保留意见限制同意范围。）Eine Enthaltung ist keine Zustimmung; Dissens bezeichnet fehlenden Konsens.（弃权不是赞成，Dissens表示未形成共识。）词语描述与具体表决规则分别阅读。

Ich stimme dem Vorschlag zu; die zuständige Stelle genehmigt den Antrag.（我赞同建议，有权机构批准申请。）Sie duldet das Verhalten, obwohl sie es nicht gutheißt.（她虽不认可这种行为，却容忍它。）zustimmen接第三格，genehmigen和dulden接第四格。

Er bestreitet die Behauptung und widersetzt sich der Anweisung.（他否认主张，并抵抗指令。）Der Beschluss wurde einstimmig gefasst.（决定一致通过。）原故事只有多数通过，不能为了换词而改写为einstimmig。
