19-9 抽象名词（Abstrakte Nomen）

本组第 9 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 31 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

抽象名词把事件、关系和判断压缩成可继续讨论的对象。比如 weil sich etwas verändert 可以名词化为 wegen der Veränderung，dass etwas notwendig ist 可以概括为 die Notwendigkeit. 但名词化越多，句子越容易变得沉重；学习时既要掌握它们的精确含义，也要能在名词结构和清楚的动词句之间切换。

精讲

  1. Wesen / Besonderheit：对象的核心性质 / 使其区别于一般情况的特有之处。
  2. Abstraktion / Konkretisierung：从个案提取一般结构 / 将一般想法变成明确内容。
  3. Allgemeinheit / Einzelheit：普遍层面或公众整体 / 构成整体的一个具体细节。
  4. Gesamtheit / Einheit：所有相关部分合成的整体 / 多个部分构成的一个单元。
  5. Vielfalt / Vielschichtigkeit：多种形式并存 / 由多个相互关联层面构成。
  6. Komplexität / Einfachheit：相互依赖部分多 / 不含多余复杂性。
  7. Eindeutigkeit / Mehrdeutigkeit：只允许一种合理解释 / 允许多种解释。
  8. Geltung / Relevanz：规则被承认为有效并适用 / 信息与当前问题相关且有影响。
  9. Tragweite：决定或变化可能影响的范围和重要程度，不只是眼前后果。
  10. Machbarkeit / Umsetzbarkeit：在资源技术下能否完成 / 能否转化为具体行动。
  11. Zugänglichkeit / Transparenz：能否找到、理解和使用 / 过程和依据能否由外部检查。
  12. Vollständigkeit / Nachvollziehbarkeit：是否没有缺项 / 他人能否沿步骤理解。
  13. Vergleichbarkeit / Übertragbarkeit：能否按共同尺度比较 / 结果能否适用于其他情境。
  14. Belastbarkeit / Beständigkeit：承受压力仍保持功能 / 随时间保持稳定。
  15. Wirksamkeit / Zweckmäßigkeit / Brauchbarkeit / Überprüfbarkeit：实际有效、适合目的、可实际使用、可独立检查。

易混辨析

  • Thema / Inhalt：文本或谈话在谈什么 / 其中具体说了什么。
  • Eigenschaft / Merkmal：对象拥有的特质 / 被选来识别或分类的特征。
  • Rahmen / Umfang：允许或规定的边界 / 实际包含的内容和数量。
  • Entwicklung / Veränderung：强调随时间逐步演变 / 只说明前后不同。
  • Behauptung / Beweis：提出某事为真 / 用可靠材料或论证支持它为真。
  • Bedarf / Anspruch：实际需要 / 基于权利、规则或期望可以提出的要求。

名词化提示

  • 动词不定式作中性名词时首字母大写：prüfen → das Prüfen，通常只用单数。
  • 常见后缀：-ung（begründen → die Begründung）、-heit/-keit（ähnlich → die Ähnlichkeit）、-nis（erkennen → die Erkenntnis）。
  • 名词结构适合标题、定义和专业文本；日常表达中，清楚的动词句往往更自然：wegen der Verzögerung der Lieferung 可改为 weil sich die Lieferung verzögert。

语境回收

Gegenstand der Untersuchung ist die Entwicklung des Projekts. Die erste Annahme stimmt nicht mit dem tatsächlichen Verlauf überein. Mehrere Hinweise sprechen für einen Zusammenhang zwischen der neuen Struktur und der höheren Stabilität, liefern aber noch keinen Beweis. Deshalb formuliert der Bericht seine Schlussfolgerung vorsichtig und erklärt auch den Umfang der verbleibenden Unsicherheit.

调查对象是项目的发展。最初的假设与实际进程不符。多项线索表明新结构与更高稳定性有关，但尚未构成证明。因此报告谨慎表述结论，同时说明仍存不确定性的范围。
