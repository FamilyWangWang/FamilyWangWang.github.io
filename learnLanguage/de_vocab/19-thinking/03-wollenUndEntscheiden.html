19-3 意愿与决定（Wollen und Entscheiden）

本组第 3 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 28 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

wollen、planen和entscheiden并不重复：它们分别帮助说明想做什么、怎样安排和最后选了什么。沿一次进修选择来读。

Wunsch 是想要某事，Absicht 是准备采取行动，Entscheidung 则是在选项之间形成确定结果。日常礼貌表达多用 möchten；讨论正式计划时常用 beabsichtigen、vorhaben 和 sich entscheiden für / gegen。

精讲

  1. Entschlusskraft / Entscheidungsreife：及时作决定的能力 / 信息已足够、可以负责决定的状态。

  2. Entscheidungsfreiheit / Entscheidungsbefugnis：自主选择的空间 / 依据职务或规则拥有的权限。

  3. Entscheidungsprozess / Beschlussfassung：从问题到实施的全流程 / 有权机构正式通过决定。

  4. Entscheidungsspielraum / Wahlfreiheit：规则内仍可选择的范围 / 不受不当限制地选择的自由。

  5. Willenskraft / Willensfreiheit：持续执行意图的能力 / 能否自主形成意志的哲学与法律观念。

  6. Beweggrund / Handlungsabsicht：促使行动的内在理由 / 已准备落实的明确意图。

  7. Handlungsoption / Wahlmöglichkeit：情境中可采取的行动 / 实际存在的选择机会。

  8. Zielsetzung / Zielkonflikt：明确的目标表述 / 两个目标无法同时充分实现。

  9. Priorisierung / Präferenz：确定处理先后 / 在可行选项中相对偏爱。

  10. Selbstbestimmung / Fremdbestimmung：依自身价值安排生活 / 行动主要由外部力量规定。

  11. Alternativlosigkeit / Wunschvorstellung：被表述为无可行替代 / 由愿望塑造、未必现实的设想。

  12. Entscheidungsgrundlage：决定所依据的事实、标准和资料，应与决定本身分开评价。

  13. sich festlegen / sich umentscheiden：明确选定一个方案 / 放弃原选择并改选。

  14. absehen / anvisieren：决定不采取某行动 / 将日期或结果作为目标。

  15. gewillt：正式说明某人已明确愿意行动，通常作表语并接 zu + Inf.。

易混辨析

  • Wunsch / Absicht：希望某事发生 / 已准备采取行动。
  • Plan / Vorhaben：包含步骤安排 / 准备实施的事项本身。
  • Entschluss / Entscheidung：强调意志和决心 / 强调选项选择结果。
  • wählen / auswählen：一般选择或投票 / 从一组中按标准挑选。
  • vorziehen / bevorzugen：用第四格表示偏好对象、第三格表示比较对象 / 一般以第四格表达偏好。
  • zurücknehmen / widerrufen：一般收回言论提案 / 按正式或法律程序撤销意思表示。

语境回收

Nach langem Zögern entscheidet sich Mara für eine Weiterbildung. Sie hat die Absicht, ihre Kenntnisse zu erweitern, und setzt dieses Ziel an erste Stelle. Zunächst wählt sie zwischen mehreren Optionen und zieht auch einen Onlinekurs in Betracht. Schließlich fasst sie einen Entschluss, legt den Starttermin fest und beginnt, ihren Plan umzusetzen.

Mara 犹豫很久后决定参加继续教育。她打算扩展知识，并把这一目标放在首位。她先在多个选项中挑选，也考虑在线课程，最后下定决心、确定开始日期，并着手落实计划。

Mara先明确扩展知识的目标，比较课程并把网课纳入考虑，再定下开始日期、着手落实。愿望、选择与执行在同一段中逐步推进。

把词放回句子

Eine Absicht richtet sich auf eine Handlung; ein Entschluss betont die gefasste Entscheidung.（意图指向行动，决心突出已作出的决定。）Eine Alternative ist eine andere mögliche Lösung, Bereitschaft die Offenheit zum Handeln.（替代方案是另一种可能解决办法，行动意愿说明愿不愿做。）这些信息仍不保证已经落实。

Ich möchte den Onlinekurs besuchen und ziehe ihn dem Präsenzkurs vor.（我想上网课，并在两者中更愿选它。）Sie entschließt sich zur Anmeldung.（她下定决心报名。）vorziehen用第四格标出偏好的对象，第三格标出比较对象；zu后再接entschließen的决定内容。

Wir setzen den Plan um und überdenken ihn bei neuen Informationen.（我们落实计划，也在有新信息时重新考虑。）Sie nimmt freiwillig teil.（她自愿参加。）freiwillig说没有受到强迫，不能从中推断能力、权限或计划一定可行。
