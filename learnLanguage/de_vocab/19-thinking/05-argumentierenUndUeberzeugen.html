19-5 争论与说服（Argumentieren und Überzeugen）

本组第 5 篇 · 共 9 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 26 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

意见要有说服力，需要把理由和可核查的支持接起来。先读清各方主张，再看异议使原观点如何调整。

一段完整论证通常包含 These、Argument、Begründung 和 Beleg。überzeugen 是凭理由让对方接受观点，überreden 更强调促使对方去做某事，不一定靠充分论据。面对反方意见，可以先承认 Einwand，再尝试 entkräften。

精讲

  1. Argumentationslinie / Argumentationsgang：贯穿全文的论证主线 / 前提推进到结论的完整路径。

  2. Beweisführung / Beweiskraft：系统证明主张的过程 / 材料支持结论的强度。

  3. Gegenrede / Gegenthese：反方发言 / 与原主张相对立的命题。

  4. Fürsprecher / Widersacher：公开支持并辩护的人 / 持续反对的一方。

  5. Glaubwürdigkeit：来源或说话者值得相信的程度，不等同于陈述已经得到证明。

  6. Streitfrage / Kernthese：尚有明显分歧的问题 / 整篇论证最中心的主张。

  7. Argumentationsstruktur / Argumentationskette：各部分的组织关系 / 逐步相互依赖的推理环节。

  8. Argumentationslücke / Gegenbehauptung：缺少必要推理步骤 / 为反驳而提出的相反陈述。

  9. Begründungszusammenhang：多个理由彼此关联并共同支持结论的结构。

  10. Widerlegung / Entkräftung：证明主张不成立 / 削弱或消除理由、疑虑的效力。

  11. Rhetorik / Polemik：有目的组织语言的方法 / 重尖锐攻击的对抗性言辞。

  12. Überredung：使人按要求行动，但并不必然使其真正接受理由。

  13. Sachlichkeit：集中讨论事实和问题本身，避免人身攻击和无关情绪。

  14. bekräftigen / kontern：再次明确立场或要求 / 迅速以反驳回应。

  15. haltlos / unanfechtbar：毫无根据 / 难以有效反驳或依法继续挑战。

易混辨析

  • Argument / Begründung：支持结论的一条理由 / 解释判断为何成立的完整理由。
  • Beleg / Beweis：支持陈述的资料 / 足以确认命题成立的严格证明。
  • Einwand / Widerspruch：针对论点提出的异议 / 两个陈述逻辑不相容。
  • überzeugen / überreden：凭理由改变看法 / 劝对方采取行动。
  • diskutieren / debattieren：一般交换观点 / 正式公开意见交锋。
  • entkräften / widerlegen：使论据失去力量 / 证明陈述错误。

语境回收

In der Debatte stellt Lea eine These auf und begründet sie mit zwei Argumenten. Ein Teilnehmer bringt einen stichhaltigen Einwand vor. Lea versucht nicht, ihn zu überreden, sondern erläutert ihre Daten und führt einen zusätzlichen Beleg an. Gemeinsam prüfen beide das Gegenargument, entkräften einen Teil und handeln schließlich einen Kompromiss aus.

辩论中 Lea 提出论题并用两个论点说明。有人提出有力异议，她没有试图劝对方照做，而是解释数据并补充证据。双方共同检查反论点，削弱其中一部分，最终协商出妥协方案。

Lea承认对方理由中的成立部分，再限制原主张。削弱理由、证明错误和谈成折中并非同一结果。

把词放回句子

Ein Argument stützt eine These; ein Beleg liefert überprüfbares Material.（论据支持主张，佐证提供可核查材料。）Ein Einwand benennt einen Grund gegen die bisherige Aussage.（异议指出反对原有陈述的理由。）提出反对还不等于已经证明对方错误。

Sie belegt die These mit Daten und widerlegt eine falsche Behauptung.（她用数据支持主张，并驳倒错误断言。）Er überzeugt die Gruppe von dem Vorschlag und plädiert für einen Versuch.（他使团体信服建议，主张试行。）von接使人相信的内容，für接倡议支持的方案。

Eine Vermittlerin vermittelt zwischen den Seiten.（调解者在各方之间促成理解。）Das Argument ist stichhaltig, doch ein Kompromiss bleibt nötig.（理由经得起检验，但仍需要折中。）理由有力不表示所有利益已经一致，讨论还要处理各方目标。
