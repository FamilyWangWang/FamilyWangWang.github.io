15-4 网络与 WLAN（Netzwerk und WLAN）

本组第 4 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Internetanschluss 是运营商提供的外部接入，Heimnetz 是家中设备之间的本地网络。Router 连接不同网络并分配数据路径，Modem 负责适配接入线路信号；家用设备常把两者集成在一起。德国日常说无线局域网通常用 WLAN。出现问题时，可依次检查 Verbindung、Signalstärke、IP-Adresse、DNS-Server 和运营商是否有 Störung。

精讲

  1. Internet / Netzwerk / Heimnetz：全球网络 / 互联设备系统 / 住宅本地网络。
  2. LAN / WLAN / Funknetz：有线局域网 / 无线局域网 / 无线通信网络总称。
  3. Router / Modem / Accesspoint / Repeater：路由转发 / 接入信号适配 / 无线接入点 / 信号中继。
  4. Mesh-Netzwerk / Netzwerkkabel / Ethernet：协同无线节点 / 网线 / 有线局域网标准。
  5. IP-Adresse / MAC-Adresse / Subnetz / Gateway：网络地址 / 接口标识 / 子网 / 出网节点。
  6. DNS-Server / DHCP：域名解析 / 自动分配网络配置。
  7. Netzwerkname / SSID / WLAN-Passwort / Netzwerkschlüssel：可见名称 / 技术标识 / 访问密码两种称呼。
  8. Verschlüsselung / WLAN-Sicherheitsstandard：加密过程 / 无线安全标准。
  9. Frequenzband / Funkkanal：频率范围 / 范围内具体信道。
  10. Bandbreite / Datenrate / Latenz / Ping：承载能力 / 传输量 / 延迟 / 测试请求。
  11. Download / Upload：远程到本地 / 本地到远程。
  12. Internetanschluss / Glasfaseranschluss / DSL-Anschluss / Kabelanschluss：互联网接入总称及三种线路方式。
  13. Verbindung / Verbindungsabbruch / Störung / Ausfall：连接 / 意外断开 / 异常 / 完全不可用。
  14. Reichweite / Signalstärke / Netzwerkadapter：覆盖范围 / 信号强度 / 网络硬件接口。
  15. Firewall / VPN / Gastnetz / Captive-Portal：通信过滤 / 保护隧道 / 访客网络 / 公共网络登录页。

易混辨析

  • Internet / WLAN：全球网络服务 / 设备接入本地网络的无线方式。
  • Bandbreite / Datenrate：链路理论或可用承载能力 / 实际或标称传输量。
  • Störung / Ausfall：功能异常或不稳定 / 服务完全不可用。
  • WLAN-Passwort / Router-Passwort：加入无线网络的密码 / 管理路由器设置的密码，不应默认相同。

语境回收

Im Arbeitszimmer ist die Signalstärke gering und die Verbindung bricht oft ab. Timo stellt deshalb einen Repeater zwischen Router und Arbeitszimmer auf. Danach verbindet er den Laptop erneut mit dem WLAN und führt einen Geschwindigkeitstest durch. Download und Upload sind besser, aber die Latenz bleibt hoch. Er prüft nun, ob beim Provider eine Störung vorliegt.

书房信号弱且经常断线，Timo 于是在路由器与书房之间放置中继器。重新连接 WLAN 并测速后，下载上传速度改善，但延迟仍高，因此他继续检查运营商是否发生故障。
