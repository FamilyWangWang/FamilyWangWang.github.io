15-8 数据与隐私（Daten und Privatsphäre）

本组第 8 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Datenschutz 关注个人数据如何被合法、公平和安全地处理，Privatsphäre 是个人不受无关观察和干预的私人领域。账户安全方面，可靠且不重复使用的 Passwort、Passwortmanager 和多因素登录比频繁使用简单变体更有效。收到索取 Zugangsdaten、制造紧迫感的消息时要警惕 Phishing；重要文件应有独立 Sicherungskopie，并定期验证能否恢复。

精讲

  1. Daten / Information / Personenbezug：可处理记录 / 有意义内容 / 数据与可识别个人的关联。
  2. Datenschutz / Privatsphäre：个人数据处理规则 / 私人生活领域。
  3. Datenverarbeitung / Datenerhebung / Datenspeicherung：处理总称 / 收集 / 保存。
  4. Datenübertragung / Datennutzung / Datenweitergabe / Datenlöschung：传输 / 使用 / 提供他方 / 删除。
  5. Datenbestand / Datensatz / Datenbank / Datei：数据集合 / 结构化记录 / 数据库 / 文件。
  6. Metadaten / Standortdaten / Kontaktdaten / Gesundheitsdaten：描述性 / 位置 / 联系 / 健康数据。
  7. Zugangsdaten / Benutzerkonto / Passwort / Passphrase：登录信息 / 账户 / 密码 / 长口令。
  8. Passwortmanager / Zwei-Faktor-Authentisierung / Einmalcode：密码工具 / 双因素证明 / 一次性代码。
  9. Authentisierung / Authentifizierung / Autorisierung：提供身份证明 / 系统验证证明 / 决定访问权限。
  10. Verschlüsselung / Ende-zu-Ende-Verschlüsselung：加密总称 / 仅通信端点可解密的设计。
  11. Backup / Sicherungskopie / Datenverlust：备份外来词 / 德语说法 / 数据无法使用。
  12. Datenpanne / Sicherheitslücke / Schadsoftware / Phishing：个人数据事件 / 可利用缺陷 / 恶意软件 / 诱骗攻击。
  13. Tracking / Cookie / Datenschutzeinstellung：行为追踪 / 浏览器状态数据 / 隐私控制选项。
  14. Einwilligung / Auskunftsrecht / Löschrecht / Widerspruchsrecht：同意及三类数据主体权利。
  15. Verantwortliche / Auftragsverarbeiter：决定处理目的方式的主体 / 按其指示处理的主体。

易混辨析

  • Datenschutz / Datensicherheit：个人数据合法处理与权利 / 各类数据的机密性、完整性和可用性保护。
  • Authentisierung / Authentifizierung / Autorisierung：出示证明 / 验证证明 / 分配或检查权限。
  • Backup / Synchronisierung：为恢复而保留独立副本 / 让多处内容保持一致，误删也可能同步。
  • anonymisieren / pseudonymisieren：不可合理恢复个人关联 / 用替代标识降低直接关联，后者仍可能重新关联。

语境回收

Nach einer Phishing-Warnung prüft Aylin ihre Benutzerkonten. Sie ändert nicht einfach überall dasselbe Passwort, sondern speichert für jedes Konto ein eigenes Passwort im Passwortmanager. Außerdem aktiviert sie die Zwei-Faktor-Authentisierung und bewahrt die Wiederherstellungscodes getrennt auf. Wichtige Dateien verschlüsselt sie und erstellt eine zusätzliche Sicherungskopie.

收到钓鱼警告后，Aylin 检查自己的账户。她没有在所有地方使用同一个新密码，而是在密码管理器里为每个账户保存独立密码。她还开启双因素认证、分开保存恢复代码，并加密重要文件、制作额外备份。

自测

  1. 个人数据处理规范领域是 _______。 2. 数据与可识别个人的关联是 _______。
  2. 文件时间格式等描述数据是 _______。 4. 保存独立恢复副本是 _______。
  3. 冒充可信方骗取登录信息是 _______。 6. 可被攻击利用的缺陷是 _______。
  4. 用户向系统提供身份证明是 _______。 8. 系统决定访问权限是 _______。
  5. 使用密钥保护数据用 _______。 10. 使数据不再可关联个人用 _______。
答案
  1. Datenschutz 2. Personenbezug 3. Metadaten 4. Backup / Sicherungskopie
  2. Phishing 6. Sicherheitslücke 7. Authentisierung 8. Autorisierung
  3. verschlüsseln 10. anonymisieren
