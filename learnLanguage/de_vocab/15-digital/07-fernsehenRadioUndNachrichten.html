15-7 电视广播与新闻（Fernsehen, Radio und Nachrichten）

本组第 7 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 19 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

德语里 Sender 可指电视台、广播台，也可指发送信号的设备；具体含义看语境。节目可在固定 Sendezeit 通过电视或广播 ausstrahlen，也可之后在 Mediathek 点播。新闻内容要区分事实性 Meldung、较完整的 Bericht、现场性的 Reportage 和表达立场的 Kommentar；遇到 Eilmeldung 时尤其要核对来源和后续更新。

词表

「用」列：留空 ＝ 可放心主动使用｜👂 ＝ 听懂即可，不必主动说｜❌ ＝ 避免（粗俗／过时／不合场合） 「支配」列：A ＝ 第四格，D ＝ 第三格；sich⁴／sich³ 表示反身代词用哪个格

固定表达

Nachrichten live verfolgen + A 实时关注新闻 继续核对更新 A2
einen Bericht recherchieren + A 为报道调查资料 使用多项可靠来源 B1
ein Interview führen + A；mit + D 进行采访 区分提问与回答 A2
eine Quelle überprüfen + A 核实新闻来源 查找原始文件和作者 A2
eine Pressemitteilung veröffentlichen + A 发布新闻稿 它代表发布机构立场 B1
eine Eilmeldung bestätigen + A 确认突发消息 等待可靠独立来源 B1

精讲

  1. Fernsehen / Fernseher：电视媒介和活动 / 电视设备。
  2. Sender / Fernsehsender / Radiosender / Rundfunk：频道或发射方 / 电视台 / 广播台 / 广播电视体系。
  3. Mediathek / Streamingdienst / Programm / Sendung：媒体库 / 流媒体服务 / 节目安排 / 单个节目。
  4. Serie / Folge / Staffel：系列作品 / 单集 / 一季。
  5. Film / Dokumentarfilm：影片总称 / 非虚构纪录影片。
  6. Nachrichtensendung / Nachricht / Meldung：新闻节目 / 信息总称 / 简短事实消息。
  7. Bericht / Reportage / Beitrag / Interview / Kommentar：报道 / 现场叙事 / 单项内容 / 采访 / 观点评论。
  8. Liveübertragung / Wiederholung：同步直播 / 再次播出。
  9. Untertitel / Synchronfassung / Originalfassung：字幕 / 配音版 / 原声版。
  10. Audiodeskription / Gebärdensprache：画面口述辅助 / 手语语言服务。
  11. Empfang / Antenne / Satellit / Kabelanschluss：接收状态 / 天线 / 卫星 / 有线接入。
  12. Fernbedienung / Lautstärke / Sendezeit / Einschaltquote：遥控器 / 音量 / 播出时间 / 收视统计。
  13. Redaktion / Journalist / Reporter / Korrespondent：编辑部 / 新闻工作者 / 现场记者 / 驻地领域记者。
  14. Nachrichtenagentur / Pressemitteilung / Quelle：新闻供稿机构 / 机构新闻稿 / 信息来源。
  15. Schlagzeile / Eilmeldung：醒目标题 / 紧急发布消息。

易混辨析

  • Fernsehen / Fernseher：媒介或看电视活动 / 物理电视机。
  • Meldung / Kommentar：报告新事实 / 明确表达分析和立场。
  • Reportage / Bericht：强调现场体验和叙事 / 侧重系统陈述事实。
  • Pressemitteilung / unabhängiger Bericht：机构自我发布的信息 / 媒体独立调查制作的报道。

语境回收

Eine Eilmeldung erscheint in der Mediathek-App. Jonas liest nicht nur die Schlagzeile, sondern öffnet auch den Bericht und prüft die genannte Quelle. Später sieht er die Nachrichtensendung live. Eine Korrespondentin berichtet vor Ort, danach folgt ein Kommentar. Jonas unterscheidet dabei zwischen bestätigten Fakten und der Bewertung des Kommentators.

媒体库应用出现一条突发消息。Jonas 不只看标题，还打开报道并核对所引来源。稍后他观看直播新闻：驻地记者现场报道，之后是评论。他注意区分已确认事实和评论员的评价。

自测

  1. 电视媒介整体是 _______。 2. 单个系列节目的一集是 _______。
  2. 一部系列的一个制作周期是 _______。 4. 现实主题非虚构影片是 _______。
  3. 现场观察和叙事体裁是 _______。 6. 表达作者立场的体裁是 _______。
  4. 机构主动发给媒体的文本是 _______。 8. 突发快速发布的消息是 _______。
  5. 切换频道用 _______。 10. 调查核实新闻事实用 _______。
答案
  1. Fernsehen 2. Folge 3. Staffel 4. Dokumentarfilm
  2. Reportage 6. Kommentar 7. Pressemitteilung 8. Eilmeldung
  3. umschalten 10. recherchieren
