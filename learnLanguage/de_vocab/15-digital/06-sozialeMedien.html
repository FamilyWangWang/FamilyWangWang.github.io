15-6 社交媒体（Soziale Medien）

本组第 6 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 18 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

社交媒体内容可出现在 Feed、Timeline、Story 或 Livestream 中。Reichweite 表示触达账户的范围，Impression 表示内容被显示的次数，两者不能直接互换。发布前应确认受众是 öffentlich 还是 privat，尊重他人的肖像、著作和个人信息；遇到冒充、骚扰或欺诈内容时，可以保存证据并使用平台的举报和屏蔽功能。

精讲

  1. Social-Media-Plattform / Profil / Konto：社交平台 / 公开资料页面 / 技术账户。
  2. Benutzername / Profilbild / Biografie：账户名 / 头像 / 简介。
  3. Feed / Timeline：连续内容流 / 按时间或算法组织的内容流，常近义。
  4. Beitrag / Post / Story / Reel：发布内容总称 / 单条帖子 / 限时形式 / 短视频形式。
  5. Livestream / Kommentar / Antwort：实时直播 / 公开评论 / 针对评论的回复。
  6. Like / Gefällt-mir-Angabe / Reaktion：点赞外来词 / 德语界面说法 / 更广的快速反馈。
  7. Follower / Abonnent：关注账户的人 / 订阅内容的人，平台用法可能重叠。
  8. Reichweite / Impression / Aufruf / Klick：触达范围 / 显示次数 / 打开播放次数 / 点击次数。
  9. Hashtag / Markierung / Erwähnung / Verlinkung：主题标签 / 标记 / 点名 / 建立链接。
  10. Direktnachricht / Gruppenbeitrag / Community：私信 / 群组帖子 / 用户社群。
  11. Moderator / Inhaltsrichtlinie / Hausregel：管理人员 / 平台内容规则 / 群组内部规则。
  12. Algorithmus / Empfehlung：排序处理规则 / 算法给出的内容建议。
  13. Trend / Challenge / viral：流行主题 / 模仿任务 / 快速广泛传播。
  14. Influencer / Creator：具有受众影响力的创作者 / 内容创作者广义称呼。
  15. öffentlich / privat：广泛可见 / 仅限授权对象可见。

易混辨析

  • Profil / Konto：他人看到的资料页面 / 保存登录、设置和数据的账户。
  • Reichweite / Impressionen：触达的不同用户范围 / 内容被显示的总次数。
  • Markierung / Erwähnung：在图片内容上标记 / 在文字中用账户名提及。
  • Follower / Freund：单向关注者 / 平台中的双向关系，具体含义依平台。

语境回收

Mila veröffentlicht einen Beitrag auf einer Social-Media-Plattform. Vorher prüft sie, ob ihr Profil öffentlich oder privat ist. Sie verlinkt die Originalquelle und kennzeichnet die Werbung. Nach der Veröffentlichung vergleicht sie Reichweite, Impressionen und Klicks. Einen beleidigenden Kommentar meldet sie der Moderation und blockiert anschließend den Nutzer.

Mila 在社交平台发布帖子。她先检查资料页是公开还是私密，链接原始来源并标明广告。发布后，她比较触达范围、显示次数和点击数。遇到侮辱性评论时，她向管理方举报并屏蔽该用户。

自测

  1. 连续展示内容的页面流是 _______。 2. 平台短视频形式常叫 _______。
  2. 内容被显示一次的统计是 _______。 4. 内容触达用户的范围是 _______。
  3. 井号开头的主题词是 _______。 6. 私下直接消息是 _______。
  4. 执行社群规则的人是 _______。 8. 短时间大量传播是 _______。
  5. 取消关注用 _______。 10. 向平台举报内容用 _______。
答案
  1. Feed 2. Reel 3. Impression 4. Reichweite
  2. Hashtag 6. Direktnachricht 7. Moderator / Moderatorin 8. viral
  3. entfolgen 10. melden
