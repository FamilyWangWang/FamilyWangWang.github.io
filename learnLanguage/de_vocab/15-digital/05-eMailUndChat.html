15-5 邮件与聊天（E-Mail und Chat）

本组第 5 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 26 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

从草稿到发件箱、送达与阅读提示，是不同阶段。下面把这些状态接到抄送和群聊，帮助理解一条消息到了哪一步。

电子邮件适合较正式、可归档的沟通，聊天工具更适合快速对话。邮件中的 Betreff 应说明主题，Anhang 要在发送前确认；CC-Feld 让所有收件人看到副本对象，BCC-Feld 则隐藏其他密送地址。群聊里可用 Erwähnung 指定提醒某人，也可把高频群组 stummschalten，但重要信息仍应通过明确渠道确认。

精讲

  1. E-Mail / Nachricht / Chat / Messenger：邮件消息 / 消息总称 / 即时对话 / 即时通信服务。

  2. Postfach / E-Mail-Konto / E-Mail-Adresse：邮箱空间 / 邮件账户 / 邮箱地址。

  3. Absender / Empfänger / Betreff：发件方 / 收件方 / 主题行。

  4. Nachrichtentext / Signatur / Anhang / Dateianhang：正文 / 签名信息 / 附件总称 / 数字文件附件。

  5. Entwurf / Posteingang / Postausgang / Gesendet-Ordner：草稿 / 收件箱 / 待发区 / 已发文件夹。

  6. Spamordner / Papierkorb：垃圾邮件区 / 删除暂存区。

  7. Verteiler / Mailingliste：收件地址组 / 订阅式邮件分发系统。

  8. CC-Feld / BCC-Feld：可见抄送栏 / 隐藏密送栏。

  9. Antwort / Weiterleitung：针对原消息回复 / 把原消息转给他人。

  10. Lesebestätigung / Zustellbestätigung：打开提示 / 到达系统提示。

  11. Thread / Chatverlauf：同主题消息串 / 按时间保存的聊天记录。

  12. Einzelchat / Gruppenchat / Chatgruppe：一对一对话 / 多人对话 / 持续群组空间。

  13. Kanal / Direktnachricht：主题频道 / 私下直接消息。

  14. Emoji / Reaktion / Erwähnung：图形字符 / 对消息反馈 / 点名提醒。

  15. ungelesen / gelesen / angeheftet：未读 / 已读 / 固定置顶。

易混辨析

  • Postausgang / Gesendet-Ordner：等待或正在发送 / 已成功发出的副本。
  • CC / BCC：收件地址彼此可见 / 密送地址对其他收件人隐藏。
  • Lesebestätigung / Zustellbestätigung：可能表明已打开 / 只表明技术上已送达。
  • archivieren / löschen：保留但移出当前列表 / 移入删除区域。

语境回收

Im Posteingang findet Sara eine ungelesene E-Mail mit einem Dateianhang. Sie prüft Absender und Betreff, öffnet den Anhang aber erst nach der Rückfrage beim Absender. Danach antwortet sie auf die Nachricht und setzt ihre Kollegin ins CC. Im Gruppenchat zitiert sie die wichtigste Passage und heftet die Nachricht für alle Teilnehmer an.

Sara 在收件箱发现一封带附件的未读邮件。她核对发件方和主题，并向发件人确认后才打开附件。随后她回复邮件并抄送同事；在群聊中，她引用最重要的一段并将消息置顶。

Sara在打开附件前回查发送者，之后抄送、引用并置顶。核验与分享是不同步骤，群里置顶也取决于权限；故事描述这次操作，不保证每个普通成员都能改全群置顶。

把词放回句子

Ein Entwurf ist noch nicht gesendet; im Postausgang warten Nachrichten auf den Versand.（草稿尚未发出，发件箱里的消息等待发送。）Der Spamordner enthält als verdächtig eingeordnete Nachrichten.（垃圾邮件夹保存被判为可疑的消息。）消息在不同文件夹的位置说明处理状态，不能由副本在已发送夹就推定对方收到。

Das BCC-Feld verbirgt die BCC-Adressen vor anderen Empfängern.（密送栏向其他收件人隐藏相应地址。）Eine Zustellbestätigung zeigt technische Zustellung; der Chatverlauf bewahrt den Austausch.（送达确认显示技术送达，聊天记录保留往来。）送达、打开与理解分开；BCC不因此加密正文。

Eine Direktnachricht geht an bestimmte Konten; eine Erwähnung nennt ein Konto im Gespräch.（私信发给指定账户，提及在谈话中点名。）Sara leitet eine Nachricht weiter und schaltet den Gruppenchat stumm.（Sara转发消息并静音群聊。）weiterleiten是leitet … weiter，stummschalten是schaltet … stumm；静音不表示屏蔽，也不保证关闭全部定向提醒。
