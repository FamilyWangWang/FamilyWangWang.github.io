15-2 软件与操作动词（Software und Bedienung）

场景导入

先想这一步要留下什么结果，再选择动词：复制、移动、改名、删除与卸载各不相同。下面沿一份报告的整理过程阅读。

Betriebssystem 管理硬件和基础功能，Programm、Anwendung、App 则完成具体任务。图形界面里常见 Fenster、Menü、Symbol 和 Schaltfläche。操作文件时要区分 kopieren、verschieben、umbenennen 和 löschen；安装更新前最好先保存工作，并确认下载来源和系统兼容性。

精讲

  1. Betriebssystem / Software / Programm：基础系统 / 软件总称 / 单个程序。

  2. Anwendung / App：完成具体任务的应用 / 尤其在应用商店生态中的简称。

  3. Benutzeroberfläche / Fenster / Menü：用户界面 / 可操作显示区域 / 功能列表。

  4. Symbol / Schaltfläche / Werkzeugleiste：图标 / 命令按钮 / 工具按钮栏。

  5. Taskleiste / Desktop：运行程序和状态区域 / 登录后的主工作区。

  6. Ordner / Datei / Dateiname：组织容器 / 数据文件 / 文件名称。

  7. Dateiendung / Pfad / Verknüpfung：格式后缀 / 位置路径 / 快捷链接。

  8. Zwischenablage / Papierkorb：复制剪切的临时区域 / 删除文件暂存处。

  9. Einstellung / Update：可修改选项 / 修复或功能更新。

  10. Installation / Deinstallation：部署软件 / 按系统流程移除软件。

  11. anklicken / doppelklicken / auswählen / markieren：单击 / 双击 / 选择 / 标记。

  12. kopieren / ausschneiden / einfügen：复制 / 剪切 / 粘贴。

  13. verschieben / umbenennen / löschen / speichern：移动 / 改名 / 删除 / 保存。

  14. herunterladen / hochladen / aktualisieren：下载 / 上传 / 更新。

  15. entpacken / komprimieren：解压 / 压缩。

易混辨析

  • Programm / Datei：执行任务的软件 / 被程序读取或写入的数据。
  • kopieren / verschieben：保留原件并创建副本 / 改变对象位置。
  • schließen / beenden：关闭某个窗口或文档 / 结束整个程序或过程。
  • löschen / Papierkorb leeren：删除 / 清空回收站；不是所有删除都进入回收站，网络位置、应用和永久删除方式可能不同。

语境回收

Mara installiert eine neue Anwendung und legt auf dem Desktop eine Verknüpfung an. Sie öffnet einen Ordner, sortiert die Dateien nach Datum und filtert nach PDF-Dateien. Einen Bericht benennt sie um, kopiert ihn in ein Archiv und komprimiert den Ordner. Vor dem Update speichert sie alle Änderungen und beendet das Programm.

Mara 安装了一款新应用，并在桌面创建快捷方式。她打开文件夹，按日期排序并筛选 PDF。她给一份报告改名、复制进归档目录并压缩文件夹。安装更新前，她保存全部修改并退出程序。

Mara依次筛选、改名、复制与压缩，最后保存再退出。kopiert保留原件，komprimiert改变归档体积或形式，beendet结束程序；这些动作不能合成一个模糊的“处理文件”。

把词放回句子

Das Betriebssystem stellt grundlegende Dienste bereit; die Benutzeroberfläche zeigt die Bedienmöglichkeiten.（操作系统提供基础服务，用户界面呈现操作入口。）Die Dateiendung ist ein Teil des Dateinamens.（扩展名是文件名的一部分。）只改这个后缀通常不转换内部格式，文件名称与文件内容要分别理解。

Die Zwischenablage hält kopierten Text bereit; gelöschte Dateien können im Papierkorb liegen.（剪贴板存复制文字，删除文件可能在回收站。）Mara möchte eine Datei in einen anderen Ordner verschieben.（Mara想把文件移动到另一文件夹。）不是所有删除都进Papierkorb；verschieben说换位置，不能拿回收站替代备份。

Sie lädt ein Archiv herunter, lädt die fertige Datei hoch und entpackt das Archiv.（她下载归档、上传完成文件并解开归档。）Eine benutzerfreundliche Oberfläche erleichtert diese Schritte.（易用界面让这些步骤更方便。）herunterladen是远程到本机，hochladen方向相反，entpacken说还原归档内容；可分形式是lädt … herunter和lädt … hoch。
