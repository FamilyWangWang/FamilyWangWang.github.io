15-1 电脑硬件（Computerhardware）

本组第 1 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

购买或排查电脑时，先区分整机、内部部件和外接设备。Prozessor 负责执行计算任务，Arbeitsspeicher 保存当前使用的数据，SSD 和 Festplatte 则用于长期存储。Bildschirm、Tastatur、Maus 等属于输入输出设备。描述接口时常用 Anschluss，描述物理连接件则常用 Stecker、Kabel 和 Adapter。

精讲

  1. Computer / PC / Rechner：计算机总称 / 个人电脑缩写 / 德语常用称呼。
  2. Desktopcomputer / Laptop / Notebook / Tabletcomputer：固定桌面机 / 便携折叠电脑 / 笔记本同义词 / 平板电脑。
  3. Gehäuse / Hauptplatine：保护内部部件的外壳 / 连接各部件的主板。
  4. Prozessor / Prozessorkern / Taktfrequenz：中央处理器 / 单个计算核心 / 工作节拍频率。
  5. Arbeitsspeicher / Speichermodul：临时运行内存 / 可安装的内存模块。
  6. Festplatte / SSD / Speicherplatz：机械长期存储 / 闪存长期存储 / 可用容量。
  7. Grafikkarte / Grafikprozessor：图形扩展部件 / 其中的计算核心。
  8. Netzteil / Lüfter / Kühlkörper：供电转换 / 风冷部件 / 被动散热金属件。
  9. Bildschirm / Monitor / Display：屏幕总称 / 电脑显示器 / 电子显示面板。
  10. Auflösung / Bildwiederholrate：像素数量 / 每秒画面更新次数。
  11. Tastatur / Taste / Maus：键盘整体 / 单个按键 / 指针设备。
  12. Touchpad / Touchscreen：触控板 / 可直接触摸操作的屏幕。
  13. Drucker / Scanner：数字内容输出到纸张 / 纸张内容转为数字数据。
  14. USB-Anschluss / HDMI-Anschluss / Netzwerkanschluss：通用数据供电 / 数字影音 / 有线网络接口。
  15. Stecker / Kabel / Adapter：插接部件 / 连接线 / 转换部件。

易混辨析

  • Arbeitsspeicher / Speicherplatz：运行中的临时内存容量 / 长期保存文件的容量。
  • Bildschirm / Monitor：显示表面或设备总称 / 电脑外接显示设备。
  • Akku / Batterie：通常可充电 / 日常多指不可充电，但技术语境需看具体类型。
  • Anschluss / Stecker：设备上的接口 / 插入接口的物理连接件。

语境回收

Lena schließt einen zweiten Monitor an ihren Laptop an. Weil der HDMI-Anschluss nicht passt, verwendet sie einen Adapter. Danach ändert sie die Auflösung. Der Rechner läuft langsam, obwohl auf der SSD noch genug Speicherplatz frei ist. Sie prüft deshalb den Arbeitsspeicher und stellt fest, dass nur ein Speichermodul eingebaut ist.

Lena 给笔记本连接第二台显示器。由于 HDMI 接口不匹配，她使用了转接器，然后调整分辨率。电脑运行缓慢，但固态硬盘仍有足够空间，因此她检查运行内存，发现只装了一条内存模块。
