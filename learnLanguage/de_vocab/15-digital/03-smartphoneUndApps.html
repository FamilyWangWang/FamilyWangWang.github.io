15-3 手机与 App（Smartphone und Apps）

本组第 3 篇 · 共 8 篇 | 本篇 60 个词汇条目 + 12 个固定表达 | 精讲 15 项 另有 16 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

Handy 是德国日常对手机最常见的称呼，Smartphone 强调可安装应用和联网功能。接入移动网络通常需要实体 SIM-Karte 或 eSIM。使用 App 时要留意 Berechtigung、Standortzugriff、In-App-Kauf 和 Abonnement；锁屏密码、生物识别和系统更新共同保护设备，但重要账户仍应使用独立而可靠的登录保护。

精讲

  1. Smartphone / Handy / Mobiltelefon：智能手机 / 德国日常说法 / 中性正式称呼。
  2. SIM-Karte / eSIM / PIN / PUK：实体用户卡 / 数字配置 / 识别码 / 解锁码。
  3. Mobilfunkanbieter / Mobilfunkvertrag / Prepaidkarte：运营商 / 后付或约定合同 / 预付产品。
  4. Guthaben / Tarif / Datenvolumen / Flatrate：余额 / 计费方案 / 流量额度 / 固定价不限量范围。
  5. Roaming / Mobilfunknetz / Empfang / Funkloch：漫游 / 移动网络 / 信号状态 / 无覆盖区域。
  6. Telefonnummer / Vorwahl / Kontakt / Kontaktliste：号码 / 前缀 / 联系人条目 / 通讯录。
  7. Anruf / Anrufliste / Mailbox：来电通话 / 通话记录 / 语音信箱。
  8. Klingelton / Vibration / Lautstärke / Benachrichtigung：铃声 / 震动 / 音量 / 通知。
  9. Sperrbildschirm / Startbildschirm / Statusleiste：锁屏 / 主屏 / 状态栏。
  10. App / App-Store / Berechtigung：应用 / 应用平台 / 系统权限。
  11. Standortzugriff / Kamerazugriff / Mikrofonzugriff：位置 / 摄像头 / 麦克风访问权限。
  12. In-App-Kauf / Abonnement：应用内单次购买 / 周期订阅。
  13. Bildschirmzeit / Energiesparmodus / Flugmodus：屏幕使用时间 / 节能模式 / 飞行模式。
  14. Hotspot / QR-Code：网络共享入口 / 二维信息图码。
  15. Fingerabdrucksensor / Gesichtserkennung / Gerätecode：指纹 / 面部 / 本地代码认证。

易混辨析

  • PIN / PUK：日常解锁 SIM 的识别码 / 多次输错 PIN 后的恢复码。
  • Guthaben / Datenvolumen：预付金额余额 / 可使用的移动数据额度。
  • Sperrbildschirm / Startbildschirm：设备锁定界面 / 解锁后的应用主界面。
  • In-App-Kauf / Abonnement：应用内购买行为 / 可能自动续费的持续服务关系。

语境回收

Noah richtet ein neues Smartphone ein. Er aktiviert die eSIM, wählt einen sicheren Gerätecode und richtet den Fingerabdrucksensor ein. Danach installiert er nur die benötigten Apps und prüft Standort-, Kamera- und Mikrofonzugriff. Für unterwegs begrenzt er das Datenvolumen und aktiviert bei niedrigem Ladestand den Energiesparmodus.

Noah 设置新手机。他激活 eSIM，选择可靠的设备码并设置指纹传感器。之后他只安装需要的应用，并检查位置、摄像头和麦克风访问权限。外出时他限制流量，并在电量低时开启节能模式。

自测

  1. 德国日常说"手机"常用 _______。 2. 数字配置的 SIM 是 _______。
  2. 多次输错 PIN 后的解锁码是 _______。 4. 资费周期内的移动数据量是 _______。
  3. 无信号覆盖区域是 _______。 6. 锁定时显示的界面是 _______。
  4. 应用内部购买是 _______。 8. 共享移动网络的功能是 _______。
  5. 在触摸屏上滑动用 _______。 10. 关闭声音提示用 _______。
答案
  1. Handy 2. eSIM 3. PUK 4. Datenvolumen
  2. Funkloch 6. Sperrbildschirm 7. In-App-Kauf 8. Hotspot
  3. wischen 10. stummschalten
