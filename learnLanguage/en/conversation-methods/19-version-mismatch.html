19 双方说的“那个文件”，可能已经不是同一份

你改好了幻灯片，同事却说数据仍然错。两人可能没有观点分歧，只是打开了不同版本。若先争论谁认真看了，文件对象的错位就会变成人际冲突。

同一个名称掩盖了不同对象

Sam: The total on slide four is still wrong.
Lea: I corrected it this morning.
Sam: I'm looking at the file in yesterday's email.
Lea: That's the earlier version. I uploaded the revised file to the shared folder at eleven.

Sam 指出第四页总数有误，Lea 说早上改过。Sam 正在看昨天邮件的文件，Lea 改的是十一点上传的共享文件。关键证据是来源和更新时间，不是双方谁语气更肯定。

对齐以后，指出应采用的具体版本

Please open “Review-Friday-v2” in the shared folder. The total on slide four is 240 in that version.

“请打开共享文件夹里的 Review-Friday-v2。这一版第四页总数是 240。”名称和一个可比对的位置帮助确认；这些是虚构文件与数据，不是实际报告的结论。

对象一致以后，再讨论内容对不对

Sam: I have the new file now. I see 240. I'll check it against the source figures.

“我现在打开新版了，看到 240。我会再与原始数据核对。”版本对齐并没有证明数据正确，它只让双方开始谈同一个对象。这个区别也适用于旧菜单、旧时间表与不同截图，不应把“你看错版本”当作自动结束所有质疑的理由。
