42 希望、预计与承诺：同一个结果，依据并不相同

都说“明天发”，希望、预计和承诺却在报告不同东西。与其把词排成由弱到强，不如看看材料到了哪一步、自己准备承担哪项行动。本篇比较缺图片说明与获批文件已备妥两种状态。

结果仍依赖别人时，说明愿望与当前预计

I hope to send the description tomorrow afternoon. The text is complete, but I am still waiting for the photograph captions. The provider said she would reply tomorrow morning, so I expect to have enough time to check them before sending. That is my current estimate, not a confirmed delivery time. If the captions do not arrive, I can send you the text for review, but not the complete public version. I will update you at noon whether or not the reply has come. Please do not plan a public announcement around the full description until I confirm that it is ready.

我希望明天下午发介绍。文字已完成，仍在等图片说明。提供者说会明早回复，因此预计还有时间核对后发送；这是当前估计，不是确认的交付时刻。说明不到时，可先发文字供审阅，不能发完整公开版。无论收到回复没有，中午都会更新。确认完整材料准备好以前，请别据此安排公告。

第一封消息的预计来自提供者说明天回复。文字已经完成，图片说明仍在等待，所以可以承诺中午更新，却不能把完整公开稿当作已备妥。

这一处给出可依赖的行动：不论外部回复来没来，中午都会告诉对方。未知结果也有跟进办法，听者因此可以等待信息，而不必猜是否还在推进。

确实能够承担时，给出动作与时间

The full description has now been checked, including the photograph captions. I will send the approved file tomorrow by ten. I have already prepared the email and confirmed which address to use. You can use that file for the announcement once it arrives; please do not use the earlier draft in the shared folder. The organiser has approved this version, and I am responsible for sending it. If I discover a new issue before ten, I will contact you immediately rather than leave you waiting without an update. At the moment, there is no outstanding information from another person that the sending depends on.

完整介绍连同图片说明都已核对。我明天最迟十点发获批文件，邮件和收件地址也已准备。收到后可用于公告，请不要用共享文件夹的旧稿。组织者已批准此版，我负责发送。十点前若发现新问题，会立即联系，不让你无更新地等。当前没有仍依赖别人提供的待补信息。

第二封消息有核对、批准、收件地址和邮件准备作依据，发送承诺便接到具体版本与十点期限。旧草稿也被区分，接收者知道该用哪份。

收到以后才能用于公告，使发送与使用顺序清楚。若新问题出现，立即更新保护的是合作过程，而不是宣布任何未来都不会变化。

本篇表达怎样发挥作用

hope to 表达目标，expect to 报告预期，will update 在原文中承担反馈动作。has now been checked 提供新状态，will send 指定发送承诺。once it arrives 限定使用阶段，不能从 send 推出已收到。
