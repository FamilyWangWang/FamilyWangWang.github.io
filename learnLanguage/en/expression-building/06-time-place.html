06 加入时间和地点，让安排清楚又容易读

时间和地点的作用，是让一个行动变成可以落实的安排。它们不需要都抢在动作前面，也不能只靠把中文原句从左到右搬过去。先确定在做什么，再看哪些补充能消除听者的疑问。

朋友把一本图书馆的书借给你，你准备帮忙归还。你先说明自己会还书，再把时间和去向补齐。

I’ll return the book.

I’ll return the book to the library tomorrow afternoon.

我会把书还回去。第二句进一步说明：我明天下午会把书还到图书馆。

第二句保留 I’ll return the book 这个核心，再用 to the library 说明去向，用 tomorrow afternoon 说明时间。听者不用等到句尾才知道主要动作，也能接着找到完成安排所需的信息。return 已经包含“归还”，不需要为了对应中文的“回去”再添一个意思重复的词。

谈话正在说什么，会影响开头

如果朋友问的是“明天下午你打算做什么”，以时间开头就很自然，因为先接住了对方的问题。

Tomorrow afternoon, I’ll return the book to the library.

明天下午，我会把书还到图书馆。

把时间放在开头并不改变归还这项行动，只是先建立时间背景。后面的 I’ll return 仍然保持主语在动词前。不是每次加时间都需要前置；如果对方问“那本书怎么办”，前一个以 I 开头的版本也很清楚。

信息越来越多时，可以分成两句

你还想解释自己当天会经过图书馆，以及还书后会告诉朋友。把所有补充塞在一个句子里，会让安排越来越难抓住。可以先给出行动，再补充后续。

I’ll return the book to the library tomorrow afternoon. I’ll let you know once it’s done.

我明天下午会把书还到图书馆。还完后我会告诉你。

第一句交代归还安排，第二句说明通知。once it’s done 在这里指归还完成以后，it 的内容由前一句提供。分句并没有减少必要信息，只是把两个先后发生的动作分别说清。

时间和地点的顺序没有一套可以覆盖所有句子的机械口诀。先让读者找到行动，再根据问题决定开头；如果补充已经形成另一个动作，就考虑另起一句。下一篇会讨论更容易影响承诺的补充：原因和条件。
