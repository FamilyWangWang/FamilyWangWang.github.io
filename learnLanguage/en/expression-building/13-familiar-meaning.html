13 一个熟词，为什么不能只记一个译法

同一个熟词，接“消息”时在说收到，接身体状态时又在说变化。只背一个中文译词，遇到新句子就容易卡住。本篇沿收到消息、需要休息与准备文件三件事，观察后面的成分怎样帮我们理解当前动作。

阅读起点：想把已经知道的事情说成完整句子时读。能借中文含义辨认谁做什么即可，搭配和说法的区别随例子解释。 句子的动作和对象仍分不清时，先看句子主干，再回来组织表达（按需补读）。 连同讲解通读约2—4分钟，仅为篇幅估算；选读局部可更短。

先从能够认出的意思开始

你正在等待同事回复，后来需要说明消息已经收到。

I got your message this morning.

我今天早上收到了你的消息。

got 是 get 的过去式。这里后面跟 your message，表示收到消息，不是在说“变成消息”。动作的对象帮你确定了当前用法。收到不代表已经处理；如果要确认内容是否看过，需要另外说明。

换一种补充，意思也会改变

你又想说明等得久了，自己的状态开始变化。这次句子说明身体状态，而不是收到一件东西。

I’m getting tired. Can we take a short break?

我开始觉得累了。我们能短暂休息一下吗？

getting 后面跟形容词 tired，表示进入疲倦的状态。这里的 get 不是“收到”，也不是一个需要另找宾语的动作。进行形式突出变化正在发生，后面的请求说明你为什么提到这种状态。

结构可以提供线索，不能代替核对

你还想请同事把文件准备好。这里涉及的已经是让某个对象进入一种状态。

Could you get the file ready before lunch?

你可以在午饭前把文件准备好吗？

get the file ready 把对象 the file 和结果状态 ready 连起来，表示使文件准备妥当。它与 get tired 的参与人不同：前者有被处理的文件，后者说明主语自身的变化。ready 也不能漏掉；只说 get the file，通常会转向取得文件，不再明确要求准备好。

这三个例子可以沿后面的成分读：消息是收到的对象，tired 是主语进入的状态，the file 与 ready 则是要处理的对象和目标状态。结构提供理解线索，但遇到新搭配仍需核对，不能把任意名词或形容词接到 get 后面。
