20 提出请求时，把人和需要的东西放对位置

一个请求里通常有接受请求的人，也有希望得到的东西或行动。只记“请求”这个动词，容易把两种对象放在同一个位置。完整搭配会告诉你：向谁说，要求什么，以及行动由谁完成。

请求一件东西

你希望同事提供一份文件副本。

I asked Maya for a copy of the file.

我向 Maya 要了一份文件副本。

ask someone for something 中，Maya 是接受请求的人，a copy of the file 是所请求的东西，for 把它接出来。这里报告已经提出请求，不代表 Maya 已经发来副本。如果结果重要，还应接着说明是否收到。

请求一个行动

你希望对方不是仅仅提供副本，而是先检查日期。

I asked Maya to check the dates.

我请 Maya 去检查日期。

这里的 to check 说明要求对方进行的行动。它与 for a copy 的名词对象不同。这一句说明请求已经提出，并不保证检查已完成；如果结果重要，还需要接着说明当前进度。

向某人提问，不等于向他索要东西

你真正需要的也可能只是一个状态答案。

I asked Maya whether the file was ready.

我问 Maya 文件是否准备好了。

whether 后面给出所问的问题。asked 在三个句子里都出现，但 for a copy、to check 和 whether the file was ready 分别组织物品、行动与信息。结构能帮助你判断当前请求到底在做什么。

需要帮助时，先分清希望得到物品、行动还是答案，再选完整结构。这样对方更容易回应，你也更容易判断请求是否已经得到满足。
