滑雪：说明第一次的担心，也听懂雪场里的说法

pick up 为什么是学会，shot 为什么说腿累坏了？本篇以李明的一次虚构滑雪出游串起初次经验、租装备、上课和休息，学习表达不确定、请求说明、分享感受，并读懂雪场常见词汇。

阅读起点：有相应生活或工作任务时可以直接选读。先借中文含义跟住谁在问、谁在回应；生词和搭配在对应情境里理解。 实际交谈中听到词却不明白时，先学怎样请对方换说法（按需补读）。 连同讲解通读约12—21分钟，仅为篇幅估算；选读局部可更短。

场景背景：滑雪度假不只有雪道上的时间

ski resort 是滑雪度假区，ski trip 是滑雪出游，skiing holiday 也可用于度假话题。美国的 Colorado、Utah、Vermont、California，以及欧洲 Alps（阿尔卑斯山）等地名，可能出现在朋友的旅行计划中；它们提示地点，不替读者判断某个雪场今天适合谁。

après-ski 源于法语，指滑雪后的休闲与社交活动，可以是吃饭、聊天或其他安排，不要求喝酒。本篇在上午课程后午休，再决定下午做什么。学习的是如何问清与反馈，具体滑雪技术由现场合格教练指导。

经验、课程和装备，分别怎样问

I've never skied before. 是以前从未滑过。Is it hard to pick up? 问难不难学会，pick up a skill 指学到一项技能；get the hang of it 则是逐渐摸到门道。例如 I'm starting to get the hang of it.（我开始摸到一点门道了。）既可用于滑雪，也可用于其他新技能，不保证具体学习天数。

gear 统称装备：skis 是雪板，boots 是雪靴，poles 是雪杖，helmet 是头盔，goggles 是护目镜。rental shop 是租赁店，availability 问是否有适合的库存，fit 问是否合身，adjusted for you 说按本人情况调整。

layers 是分层穿衣，base layer 指贴身层，mid layer 指中间保暖层，outer layer 指外层。套餐可能不含衣物，问 Which items are included?（包含哪些东西？）再问需自备什么，胜过把“装备都能租”当成无需准备。

行程话题里的 Presidents' Day weekend 常指二月美国相关长周末，是否放假、出行日期及价格要看当年与自己的安排。比较课程、租赁和场地费用后再预订，不靠“哪州最好”来决定。

课堂里，短问题也能准确说明担忧

bunny hill / bunny slope 是初学练习坡的俗称，bunny 是小兔子；beginner slope 是较直白的说法。How do I stop? 直接问怎样停下，That's the part I'm most worried about. 说明最担心哪一部分，教练才能回应和观察。

snowplow 在滑雪话题中指犁式，pizza 是帮助记住形状的比喻；有时还会听到 french fries 比喻两板平行。它们是课堂里可能出现的记忆词，不能拼成一份自学动作教程，尤其不应把“平行就加速”作为所有情况的操作指令。

memory aid 是记忆辅助，move on 是进入下一步。I'd like to go over that again.（我想再过一遍刚才的内容。）可以用于没听懂、不确定的环节；把问题说出来，比用自嘲代替真实反馈更有帮助。

从累了、饿了，说到接下来适不适合

My legs are shot. 是腿累坏了，shot 在这个语境中不是中枪。epic 在朋友聊天里可夸“特别棒”，powder 指松软的新雪；这类感受词说明说话人的体验，不保证某种雪质适合初学者。

I'd rather stop … than push through. 是宁愿停下来，也不硬撑；would rather 与 than 连起选择。base lodge 是山脚的服务休息处，lodge 也可随场合指山间住宿。hot toddy 是一种含酒精的热饮名称，不能当成保暖或恢复体力的治疗方法，茶、热巧克力和食物也都是选择。

I could go for something warm. 表示“我想来点热的”，could go for 用来委婉说想吃、想喝什么。a million calories 用“一百万卡路里”夸张说活动很耗体力；它是说笑，不是运动能量计算。

green run 在美国常见分级里属于较容易的雪道。green circle、blue square、black diamond、double black diamond 分别是绿色圆圈、蓝色方块、黑色菱形、双黑菱形的标记，具体相对难度仍按该雪场图示。I can handle that. 是“我能应付”，应建立在实际判断上；I value my life. 则是很强的玩笑“我还想活呢”，真有担忧时应直接告诉教练。

读懂票务与提示，才能接到自己的行程

lift ticket 是缆车或雪场通行票，ski pass 也可能涉及多日或季节通行产品。Epic Pass、Ikon Pass 是可能看到的产品名称，不等于一张票能在所有雪场、所有日期用；比较日期限制、预订、课程和租赁是否另算，再看总价。

欧洲一些雪场常用蓝、红、黑区分难度，与美国标识不同，不能把颜色机械换算成自己的能力。可参看 NSAA 雪道标识说明及本文末的 FIS 准则，认清让行、观察和保持距离等提示，再按现场指导选择。

altitude 是海拔，altitude sickness 是高原病相关的名称。去高海拔地区要了解个人适应情况；不舒服可说 I don't feel well. I need help.（我不舒服，需要帮助。）本篇不把喝水或休息几分钟当成治疗，也不把戴好头盔理解为可以超出能力冒险。
