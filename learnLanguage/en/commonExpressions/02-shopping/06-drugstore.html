英语药店：问清商品，再把用药问题交给药剂师

找到了货架，不等于已经知道该选哪种药。这篇把找商品、药房柜台取药和日用品结账分成三个独立过程，沿每次问答看清哪些信息已确认，哪些还在等待。店价、积分服务和处理安排都属于模拟场景。

阅读起点：有相应生活或工作任务时可以直接选读。先借中文含义跟住谁在问、谁在回应；生词和搭配在对应情境里理解。 实际交谈中听到词却不明白时，先学怎样请对方换说法（按需补读）。 连同讲解通读约11—19分钟，仅为篇幅估算；选读局部可更短。

场景背景：综合商店里，药房柜台承担不同工作

drugstore 可指同时卖药品与日用品的综合店，pharmacy counter / pharmacist 是药房柜台、药剂师；英国也常见 pharmacy、chemist。柜台位置、提供的服务和商品范围看现场，并不因为名称相似就完全相同。

prescription medicine / OTC (over-the-counter) 区分处方药与非处方药。能在货架看到产品，只解决位置问题；是否适合自己、怎样与正在服用的药协调，另请药剂师核对。下面三段把咨询、取药和普通购物分开，不要求读者先决定药品才能学会提问。

货架前：问区别，先得到合适的咨询对象

老李在一家有药房柜台的综合药店寻找感冒用品，走到货架后拿起两盒比较。普通店员帮他联系药剂师。

You：

Excuse me, where do you guys keep the cold medicine?

打扰一下，你们感冒药放哪儿？

Staff：

Aisle 3, right side — next to the pain relievers.

3号通道右边——止痛药旁边。

You：

Hey, what's the difference between these two cold medicines?

你好，这两种感冒药有什么区别？

Staff：

Let's ask the pharmacist to check the ingredients and the drowsiness warnings with you.

我们请药剂师和你一起看看成分与嗜睡警示吧。

You：

Good idea. I'll ask before I choose. Also, where are the things for a sore throat?

好主意，我先问清楚再选。对了，缓解嗓子疼的用品在哪里？

Staff：

Same aisle — there's lozenges, throat spray, the whole nine yards. The pharmacist can help with those too.

同一条通道，有含片、喉喷剂等很多选择。这些也可以问药剂师。

问位置，再把区别问到成分与警示

Where do you keep …? / right side / next to 是放在哪、右侧、旁边；cold medicine / pain relievers / sore throat 分别是感冒药、止痛药、喉咙疼。What's the difference between these two? 才问两款区别，these two 需要实物或名称指明。

ingredients / drowsiness warnings / drowsy 是成分、嗜睡警示、犯困。knock someone out 在随意话里可夸张形容让人睡过去或失去意识，不能当作任意药物对所有人的效果描述。店员把问题交给药剂师，顾客 I'll ask before I choose 也明确还未选药。

lozenges / throat spray / the whole nine yards 是含片、喉喷剂、相关选择一应俱全的夸张说法，不是全都要买。FDA成分核对说明提醒不同产品可能含同一成分；所以日用、夜用或品牌名称不能替代具体标签与专业核对。

取处方药：找到记录，再问续配是否符合条件

另一段发生在药房柜台。老李来取已准备好的处方药；药剂师核对身份并询问，之后听到自动续配请求。

You：

Hi, I need to pick up a prescription. The last name is Li, L-I.

你好，我来取处方药。姓李，L-I。

Pharmacist：

Alright, let me pull that up... Yep, it's ready. Can I see your ID?

好，我查一下…有了，准备好了。能看一下你的证件吗？

You：

Sure, here's my driver's license.

好的，这是我的驾照。

Pharmacist：

Great. Do you have any questions about this medication? Any side effects you've been noticing?

好的。这个药你有什么问题吗？有注意到什么副作用吗？

You：

No, I've been on it for a while now. I'm just doing a refill.

没有，我已经吃了一阵子了。我就是来续药的。

Pharmacist：

Perfect. Your copay is fifteen dollars.

好，这次你需要支付的保险共付金额是15美元。

You：

Can I set up automatic refills? It's a pain to remember every time.

我可以设自动续药吗？每次记太麻烦了。

Pharmacist：

I'll check whether this prescription is eligible. If it is, we can arrange refills and text you when they're ready.

我先查这份处方是否符合条件。如果符合，我们可以安排续配，准备好后发短信。

You：

Sounds good. Thanks for checking!

好，谢谢你帮忙查！

这次药已备好，自动续配仍需另查

pick up a prescription / last name / pull that up 在此是取按处方配好的药、姓氏、调出记录；ID / driver's license 是身份证件、驾照，本人物用驾照，不等于任何地点都只认它。it's ready 已确认的是这一次的药。

medication / side effects / I've been on it for a while / refill 分别是药物、副作用、已服用一阵、续配。on it 的 it 指这项药，不是站在药盒上；续配不等于自己重新决定剂量。copay 是保险安排中的共付金额，15美元不是普遍售价或全部医疗自付费用。

It's a pain to remember every time. 说每次记着很麻烦，pain 在此是烦人的事。set up automatic refills / eligible / if it is 是申请自动续配、符合条件、如果符合；店员先查再决定。shoot you a text 也可随意说发短信，收到何种通知仍看实际服务。末句只谢帮查，未确认注册成功。

标签与服务名称，先认识，再问具体安排

insurance card、generic、brand name、drive-through pharmacy 分别是保险卡、仿制药、品牌名称、驾车取药窗口。是否适用自己的处方、费用如何、需要什么资料，可以向该药房问清，名称本身不作承诺。acetaminophen / paracetamol 是同一种成分的不同常见叫法，FDA的说明也指出这一点，不是两种药可以重复叠加的理由。

Tylenol、Advil、DayQuil、NyQuil、Benadryl、Pepto-Bismol、Tums、Neosporin 是可能在货架遇到的品牌或系列名称，配方和适用条件看具体包装；Band-Aid 还常作为创可贴的品牌名出现。先把这些名称认作查找标签的线索，再请药剂师说明适用情况。英国NHS相关处方收费、豁免和流程随地区与个人情况不同，需按具体地区和资格询问。
