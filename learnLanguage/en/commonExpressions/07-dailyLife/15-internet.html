安装网络：套餐、接线和故障分开问

“家里没网”可能指没开通、设备没接好，也可能只是无线连接出问题。本篇先选套餐，再按一套同轴有线宽带设备的说明连接，最后联系客服。运营商与报价均为虚构，设备步骤限本例，不套用到光纤或其他型号。

把速度、流量与优惠期分开听

Set up internet 是开通网络，ZIP code / postcode 分别是美式和英式邮编说法，最终可用性还要查完整地址。300 meg 或 megs 通常口语指 300 Mbps，gig 在这里指千兆速率级别；GB 或 TB 却是数据量。Plenty 是对目前需求说够用，不表示所有家庭都够。

Promo 是 promotion 的简称，指促销。45 美元 goes up to 75 美元，是月 13 起涨到 75；优惠价与常规价都应写进比较。

以后比较方案，还会遇见哪些词

download 与 upload 分别是下载和上传，bandwidth 常说连接可承载的数据速率，latency / ping 说响应延迟，不能只用下载数字判断视频通话或游戏体验。Mbps 是每秒兆比特，MB/s 是每秒兆字节，理想换算相差八倍，实际还受传输开销影响。

router rental 是设备租费，兼容设备能否自购、退还期限和提前终止费应看条款；retention deal 是挽留客户的优惠，不保证一开口就有。英国可能遇到 engineer 表示上门技术人员，Openreach 也不是所有网络的共同接入商。涉及最低速度承诺时，查Ofcom 消费者指引，确认服务商、方案与适用条件，再提出问题。

Month-to-month 是按月持续的安排，不自动代表没有合同；ETF 是 early termination fee，即提前结束可能收取的费用，是否适用按方案核。Speed test 是测速，保留条件和结果，才便于服务方复核。
