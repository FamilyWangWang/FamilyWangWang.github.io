自动售货机：钱付了，东西没出来，怎样说清楚

薯片卡住、另一台饮料机没出货、第三次刷卡被拒，是三个独立片段。先稳住动作，再记录、联系和确认结果，不用把小额损失说成不值得问。机器编号、金额及补救方案均为虚构。

阅读起点：有相应生活或工作任务时可以直接选读。先借中文含义跟住谁在问、谁在回应；生词和搭配在对应情境里理解。 实际交谈中听到词却不明白时，先学怎样请对方换说法（按需补读）。 连同讲解通读约13—23分钟，仅为篇幅估算；选读局部可更短。

场景背景：先描述状态，不必自己诊断机器

vending machine 是自动售货机，snack machine 卖零食，beverage machine 卖饮料。It ate my money 像机器吃掉钱，是抱怨；报障再补金额、机器编号和没出货的事实，客服才能查这一笔。

接住烦恼，再找能处理的人

Took my money / hanging there / stuck 分别说收了钱、挂在那里、卡住。Seriously? 表达不是吧的懊恼，朋友先说 frustrating（令人烦恼），才接住情绪。It's the principle 说在意公平处理，不只在意 1.50 美元。

Facilities 是楼宇设施管理部门，可帮联系 operator（运营方），open it up 是打开机器，需要授权人员。Give it a nudge / rock it 是推一下或摇动，识词也要知道本例明确不这样做；no luck 是没成功，不是继续加力的信号。保留 reference（编号），比再付款想撞下商品更能推进。

Refund 是退款，promo code 在这里是可选补领码，二者不同。keypad 是按键区，star key 是星号键，make your selection 是选择商品，具体操作依型号。Make it right 说妥善解决问题；当前先确认收到码与操作说明，不把收到码写成饮料已经到手。

被拒的提示，不足以说明钱最终怎样处理

Card reader 是读卡器，transaction declined 是交易请求被拒。设备 finicky 是不太好使、很挑剔，a couple of tries 是几次尝试；这种评价不证明连续碰卡没有风险。Nope 是更随意的 No。

从部位和商品名称接着问

slot 是槽口，coin slot 是投币口，coin return 可指退币装置或退币处，refund 才说退款。Tap to pay / contactless payment 是感应支付，接受哪种卡或钱包看标志。

英国 crisps 通常对应美式袋装薯片 chips，chocolate bar 是巧克力棒，candy bar 是糖果棒，biscuits 常说饼干。Ribena、Lucozade 或 Fanta 是商品品牌，选择看本机和配料。building manager 或商店人员能否退钱，先核运营方，不用国别卫生排名或固定加价倍数解释故障。

How much did you lose? 中 lose 问这次未得到商品而损失的金额，不是断言银行最终已完成扣款。Dispensing 是 dispense 的-ing 形式，如 The machine is not dispensing drinks（机器不出饮料）；看见状态词就能把问题说明得更具体。
