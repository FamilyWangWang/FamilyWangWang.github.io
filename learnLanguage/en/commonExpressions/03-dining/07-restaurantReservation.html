英语餐厅预约：改了人数和时间，最后再核一遍

同一笔预约经历初订、修改和到店三步：四位晚8:15，后来改成五位晚8:30。卡座先只是请求，到店才确认。跟住哪些信息已经确定，就不会把一句“我记下了”误当全部安排完成。

阅读起点：有相应生活或工作任务时可以直接选读。先借中文含义跟住谁在问、谁在回应；生词和搭配在对应情境里理解。 实际交谈中听到词却不明白时，先学怎样请对方换说法（按需补读）。 连同讲解通读约12—20分钟，仅为篇幅估算；选读局部可更短。

场景背景：一笔预约，有固定信息也有偏好

make a reservation / book a table 都可说订位，party size 是用餐人数，special request 是特殊请求。电话、餐厅网站或预约服务都可能办理；waitlist 是等位名单，walk-in 是未预约直接到店，first come, first served 是先到先服务，不等于已保留桌位。

本篇同一预约从四位8:15改成五位8:30，再到店核对。日期、人数、登记名与电话用来找订单；booth（卡座）是另行申请的座位偏好，先记下不代表保证。

特殊需求怎样说得可办理

Could we have a table by the window? 请求靠窗；We'd like a quiet table, if possible. 请求安静处；It's a birthday celebration. 说明生日聚餐，不能推定赠送甜点。预约平台上的备注不一定完成所有安排，重要需要应再确认。

饮食需要要用准确名称。I have coeliac disease and need gluten-free food. 是患乳糜泻需无麸质食物；I have a wheat allergy. 是小麦过敏，两者不同，别笼统混成“麸质过敏”。用自己的真实情况说明，再核厨房能否处理，参见FSA说明。

Can we push it back thirty minutes? 请求推迟半小时，方向由 back 说明；The first one works. 选第一个时段。OpenTable、Resy 等是预约服务的例子，Yelp Waitlist 名称里的 waitlist 说等位，不能把加入等位名单都当订座成功；可用渠道查餐厅当前说明。
