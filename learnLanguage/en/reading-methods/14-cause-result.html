14 原因与结果，决定你从哪一边理解关系

“因为”和“所以”都可以连接同一项事件，但一个引入理由，一个推进结果。阅读时看清两边各是什么，就不会把行动的原因读成已经完成的结果，也不会把单纯的先后升级成因果。

先说明正在解释哪项行动

We need to update the invitations because the date has changed.

我们需要更新邀请，因为日期变了。

主句说明需要更新，because 给出这个需要的理由。日期已变是理由，邀请已更新却不是原句报告的结果。读者若只抓住两个动作词，很容易漏掉 need to 保留的未完成任务。

先给事实，再推出下一步

The date has changed, so we need to update the invitations.

日期变了，所以我们需要更新邀请。

so 从事实向行动需要推进，与前一句可以表达相同的因果关系。信息顺序改变，并不自动改变时间状态；第二部分仍是需要做，而不是已经做。

因果解释可能是说话人的判断

I think the delay happened because we used the wrong address.

我认为延误是因为我们用了错误地址。

I think 把因果解释标为说话人的判断，不能转述成已经查明原因。because 清楚连接理由，也不代表它所引出的理由已经得到独立核实。

连接词说明说话人怎样组织关系，事实是否成立还要看原句的状态与来源。下一篇会把几种关系放在一段持续论述里。
