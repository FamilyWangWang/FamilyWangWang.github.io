20 “只有”放在哪里，会限制不同的信息

限制词会缩小一句话覆盖的范围。读到“只有”时，要看它限制的是谁、做什么，还是在哪个时间发生。下面谈的是本周报告检查，不是对某个人全部工作经历的概括。

限制行动者

Only Maya checked the dates.

只有 Maya 核对了日期。

Only Maya 限定在当前讨论的人里由谁完成检查。它不说明 Maya 只做了日期检查，也没有否认她还修改过其他内容。人物范围与任务范围要分开。

限制检查对象

Maya checked only the dates.

Maya 只核对了日期。

only the dates 限定检查对象。在正在比较日期与地址的背景里，它说明 Maya 没检查其他这些内容，但不排除别人也检查了日期。与 Only Maya 的判断不能交换。

限制时间，还需要保留讨论范围

Maya checked the dates only on Monday.

Maya 只在周一核对了日期。

only on Monday 在当前这周的安排里限制检查时间，不是说她一生只检查过这一次。若重音或上下文另外突出某项内容，读者还要结合那些线索，不能只找最近单词。

否定与限制读准后，下一部分会看句子怎样突出信息，让读者知道当前究竟在回答哪个问题。
