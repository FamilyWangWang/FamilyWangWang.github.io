01 长句先抓住主要判断，再接回细节

读到一条很长的报告消息，先记住了订单和月份，读完却说不清报告到底怎么了，这种卡顿很常见。先把“报告”与“需要核对”连起来，其余内容就有了放置的位置。本篇只需认得报告、订单和发送这几个日常词，新的结构会随例子解释。

先让句子回答报告怎么了

你正准备发送报告，同事提醒你先做检查：

The report on last month’s orders needs to be checked before we send it.

关于上个月订单的那份报告，需要在我们发送前核对。

The report 是主要对象，needs to be checked 是对它作出的判断，合起来是“报告需要被核对”。needs 表示需要，to be checked 表明报告是接受核对的东西；这里没有说报告自己去检查，也没有交代由谁检查。

所谓主干，是先认出原句中彼此关联的对象和判断。它给理解一个起点，接下来仍要把整句读全。

接回细节时，让它们各找到位置

on last month’s orders 跟在 report 后面，说明报告涉及上个月的订单。这里的 orders 是订单，不是另一位检查者；月份限定订单的范围。before we send it 再说明核对应在发送之前进行，it 仍指这份报告。

现在可以把两项补充放回主干：核对的是上个月订单的那份报告，核对要先于发送。若换成任何一份报告，或读成先发出再核对，虽然还记得“检查”这个动作，任务已经变了。

同一个检查动作，也可能处在不同阶段

同事后来又发来一条状态更新：

The report has already been checked.

报告已经核对过了。

has been checked 是完成时的被动结构，already 表示已经。它报告核对已完成，与 needs to be checked 的“仍需进行”不同。抓主要判断时，需要、可以、已经以及否定都要一起保留，不能把它们压成同一个“检查”。

这条更新解决了是否核对的问题，并没有单独报告是否已经发送。读清每条消息新增了什么，才容易接上下一步。

本篇先把对象与完整判断接起来，再恢复报告范围和时间顺序。下一篇读从句边界，看中途出现的一段说明怎样识别对象，又怎样接回主句。
