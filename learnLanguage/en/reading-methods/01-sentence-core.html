01 长句先抓住主要判断，再接回细节

读长句时，有时刚看到报告，眼睛就被订单、月份和发送时间带走，读到最后仍没弄清报告到底怎么了。先把对象与判断连起来，句子就有了可接细节的骨架。本篇从一条报告消息开始，只需认得简单的报告与发送词汇。

先让句子回答报告怎么了

你准备发送一份报告，收到下面这条消息。

The report on last month’s orders needs to be checked before we send it.

关于上个月订单的那份报告，需要在我们发送前核对。

读者先取得一条关系：报告需要核对。报告内容和发送时间稍后都能接到这条关系上。这里的主干不是另造一个简短句替代原文，而是先看出长句中哪两部分彼此关联，减少读一半就忘了开头的负担。

The report 是主要对象，needs to be checked 说明它需要接受核对。on last month’s orders 贴在 report 后，告诉你这是哪份报告。

接回细节时，让它们各找到位置

沿原句继续看，订单和发送分别回答不同问题。

上个月订单说明报告涉及什么，发送之前说明核对应在什么阶段完成。两项补充都重要，但它们不会竞争主要对象的位置。先建立报告与核对的关系，读者就能把它们分别放回对象范围和时间关系里。完整含义由这些关系一起形成。

before we send it 给核对放上先于发送的顺序，it 接住报告。因此这条消息可用于安排发送前的检查。

同一个检查动作，也可能处在不同阶段

现在比较另一条消息，看看主要判断为什么不能只剩检查这个词。

The report has already been checked.

报告已经核对过了。

前一条要求核对，这一条报告核对已完成。两句都谈报告和检查，能支持的下一步却不同。掌握主干，要连同需要、已经这类阶段信息一起掌握。这样读者得到的不是孤立动作，而是当前究竟到了哪一步。

has already been checked 中的 already 把完成状态点出来；与 needs to be checked 放在一起，差别更容易看见。

从这里继续

本篇的收获是：先连主要对象与判断，再接对象范围和时间，不必让每个长词都同时占住注意力。下一篇读从句边界，看中途插入的说明怎样找到归属。语气和消息来源会在后面的课程另行展开，这里先把句子里的关系接清楚。
