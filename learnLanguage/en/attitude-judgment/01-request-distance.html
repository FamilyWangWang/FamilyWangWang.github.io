01 请求变委婉时，行动和条件仍要说清楚

请同事发文件时，改变一个动词形式，可能把“直接要求”变成“询问是否方便”。这种距离让对方更容易说明困难，但不会自动解决时间、权限或工作量的问题。

先看形式怎样改变接话空间

Can you send me the revised file today? Could you send me the revised file today?

两句都在问：“你能今天把修改后的文件发给我吗？”在普通同事交流中，can 可以直接提出请求；could 通常让询问显得更试探。这里 could 不在报告过去的能力。过去形式可以表达与当前要求的距离，时间仍由 today 指向今天。

I was wondering if you could send me the revised file today.

“我想问问，你是否方便今天把修改后的文件发给我。”was wondering 是常见的缓和开头，不意味着请求已经过期。它比前两句更铺垫，但连续叠加缓和词会让一个小请求显得沉重。

委婉以后，也要保留真正的需要

如果文件三点前必须交付，单说“今天”会给人留下直到晚上的空间。应把期限写进请求，并说明原因。温和来自给对方清楚的回应机会，不来自隐藏限制。

Could you send it by three? I need to include it in today's report. If that is too soon, please let me know.

“能否三点前发给我？我需要把它放进今天的报告。如果时间太紧，请告诉我。”文件、期限和困难出现后的回应都明确了。

形式不能代替关系与权限

一句委婉请求仍可能给下属带来压力；紧急情况下，直接而有理由的请求也可以得体。先确定对方能够决定什么，再选择形式。若要表达感受或设定边界，可接着读语气课程。

请求与催促用完整审阅过程说明，首次请求、已有约定和重新安排怎样影响力度。
