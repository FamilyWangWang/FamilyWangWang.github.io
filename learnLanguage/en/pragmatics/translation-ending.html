英语专题：“算了”“没事”：撤回、宽慰与结束

区分撤回请求、放弃当前方案、结束话题和已经原谅。

中文直译专题 · 综合训练 · 课程目录

先看本章的问题

“算了”省去了你究竟撤回什么，“没事”省去了事是否仍需处理。Never mind、Forget it、Schon gut 等表达都有实际使用场合，但不自动对齐中文所有意图。先处理当前动作，再决定是否要谈感受。

算了：不需要帮助了

给定情境：朋友没听清你的请求，但你已自己找到钥匙。

收到或准备发送的原句： Never mind.

既然任务已解决，撤回请求合理。补上找到钥匙的事实可避免对方误以为你因他没帮忙而放弃交流。

真正要表达的意图 可用说法 中文意思
任务已解决 I found the keys, so I don’t need help now. Thanks. 找到钥匙，不需帮忙了。
任务未解决但停止当前请求 I’ll try another way. You don’t need to look for them. 换方法，你无需继续找。

停止请某人帮忙不等于任务消失；如后续仍有共同安排，要说明状态。

算了：不想继续争

给定情境：你们为小事争执，想暂停但未决定放弃自己的需要。

收到或准备发送的原句： Forget it.

这类直接撤回可被读成整件事结束或关系退出。若只是暂停，要说什么时候或怎样恢复。

真正要表达的意图 可用说法 中文意思
暂停讨论 I don’t want to argue now. Let’s return to this tomorrow. 现在不争，明天再谈。
真正放弃本次方案 I’ve decided not to pursue that plan. 决定不继续此方案。

暂缓不应伪装成结束；真正结束也不应留下“以后再说”的虚假期待。

没事：不追究，但仍有影响

给定情境：朋友迟到，你接受道歉，不过已经错过电影开场。

收到或准备发送的原句： It’s fine.

可以是接住道歉，也可能让实际问题被跳过。你可以不要求继续道歉，同时明确接下来换票或改计划。

真正要表达的意图 可用说法 中文意思
接受道歉并处理后果 Thanks for apologising. We still need to decide what to do about the tickets. 谢谢道歉，还需处理票。
尚不能说已放下 I appreciate the apology, but I’m still upset. 感谢道歉，仍难受。

不需要为了显得大度立即说“没事”；对方也不应把一句短回应推成已原谅全部。

两段后续：发送之后还要接住回应

下面对话为原创模拟场景。先遮住“你”的两句，按对方新信息补写；自己的真实选择不同时，应相应改写结局。

任务解决与关系状态

你说算了，对方误以为你生气。

说话人 原句 中文意思
对方 Are you upset that I didn’t help? 因没帮忙生气？
你 No. I found the keys while we were talking. 不，谈时找到了。
对方 So I don’t need to come over? 不用过去？
你 Right, you don’t need to come. Thanks for offering. 对，无需来，谢谢愿帮忙。

同时回答感受推测与行动确认，避免只说不生气却让对方仍出发。

接受道歉后保留边界

朋友认为“没事”意味着可再次借物。

说话人 原句 中文意思
对方 So I can borrow it again tomorrow? 明天可再借？
你 I accepted your apology. I haven’t agreed to lend it again. 接受道歉，未答再借。
对方 I thought everything was settled. 以为都解决了。
你 The repair is settled. I’m keeping the item for myself for now. 修理定了，暂自己保留物品。

按事项缩小“解决”范围。感受修复、损坏处理和未来许可不同。

练习：先写，再看依据

1. 你只想撤回今晚吃饭邀请，仍想以后联系。

查看参考处理与理由

撤回对象是今晚安排；明确保留联系愿望。

Let’s cancel tonight. I’d still like to meet another time when we can both confirm.

取消今晚，双方能确认时另见。

2. 对方说没事，你能安排下次同样玩笑吗？

查看参考处理与理由

不能。短回应未授权重复，也可能只是不继续谈。先尊重已出现的边界。

I won’t joke about that again. You don’t need to reassure me right now.

不再玩笑，无需现在安慰我。

3. 你不愿明天恢复谈话，却准备说“明天再说”以结束今晚。

查看参考处理与理由

不要制造未来承诺。把结束本次讨论和仍需处理的安排分开。

I don’t want to continue this discussion. We still need to confirm the practical arrangements.

不继续讨论，实际安排仍需定。

检查自己的版本

把意图、事实、请求和选择分别划出来。若你的版本比题目多承诺了一项行动，确认自己确实愿意并有能力完成。若你的判断依赖声音或背景，写明证据来自题目；真实消息中没有这些条件，就保留“尚不能确定”。

选一句自己的“没事”，分别标注感受、许可和待办事项，找出其中未说清的一项。
