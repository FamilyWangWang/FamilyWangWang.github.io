05-9 维修与故障（Repairs and Faults）

本组第 9 篇 · 共 10 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 8 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

有效报修要说明设备、位置、症状、开始时间和影响：The heating has been cutting out since yesterday 比 The heating is bad 更容易处理。可以记录 error code、异常声音和漏水位置，并用照片 document 可见损坏。

涉及电路、燃气气味、大量漏水或结构不稳时，不要继续拆修。先远离危险并联系当地紧急服务、物业或合格专业人员；只有在安全且明确知道如何操作时，才使用设备规定的隔离开关或阀门。

精讲

failure / malfunction

failure 强调部件或功能未能工作；malfunction 强调设备运行异常，不一定完全停机。

damage / defect

damage 是已经造成的损害，通常不可数；defect 是产品或部件中的具体缺陷，可数。

wear and tear / breakage

wear and tear 是长期正常使用造成的逐渐磨损；breakage 是破裂或损坏事件。责任认定取决于合同和当地规则。

leak / blockage

leak 让液体或气体逸出，blockage 阻止管道内物质正常通过。

breakdown / power outage

breakdown 常指某台设备停止工作；power outage 指某个区域停止供电。

error message / error code

error message 是完整提示，error code 是便于识别故障类型的短代码。

repair / maintenance / inspection

repair 修复已有问题，maintenance 预防故障，inspection 检查当前状态。

warranty

warranty 的期限、范围和条件以具体文件及当地规则为准，不能仅凭该词判断是否免费维修。

estimate / invoice

estimate 是工作前的估算，invoice 是已提供服务后的收费文件；估算是否有约束力取决于表述和当地规则。

break down / cut out

break down 常表示整体停止工作；cut out 强调突然或反复中断。

jam / squeak

jam 描述机械部件卡住，squeak 只描述尖细摩擦声，不能单独说明故障原因。

leak / drip

leak 泛指泄漏，drip 强调液体一滴一滴落下。

repair / replace

repair 修复现有部件，replace 用另一个部件替换它。

report / hire

report 是把问题告知负责方，hire 是付费委托某人完成工作，两步不一定由同一方负责。

diagnose / troubleshoot

troubleshoot 是逐步排查问题，diagnose 是确定故障性质或原因；专业诊断可能需要合格人员。

易混辨析

  • unusual sound / odor：前者是声音线索，后者是气味线索；都应客观描述而非猜测原因。
  • contractor / property manager：前者实施受委托的工作，后者协调管理楼宇和维修事务。
  • service call / appointment：前者是技术人员的一次上门服务，后者只是约定的时间。
  • faulty / damaged：前者强调功能不可靠，后者强调已受到损伤，两者可能同时成立。
  • callout fee / repair cost：前者可能仅因上门产生，后者是维修工作的费用。

语境回收

Since yesterday, the heating has been cutting out and showing an error code. Nora took photos of the display and reported the malfunction to the property manager. A contractor scheduled a service call, diagnosed a pump failure, and provided a written estimate. Because there was no active leak or immediate danger, they arranged a regular repair appointment for the next morning.

自测

  1. 选择：设备间歇性突然停止是 cut out / maintain。
  2. 填空：Please note the error ______ shown on the display.
  3. 改错：The pipe has bursted.
  4. 翻译：请拍下损坏情况并书面报告。
  5. 选择：工作开始前的费用估算是 invoice / estimate。
  6. 填空：The technician diagnosed the problem ______ a sensor failure.
  7. 改错：There are extensive water damages.
  8. 选择：定期预防性保养是 maintenance / repair。
  9. 翻译：冰箱一直发出异常声音。
  10. 填空：Do not use an ______ shelf until it has been made safe.
