14-1 身份证明与官方文件（Identification and Official Documents）

本组第 1 篇 · 共 6 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 11 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

办事材料常同时回答三件事：证明什么、交哪种版本、是否需要翻译或来源认证。本篇先把这三层分开，下一篇再寻找负责办理的机关。

提交官方文件前，应先确认接收机构要求的是原件、普通副本、认证副本、官方摘录还是翻译件，以及是否需要公证、海牙认证或其他领事认证。不同国家对文件名称、签发机构、有效期和认证人员资格的规定并不相同。

certified copy 只说明副本按适用规则被确认为与所见原件一致；notarization、apostille 和 legalization 核验的对象和适用范围各不相同，并不自动证明文件内容真实。本篇用于语言理解，不构成法律或行政建议。

精讲

ID / identity document

ID 是口语总称，可指卡片或其他证件；identity document 更正式，强调依法或按规则证明身份。

proof of identity / address

前者证明“你是谁”，后者证明“你住在哪里”；同一文件是否被接受由接收机构决定。

birth certificate / vital record

出生证是具体文件；vital record 是美国对出生、死亡、婚姻等生命事件记录的总称。

nationality / citizenship

两者常有重叠，但法律定义和表格用途依国家而异，应按主管机构说明填写。

legal / former / maiden name

legal name 是官方当前姓名，former name 包括所有过去姓名，maiden name 是传统且范围较窄的旧称。

original / duplicate / certified copy

original指具有原始签发效力的文件；duplicate指另制的一份，也可能由机关正式补发，不能一概等同普通复印件。certified copy由符合规则者确认与所见原件一致；具体效力仍看签发和接收规则。

certificate / extract

证书以规定格式证明某一事实，摘录只包含登记记录中的选定内容。

translation / transliteration

翻译转换含义，转写只把字符从一种书写系统转换成另一种。

official / sworn translation

official translation 是接收机构认可的广义说法；sworn translation 是部分司法辖区的具体制度。

certification / notarization

认证副本确认副本与原件一致；公证的具体行为可能是见证签名、认证副本或其他事项，依当地权限而定。

apostille / legalization

海牙认证用于公约在相关国家间生效且适用的特定公文；不是只要两国在名单中，所有文件就一律适用。其他跨境用途可能采用不同认证链，翻译与材料接受规则仍另核对。

authentication / content

认证通常核验签章、身份或来源，不自动确认文件陈述的全部内容真实。

issue / expiration date

签发日期说明何时正式签发，到期日期说明何时停止标示有效；有些文件没有到期日。

legible / valid

legible 只说明看得清，valid 说明在相关规则下有效；清晰文件仍可能无效。

document number / personal identifier

文件号识别一份文件，个人识别号码识别一个人；更新文件时两者的变化规则不同。

易混辨析

  • certified / authenticated：前者常确认副本，后者常核验签章或来源，具体含义依制度。
  • notary / lawyer：部分地区角色重叠，部分地区权限和训练完全不同。
  • legalization / validity：办理认证不保证接收机构一定接受文件内容或用途。
  • machine-readable / electronic：可机器读取不一定表示文件完全电子化。
  • date of birth / issue date：前者属于持有人资料，后者属于文件签发资料。
  • PIN / document number：PIN 常用于身份验证，应避免公开；文件号可能印在证件上。

语境回收

Nadia needed to use her birth certificate abroad. The receiving authority asked for an original or certified copy, an official translation, and an apostille. Nadia checked the requirements before paying any fees. A qualified person certified the copy, the translator supplied the required declaration, and the competent authority apostilled the document. Nadia kept the original secure and redacted unnecessary identifiers from an informal email copy.

Nadia需要在国外使用出生证明。接收机关要求原件或认证副本、正式译文和海牙认证。她在付费前核对要求。合资格人员认证副本，译者提供规定声明，主管机关为文件办理海牙认证。Nadia妥善保存原件，并在一份非正式邮件副本中遮盖不必要的识别信息。

Nadia先查接收方要求，再付费办理副本认证、翻译和apostille。这是她那次申请的材料组合；三项不能互相替代，也不代表每份外国文件都要全部办理。
