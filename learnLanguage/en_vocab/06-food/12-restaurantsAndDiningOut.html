06-12 餐厅与外出就餐（Restaurants and Dining Out）

本组第 12 篇 · 共 13 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

餐厅流程通常包括预订、入座、看菜单、点单、确认特殊需求、用餐和结账。menu 是菜品清单，set menu 是固定组合套餐，specials 是当天或限时供应的菜。美式结账常说 check，英式更常说 bill。

小费、服务费、税费展示和分账习惯因国家、地区及餐厅而异。点单前应查看菜单和账单说明；涉及过敏原时，要明确询问餐厅是否能够安全满足需求，而不能仅凭菜名推断。

精讲

appetizer / starter

美式常说 appetizer，英式更常说 starter，都指主菜前的小份菜。

main course / side dish

main course 是主菜，side dish 是搭配主菜的配菜，不是第二份主菜。

menu / set menu

menu 是菜品清单，set menu 是固定价格和组合的多道餐；美式也说 prix fixe menu。

special / soup of the day

daily special 是当天特别供应的菜，soup of the day 只指当天的汤。

restaurant / bistro / cafe

restaurant 最宽泛，bistro 通常较小且休闲，cafe 侧重咖啡、轻食和甜点。

pub / bar

pub 是英式酒馆式营业场所，常供应餐食；bar 可指酒吧，也可指餐厅内酒水柜台。

cafeteria / buffet

cafeteria 是自选取餐的场所，buffet 是自取多种食物的供应形式。

server / waitstaff / host

server 负责点单送餐，waitstaff 是服务人员集合，host 负责迎宾和安排座位。

check / bill

美式餐厅常说 check，英式常说 bill；receipt 是付款后的交易凭据。

tip / service charge

tip 通常是自愿小费，service charge 是账单列出的服务费。规则和惯例依地区而异。

reserve / order

reserve 是提前留桌，order 是到店后点菜饮品。

recommend

结构是 recommend something to someone，或 recommend that ...，不说 recommend me this dish。

split / pay separately

split the bill 可按人数或项目拆分，pay separately 只说明各自付款，应提前确认餐厅能否操作。

complain / request a correction

complain 可表达不满；具体问题更适合清楚说明并请求纠正，例如菜送错或账单项目有误。

vegetarian / vegan / meat-free

vegetarian 通常不含肉鱼但可含蛋奶，vegan 不含动物来源食材，meat-free 只明确不含肉。

易混辨析

  • order / reservation：点下的餐饮内容与预留桌位安排。
  • customer / guest：购买服务的人与接受接待服务的人，餐厅均可使用。
  • counter / booth：点餐取餐台与带固定长椅的座位。
  • homemade / local：店内或家庭制作与来自附近地区不是同一属性。
  • sold out / unavailable：前者强调库存已售完，后者只是当前不能提供。

语境回收

Nora reserved a table for four at a neighborhood bistro. The host seated them in a booth, and their server explained the daily special. They ordered an appetizer, two main courses, a vegetable curry, and a vegan burger. At the end, they asked whether service was included, split the bill, paid by card, and requested a receipt.

  5. 选择：付款后的交易凭据是 bill / receipt。
  6. 填空：Could we split the bill three ______?
  7. 改错：Meat-free always means vegan.
  8. 选择：负责迎宾安排座位的是 host / customer。
  9. 翻译：这不是我点的菜。
  10. 填空：The daily special is no longer available; it is sold ______.
