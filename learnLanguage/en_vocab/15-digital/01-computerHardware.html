15-1 电脑硬件（Computer Hardware）

本组第 1 篇 · 共 8 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

购买或排查电脑时，先区分整机、内部部件和外围设备。processor 执行指令，RAM 临时保存当前程序使用的数据，SSD 和 hard drive 则用于长期存储。运行内存不足和磁盘空间不足会产生不同问题，不能都笼统地说 “not enough memory”。

接口形状相同也不保证功能、速度或供电能力相同。连接显示器、存储设备或电源前，应核对端口标准、线缆规格和设备兼容性；拆装内部部件时，还要先正常关机、断电并遵守制造商的安全说明。

精讲

computer / PC

computer 是最宽泛的计算机总称。PC 原指个人电脑，日常语境中常与 Mac 对举，但技术上 Mac 也是 personal computer。

desktop / laptop / tablet

台式机主要固定使用，笔记本整合屏幕和键盘，平板主要通过触摸屏操作。desktop 也可表示操作系统的桌面界面。

processor / CPU / core

processor 是处理器广义称呼，CPU 是中央处理器，core 是其中能相对独立执行指令的计算核心。

clock speed / performance

时钟频率是性能指标之一；架构、核心数、散热、内存和工作负载也会影响实际速度，不能只比 GHz。

RAM / disk space

RAM 临时保存程序正在使用的数据，磁盘空间长期保存文件和应用。关闭程序可释放 RAM，删除或转移文件才会释放磁盘空间。

hard drive / SSD

日常说 hard drive 有时泛指存储盘，严格说 HDD 使用旋转盘片，SSD 使用闪存且无机械盘片。

graphics card / GPU

显卡是完整部件，GPU 是执行图形计算的芯片。GPU 也可能集成在处理器中，并不一定有独立显卡。

power supply / charger

台式机电源为内部部件转换和分配电力，充电器主要给便携设备或电池供电。两者不能仅凭插头相似互换。

fan / heat sink

风扇主动推动空气，散热器通过金属表面积散热。两者常配合使用，灰尘或接触不良都可能影响温度。

screen / monitor / display

screen 最日常，monitor 常指电脑独立显示器，display 可指显示面板、整套显示设备或显示功能。

resolution / refresh rate

分辨率描述像素数量，刷新率描述每秒更新次数。更高的数值通常需要设备、线缆和端口共同支持。

keyboard / key

键盘整体是 keyboard，单个按键是 key。组合键常说 keyboard shortcut 或具体如 Ctrl+C。

mouse / touchpad / touchscreen

鼠标和触控板控制指针，触摸屏允许直接操作画面内容。mouse 的计算机义复数通常也是 mice。

port / connector / adapter

port 是设备上的接口，connector 是插入接口的物理连接端，adapter 在不兼容的接口或信号标准之间转换。

input / output device

键盘和麦克风输入数据，显示器和扬声器输出结果；触摸屏既显示画面又接收触摸，因此可兼具两类功能。

易混辨析

  • memory / storage：日常技术语境中前者常指 RAM，后者指长期存储；产品说明应看具体单位和上下文。
  • USB port / connector：USB 是多代标准家族，接口外形相同不保证速度、视频或充电能力相同。
  • integrated / dedicated graphics：集成图形共享系统资源，独立显卡拥有单独硬件；实际性能仍看具体型号。
  • power button / power switch：按钮常向系统发送电源指令，电源开关可能直接接通或切断电路。
  • wireless / portable：无线表示不用数据线通信，便携表示适合携带，两者不是同一属性。
  • reboot / reset：重启是重新启动系统，reset 可能还表示恢复设置或清除数据，操作前应确认含义。

语境回收

Maya connected a second monitor to her laptop through an adapter. The display worked, but the refresh rate was lower than expected because the cable and port did not support the selected setting. Her computer also became slow when several large programs were open. Since the SSD still had plenty of disk space, she checked RAM usage instead of deleting files.

自测

  1. 选择：程序运行时临时使用的是 RAM / disk space。
  2. 填空：The monitor is connected ______ the HDMI port.
  3. 改错：A higher clock speed always means a faster computer in every task.
  4. 翻译：请先正常关机并断开电源。
  5. 选择：执行图形计算的芯片是 GPU / graphics card。
  6. 填空：This adapter is compatible ______ the laptop.
  7. 改错：Deleting files is the normal way to free up RAM.
  8. 选择：每秒更新画面次数是 refresh rate / resolution。
  9. 翻译：接口外形相同不保证功能相同。
  10. 填空：Dust can prevent the cooling fan ______ moving enough air.

  1. RAM
  2. to
  3. Clock speed is only one factor that affects performance.
  4. Please shut the computer down safely and disconnect the power first.
  5. GPU
  6. with
  7. Closing unused programs can free up RAM; deleting files frees storage space.
  8. refresh rate
  9. The same port shape does not guarantee the same functions.
