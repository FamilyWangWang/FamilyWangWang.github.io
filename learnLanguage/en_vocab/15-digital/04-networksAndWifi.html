15-4 网络与 Wi‑Fi（Networks and Wi‑Fi）

本组第 4 篇 · 共 8 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

互联网接入是运营商提供的外部服务，家庭网络是住所内部设备之间的本地网络。router 在网络之间转发数据，modem 适配运营商接入线路，access point 提供无线接入；一台家用设备可能集成这些功能。

网速问题不能只看“信号满格”。带宽、实际数据率、延迟、丢包、无线干扰和远端服务负载都会影响体验。排查时应先确定问题发生在单台设备、本地网络、互联网线路还是特定网站。

精讲

internet / network / home network

互联网是全球互联体系，网络是任何互联设备系统，家庭网络是住所内部的局域网络。

LAN / Wi-Fi / Ethernet

LAN 描述局域网范围，Wi‑Fi 是无线接入技术，Ethernet 是常见有线局域网技术；LAN 不等于只用网线。

router / modem

路由器在网络间转发数据，调制解调器适配运营商线路信号。家用网关常把两者装在同一外壳中。

access point / repeater / mesh

接入点把无线设备接入网络，中继器重复信号，mesh 节点协同管理覆盖；扩展覆盖不一定提高外部带宽。

IP / MAC address

IP 地址用于网络层路由，MAC 地址标识链路层接口；两者用途不同，也都可能被系统以不同方式呈现或随机化。

subnet / gateway

子网定义一组逻辑地址范围，默认网关把发往其他网络的流量转出本地子网。

DNS / DHCP

DNS 把域名解析为地址等记录，DHCP 自动分配 IP、网关和 DNS 等配置；解析失败不等于互联网线路完全中断。

network name / SSID

日常看到的是网络名，技术配置中常称 SSID。隐藏 SSID 不是强安全措施，仍需可靠加密和密码。

password / encryption

密码控制谁能加入网络，加密保护无线传输内容。公开网络即使有登录页面，也不必然提供端到端保护。

band / channel

频段是一段无线频率范围，信道是其中的具体使用区间。不同频段在速度、覆盖和穿墙能力上有不同权衡。

bandwidth / data rate

带宽表示链路承载能力，数据率表示实际或标称传输量；协议开销和共享使用会让实际速率低于理论值。

latency / ping

延迟是数据响应所需时间，ping 是测量目标可达性和往返时间的工具或结果；低 ping 不保证高下载速率。

download / upload

下载从远端到本地，上传从本地到远端。许多接入服务的两方向速度不同。

drop / outage

连接中断可只影响一台设备或片刻，服务中断通常表示某项网络服务在一段时间内不可用。

firewall / VPN

防火墙按规则过滤通信，VPN 建立受保护隧道；VPN 不自动证明目标网站可信，也不能替代账户安全措施。

易混辨析

  • signal strength / internet speed：强信号只说明本地无线接收较好，不保证运营商线路或远端服务快速。
  • repeater / access point：中继器无线重复现有信号，接入点通常通过网络回程提供新无线接入。
  • ISP / Wi-Fi provider：ISP 提供互联网接入；Wi‑Fi 往往由本地路由器或场所提供。
  • captive portal / Wi-Fi password：前者是连接后的网页认证，后者在加入加密网络前使用。
  • packet loss / latency：丢包是数据未到达，延迟是到达所需时间；实时通话会同时受两者影响。
  • guest network / VPN：访客网隔离本地设备，VPN 保护到 VPN 端点的连接，目的不同。

语境回收

Jon's laptop showed a strong Wi-Fi signal, but video calls still froze. He connected it by Ethernet and ran a speed test. Download speed was acceptable, but latency and packet loss were high on every device. After restarting the modem and router, he checked the ISP's status page and found a regional outage rather than a problem with his laptop.

  7. 改错：A VPN automatically makes every website trustworthy.
