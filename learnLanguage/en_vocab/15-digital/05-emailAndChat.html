15-5 邮件与聊天（Email and Chat）

本组第 5 篇 · 共 8 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 16 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

电子邮件适合较正式、可检索和可归档的沟通，即时聊天适合快速对话。邮件的 CC field 让其他收件人看到抄送地址，BCC field 隐藏密送地址；群聊中的 mention 则定向提醒成员。

已送达、已打开和已理解不是同一件事。涉及隐私时，还要区分传输加密、端到端加密和聊天备份是否加密；重要决定不应只依赖一个表情反应或已读标记。

精讲

email / message / chat

邮件是特定通信系统中的消息，message 是消息总称，chat 是接近实时的连续对话。

account / address / domain

邮件账户包含登录和邮箱服务，邮件地址标识收件位置，域名是 @ 后的部分；别名可指向同一邮箱。

CC / BCC

CC 地址对其他收件人可见，BCC 地址通常对其他收件人隐藏。密送保护地址可见性，但不等于内容加密。

draft / outbox / sent folder

草稿尚未发送，发件箱保存待发或发送中的邮件，已发送文件夹保存发出后的副本；副本存在不证明已送达。

delivery / read receipt

送达回执表示目标系统接收，已读回执表示消息被打开或标记；两者都不能证明内容被理解或接受。

thread / group chat

消息串按主题或回复关系组织内容，群聊按成员形成持续空间；一个群聊可以包含多个讨论主题。

direct message / message request

私信直接发给账户，来自非联系人的私信可能先进入消息请求区，接受前应核验身份。

emoji / reaction / sticker

emoji 是标准字符，reaction 附着于具体消息，sticker 是较大的图片元素；平台显示效果可能不同。

mention / notification

提及点名特定账户并常触发通知；静音群聊可能仍保留定向提及或重要提示，取决于设置。

SMTP / IMAP

SMTP 主要处理邮件提交和转发，IMAP 让客户端同步访问服务器端邮箱；它们不是邮件地址本身。

auto-reply / status message

自动回复在收到邮件后发出，状态消息展示可用性但不主动回复每位联系人。

pin / archive / delete

固定让内容易找，归档移出主列表但保留，删除把内容移入删除流程；三者不会产生相同结果。

unsend / delete

unsend 尝试在服务允许时撤回消息，删除本地副本通常只影响自己看到的记录；撤回范围和期限依平台。

encryption / backup

聊天传输可能端到端加密，但云端备份可能采用不同保护方式；应分别检查消息和备份设置。

disappearing / permanent record

消失消息降低界面保留时间，却不能阻止截图、转发、通知预览或其他副本，因此不等于绝对不可保存。

易混辨析

  • reply / reply-all：前者通常只回发件人，后者发送给全部可见收件人；发送前应核对地址。
  • mute / block：静音只关闭提示，屏蔽阻止或限制对方联系，具体效果依平台。
  • admin / moderator：管理员控制群组设置和成员，版主更侧重内容与行为管理；权限可能重叠。
  • online / available：在线只说明账户连接，不保证本人正查看或能立即回复。
  • link / attachment：链接指向外部资源，附件随消息传送；两者都需核验来源。
  • end-to-end encrypted / private：端到端加密保护传输内容，不自动控制收件人如何保存或分享。

语境回收

Priya received a message request with an invite link to a group chat. She verified the sender before joining, reviewed the pinned message, and muted routine notifications. When sharing a document, she checked the attachment and used BCC for a large external list. A delivery receipt confirmed arrival, but she asked for an explicit reply instead of treating the receipt as agreement.

自测

  1. 选择：对其他收件人隐藏地址的是 CC / BCC。
  2. 填空：Please reply ______ the same message thread.
  3. 改错：A delivery receipt proves that the recipient understood the message.
  4. 翻译：删除自己的消息副本不一定会撤回对方的副本。
  5. 选择：把对话移出主列表但保留记录是 archive / delete。
  6. 填空：She copied her manager ______ the email.
  7. 改错：A disappearing message can never be copied or captured.
  8. 选择：显示对方正在输入的是 typing indicator / timestamp。
  9. 翻译：加入群组前请核验邀请链接。
  10. 填空：The backup may use different encryption ______ the live chat.
参考答案
  1. BCC
  2. within / in
  3. A delivery receipt confirms technical delivery, not understanding or agreement.
  4. Deleting your copy of a message does not necessarily retract the recipient's copy.
  5. archive
  6. on
  7. A disappearing message can still be captured, forwarded, or copied.
  8. typing indicator
  9. Please verify the invite link before joining the group.
  10. from
