15-8 数据与隐私（Data and Privacy）

本组第 8 篇 · 共 8 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

privacy 关注个人生活免受无关观察和干预，data protection 关注个人数据如何被收集、使用、共享、保存和删除。安全措施支持这些目标，但“加密了”并不自动表示某项处理合法、必要或透明。

账户方面，应为重要服务使用独立密码或长口令、可靠的密码管理器和多因素认证。备份应与同步区分，并定期验证能否恢复；收到索取登录信息、制造紧迫感的消息时要警惕钓鱼。

精讲

data / information

Data 是可记录和处理的事实或符号，information 是经解释后传达意义的内容；日常用法常有重叠。

privacy / data protection

隐私是更宽的私人领域，数据保护聚焦个人数据处理规则和保障；数据安全只是支持它们的一部分。

personal / anonymous data

个人数据能关联到可识别个人，匿名数据不能被合理重新关联。只删除姓名通常不足以实现匿名化。

collection / processing

收集是取得数据，处理是涵盖收集、存储、使用、共享和删除的广义操作。

controller / processor

在采用这些术语的制度中，controller 决定处理目的和方式，processor 按其指示处理；实际角色要依事实和适用法律判断。

authentication / authorization

认证核验“你是谁”，授权决定“你可以做什么”。登录成功不代表可以访问所有资源。

password / passphrase

密码可为任意字符组合，长口令由多个词组成。长度、唯一性和防泄露通常比频繁做简单变体更重要。

2FA / MFA

2FA 使用两个不同类别因素，MFA 使用两个或更多因素；两个密码仍属于同一“知道的信息”类别。

one-time / recovery code

一次性代码用于单次登录或短期验证，恢复代码在主要因素不可用时备用，应分开安全保存。

encryption / hashing

加密可用密钥解密，哈希设计为单向转换。密码存储需要适合密码的哈希方案，而不是简单通用哈希。

backup / sync

备份保存可恢复副本，同步让多处保持一致；误删或破坏也可能通过同步传播，因此同步不能替代备份。

breach / vulnerability

漏洞是可被利用的缺陷，数据泄露是数据安全实际受损的事件；发现漏洞不自动证明数据已被窃取。

phishing / malware

钓鱼通过冒充和诱导骗取信息或操作，恶意软件是在设备上执行有害功能的程序；一次攻击可能同时使用两者。

cookie / tracking

Cookie 是浏览器保存的一段状态数据，可用于登录、偏好或追踪；追踪是关联行为的过程，不只依赖 cookie。

anonymization / pseudonymization

匿名化要求无法合理恢复个人关联；假名化用替代标识降低直接关联，但保留重新关联可能，因此仍可能属于个人数据。

易混辨析

  • confidential / encrypted：机密描述允许谁知悉，加密是技术保护方式；机密数据可能未加密，加密数据也可能并非机密。
  • data breach / data loss：泄露强调安全事件，丢失强调数据不可再使用；同一事件可能同时造成两者。
  • privacy notice / consent：隐私通知提供处理信息，同意只是某些制度中的一种依据；阅读通知不自动等于有效同意。
  • deletion / anonymization：删除移除数据，匿名化保留数据但解除可识别关联，目标和验证方式不同。
  • metadata / content：元数据描述时间、位置、格式和通信关系等，可能同样揭示敏感信息。
  • legal basis / security measure：法律依据说明为何可以处理，安全措施说明如何降低风险，两者不可替代。

语境回收

After a phishing alert, Aylin reviewed her important accounts. She replaced reused passwords with unique passphrases stored in a password manager, enabled multi-factor authentication, and saved recovery codes offline. She encrypted sensitive files, created an independent backup, and tested a restore. When a service announced a possible data breach, she verified the notice through the official website before changing her credentials.

自测

  1. 选择：决定用户可执行哪些操作的是 authorization / authentication。
  2. 填空：Restore the files ______ the verified backup.
  3. 改错：Synchronizing files is always the same as keeping an independent backup.
  4. 翻译：删除姓名并不一定使数据匿名化。
  5. 选择：可被利用的系统缺陷是 vulnerability / breach。
  6. 填空：The service collected data ______ a stated purpose.
  7. 改错：Encryption automatically makes every use of personal data lawful.
  8. 选择：用替代标识但保留重新关联可能的是 pseudonymization / anonymization。
  9. 翻译：请通过官方网站核验数据泄露通知。
  10. 填空：Access should be limited ______ authorized personnel.
参考答案
  1. authorization
  2. from
  3. Synchronization can propagate deletion or corruption; an independent backup supports recovery.
  4. Removing names does not necessarily anonymize the data.
  5. vulnerability
  6. for
  7. Encryption is a security measure; it does not by itself establish a lawful basis or necessity.
  8. pseudonymization
  9. Please verify the data-breach notice through the official website.
  10. to
