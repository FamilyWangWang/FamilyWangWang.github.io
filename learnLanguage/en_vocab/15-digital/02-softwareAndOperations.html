15-2 软件与操作（Software and Operations）

本组第 2 篇 · 共 8 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

operating system 管理硬件和基础服务，software 是程序总称，program、app 则完成具体任务。处理文件时要区分复制、移动、重命名和删除；下载是从远程系统传到本机，保存则把当前内容写入存储。

安装软件或更新前，应核对来源、系统要求和许可证。删除桌面图标不等于卸载程序，清空回收站也会降低恢复文件的可能性。

精讲

operating system / software / program

操作系统管理硬件和基础服务，软件是数字程序总称，程序是可执行特定任务的单个软件单位。

program / application / app

三者大量重叠。app 最口语，常见于应用商店生态；application 比 app 正式，也有“申请”这一非技术义。

interface / window / menu

界面是用户与软件交互的整体，窗口显示一个程序或文档区域，菜单按类别列出命令。

icon / button / toolbar

图标代表对象或功能，按钮触发动作，工具栏把一组常用按钮和控件集中排列。

desktop / taskbar

桌面是登录后的主工作区，任务栏显示程序入口、运行状态和系统功能；不同操作系统名称和布局不同。

folder / file / filename

文件保存数字数据，文件夹组织文件，文件名用于识别文件。文件名可以相同，只要所在路径不同。

extension / format

扩展名是文件名的一部分，格式是数据内部的组织方式。只改扩展名通常不会真正转换文件格式。

path / shortcut

路径指出资源实际位置，快捷方式只是指向它的入口；删除快捷方式通常不会删除原文件。

pointer / cursor

指针随鼠标或触控板移动，光标多指文字输入位置；日常交流中两词有时会混用。

copy / cut / paste

复制把副本放入剪贴板，剪切准备移动原内容，粘贴把剪贴板内容放到目标位置。

move / rename / delete

移动改变位置，重命名改变名称，删除移除项目。跨磁盘移动有时实际包含复制后删除。

save / download

保存把当前内容写入本机或指定存储位置；下载把远程内容传到本机。浏览器下载后仍需要知道保存位置。

delete / uninstall

删除图标或单个文件不等于卸载。卸载会由系统移除程序及其注册组件，但有时保留用户数据。

update / upgrade

更新通常在现有版本内修复问题或增加功能，升级常指转到较大的新版本或更高产品级别；厂商命名不完全一致。

minimize / close / exit

最小化只隐藏窗口，关闭结束当前窗口，退出通常结束整个程序；带后台服务的应用退出后仍可能保留进程。

易混辨析

  • Recycle Bin / Trash：Windows 常用前者，macOS 等常用后者；两者都是界面名称。
  • open-source / free of charge：开源描述许可证和源代码可用性，不保证免费；免费软件也不一定开源。
  • default / recommended：默认值是系统自动采用的选择，不一定代表每位用户的最佳选择。
  • archive / backup：归档文件用于打包或压缩，备份用于在原数据丢失后恢复。
  • read-only / locked：只读限制修改，锁定还可能限制打开、移动或由其他进程使用。
  • click / tap：鼠标通常 click，触摸屏通常 tap。

语境回收

Eli downloaded an installer from the developer's official website and checked the version number before installation. He created a project folder, extracted the archive, and launched the program. When he renamed a data file, he kept its extension unchanged. Before closing the app, he saved his changes and created a backup instead of relying on the Recycle Bin.
