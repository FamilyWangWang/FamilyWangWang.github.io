18-3 数字与运算（Numbers and Arithmetic）

本组第 3 篇 · 共 6 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 9 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

从一个具体算式看谁参与运算、谁是结果，再看数字怎样书写和取近似值。这样记术语，比只背一排加减乘除更容易定位。

英语口头读算式时可以说 three plus five equals eight、six times seven is forty-two。要区分 number、digit 和 numeral：number 是抽象的数，digit 是 0 到 9 中的单个数字符号，numeral 是用书写符号表示一个数的形式。

英语小数通常用点号，读作 point，如 3.5 读作 three point five。正式计算中还要区分运算本身与结果，例如 addition 是加法过程，sum 才是相加所得的和。

精讲

number / digit / numeral

Number 是抽象数值；digit 是 0 至 9 中的一个符号；numeral 是写出某个数的符号组合，如 42 或罗马数字 XLII。

zero / one / place value

Zero 表示无数量或数轴原点，one 表示一个单位；place value 决定同一 digit 在个位、十位等位置的实际值。

decimal point / decimal place

Decimal point 是分隔整数与小数部分的符号；decimal place 是点后某一位的位置。英语 3.14 读作 three point one four。

plus sign / minus sign / equal sign

Plus sign 可表示加法或正号，minus sign 可表示减法或负号；equal sign 表示两边数值相等。

addition / sum / addend

Addition 是运算过程，addends 是参与相加的数，sum 是最终结果。

subtraction / difference / minuend / subtrahend

在 12 − 5 = 7 中，12 是 minuend，5 是 subtrahend，7 是 difference。

multiplication / factor / product

Multiplication 是乘法过程，factors 是参与相乘的数，product 是乘积。

dividend / divisor / quotient / remainder

在 17 ÷ 5 = 3 remainder 2 中，17 是 dividend，5 是 divisor，3 是 quotient，2 是 remainder；divisor 不能为零。

fraction / numerator / denominator

Fraction 可表示整体等分数，也可大于一或带负号；numerator 在分数线上方，denominator 在下方且不能为零；在正整数等分模型中说明分成多少份。

percent / percentage / proportion

Percent 是“每一百”的单位并紧跟数值；percentage 是用百分数表达的比例值；proportion 可不用百分号表达部分与整体的关系。

ratio / fraction

Ratio 比较两个或多个量，如 2:1；fraction 通常表示一个整体中的若干等份，如 2/3。

average / mean

Average 在日常语境中常指算术平均数，也可泛指代表性水平；mean 是统计学中一类平均数，需说明采用哪种算法。

minimum / maximum

Minimum 是允许范围或数据集中的最小值，maximum 是最大值；两者可指限制，也可指实际观测结果。

compute / estimate / approximate

Compute 按规则算出数值；estimate 根据有限信息作粗略判断；approximate 用接近值代替难以精确确定的值。

round off / decimal places

Round off 从已知数值出发，按指定精度取近似值；round to two decimal places 指保留小数点后两位。

易混辨析

  • number / numeral / digit：抽象数值 / 书写表示 / 单个 0–9 符号。
  • percent / percentage：跟在数值后的百分单位 / 百分比这一数值或概念。
  • average / median：常指算术平均数 / 排序后位于中间的数。
  • estimate / round：根据有限信息估算 / 从已有数值按位数取近似值。
  • times / multiplied by：口头常用乘法读法 / 更正式的运算表达。
  • twice as much / twice as many：搭配不可数数量 / 搭配可数项目。

语境回收

Noor tallied all the measurements and added the values. She divided the sum by the number of observations to compute the average, then rounded off the result to two decimal places. One negative value was checked separately. Finally, she calculated the percentage change and verified the result with a second formula.

Noor汇总全部测量并相加，用总和除以观测次数计算平均值，再把结果取到小数点后两位。她另行核查一个负值。最后，她计算百分比变化，并用第二个公式核对结果。

Noor先合计，再除以观测次数，明确这里的average是算术平均。取两位小数改变报告精度，不改变原始观测；负值单独核查也不等于一定删掉。

把词放回句子

A digit is one decimal symbol; in 3/5, three is the numerator.（digit是一个十进数字符号，3/5中的三是分子。）Subtracting five from twelve gives seven.（从十二减五得到七。）from后的数是被减数，语序决定运算方向。

Round the result to two decimal places; six times seven has the product forty-two.（结果取两位小数，六乘七的积是四十二。）A divisor must be nonzero.（除数不能为零。）factor是参与相乘的数，product才是结果。

An estimate may use limited information; rounding starts from a known value, which itself may be approximate.（估算可依据有限信息，舍入从已知值出发，该值本身也可能近似。）The minimum is the smallest value in the stated set.（最小值是指定集合内最小的值。）The ratio is two to one.（比是二比一。）先说明集合和比较对象，数值才有意义。
