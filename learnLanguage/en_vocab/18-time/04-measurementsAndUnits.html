18-4 度量衡与单位（Measurements and Units）

本组第 4 篇 · 共 6 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 4 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

描述测量结果时，要同时给出数值和单位，如 5 km、20 °C。日常英语中的 weight 常用来回答“有多重”，但物理学严格区分 mass 和由重力产生的 weight force。

还要特别区分 power 与 energy：kilowatt 是功率单位，kilowatt-hour 是能量单位。电器“功率为 2 kW”和“一小时消耗 2 kWh”描述的不是同一个物理量。

精讲

dimension / unit / measured value / measurand

Dimension 是长宽高等尺寸；unit 是比较同类量的标准；measured value 是所得数值；measurand 是准备测定的物理量。

length / width / height

Length 通常沿主要方向，width 是横向尺寸，height 是从下到上的垂直尺寸；实际工程图应按规定坐标和基准解释。

circumference / area / surface area

Circumference 是圆周长度；area 是二维区域大小；surface area 是三维物体表面的总面积。

mass / force

Mass 是物体惯性和物质量相关的物理量；force 是能改变运动或造成形变的作用，重量在严格物理语境中是一种力。

power / energy

Power 是单位时间内做功或转换能量的速率；energy 是完成工作的量。相同功率运行越久，使用的能量通常越多。

meter / millimeter / kilometer / nanometer

这些都是长度单位：一千米等于一千个米，一米等于一千毫米，一纳米等于十亿分之一米。

square centimeter / cubic centimeter

Square centimeter 是面积单位，维度为长度的平方；cubic centimeter 是体积单位，维度为长度的立方。

liter / milliliter / cubic meter

Liter 常用于液体和容器容量；一毫升等于一立方厘米，一千升等于一立方米。

gram / kilogram / tonne

一千克等于 1,000 克，一公吨等于一千千克；处方或实验中的 milligram 和 microgram 相差一千倍。

watt / kilowatt / kilowatt-hour

Watt 和 kilowatt 都测功率；kilowatt-hour 测能量。kW/h 不是 kilowatt-hour 的写法。

volt / ampere

Volt 是电势差单位，ampere 是电流单位；两者描述不同物理量，不能只凭一个数推断另一个。

newton / joule / pascal

Newton 测力，joule 测能量和功，pascal 测压力；一个 pascal 等于每平方米一个 newton。

measurement range / display resolution

Measurement range 是仪器可按规定性能测量的范围；display resolution 是显示可区分的最小步进，不等于整体准确度。

accuracy / precision / tolerance

Accuracy 关注结果接近参考值；precision 常关注重复结果彼此接近；tolerance 是规格允许的偏差范围。

calibration / check against

Calibration 是在规定条件下把仪器示值与可追溯参考标准比较并建立关系；普通 check 不能自动等同于完整校准。

易混辨析

  • mass / weight：质量 / 日常重量；严格物理语境中 weight 是重力作用产生的力。
  • power / energy：能量转换速率 / 能够做功的量。
  • kilowatt / kilowatt-hour：功率 / 能量。
  • accuracy / resolution：接近参考值的程度 / 显示可区分的最小步进。
  • exact / precise：数值恰好一致 / 方法或表达分辨细、重复性好。
  • square unit / cubic unit：面积单位 / 体积单位。

语境回收

Lena measured the length, width, and height of a cabinet. Its width was exactly eighty centimeters. She then took an instrument reading for the mass of each part and converted the values from grams to kilograms. The manual also listed the electrical power in watts and the yearly energy use in kilowatt-hours.
