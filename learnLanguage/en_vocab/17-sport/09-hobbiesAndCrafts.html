17-9 爱好与手工（Hobbies and Crafts）

本组第 9 篇 · 共 9 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 10 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

介绍爱好时，可以说 My hobby is ...、I'm interested in ... 或 In my spare time, ...。谈手工时，最好同时说明材料、工具和技法：knit with wool、sew a seam、work from a template。

craft 可指业余手作，也可指需要长期技能训练的工艺；使用刀具、胶黏剂、涂料或烧制设备时，应遵循产品说明并保证适当通风和防护。

精讲

hobby / leisure activity / interest

Hobby 是经常实践的业余活动，leisure activity 是更广的休闲行为，interest 只表示关注倾向，不一定亲自实践。

collection / collector

Collection 是按主题整理的物品集合，collector 是持续收集的人；偶然拥有几件同类物品不一定构成收藏活动。

handicraft / craft / crafting

Handicraft 常指传统手工制品或技艺，craft 范围更广并可成为职业，crafting 常指业余创意小制作。

material / tool / instruction

Material 是原料，tool 是加工器具，instruction 是操作步骤；安全说明也属于必须阅读的 instructions。

template / design / workpiece

Template 是可直接描画或剪裁的样板，design 是整体方案，workpiece 是正在加工的实物。

paper / cardstock / cardboard

Paper 最薄且用途广，cardstock 较厚但仍适合打印裁切，cardboard 更厚并常用于结构和包装。

fabric / wool / yarn / thread

Fabric 是布料，wool 是纤维或毛线日常称呼，yarn 是编织线材，thread 通常更细并用于缝纫刺绣。

sewing / knitting / crochet tools

Sewing needle 有针眼，knitting needles 通常成对使用，crochet hook 前端带钩且通常单根使用。

adhesive / paint / canvas

Adhesive 用于粘合，paint 提供颜色和表面涂层，canvas 是常见绘画承载面；各材料的通风和固化要求不同。

sketch / drawing / design

Sketch 通常快速记录想法，drawing 可是完成度较高的线条作品，design 还包含结构、尺寸和用途方案。

photography / camera / lens / subject

Photography 是实践与艺术，camera 是设备，lens 形成光学影像，subject 是被表现对象。

board game / card game / jigsaw puzzle

Board game 使用棋盘等组件，card game 以纸牌为核心，jigsaw puzzle 通过拼片复原图案。

model making / scale model

Model making 是活动，scale model 按固定比例表现实物；并非所有创意模型都遵守比例。

pottery / woodwork

Pottery 以陶土塑形和烧制为核心，woodwork 以木材切削、连接和表面处理为核心，工具风险不同。

seam / stitch / pattern

Stitch 是一个针迹单位或针法，seam 是针迹连接材料形成的接合线，pattern 是重复图案或制作说明。

易混辨析

  • handmade / homemade：主要通过手工制作 / 在家制作；家庭制作也可能使用机器。
  • yarn / thread：较粗、常用于针织钩织 / 较细、常用于缝纫刺绣。
  • knit / crochet：通常用两根针形成线圈 / 用一根钩针逐针钩织。
  • template / pattern：可直接描画裁切的样板 / 重复图案或完整制作说明。
  • subject / motif：作品表现对象 / 反复出现并具有主题意义的视觉元素。
  • drying time / curing time：表面变干所需时间 / 材料达到完整强度或性能所需时间。

语境回收

Mina enjoys sewing and photography. For a handmade gift, she first drew a sketch and chose a durable fabric, thread, and dress pattern. She threaded the sewing machine, aligned two fabric panels, and sewed a straight seam. Later, she photographed the finished workpiece in natural light. At the weekend, she also assembled a small scale model from cardstock.

自测

  1. 选择：供照着描画或裁切的样板是 template / workpiece。
  2. 填空：Fiber spun into a continuous strand for knitting is ______.
  3. 改错：Knitting and crochet always use the same tools.
  4. 翻译：请仔细按照说明操作。
  5. 选择：相机汇聚光线的光学组件是 lens / subject。
  6. 填空：Use straight pins to hold the fabric ______ together.
  7. 改错：Every model is necessarily built to a fixed scale.
  8. 选择：用线连接材料后形成的是 seam / stitch。
  9. 翻译：她在自然光下拍摄了手工作品。
  10. 填空：Allow the adhesive to cure before moving the ______.
参考答案
  1. template
  2. yarn
  3. Knitting normally uses needles; crochet uses a hook.
  4. Please follow the instructions carefully.
  5. lens
  6. panels
  7. A scale model follows a fixed ratio; other models may not.
  8. seam
  9. She photographed the handmade piece in natural light.
  10. workpiece
