11-8 项目与工作流程（Projects and Workflows）

本组第 8 篇 · 共 10 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 13 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

项目通常有明确目标、有限时间和资源，以及可判断是否完成的结果；持续重复产生同类结果的工作更适合称为 process 或 workflow。规划时先明确 project scope，再把目标拆成 work packages 和 subtasks，标出依赖关系，并为每项工作指定负责人、期限和交付物。

状态更新不应只说“正在进行”。更有用的汇报会说明完成进度、计划偏差、风险、瓶颈、下一步行动和需要谁作决定。变更范围、时间或预算时，也应记录基准受到的影响。

精讲

project / process / workflow

项目为特定结果而设，通常有结束点；流程持续重复产生结果；工作流强调任务在步骤、角色或状态之间如何流转。

objective / charter

项目目标说明要达到什么结果，项目章程正式确认项目目的、授权、关键角色和初始边界。

scope / phase

范围定义包含和不包含哪些工作，阶段把项目生命周期划分为目标相近的时间段。

milestone / work package / subtask

里程碑是检查重要结果的节点，工作包是可估算和验收的一组工作，子任务是更小的单项活动。

project plan / timeline

项目计划包含范围、资源、风险和控制方式等多方面内容，时间线重点显示日期、顺序和节点。

capacity / resource

能力容量是一段时间内可承担的工作量，资源是完成工作需要的人、资金、设备或信息。

budget / cost limit

项目预算是计划或批准使用的资金总额，费用上限是不应超过的边界；两者可能相同，也可能不同。

time frame / deadline / target date

时间范围给出大致区间，截止日期是最晚界限，目标日期是计划完成的具体时点。

delay / bottleneck

延误是结果落后于计划，瓶颈是限制整体进度或吞吐量的环节；找到瓶颈有助于解释延误原因。

dependency / prerequisite

依赖描述事项之间的关系，先决条件是某项活动开始前必须满足的具体条件。

risk / issue

风险是可能发生的不确定事件，问题是已经发生并需要处理的情况。风险实现后可能转化为问题。

corrective action / mitigation

纠正措施处理已经发生的偏差及原因，风险缓解措施降低未来不确定事件的可能性或影响。

status / progress / completion rate

项目状态是整体健康状况，进度说明向目标推进的情况，完成率用比例量化一组工作的完成程度。

handover / acceptance / approval

移交传递成果、资料和责任，验收确认交付符合标准，批准允许项目、阶段或变更继续；三个动作可能由不同角色完成。

baseline / variance / change request

基准是经批准的比较依据，偏差是实际与基准的差异，变更申请正式提出修改并记录对范围、时间或成本的影响。

易混辨析

  • task / work package：单项工作与可分配、估算和验收的一组相关工作。
  • owner / contributor：对结果负主要责任的人与协助完成工作的人。
  • contingency / mitigation：预留的备用资源或方案与降低具体风险的措施。
  • on schedule / overdue：整体进度符合计划与某项任务已过截止日期。
  • retrospective / status meeting：回顾过去以改进工作方式与同步当前进展。

语境回收

The project plan contained four work packages and three milestones. During the weekly status review, the team reported a resource bottleneck and a schedule variance. The project manager assessed the risk, assigned a mitigation task to a clear task owner, and updated the timeline. A formal change request documented the expected effects on scope, budget, and the target date.

自测

  1. 选择：项目包含和不包含的工作边界是 project scope / project phase。
  2. 填空：Break the objective ______ smaller tasks.
  3. 改错：A risk is always an issue that has already happened.
  4. 翻译：项目进度仍符合计划。
  5. 选择：可估算并验收的一组工作是 work package / target date。
  6. 填空：The actual cost varied ______ the approved baseline.
  7. 改错：Approval, acceptance, and handover always mean the same action.
  8. 选择：限制整体进展的环节是 bottleneck / retrospective。
  9. 翻译：请给这项任务指定明确负责人。
  10. 填空：We need to mitigate the risk ______ delaying the launch.
