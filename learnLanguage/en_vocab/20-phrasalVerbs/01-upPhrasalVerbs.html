20-1 up 短语动词（Phrasal Verbs with Up）

本组第 1 篇 · 共 10 篇 | 本篇 60 个主词条 + 10 个固定表达 | 精讲 15 项

场景导入

up 不只表示“向上”。在短语动词里，它还经常表示完成、增加、靠近、出现、聚集或状态改变。比如 eat up 强调吃完，speed up 表示加速，show up 表示出现。

学习短语动词时必须同时记住是否可分。可分短语动词遇到代词时，代词必须放在中间：pick it up，不能说 pick up it。不可分短语动词则不能拆开：put up with it。

精讲

bring up — 提起；养育

  • 可分：bring the issue up 和 bring up the issue 都可以；代词只能说 bring it up。
  • 例句：I didn't want to bring it up during lunch. — 我不想在午饭时提起这件事。

catch up — 赶上；补上

  • catch up with someone：赶上某人，也可指和旧识聊近况。
  • catch up on something：补做积压的工作、阅读或睡眠。
  • 例句：I need the weekend to catch up on sleep. — 我周末得补补觉。

come up / come up with

  • come up 不及物：问题、话题或机会出现。
  • come up with 及物：某人想出主意、计划或答案。
  • 例句：A problem came up, but Leo came up with a solution. — 出了一个问题，不过 Leo 想出了解决办法。

end up — 最终变成或落到某种结果

  • 常用 end up doing，不能说 end up to do。
  • 例句：We missed the train and ended up taking a taxi. — 我们错过火车，最后只好坐出租车。

give up — 放弃；戒掉

  • 接动作时用 give up doing。
  • 例句：She gave up drinking coffee in the evening. — 她戒掉了晚上喝咖啡的习惯。

keep up / keep up with

  • keep up something：让某种水平、速度或努力继续。
  • keep up with someone / something：跟上人或变化。
  • 例句：It's hard to keep up with all the updates. — 很难跟上所有更新。

live up to — 不辜负、达到

  • 不可分，常接 expectations、reputation、promise。
  • 例句：The restaurant didn't live up to its reputation. — 这家餐厅名不副实。

look up — 查找

  • 可分；代词必须放中间：look it up。
  • 例句：If you don't know the word, look it up. — 如果不认识这个词，就查一下。

make up — 编造；组成；和好

  • make up an excuse：编借口。
  • make up 30 percent of：构成百分之三十。
  • make up with someone：和某人和好。
  • 例句：Children under 12 make up half the group. — 十二岁以下儿童占这个组的一半。

own up — 主动承认

  • 用 own up to something / doing something。
  • 例句：He eventually owned up to breaking the window. — 他最终承认打破了窗户。

pick up — 捡起；接人；学会；好转

  • 具体意思由宾语决定：pick up a bag、pick up a friend、pick up a language。
  • 例句：I picked up some Italian while living in Rome. — 我住在罗马时学会了一些意大利语。

put up / put up with

  • put up 可分，表示张贴、搭建或留宿。
  • put up with 不可分，表示忍受。
  • 例句：I don't know how you put up with that noise. — 我不知道你怎么忍受那种噪音。

set up — 建立；安装；安排

  • 可分；代词说 set it up。
  • 例句：Can you help me set up the new printer? — 你能帮我安装新打印机吗？

take up — 开始；占用

  • take up a hobby：开始一项爱好。
  • take up time / space：占用时间／空间。
  • 例句：The sofa takes up too much space. — 这张沙发太占地方了。

turn up — 调高；出现

  • 调高设备时可分：turn the volume up。
  • 表示“出现”时不及物：Nobody turned up。
  • 例句：He turned up forty minutes late. — 他迟到了四十分钟才出现。

易混辨析

① come up / come up with / bring up

  • 一个问题自己“出现”：A problem came up.
  • 某人“想出”办法：She came up with a solution.
  • 某人“提起”话题：He brought up the budget.

② give up / end up

  • give up 是主动停止或放弃。
  • end up 描述经过一系列事情后的最终结果。

③ show up / turn up

两者都能表示“出现、到场”。show up 在美式英语里尤其常见；turn up 在英式英语中更常见，但两者都能被广泛理解。

④ put up / put up with

put up 可分且含义很多；put up with 是一个不可分的整体，固定表示“忍受”。

语境回收

English

Our team set up a small online store last year. At first, orders were slow, but sales gradually picked up. Then complaints began to pile up because deliveries were late. During a meeting, Nina brought up the problem and asked us to come up with a better process. We followed up with customers, backed up the order data and cleaned up the tracking system. It took time to catch up, and we sometimes ended up staying late. Nobody gave up, though. Within a month, delivery speed had improved and the new process was finally up and running.

中文

我们团队去年建立了一家小型网店。起初订单不多，但销量逐渐好转。后来因为配送延迟，投诉开始堆积。一次会议中，Nina 提出了这个问题，并要求我们想出更好的流程。我们跟进了客户、备份了订单数据，还清理了追踪系统。赶上进度花了一些时间，我们有时最后不得不加班。不过没有人放弃。一个月内，配送速度得到改善，新流程终于启动并正常运行了。

自测

  1. 填空：I need to catch up ________ my emails.
  2. 改错：Please look up it online.
  3. 选择：问题自己出现用 come up / come up with。
  4. 填空：She ended up ________ (stay) at home.
  5. 翻译：我受够了这种噪音。
  6. 选择：表示“达到期望”用 keep up with / live up to。
  7. 填空：He finally owned up ________ losing the key.
  8. 翻译：请把音量调高一点。
  9. 改错：I can't put this noise up with.
  10. 选择：接人和学会语言都可以使用 pick up / set up。
答案
  1. on
  2. Please look it up online.
  3. come up
  4. staying
  5. I'm fed up with this noise.
  6. live up to
  7. to
  8. Please turn the volume up a little.
  9. I can't put up with this noise.
  10. pick up
