09-6 地址与快递（Addresses and Parcel Delivery）

本组第 6 篇 · 共 6 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 11 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

地址通常包括收件人、街道和门牌信息、城市、行政区、邮政编码及国家，但排列顺序和必填字段因国家而异。美式常用 ZIP code，英式使用 postcode，跨国寄件宜按目的地邮政机构要求书写，并把国家名放在清晰位置。

包裹寄出后会经历收寄、分拣、运输、末端投递和签收等环节。shipped、out for delivery 和 delivered 表示不同阶段；限制物品、包装、海关申报和赔偿规则应以承运人及主管机构的当前规定为准。

精讲

address / street address

address 是地址信息总称，street address 强调可定位实体建筑的街道和门牌信息。

mailing / residential / delivery address

三者分别是可收邮件的地址、实际居住地址和本次配送目的地址，可能相同也可能不同。

recipient / addressee

recipient 是实际接收者，addressee 是地址栏明确写明的对象，两者通常相同但并非必然。

house number / apartment number

门牌号识别街道上的建筑或地块，公寓号识别建筑内部的具体住宅单元。

postal code / ZIP code / postcode

postal code 是通称，美国使用 ZIP code，英国使用 postcode；格式依目的国家。

parcel / package

两者都指包裹；parcel 在英式英语中尤其常见，package 在美式英语中更常见。

mail / post

美式常用 mail 指邮政邮件及寄出动作，英式更常用 post。

postage / shipping fee

postage 是邮政寄递的邮资，shipping fee 是商家或承运服务收取的运输费用。

shipping label / address label

运输标签通常含条码、服务和追踪数据，地址标签主要呈现收发地址。

postal service / courier

邮政服务运行广泛的邮件网络，快递企业或人员常提供更专门、较快速或可追踪的投递。

sorting center / distribution center

分拣中心按目的地处理邮件，配送中心还可能储存货物并向多个渠道分发。

delivery attempt / delivered

投递尝试不代表已经送达；delivered 表示系统记录交付完成，但应查看具体交付位置。

estimated delivery date / delivery window

前者是预计日期，后者是某日内更具体的预计时间范围，两者都可能变化。

proof of delivery / signature

交付证明可以包含时间、位置、照片或签名；签名只是其中一种确认方式。

shipment / consignment

shipment 是常用运输批次或项目，consignment 更正式，强调交给承运人或接收方的一批货物。

易混辨析

  • sender / recipient：寄件方与收件方。
  • mailbox / parcel locker：传统邮件箱与自助包裹柜。
  • pickup point / delivery address：领取地点与上门配送地址。
  • dispatch / out for delivery：从仓库发出与已经进入末端派送。
  • tracking number / tracking status：查询所用编号与当前物流事件。

语境回收

Mina printed a shipping label, checked the delivery address, and added her return address. Because her carrier required a customs declaration for this international shipment, she completed one with an accurate contents description. She kept the tracking number and later redirected the shipment to a nearby parcel locker when the first delivery attempt failed.

自测

  1. 选择：美国邮政编码通常叫 ZIP code / postcode。
  2. 填空：Please affix the label ______ the package.
  3. 改错：Out for delivery always means the package has already been delivered.
  4. 翻译：请填写公寓或单元编号。
  5. 选择：地址栏写明的收件对象是 addressee / sender。
  6. 填空：I redirected the parcel ______ a pickup point.
  7. 改错：Postal address formats are identical worldwide.
  8. 选择：证明包裹已经交付的记录是 proof of delivery / postage。
  9. 翻译：请保留查询编号。
  10. 填空：The package was returned ______ the sender.
