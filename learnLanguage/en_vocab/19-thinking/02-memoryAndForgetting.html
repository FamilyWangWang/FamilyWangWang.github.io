19-2 记忆与遗忘（Memory and Forgetting）

本组第 2 篇 · 共 9 篇 | 本篇 60 个主词条 + 12 个固定表达 | 精讲 15 项 另有 6 条复现词（标 （→ 见 XX-Y）），主篇在别处，不计入本篇词数

场景导入

英语中 remember 表示记得或想起，commit to memory 强调主动记住，retain 强调学习后仍能保留，retrieve 则强调需要时从记忆中提取。一个名字一时想不起来，可以说 It slipped my mind；后来突然想起，可以说 It came back to me。

记忆不是对过去的完整录像。Retrieval 常依赖 cue，回忆也可能根据零散信息重新 reconstruction。因此，生动、自信的 memory image 并不自动保证细节准确。

精讲

memory / recall ability

Memory 是存储、保持和提取信息的系统或回忆内容；recall ability 特别关注没有直接呈现答案时主动调出信息的能力。

short-term / working memory

Short-term memory 强调短时保持；working memory 还包括为当前任务操作和更新信息，两者相关但不完全相同。

long-term memory / episodic memory

Long-term memory 是长期保存系统总称；episodic memory 是其中保存个人经历及时间地点背景的一类。

encoding / retention / retrieval

Encoding 把信息转化为可存储表征，retention 是随时间保持，retrieval 是需要时把信息调出。

recall / recognition / familiarity

Recall 需要主动产生答案；recognition 是在再次见到时辨认；familiarity 只是熟悉感，可能缺少具体来源细节。

memory gap / memory loss

Memory gap 是某个事实或时段想不起来；memory loss 可指更广的内容或能力丧失。持续或突然的明显变化应由专业人员评估。

memory trace / retrievability

Memory trace 是学习留下的表征；retrievability 是在当前线索和状态下能否提取。暂时提取失败不必然表示信息完全消失。

cue / memory prompt / reminder

Cue 是帮助提取或行动的提示；memory prompt 专门唤起过去内容；reminder 常用于未来任务和约定。

reconstruction / memory fragment

Reconstruction 根据碎片和线索重新组成过去；memory fragment 是零散内容。重构结果可能混入后来信息。

forgetting curve

Forgetting curve 是描述可提取信息随时间变化的模型，不是一条适用于所有人、所有材料的固定曲线。

remember / remind

Remember 的主体自己记得；remind 需要一个提示者或提示物，使另一个人想起，如 Remind me to call。

memorize / retain

Memorize 是主动记入，retain 是一段时间后仍能保留；成功背过一次不保证长期保持。

slip one's mind / come to mind

Something slips one's mind 表示一时忘掉；something comes to mind 表示想法或答案进入意识，两者都以信息作主语。

recap / recite

Recap 按要点简要回顾，不要求逐字；recite 通常是不看原文完整说出背熟内容。

memorable / unforgettable

Memorable 表示值得或容易记住，强度可高可低；unforgettable 强调印象极深，是更强的主观评价。

易混辨析

  • remember doing / remember to do：记得做过 / 记得要去做。
  • recall / remind：自己回想起 / 使别人想起。
  • retain / retrieve：保持在记忆中 / 从记忆中调出。
  • recognize / know：再次见到时辨认 / 掌握事实或熟悉对象。
  • forget / leave：忘记信息或任务 / 把物品遗留在某处。
  • memory / memoir：记忆或回忆内容 / 个人回忆录。

语境回收

Mila could not remember the speaker's name; it had slipped her mind. A note provided a useful cue, and she recognized the familiar voice again in a recording. The conversation then came back to her. She wrote down several keywords, reconstructed the sequence of events, and used a photograph as a memory prompt for the remaining details.
