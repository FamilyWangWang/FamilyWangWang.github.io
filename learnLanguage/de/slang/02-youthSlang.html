年轻人俚语 (Jugendslang)

本页以听懂青年与网络交流为主，并保留跨年龄或地区表达作比较。是否主动使用取决于关系和个人风格，不按35岁、50岁划固定界限，也不保证每个年轻人都采用同样的词。

听到Bock auf Pizza，重点是对方在问想不想吃披萨；听到cringe，则是在表达尴尬评价。本篇保留各类词条，但不把它们都当成青年专属，也不把网络用语当成实时流行榜。

从一段对话读起

A: Hast du Bock auf Pizza?

B: Ja, aber nicht in dem Laden von gestern.

A: Okay. Dann checken wir erst die Speisekarte.

中文：A问B想不想吃披萨。B想吃，但不愿再去昨天那家店。A答应，提议先看看菜单。

Bock auf接吃什么，B的aber给选择加了条件；checken在这里是查看，而Ich check das nicht又表示没理解。对象和后续回应决定是哪一个意思。

一、打招呼和称呼

Alter

  • 发音：[al-ta]（近似"阿尔塔"）
  • 字面意思：老家伙（原为"年纪大的"）
  • 实际意思：哥们 / 伙计 / 嘿（打招呼或感叹，类似英语 "bro/dude"）
  • 使用场景：随意朋友间的称呼或感叹，不宜假定每个人每句都用
  • 例句：
  • "Alter, du glaubst das nicht!" — 哥们，你不会相信的！
  • "Was geht, Alter?" — 怎么样，兄弟？
  • "Alter Schwede!" — 我的天呐！（固定搭配，加强惊讶）

digga / Digga

  • 发音：[di-ga]（近似"迪加"）
  • 来源：源自"个大"（Dicker）"胖哥们"的汉堡方言发音
  • 实际意思：哥们 / 兄弟（类似 Alter，但更北德风格）
  • 使用场景：打招呼或强调
  • 例句：
  • "Digga, was soll der Quatsch?" — 哥们，搞什么鬼？
  • "Eh, digga, komm mal ran." — 哎，哥们，过来一下。

Brudi / Bruder

  • 发音：[bruu-di]（近似"布鲁迪"）
  • 来源：Bruder（兄弟）的口语变体
  • 实际意思：兄弟 / 哥们
  • 使用场景：朋友之间的称呼
  • 例句：
  • "Alles klar, Brudi?" — 一切好吗，兄弟？
  • "Danke, Brudi!" — 谢了，哥们！

二、态度和意愿

Bock haben (auf + Akk.) / null Bock

  • 发音：[bok ha-ben] / [nul bok]
  • 字面意思：有公羊（Bock原意为公山羊）
  • 实际意思：有兴趣 / 想做某事（Bock haben）/ 毫无兴趣（null Bock）
  • 使用场景：表达是否想做某事
  • 例句：
  • "Hast du Bock auf Pizza?" — 想吃披萨吗？
  • "Ich hab null Bock auf Arbeit." — 我一点都不想上班。
  • "Null Bock-Tag" — 啥都不想干的一天。

go / gehen：先听清实际搭配

  • 发音：[goo] / [gee-en]
  • 实际意思：开始或出发要看具体搭配；gehen本身不是“青年俚语”
  • 使用场景：决定做某事时
  • 例句：
  • "Let’s go!" — 走吧！；Lass uns go不作为通用德语句型
  • "Bereit? Los geht’s!" — 准备好了吗？开始吧！；不把Gehen!单独当作一般邀请
  • "Wir gehen heute ab!" — 今晚我们要嗨翻！

abgehen / geht ab

  • 发音：[ap-gee-en] / [geet ap]
  • 字面意思：（从某处）离开
  • 实际意思：嗨翻了 / 超级棒 / 气氛爆了
  • 使用场景：形容派对、活动气氛好，或某人表现很棒
  • 例句：
  • "Gestern auf der Party ging es richtig ab!" — 昨天的派对真的嗨翻了！
  • "Der Song geht ab!" — 这首歌太炸了！

三、评价和描述

based

  • 发音：[beist]（近似英语发音）
  • 来源：英语网络用语，近年来进入德语年轻人词汇
  • 实际意思：太厉害了 / 很有态度 / 令人钦佩（表示由衷的认可）
  • 使用场景：赞美人做了很酷或很勇敢的事
  • 例句：
  • "Er hat einfach die Wahrheit gesagt, based." — 他直接说了真话，太厉害了。

cringe

  • 发音：[krindsh]（近似英语发音）
  • 来源：英语
  • 实际意思：尴尬 / 让人替别人感到不好意思
  • 使用场景：看到令人尴尬的事情
  • 例句：
  • "Oh Mann, das ist so cringe." — 天呐，这太尴尬了。
  • "Cringe alert!" — 尴尬预警！

wild

  • 发音：[vilt]（近似"维尔特"）
  • 字面意思：野的
  • 实际意思：疯狂 / 不可思议 / 混乱的（年轻人用法比传统含义更广泛）
  • 使用场景：对意外或极端情况的反应
  • 例句：
  • "Das ist so wild." — 这也太离谱了。
  • "Pretty wild, oder?" — 相当疯狂，是吧？

W / L：Win与Loss

  • 发音提示：可以按德语字母名读W、L，也可能用英语字母名；Wetten不是这里的展开式
  • 来源：游戏和社交媒体文化（W = Win, L = Loss）
  • 实际意思：W = 赢了/太棒了；L = 输了/失败
  • 使用场景：评价结果或情况
  • 例句：
  • "Das ist ein riesiges W!" — 这是大赢特赢！
  • "Eh, das war ein L." — 唉，那是个败笔。

sigma

  • 发音：[zig-ma]
  • 来源：网络文化中的"sigma male"概念
  • 实际意思：独来独往但很厉害的人 / 很酷
  • 使用场景：形容或称赞某人很酷、独立、有型
  • 例句：
  • "Er ist so sigma." — 他太有型了。

Literally

  • 发音：[li-te-ral-li]（英语发音）
  • 来源：英语
  • 实际意思：简直 / 真的是（年轻人用英语词点缀德语对话）
  • 使用场景：强调某事
  • 例句：
  • "Ich literally kann das nicht." — 我真的受不了这个。

四、日常感叹

Moin

  • 发音：[mo-in]（近似"莫因"）
  • 来源：北德传统问候语（不是年轻人的发明，但年轻人尤其爱用）
  • 实际意思：你好，常不限早晚；本页先按问候理解，不当作通用告别
  • 使用场景：打招呼，特别在北德
  • 例句：
  • "Moin moin!" — 你好啊！（加强版）
  • "Moin, alles fit?" — 嗨，一切都好？
  • 💡 说明：虽然放在"年轻人俚语"这章，但 Moin 实际上是跨年龄段的北德问候语。如果你在汉堡、不来梅等地，完全可以使用。

Yallah

  • 发音：[ja-la]（近似"亚拉"）
  • 来源：阿拉伯语，通过移民社区进入德语
  • 实际意思：走吧 / 快点 / 来吧
  • 使用场景：催促或招呼别人一起走
  • 例句：
  • "Yallah, wir gehen!" — 走吧，我们出发！
  • "Yallah, yallah, keine Zeit!" — 快快快，没时间了！

Wallah

  • 发音：[va-la]（近似"瓦拉"）
  • 来源：阿拉伯语"I swear"（我发誓）
  • 实际意思：真的 / 我发誓 / 确实
  • 使用场景：强调自己说的是真的
  • 例句：
  • "Wallah, ich war da!" — 我发誓，我当时在场！
  • "Das ist wallah der beste Film." — 这真的是最好的电影。
  • ⚠️ 注意：Wallah有誓言背景，也可在具体群体里弱化为强调；不熟悉这种关系和语境时，理解其作用即可，不凭年龄判定自然与否。

Schatzi

  • 发音：[sha-tsi]（近似"沙茨"）
  • 字面意思：小宝贝（Schatz 的指小词）
  • 实际意思：宝贝 / 亲爱的（情侣间）或朋友间的玩笑称呼
  • 使用场景：亲密称呼或熟人玩笑，不限年轻女性；不要据此随便称呼陌生人
  • 例句：
  • "Schatzi, kannst du mir helfen?" — 宝贝，能帮我吗？

五、网络衍生词（年轻人日常使用）

no cap

  • 发音：[noo kæp]（英语发音）
  • 来源：英语网络用语
  • 实际意思：说真的 / 不骗人 / 没开玩笑
  • 使用场景：强调真诚
  • 例句：
  • "No cap, das war das Beste." — 真的，那是最好的。

RIP

  • 发音提示：文字常见RIP，口头可按字母或英语词样读；原ri-pi不能准确表示三个字母名
  • 来源：Rest in Peace 的引申用法
  • 实际意思：完了 / 没救了 / 搞砸了（不一定和死亡有关）
  • 使用场景：某事失败时
  • 例句：
  • "RIP, die Prüfung war ein Desaster." — 完了，考试彻底崩了。

toxic

  • 发音：[tok-sik]
  • 来源：英语
  • 实际意思：有害的 / 让人不舒服的（形容人或氛围）
  • 使用场景：形容不好的社交环境或人
  • 例句：
  • "Die Stimmung da ist so toxic." — 那里的氛围太毒了。

over / it's over

  • 发音：[oo-faa] / [its oo-faa]
  • 实际意思：完了 / 没戏了 / 彻底没指望了
  • 使用场景：悲观地评价某事
  • 例句：
  • "It's over, wir schaffen das nicht." — 完了，我们做不到了。

六、动词的年轻人用法

abchecken / checken

  • 发音：[ap-shé-ken] / [shé-ken]
  • 来源：英语 check
  • 实际意思：了解 / 看看 / 搞清楚
  • 使用场景：表示理解或要去查看
  • 例句：
  • "Ich check das nicht." — 我搞不懂这个。
  • "Lass mal abchecken." — 咱们去看看。
  • "Hast du den neuen Film gecheckt?" — 你看了那部新电影吗？

abgehen：不是“购物”的专门动词

  • 实际意思：此处表示放开活动、热闹或表现强烈；是否购物由场景补出，不能从abgehen直接推出
  • 例句：
  • "Wir gehen heute im Zentrum ab!" — 今天我们要在市中心好好嗨一番！若明确说购物，可说Wir gehen heute shoppen.（我们今天去购物。）

flame / flaming

  • 发音：[fleim] / [fleim-ing]
  • 来源：英语
  • 实际意思：激烈攻击或辱骂，常见于网络；借词动词可作flamen，完整中性说明可用beleidigen
  • 使用场景：形容网络或现实中激烈争吵
  • 例句：
  • "Er hat mich im Chat heftig beleidigt." — 他把我狠狠骂了一顿。

zocken

  • 发音：[tso-ken]
  • 字面意思：赌博（原意）
  • 实际意思：打游戏（本页游戏场景的意思）
  • 使用场景：游戏场景常指打电子游戏，也仍有赌博义；看具体对象
  • 例句：
  • "Was zockst du gerade?" — 你在打什么游戏？
  • "Lass uns zocken!" — 来打游戏吧！

七、总结

按交际用途回看本页词条

表达 意思 辨认重点
Alter 哥们 称呼还是感叹
digga 哥们（北德） 熟悉关系中的称呼
Bock haben 想做/有兴趣 auf后的对象

听懂之后，选择适合关系的回应

Bock haben、checken和Moin都不专属于年轻人，Moin还带地区问候传统。Alter、Digga、Brudi用于称呼时涉及熟悉程度；Schatzi通常要求亲密关系，不能仅凭词义“亲爱的”就拿来叫同事。

based、sigma与W/L常带圈内玩笑或立场色彩。no cap、Wallah是在强调自己说真的，不自动证明内容真实；toxic、cringe和flaming又在评价人、行为或气氛，要看具体事件。识别后可以说Verstehe（明白）、Was meinst du genau?（你具体指什么）或用普通句回应，不需要为了显年轻模仿整套风格。
