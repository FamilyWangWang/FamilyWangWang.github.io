德语酒吧：加入一轮，也保留各自的选择

Thomas、Sabine、Lukas和你下班去小酒馆。第一轮Thomas请，第二轮Lukas请，但他换喝可乐。读这一篇时，跟着每个人的选择走：Runde关心这次谁请，不要求大家喝一样，也不把某个朋友的习惯写成全德国的规矩。

阅读起点：有相应生活或工作任务时可以直接选读。先借中文含义跟住谁在问、谁在回应；生词和搭配在对应情境里理解。 实际交谈中听到词却不明白时，先学怎样请对方换说法（按需补读）。 连同讲解通读约19—33分钟，仅为篇幅估算；选读局部可更短。

场景背景：一轮请客，是可商量的安排

Kneipe 是小酒馆，Bar 泛指酒吧，Theke 是吧台，Biergarten 是啤酒花园；服务方式和价位依门店，不由名称一概判断。Kneipentour / Kneipen-Hopping 指一晚去多家酒吧的活动，不是必须参与的生活方式。

四位同事下班步行到店，Thomas请第一轮，Lukas请第二轮并自己换可乐。下面练习如何加入、点各自的饮品、聊口味并结束聚会；Runde 不要求人人喝酒或跟随相同数量。

从自己喝到的味道，聊到标签与环境

Aufs Wochenende / Auf dich / Auf uns 为周末／你／我们祝愿，auf 后接宾格，aufs 是 auf das，标准拼写无需在 aufs 中加撇号。ein Weißbier-Mensch 用偏好描写自己，类似 Kaffee-Mensch；不能据此判断所有人的国籍性格。

Daran kann man nichts ändern 是对此改不了，man 补齐动作主语，nix 是 nichts 的口语形式，dran 是 daran。Da kann nix dran ändern 缺少主语，不能只说吞音就照教。白酒是 chinesische Spirituose，52%仅某一瓶标签，不是所有酒的统一度数，更不能推算可喝几杯。

Puh / aufpassen / ziemlich stark 可说哇／注意／挺烈，感叹不等于医学判断。gemütlich / Ecklokal 是舒服／街角小馆。Zimmerlautstärke 是室内或不打扰邻人的音量概念，不等于 Ruhestörung（扰民行为），本篇不用它制造酒后必大声的国籍玩笑。
