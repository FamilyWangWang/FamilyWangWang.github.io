德语跳蚤市场：一把椅子、两本书和一段自然闲聊

先为椅子谈价，再挑读物，最后由一本地图集聊到收藏爱好。购物与闲聊自然交织，但读者始终能知道：现在谈哪件东西、选中了什么、哪些只是随口推荐。下面是虚构市场的一次周日购物，不预设每个摊位都应讲价。

阅读起点：有相应生活或工作任务时可以直接选读。先借中文含义跟住谁在问、谁在回应；生词和搭配在对应情境里理解。 实际交谈中听到词却不明白时，先学怎样请对方换说法（按需补读）。 连同讲解通读约14—25分钟，仅为篇幅估算；选读局部可更短。

场景背景：逛旧物与聊天，可以不以买完为目的

Flohmarkt、Antikmarkt、Garagenflohmarkt 是跳蚤市场、古董市场、家庭车库旧物出售；gebraucht、Bargeld、stöbern 是二手、现金、随意翻看。不同市场的开放日、付款与谈价条件按现场确认，不预设每一笔都要从半价开始。

单把还是一对，先把问价对象固定

der Stuhl / den einzelnen / das Paar / den dunkelbraunen 分别指椅子、单把、一对、深棕色那把。meinen 是指的是；den 接回阳性Stuhl的第四格，不能把单复数或冠词错误解释为随意口语规则。Eichenstuhl / aus den 60ern 是橡木椅、约20世纪60年代的，仍是卖方说法。

Kratzer / Geht da noch was? / hat Charakter / halt gebraucht 说划痕、价钱还有空间吗、有韵味、它就是二手的嘛。ja 在此提醒可见划痕，halt 接受旧物有痕迹。愿意谈价由 über den Preis können wir reden 表达；gesprächig 主要是健谈，可核Duden，不等于愿降价。

Was haben Sie im Sinn / knapp / einen Deal / eine runde Sache 是想出多少、有点低、成交提议、事情办得妥当。25为要价，15、20、18为来回提议，最后 Abgemacht 接受19；给20找1，runde Sache 不说19是整十。

Verarbeitung / Neuware / finde ich 是做工、新品、我认为。卖方称做工扎实是评价，不证明旧家具总比新货好。Stimmt so. 在给款且有零头的场合可说不用找，此处没说，所以仍找1欧，不制造固定小费惯例。

Wo waren die noch gleich? 回想东西放哪来着，noch gleich 在问句中有“来着”的作用。Vokabelhilfen / Band 2 / Niveau 是词汇提示、第二册、级别；第一本A2、第二本B1，不能由同系列推成同难度。

看见平台或品类名称，也仍要问具体物品

Kleinanzeigen、Vinted 是可以遇到的二手平台名称，Gebrauchtwarenladen 是二手店；网上联系、当面交易、邮寄、捐赠给慈善机构是不同过程。机构是否接收、卖方是否发货、怎样付款另核，不保证任何平台一定最便宜。

Werkzeug、Küchenutensilien、Schallplatten、Landkarten 分别是工具、厨具、唱片、地图，可以从材料、缺件、使用史或收藏经历问起。Was ist Ihr bester Preis? / Ich würde … Euro geben. 询问可接受价格、提出自己的出价；和直接说 Das ist Schrott!（这是破烂！）或命令式要求不同。是否继续谈由双方决定，不把两三欧不可讲价、固定收摊必最低当规则。
