阅读起点：有相应生活或工作任务时可以直接选读。先借中文含义跟住谁在问、谁在回应；生词和搭配在对应情境里理解。 实际交谈中听到词却不明白时，先学怎样请对方换说法（按需补读）。 连同讲解通读约23—41分钟，仅为篇幅估算；选读局部可更短。

没看见偷拿，就把怀疑说成怀疑

Ist weg / verloren gegangen 都可说不见或遗失，ich vermute einen Diebstahl 表怀疑被盗。Wurde gestohlen 是过去时被动，不是完成时；ist gestohlen worden 才是相应完成时被动。Muss jemand genommen haben 强烈推测有人拿走，仍不等于目击证据。

有人在柜台靠近是观察，不足以按年龄衣着给对方贴Taschendieb扒手标签。Portemonnaie是中性名词，所以用es或das指代；若前面说的是阳性的Geldbeutel，宾格代词才用den。

Bankkarten sperren lassen 用lassen加动词说请机构停用，gleich / offizielle Hotline 是马上与官方热线。旧称EC-Karte仍可能听到，具体girocard、借记或信用产品分别核，不因为报过警就假定各卡自动停用。

系统有登记，与物品已经找回不同

Abgegeben / erfasst / kein passender Eintrag 分别是物品被交来、资料已录入、无相符记录。日期、地点、颜色材质和联系方式使匹配有依据。Sagen wir mal so / eher schlecht 可以委婉引出不乐观评价，却不能装成有个案找回概率的数据。

Das Zeug / auftauchen / wegwerfen 是口语泛指东西、出现、丢弃；钱和证件可能分离，不据此保证哪一项一定回来。Wenn die gefunden werden … 的die承接前面的物品，不随意认作某个具体嫌疑人。

Aufbewahrungsfrist是保管期，Kostenersatz是相关费用。Die Meldung selbst … 用selbst限定登记本身，不能推出领取和邮寄都免费；期限后的处理依物品与适用规则，也不是半年后一律扔掉。去现场前核地址与预约。
