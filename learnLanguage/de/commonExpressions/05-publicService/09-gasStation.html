第9章：加油站——油款、用品和服务分开确认

加完油只说“我要付款”还不够，柜台首先要知道是哪一台。这里跟林先生从报泵号开始，顺便问机油、胎压和玻璃水，最后换到一次高速站停靠。品牌、价格与赠饮是本例安排，不能当成所有德国加油站的做法；油品和车辆用品要按车辆要求选择。

泵号、金额和凭证，各用一个明确词

An Säule drei 说在3号机，完整名称Zapfsäule。Ich habe … getankt 是已经加过油，柜台据此调记录。Super fünfundneunzig是95号汽油，95按标准数词读fünfundneunzig，不能照中文字序拼neunzigfünf。

Das macht vierundsechzig Komma fünfzig Euro. 用das macht报总额，Komma标小数；不是每升价格。Einstecken / kontaktlos zahlen / Lesegerät 分别是插卡、感应支付与读卡器，contactless是还可能看见的英语词，是否支持看终端。

Das sollte passen. 在刷卡动作后预计这样可以，仍看成功提示。Quittung和Beleg都可用于问凭证，Kfz-Kosten 中Kfz是Kraftfahrzeug，指车辆费用；取得记账凭证不自动决定是否可税务扣除。Sonst noch was? — Eigentlich ja. 一问一答把话题转到还有别的需求。

请求帮助时，把产品和规格分开问

Ich bräuchte … / Was für einen Motor? 分别是礼貌说需要、询问哪一种发动机；Benziner指汽油车，Diesel可依语境指柴油或柴油车。1.4 Liter说排量，Herstellerfreigabe才指厂商认可规格。5W-30可读fünf W dreißig，是黏度标号，也不能单凭它确认全部兼容性。

Reifendruckgerät / Reifendruckfüller 指胎压检查或充气设备，selbst machen / prüfen lassen 对比自己做与请人检查。Aufkleber是标签，Tankklappe是油箱外盖，B-Säule是车门之间的B柱；胎压要求在哪一标签、适用怎样负载与冷胎条件，看本人车辆。

Fertigmischung / Konzentrat 是预混液与浓缩液。Reinkippen 是hineinkippen的随意说法，表示倒进去，不能因为动作简单就省掉标签的稀释与温度要求。本次仅买3.90欧预混液，机油待核，因此64.50欧油款不再次收取。
