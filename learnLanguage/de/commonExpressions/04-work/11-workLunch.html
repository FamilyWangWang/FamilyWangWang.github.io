第十一章：工作午餐 (Mittagessen / Mittagspause)

场景背景

在德国职场，Mittagspause（午休）通常是12:00到13:00之间，大约30到60分钟。和同事一起去吃午饭（gemeinsames Mittagessen）是融入团队的重要社交活动。德国人午饭的选择很多：公司食堂（Kantine）、附近餐厅、快餐店（Dönerladen、Bäckerei）、或者自己带饭。结账时AA制（getrennt zahlen）是默认做法——不争着买单，也不觉得不好意思。本章涵盖从选择餐厅到结账的全过程。

文化提示： 德国工作午餐文化与中国有本质不同：(1) AA制（getrennt zahlen/getrennt bitte）是绝对默认——没有人会请客，也没有人觉得需要请客；(2) 午餐时间不太聊工作，更多聊私人话题（周末计划、度假、爱好等）；(3) 午餐通常是热餐，但也有不少人只吃一个面包（belegtes Brötchen）或沙拉；(4) 德国人在餐厅不会大声说话，也不会催服务员——节奏相对悠闲但不会太久；(5) 用餐结束后说"Danke, es war sehr lecker"是礼貌的表现。

逐句详解

第1句

  • Thomas: So, Hunger! Wer hat Lust auf Mittagessen?
  • ✅ So, Hunger! = 省略了ich habe，直接说"Hunger!"表示饿了
  • ✅ Wer hat Lust auf ... = "谁想..." → 提议做某事的标准口语表达
  • 午饭邀请在德国职场是最常见的社交方式

第2句

  • Sarah: Ich könnt grad nen Bissen vertragen.
  • ✅ nen Bissen vertragen = 口语表达"很饿，能吃下一顿" → vertragen原意是"能承受"
  • 👂 Ich könnt grad nen Bissen vertragen = 比较口语的说法，意思是"饿得要命"
  • 也可以简单地说 Ich hab richtigen Hunger

第3句

  • Du: Ich bin auch dabei. Hab richtig Hunger gekriegt.
  • ✅ dabei sein = "算我一个" → 表示参与
  • ✅ Hunger gekriegt = Hunger bekommen → kriegen代替bekommen，非常口语
  • richtig 作副词 = "真的"

第5句

  • Sarah: Kantine hab ich heute nicht so.
  • ✅ ... hab ich nicht so = "我今天不太想..." → 表达偏好的委婉方式
  • 省略了" Lust auf die"，直接说"Kantine hab ich nicht so"
  • dieselbe ... wie immer = "和以前一样的" → 吐槽食堂菜品重复

第6句

  • Thomas: Wie wär's mit dem Inder hier um die Ecke?
  • ✅ Wie wär's mit ... = "......怎么样？" → 提建议的超高频口语
  • ✅ dem Inder = dem indischen Restaurant → 口语中直接用国籍代指该国餐厅
  • ✅ um die Ecke = "拐角/附近" → 口语常用

第7句

  • Du: Sind die Portionen groß? Ich hab nämlich ziemlich großen Hunger.
  • ✅ nämlich = 语气词，"因为/其实" → 解释原因
  • 询问分量大小在德国餐厅完全正常

第8句

  • Sarah: Da wirst du satt.
  • ✅ satt werden = "吃饱" → 口语表达
  • ✅ echt empfehlenswert = "真的值得推荐" → 肯定评价

第9句

  • Thomas: Perfekt, dann marsch!
  • ✅ dann marsch! = "出发/走吧" → marsch原意是"行军"，口语中相当于"los!"
  • ✅ in einer Stunde wieder zurück sein = "一小时内回来" → 工作午餐的时间限制

第11句

  • Thomas: Nein, wir sind zu dritt. Haben Sie noch was frei?
  • ✅ zu dritt = "三个人" → zu + 数字表达人数（zu zweit, zu dritt, zu viert...）
  • ✅ noch was frei = noch etwas frei → 还有空位吗

第13句

  • Sarah: Wei, isst du scharf?
  • ✅ scharf essen = "吃辣" → 口语中直接用形容词作动词补语
  • ✅ nämlich = 这里用来补充信息，"因为这家挺正宗的"
  • 注意：德国人通常不太能吃辣，问你是否吃辣是关心你的表现

第15句

  • Sarah: Das Chicken Tikka Masala is der Hammer.
  • ✅ der Hammer = 口语表达"太棒了/绝了" → 年轻人常用，但已被广泛接受
  • 也可以说 top 或 mega lecker

第17-19句（点餐）

  • Thomas: Ich nehm das Butter Chicken mit Naan-Brot, bitte.
  • ✅ Ich nehm ... = Ich nehme ... → 点餐最常用的句型
  • ✅ mit ... statt ... = "配...而不是..." → 替换配菜
  • ✅ Ich probier mal ... = "我试试..." → 尝试新菜品
  • medium scharf = 中等辣 → 也可以说 mittelscharf

第21-23句（点饮料）

  • ✅ Sprudel = 气泡水 → 德国午餐常见饮品
  • ✅ Mango Lassi = 印度酸奶饮品 → 印度餐厅标配
  • ✅ dann mach ich das auch = "那我也一样" → 跟着别人点

第24句

  • Thomas: So, können wir zahlen bitte?
  • ✅ zahlen bitte = "买单" → 德国餐厅中招呼服务员结账的说法
  • 也可以举手说 Zahlen, bitte 或 Die Rechnung, bitte

第25-26句

  • Kellner: Zusammen oder getrennt?
  • Thomas: Getrennt, bitte.
  • ✅ getrennt zahlen = AA制/分开付 → 德国职场午餐的绝对默认
  • ✅ 如果想一起付（极少见），说"Zusammen, bitte"
  • 文化要点： 德国同事一起吃饭，默认各付各的，不存在"这次你请下次我请"的说法

第28句

  • Thomas: Stimmt so.
  • ✅ Stimmt so = "不用找了" → 给小费时的标准说法
  • 意思是"你保留找零作为小费"
  • 德国小费通常是5-10%，不是必须的但很常见
  • 也可以说 das passt so

第30句

  • Sarah: Passt so, das restliche is Trinkgeld.
  • ✅ das restliche = "剩下的" → 口语
  • ✅ Trinkgeld = 小费 → 字面意思是"喝钱"
  • 另一种给小费的方式：付整不付零，比如13.80就付14欧

第34句

  • Sarah: Danke fürs Mittagessen — ich mein, danke für die Gesellschaft.
  • ✅ Danke fürs ... = Danke für das ... → 口语缩合
  • ✅ ich mein = ich meine → 口语自我纠正
  • 她意识到说"谢谢这顿饭"不太对（因为各付各的），所以纠正为"谢谢你们的陪伴"
  • ✅ Gesellschaft = 陪伴 → "谢谢你们的陪伴"是德国人午餐结束时的客气话

注意事项

1. 德国午餐AA制——不争不抢

  • 绝对默认是getrennt zahlen（各付各的）
  • 不要试图请德国同事吃饭——他们可能会觉得不舒服
  • 如果有人说"Das geht auf mich"（我请客），通常是特殊场合（生日、升职等）
  • 服务员会自动问"Zusammen oder getrennt?"
  • 如果你请客才说"Zusammen, bitte"或"Ich lad euch ein"

2. 德国餐厅小费（Trinkgeld）规则

  • 午餐：凑整即可，比如12.50付13欧
  • 晚餐：5-10%是常见的
  • 不给小费也可以，但给一点更礼貌
  • 给小费时说"Stimmt so"或"Passt so"
  • 重要： 小费是留在桌上或直接告诉服务员金额，不需要特别计算

3. 德国人的午餐选择

类型 德语名称 价格区间 说明
公司食堂 Kantine 3-6欧 最便宜，但选择有限
面包店 Bäckerei 3-5欧 三明治/面包+咖啡
土耳其烤肉 Dönerladen 5-8欧 最常见的快餐
餐厅 Restaurant 10-18欧 偶尔去，同事聚餐
自己带饭 eigenes Essen — 有些人会自己带，用微波炉加热

4. 点餐用语速查

  • Ich nehme ... = 我要...（最常用）
  • Ich hätte gerne ... = 我想要...（更礼貌）
  • Für mich ... = 给我来...
  • Ich probiere mal ... = 我试试...
  • Was empfehlen Sie? = 您推荐什么？
  • Gibt es das auch vegetarisch? = 有素食版本吗？
  • Ohne Zwiebeln, bitte = 不要洋葱

5. 和同事吃午饭的社交技巧

  • ✅ 午餐是了解同事的好机会——聊度假、爱好、周末计划
  • ✅ 不需要每天都和同事一起吃——一周一两次就足够
  • ✅ 可以主动邀请同事："Ich geh was essen — hast du Lust mitzukommen?"
  • ❌ 不要在午餐时聊太多工作——午餐是放松时间
  • ❌ 不要在午餐时抱怨其他同事——这会让人觉得你不可靠

6. 50岁左右男性使用建议

推荐使用：

  • "Ich bin dabei" 是最自然不过的表达，任何年龄适用
  • "Wie wär's mit dem Inder?"是提议餐厅的标准说法
  • "Stimmt so"给小费时的说法，非常得体
  • "Ich nehm das..."点餐简洁有力

需要注意：

  • "der Hammer"偏年轻人用语（但40+也在用），如果想更稳重，可以说"sehr empfehlenswert"或"richtig gut"
  • "nen Bissen vertragen"可以了解，但日常使用"richtig Hunger haben"更自然
  • "dann marsch!"比较活泼，50岁男性完全可以用，也可以用更中性的"dann los"
